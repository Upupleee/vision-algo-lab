# 深度学习路线（dl/）

端到端神经网络研究路线，各文件完成度不同：自动对焦包含网络和训练循环，边缘方向包含网络和损失函数，学习式匹配仅有未实现接口；不是完整训练／推理系统。在仓库根目录执行 `pip install -r requirements-dl.txt` 安装依赖。

| 文件 | 方向 | 参考 |
|------|------|------|
| `autofocus_cnn.py` | 自动对焦 | CNN 从单帧回归离焦量（Pertuz et al. 2019 思路） |
| `learned_matching.py` | 模板匹配（未实现接口） | 学习式稀疏特征路线：SuperPoint + SuperGlue/LightGlue；另一条路线：LoFTR 无检测器匹配 |
| `subpixel_edge_net.py` | 亚像素边缘 | U-Net 风格网络输出 3 通道：边缘 heat logit 与 dx/dy 偏移；损失意图为 BCE + 边缘处 L1 |

`learned_matching.match` 当前抛出 `NotImplementedError`；安装依赖或下载权重不会自动完成推理接入。旋转、尺度、遮挡鲁棒性和亚像素精度均须通过接入后的数据评测确认，不是当前已验证能力。上述路线还需要几何验证；单应矩阵适用条件、内点空间分布及重投影误差不能由匹配分数替代。

传统实现的坐标和评测边界见 [核心理论与现场排障](../docs/pose_ncc.md)。DL 草案将位置描述为变换后四角的均值，不能直接与传统原点坐标比较；一般透视变换下，四角映射均值也不等于模板中心的映射。源码草案的元组返回描述与 `dict` 类型标注尚未统一，当前没有可用返回协议。

训练脚本固定 seed 和保存 checkpoint 是研究要求，并非当前骨架已实现的能力。现有代码没有统一设置随机种子或保存权重，边缘网络也没有训练循环；精度与重复采集的重复性均尚未验证。后续实验须记录数据划分、随机状态、权重、依赖／硬件环境，并分别报告相对真值误差与重复测量离散程度，不能以单次前向输出小数或固定 seed 代替精度证明。

## 研究约定

- 数据集构建必须复用 `data/synthetic.py`（含真值）或记录真实采集参数。
- 与传统基线对比实验放在 `docs/experiments.md`，指标用 `tests/metrics.py`。
- 训练脚本固定 seed，记录 checkpoint 到 `runs/`（已 gitignore）。
