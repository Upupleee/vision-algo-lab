## 1. 范围与领域演进核心主线

缺陷检测持续优化的不是“网络有多深”，而是：**在允许的正常变化中，保留对不允许偏差的敏感性，并把偏差变为可定位、可拒识、可验收的证据。** 正常纹理起伏、产品位姿、曝光和批次变化不应一概报缺陷；细划痕、缺料、污染又不能被配准、平滑或正常模型吸收。本文沿正常定义、表示、监督、空间评分、小缺陷与决策成本展开，不把匹配领域的相似度／搜索维度直接套来。

**方法演进线**是“可比参考与纹理统计 → 正常支持域／重建／预训练特征的并行建模 → 面向局部偏差的评分与判别”。**工程实践线**是“规格与可见性 → 成像／配准 → 分组数据 → 模型及热图 → 阈值与区域证据 → 分缺陷验收／漂移监控”。箭头表示问题依赖，不表示发表年代上的全面替代。纹理特征本身没有规定监督方式；同一特征可以用于多类分类，也可以只拟合正常分布。[cite:1](#source-1)[cite:2](#source-2)[cite:3](#source-3)

本章核验日期 **2026-11-04**。选择七个方法节点及一个基准节点，不宣称完整算法史、唯一首创或核验日最新排名。D01–D04 均为已有教学方案，仍无专用实现；本章不新增算法、权重、数据集或实测结果，不升级原卡 L1–L5 状态。所有工程建议是机制推论，尚须现场验证。

| 核心维度 | 演进要解决的问题 | 必须保留的边界 |
|---|---|---|
| 正常与异常定义 | 从单一良品模板走向允许多种正常外观 | 统计稀有不必然违反规格；常见缺陷也可能进入正常模型 |
| 特征表示 | 从灰度、局部共现／二值纹理到多层深度嵌入 | 对光照或位姿的容忍可能同时掩盖细小缺陷 |
| 监督与样本组织 | 从已知缺陷标签到正常样本建模、合成异常监督 | 无真实缺陷标签不等于无数据、无预训练或无监督信号 |
| 评分与定位 | 从整图判别到窗口、patch、像素热图 | 热图插值到原图不等于原生像素精度，异常分数不是缺陷概率 |
| 小缺陷与上下文 | 局部细节和整件布局同时保留 | 局部正常的零件仍可能放错位置；需装配关系分支 |
| 阈值与跨域泛化 | 从离线排序到指定漏检／误报代价下的操作点 | AUROC 不决定上线阈值，公开数据不能认证产线 |

## 2. 任务并行分支与组合关系

| 分支与输入 | 输出及正常依据 | 数据／监督前提 | 适用交接与排除项 |
|---|---|---|---|
| 配准差分：参考良品＋待检图 | 残差、连通候选；参考定义正常 | 可信良品、有效支持与光度可比，无须缺陷类别标签 | [D01](algorithm_cards/remaining_domains.md#d01-配准后绝对差分)；不是语义缺陷分类 |
| 时间背景：固定机位图像序列 | 前景及统计状态；历史背景定义常态 | 确认正常初始化、可信区域更新 | [D02](algorithm_cards/remaining_domains.md#d02-单高斯指数背景模型)；前景不是质量 NG，单高斯不是 MOG2 |
| 纹理统计：材料窗口 | 共现／LBP 分布距离或分类 | 纹理尺度与采集条件稳定；可配有标签分类或正常参考 | [D03](algorithm_cards/remaining_domains.md#d03-lbp-纹理直方图基线)；直方图不保全部空间布局 |
| 正常特征建模：正常训练集 | 支持域外分数、位置异常图 | 目标训练仅正常，需覆盖合法变化 | D04／One-Class SVM／PaDiM／PatchCore；四者不是同一实现 |
| 重建与合成异常判别 | 重建残差或学习式异常分割 | AE 只学正常重建；DRAEM 另用人工合成异常与掩膜 | 不要求真实缺陷训练标签，但不是无训练过程 |
| 已知缺陷分类／检测／分割 | 缺陷类别、框或掩膜 | 分别需要图像级、框级或像素级标签；弱监督另列协议 | [分割总览](segmentation_regions.md)；只有整图标签不能默认拥有精确边界 |
| 结构／逻辑异常 | 数量、位置、朝向或关系违例 | 产品规格、对象身份、坐标与可见性 | [A01](algorithm_cards/remaining_domains.md#a01-数量与相对几何装配规则)；表面热图不能取代关系检验 |

组合示例为“产品定位 → D01 差分＋局部正常特征评分 → 候选合并 → 尺寸与区域规则”。这是方案而非仓库系统；合并规则、共同误报源和未检区域都要单独验收。对重复纹理，可优先研究局部统计而不强行逐像素模板对齐；对位置关键的接口，不应只用可跨位置检索的正常 patch 库。

## 3. 方法演进线：有据代表节点

### 3.1 E01：共现统计给传统纹理一个可计算表示

**先前瓶颈 → 改变维度 → 机制：**平均灰度不能描述织纹排列。Haralick、Shanmugam、Dinstein 用指定距离与方向的灰度对共现矩阵，提取对比度、均匀性等统计特征，把“纹理像不像”转为特征比较。原文研究的是图像分类，包括有标签训练／测试；它不是一篇仅正常样本的工业异常检测论文。[cite:1](#source-1)

**新增代价与遗留问题：**要选择灰度量化、距离、方向和窗口；灰度级数为 G 时单个稠密共现矩阵占 O(G²) 存储，多方向另计。窗口大可稳定统计却稀释小缺陷；相同统计不能唯一还原纹理。用于织物／磨削纹理的正常偏离是工程迁移，需要正常参考和阈值，不能直接继承原文分类性能。仓库 GLCM 仅族级边界，未有独立卡或实现。

### 3.2 E02：LBP 将局部纹理表示与分类规则拆开

**先前瓶颈 → 改变维度 → 机制：**绝对强度易受整体光变影响，单个统计均值又丢失分布。1996 原文在 3×3 邻域内以中心值二值化邻居，形成 256 种模式，比较特征分布及互补特征。原文使用有类别标签的纹理原型，并讨论 Kullback 判别；原卡 D03 的卡方型距离是明确选定的教学变体，不是该论文逐项复现。[cite:2](#source-2)

**新增代价与遗留问题：**基本 LBP 对理想严格单调灰度映射保序，但量化、噪声和饱和会翻转位；旋转改变编码。直方图省去精确像素对齐，也丢掉空间位置；小窗口统计稀疏，大窗口漏小斑。D03 只覆盖基本 8 邻域，不把后续旋转不变、uniform 或多尺度版本倒写到 1996。工程上先核位序／尺度，再比较正常直方图漂移。

### 3.3 E03：从两类分界改为正常支持域

**先前瓶颈 → 改变维度 → 机制：**缺陷稀缺、类型未知时，不能为每一种异常收集训练标签。One-Class SVM 在核特征空间中将样本与原点以间隔分开，得到包含大部分训练数据的接受区域。2001 期刊原文面向无标签分布样本；工业用法额外要求这些样本可作为正常总体，不能把混入缺陷的数据自动解释为干净良品。[cite:3](#source-3)

**新增代价与遗留问题：**特征缩放、核宽度和 ν 共同决定边界；核矩阵与支持向量增加训练／推理开销。ν 不是现场缺陷发生率，也不是未来漏检率承诺。整图特征只能给整图分数，定位需窗口特征或另设机制。它与 D04 的收缩单高斯并行：前者核支持域可表达非线性边界，后者以协方差白化表示正常变化；不能把现有两类 SVC 重排器改称单类异常检测器。

### 3.4 E04：重建路线改的是“怎样比较”，不是保证异常重建失败

**先前瓶颈 → 改变维度 → 机制：**逐像素重建误差会把轻微边缘错位放大，却可能忽略强度接近但结构已改变的缺陷。Bergmann 等用局部 SSIM 比较亮度、对比度和结构，并用于自编码器训练及残差评价；训练只使用无缺陷样本。这里采用 2018 预印本及已读取的 2019 v3，不把首次失败的 CVPR Workshops 地址当成会议归属。[cite:4](#source-4)

**新增代价与遗留问题：**增加编码器／解码器训练、结构窗口和模型容量选择；SSIM 的局部容忍也可能降低对某些细节变化的敏感性。正常图可能重建差，异常也可能被重建得很好，因此“重建好即正常”没有通用保证。适合研究无精确参考但能收集正常纹理的场景；先同时看输入、重建和残差，不能只看热图。原卡只有族级重建边界，无此网络实现。[cite:4](#source-4)[cite:6](#source-6)[cite:7](#source-7)

### 3.5 E05：评测从未知大类转向同一物件的细微局部偏差

**先前瓶颈 → 改变维度 → 机制：**把分类数据集某些类别当异常，不足以验证细划痕或局部污染。MVTec AD 在正常训练图之外提供正常／异常测试图及异常像素标注，使图像级判断和局部定位能够分开评测；2019 原文还对传统统计、重建和预训练特征方法作对照。[cite:5](#source-5)

**新增代价与遗留问题：**需要真实缺陷采集与标注，数据集的对象、照明和缺陷覆盖仍有限。像素掩膜用于评测不意味着目标训练使用它；若用测试缺陷选阈值或超参数，就改变了协议。这是**数据与评价节点，不是新检测算法**；本文不下载数据、不复现表中结果，也不把 MVTec AD 与其他同品牌基准混为同一版本。

### 3.6 E06：PaDiM 用逐位置统计替代目标域网络优化

**先前瓶颈 → 改变维度 → 机制：**从零训练重建网络有优化成本，保留全部正常特征作近邻又有扩展成本。PaDiM 固定预训练 CNN，将不同层的空间对应特征拼接并抽取部分维度，在每个 patch 位置拟合正常均值／协方差，再以 Mahalanobis 距离评分。目标数据只需正常图，但特征已从外部预训练获得；“不用训练目标域 CNN”不等于“没有拟合”。[cite:6](#source-6)

**新增代价与遗留问题：**若网格有 P 个位置、保留维数 d，逐位置稠密协方差存储为 O(Pd²)，求解与特征提取另计。位置一致性、单高斯近似、小样本协方差与缩图都影响结果；原文测试了未对齐扰动，不可反推任意姿态不变。D04 是固定手工特征＋收缩协方差，而原文使用多层深度嵌入和加 εI 的协方差，不能互换名称或验证状态。

### 3.7 E07：DRAEM 用可生成的监督弥补单纯重建目标

**先前瓶颈 → 改变维度 → 机制：**只优化重建并不直接学习正常／异常边界。DRAEM 在正常图上模拟异常及掩膜，重建网络学习恢复原正常图，判别网络联合观察输入和重建并学习异常定位；原文描述 Perlin 噪声形状、外部异常纹理源、重建与 focal 分割损失。[cite:7](#source-7)

**新增代价与遗留问题：**训练两条子网络，并引入合成分布、混合强度和损失平衡。目标任务不需要真实缺陷标注，但明确有合成像素监督，不能简单称为“完全无监督”。模拟划痕有效不保证覆盖真实缺料、微裂纹或逻辑错装；需真实保留集检验。论文中的合成训练是被研究的方法机制，本文未生成任何合成实验数据，也没有将其当作真实验收证据。

### 3.8 E08：PatchCore 用正常局部覆盖换取非参数表达能力

**先前瓶颈 → 改变维度 → 机制：**逐位置单高斯约束可能过强，全部深度特征检索又占资源。PatchCore 使用 ImageNet 预训练网络的中层局部聚合特征，建立正常记忆库，选取有代表性的 coreset 子集，推理时对 patch 查正常近邻并形成异常图／整图分数。目标样本仅正常；ImageNet 预训练不能从监督账目中消失。[cite:8](#source-8)

**新增代价与遗留问题：**若记忆库 M 个向量、每向量 d 维、待检 P 个 patch，朴素精确查询约 O(PMd)，存储 O(Md)，特征提取和 coreset 建库另计；近似索引不是无损保证。共享记忆库降低逐位置依赖，但合法局部出现在错误位置可能仍得低分，因此不保证逻辑异常检出。应记录压缩率、检索方式、输入分辨率与尾延迟，不引用论文“total recall”题名承诺零漏检。

## 4. 工程实践线：选型、评分与验收

### 4.1 从约束选基线

| 场景与约束 | 优先评估 | 新增成本／回退 | 首要验收证据 |
|---|---|---|---|
| 固定工位、良品可精确对齐、CPU 预算紧 | D01 差分＋有效域＋区域规则 | 配准与参考维护；不可比时 UNKNOWN | 正常错位残差、最小缺陷尺寸、未检区域 |
| 稳定重复材料、局部纹理变化明显 | LBP／GLCM＋正常分布；必要时 One-Class SVM | 量化／窗口／方向与样本覆盖 | 跨方向、批次、纹理尺度的误报与漏检 |
| 正常特征近似单峰且样本较少 | D04 收缩统计；深度特征再评估 PaDiM | 协方差稳定性、位置依赖、骨干域差 | 条件数／正则敏感性、配准扰动、缩图前后漏检 |
| 正常外观多模态且允许特征库 | PatchCore 与统计基线对照 | 内存、建库、检索与压缩损失 | 罕见正常模式覆盖、困难帧耗时、错位置反例 |
| 无精确模板，希望学习正常重建 | SSIM-AE；可设计异常模拟时再评估 DRAEM | 训练成本、合成到真实差距 | 正常／异常的重建对照、真实缺陷留出集 |
| 缺陷类型明确且标注充足 | 监督分类／检测／分割与异常支线组合 | 缺陷标签、持续维护与未知类拒识 | 已知缺陷分类别召回和未知缺陷独立测试 |
| 零件本身正常但漏装、反装或互换 | A01 数量／相对几何＋必要的关系模型 | 对象身份、坐标与可见性 | 按漏／多／错／反装统计整件漏放 |

上述不是性能排名。静态良品库不应与时间背景在线更新混为一谈；后者会吸收长期静止前景，前者也会因错误接纳不良品而污染。更新应有人工确认或可信业务标签、版本与回滚，不能把模型低分自己当成“确认正常”。

### 4.2 评分与决策契约

对 D01，固定有效支持下的光度校正残差可写为 \(r(p)=|I(Wp)-aT(p)-b|\)。小错位 δ 的灰度影响一阶约为 \(\nabla I^T\delta\)，故强边缘双线先排查配准而非放宽缺陷阈值。这是已有 [D01 推导](algorithm_cards/remaining_domains.md#d01-配准后绝对差分) 的工程解释；不是所有残差都有唯一缺陷原因。

对固定高斯特征模型，\(D^2=(f-\mu)^T\Sigma^{-1}(f-\mu)\) 是偏离分数，不自动等于缺陷概率。热图取最大值对局部异常敏感，但测试位置数、噪声尖峰与图像尺寸变化都会改变整图分布；位置分数与整图阈值要分别校准。形态学、平滑、面积门会改变检出对象，必须留存处理前后热图，不能以“看起来干净”作为改进证据。[cite:6](#source-6)[cite:8](#source-8)

决策输出至少区分 **OK（当前可检规格均通过）／NG（有明确超限证据）／UNKNOWN（无可靠观测或模型越界）**。记录缺陷候选位置、面积／长度及单位、原始分数、阈值版本、有效检测范围和原因。无法从纯正常验证集测出真实缺陷召回率；纯正常分位数仅帮助约束该正常分布内误报，不能提供跨域检测保证。

### 4.3 按症状排障

| 症状 | 优先检查的证据 | 调整顺序 | 禁止混淆 |
|---|---|---|---|
| 边缘成双线、全局高分 | 配准残差、变换支持、饱和与曝光 | 成像 → 几何 → 光度 → 阈值 | 不先放宽阈值掩盖错位 |
| 细划痕缩图后消失 | 原图缺陷宽度、网络步幅、插值与平滑 | 保分辨率／切片 → 特征层 → 后处理 | 上采样热图不恢复已丢细节 |
| 纹理换方向大量误报 | LBP 变体、GLCM 方向、窗口覆盖 | 统一方向或明确方向建模 → 正常库 → 阈值 | 基本 LBP 不自动旋转不变 |
| 模型逐渐接受污点 | 更新样本、人工确认、模型版本 | 停止污染更新 → 回滚 → 重建可信集 | 自举低分不等于良品证明 |
| PaDiM 某位置异常高 | 样本量、协方差条件数、对齐与特征维 | 数据／坐标 → 稳定求解 → 正则 | 不只加极小数掩盖错误特征 |
| PatchCore 局部正常但整体错装 | 正常近邻来自何处、对象身份与布局 | 补位置／关系证据 → A01 或结构分支 | 正常 patch 不等于正确装配 |
| AE 重建缺陷仍很好 | 输入／重建／残差、容量与训练污染 | 清理数据 → 目标／结构窗口 → 比较嵌入或判别线 | 重建损失下降不代表漏检下降 |
| 离线优秀、换批失效 | 工件／批次划分、归一化、光照和原料变化 | 排泄漏 → 控采集 → 域验证 → 再拟合 | 不能拿测试批反复调阈值再当验收 |
| AUROC 高但放行漏检 | 操作阈值、缺陷严重度、图像级聚合 | 固定业务代价 → 保留集操作点 → 分层统计 | 排序指标不是指定误报下召回 |

### 4.4 最小验证设计

- **数据隔离：**按实物、批次和采集日期分训练／调参／验收；同一工件相邻帧、同图裁片不得跨组。正常库涵盖合法变化，保留罕见正常和未见缺陷。
- **指标：**分别报告图像级 AUROC、像素／区域定位指标与固定阈值下整件漏检／误报；PRO 等曲线注明积分范围和实现。严重缺陷按尺寸、类型、材质单列，不能用大区域像素量掩盖微缺陷。
- **阈值：**记录只用正常验证，还是额外用少量真实缺陷校准；后者是不同的数据使用协议。验收集冻结，不将测试标签用于选择 coreset、特征层或后处理。
- **资源：**记录 ROI／切片、网络输入尺寸、骨干权重、特征层、d、M、查询方式、预热、内存峰值和端到端尾延迟；不能只报网络前向平均时间。
- **失效回退：**对相机异常、无效配准、未知材质、超时与漂移返回 UNKNOWN 或复检；量化 UNKNOWN 比例，不能删除这些样本后宣称零漏检。

这些是测试设计，均未执行缺陷端到端实验。本章没有通用理论误差上界、检出率或现场节拍承诺。
