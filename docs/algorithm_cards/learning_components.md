## 演进维度与源码基线

组件演进按 **表示与假设、空间／上下文、监督与目标、优化求解、数值稳定性、计算与数据成本** 比较。不能把类别分类器年代当作像素分割首创年代，也不能把损失函数年代当作网络模型年代。

| 分支 | 瓶颈 → 机制改进 | 代价与遗留问题 |
|---|---|---|
| 标准化＋SVM | 特征尺度失衡、线性边界不足 → 训练集统计缩放与核间隔 | 标准化泄漏、核矩阵成本、仍依赖手工特征 |
| RF／GBDT | 单树方差或残余误差 → 并行随机平均／序贯负梯度拟合 | RF 树存储、GBDT 序贯训练；均不天然有像素空间一致性 |
| 卷积／池化／跳连 | 参数量和上下文不足 → 共享核、多尺度、细节旁路 | 下采样信息损失、激活显存、对齐问题 |
| 归一化／激活／注意力 | 优化尺度和固定局部上下文 → 非线性、统计变换、数据依赖聚合 | 统计漂移、掩码／位置设计、全局注意力二次成本 |
| Adam（2014 预印本，2015 论文版本） | 梯度尺度与噪声 → 一阶／二阶矩自适应更新 | 额外状态；并非任意非凸问题全局收敛 |

| L1／MSE、IoU | 回归残差／区域验收 → 统计估计目标与重叠协议 | 异常点、单位与聚合方式；指标不等于训练算法 |

## 特征处理与分类器

### C01 StandardScaler

任务／前提／状态：训练特征及后续样本 → 同一统计尺度特征；要求各列语义稳定。演进：尺度失衡 → 表示标准化 → 各维方差归一 → 存储统计成本 → 异常值及域偏移仍在。本地 pipeline 已调用，未做本次运行验证；覆盖见五元协议；来源：[cite:2](#lc-source-2)[cite:3](#lc-source-3)，源码已读、官方摘要已核。

- **L1 步骤**：仅在训练分组内 fit 每列 μ、σ；训练、验证、推理均用同一 transform；零方差列缩放因子置 1；一次统计及逐行变换结束。交叉验证每折各自 fit。
- **L2 机制**：RBF 距离和正则化会受量纲支配；中心化／缩放改变模型的几何先验。用验证集重新 fit 会改变决策坐标系并泄漏，不是公平的自适应。
- **L3 工程**：均值与 σ 同特征单位，变换后无量纲。先查列顺序和训练分布，再异常值、常量列，最后调 SVM；稀疏输入中心化会变稠密，必要时 `with_mean=False`。计算 O(nd)。
- **L4 推导**：`μj=Σxij/n`，`vj=Σ(xij-μj)²/n`，`zij=(xij-μj)/√vj`；这是总体式 ddof=0。仅对拟合样本的非零方差维度保证均值零、方差一；标准化不等于白化，因为协方差非对角项仍在。
- **L5 实现**：本地通过 make_pipeline 保证训练 fit 后用同统计预测；需持久化 scaler 和模型整体。测试常量列、列换序、训练统计冻结及稀疏异常；宽精度累积避免大偏置相消，不能只在预测时再 fit。

**分层面试答案**：L1 问“在哪 fit？”答：训练折内；L2 问“为何影响 SVM？”答：距离和正则几何改变；L3 问“稀疏矩阵怎么做？”答：避免中心化致稠密；L4 问“等于白化吗？”答：不去相关；L5 问“上线分数漂移？”答：核对 scaler、列顺序和版本。易错：全数据标准化后再划分。证据入口为本卡来源。

### C02 支持向量机 SVM／RBF SVC

任务／前提／状态：手工特征 X、类别 y → 决策分数或类别／校准概率；要求特征可分且样本代表场景。演进：线性分类不足 → 核特征与最大间隔 → 可非线性边界 → 支持向量成本 → 不提供空间连通性。本地是候选重排序，不是像素分类；覆盖见协议；来源：[cite:2](#lc-source-2)[cite:4](#lc-source-4)，源码已读、官方摘要已核。

- **L1 步骤**：按原图／批次划分，提 HOG 等特征并 fit scaler；训练 SVC，验证 C、γ 和拒识协议；推理 transform 后算 f 或 probability。求解达到容差／迭代限制停止；区域应用还需恢复位置和后处理。
- **L2 机制**：间隔正则限制复杂度，slack 允许错分，RBF 用距离表达非线性。移除缩放会让大尺度维支配；概率是额外校准，不是原始间隔自动等于概率。
- **L3 工程**：C 为相对损失权重；γ 单位为特征距离平方倒数。先查划分、特征和尺度，再在验证集联合选 C／γ；支持向量增多会增加推理成本。`probability=True` 额外训练校准，本地未固定 SVC 的 random_state。
- **L4 推导**：二分类 `min 0.5||w||²+CΣξi`，约束 `yi(wᵀφ(xi)+b)≥1-ξi, ξi≥0`；消去原变量得对偶与 `f(x)=ΣαiyiK(xi,x)+b`，`K=exp(-γ||x-xi||²)`。有效 PSD 核下是凸优化，但泛化不由训练最优保证；稠密核存储可 O(n²)，推理 O(nSV·d)。
- **L5 实现**：本地每次 `verify_candidates` 重新建教学样本训练，遍历合法窗口并排序，**未按门限剔除**。HOG 函数直接 uint8 转换可能量化／回绕浮点扰动，应把输入范围列入测试设计。预测正类列须匹配 `classes_`；测边缘裁窗、标签映射、可重复性和固定模型复用。

**分层面试答案**：L1 问“输出一定是概率？”答：原生是间隔，SVC 概率另校准；L2 问“核做什么？”答：隐式非线性表示；L3 问“γ 太大？”答：边界局部化、过拟合风险；L4 问“支持向量为何关键？”答：对偶非零 α 决定 f；L5 问“本地是否剔除假候选？”答：只排序未拒识。易错：把教学样本效果外推产线精度。证据入口为本卡来源。

### C03 随机森林 RF

任务／前提／状态：像素／区域特征 → 类别或平均概率；依赖可用特征和分组监督。演进：单树方差大 → bootstrap＋节点随机特征 → 降低相关性的平均 → 树数成本 → 高偏差与域偏移不消失。本地未实现；覆盖见协议；来源：[cite:5](#lc-source-5)，官方摘要已核，机制为标准模型展开。

- **L1 步骤**：每树抽样训练数据，节点随机选特征子集并选最佳分裂；达到深度、叶最小样本或纯度条件停；生成 T 树；推理平均树的类概率再决策。像素结果需重建图和空间约束。
- **L2 机制**：bagging 平均减少方差，随机特征降低树间相关；仅增加高度相同的树没有同样收益。树按排序分裂，通常不要求 StandardScaler，但特征有效性仍重要。
- **L3 工程**：先检查分组泄漏、类别平衡，再调叶最小样本／深度，最后树数和特征子集。像素 bootstrap 不等于跨工件 OOB；同图邻点相关使 OOB 过于乐观。推理约 O(T·depth)，内存随节点总数增长。
- **L4 推导**：Gini `G=1-Σpk²`，节点选择最大 `Δ=Gparent-(nL/n)GL-(nR/n)GR`。若树预测等方差 σ²、两两相关 ρ，平均方差为 `σ²[ρ+(1-ρ)/T]`；这只是等方差相关模型，不保证真实森林精度单调变好。
- **L5 实现**：参考 sklearn RandomForestClassifier，未接入；明确 `predict_proba` 平均叶概率，而非一定多数硬投票。测类别列、极小叶、重复特征、group 划分和种子；并行树可加速但须检查内存及可重复性。

**分层面试答案**：L1 问“如何合并树？”答：此接口平均类概率；L2 问“为何随机特征？”答：去相关；L3 问“像素 OOB 可验收？”答：不能代替工件级独立集；L4 问“T 无限方差归零？”答：ρ 非零时仍有下限；L5 问“本地有吗？”答：没有，仅参考路线。易错：RF 天生输出空间平滑区域。证据入口为本卡来源。

### C04 梯度提升树 GBDT

任务／前提／状态：特征和监督标签 → 加性分类函数；需适当损失与验证集。演进：现有模型残余误差 → 序贯负梯度拟合 → 持续纠偏 → 串行与轮数成本 → 易追逐噪声。本地未实现；覆盖见协议；来源：[cite:6](#lc-source-6)，官方摘要已核。

- **L1 步骤**：初始化常量 F0；每轮在当前预测处算负梯度，拟合回归树；求叶值／步长，乘学习率累加；达到轮数或独立验证早停即停。二分类推理将 logit 经 sigmoid，多类按约定 softmax。
- **L2 机制**：后树专门拟合前模型尚未解释的方向，不是 RF 的独立并行投票。不同损失的伪残差不同，只有平方损失时与普通残差成比例。
- **L3 工程**：先定损失和数据划分，再选叶大小／深度、学习率与轮数，最后子采样。小学习率通常需更多轮，不保证不欠拟合；无量纲学习率不能脱离损失尺度比较。推理 O(T·depth)。
- **L4 推导**：令 `ri=-∂ℓ(yi,F(xi))/∂F`，拟合 hm 近似 r，`Fm=Fm-1+ηhm`，叶值可再作线搜索。Bernoulli NLL 的 logit 参数化给 `r=y-σ(F)`；一般损失不等于 y-F。贪心函数空间下降不保证全体树结构全局最优。
- **L5 实现**：参考 GradientBoostingClassifier；不能直接把 XGBoost／LightGBM 二阶目标、直方图及缺失值策略当同一实现。测试第一轮伪残差、叶更新和 staged 验证曲线；早停用分组验证，若内部随机验证破坏分组需外部管理。

**分层面试答案**：L1 问“树训练顺序？”答：依赖前轮；L2 问“为何不是 RF？”答：梯度纠偏而非独立平均；L3 问“过拟合先改什么？”答：先核验证划分，再约束树与轮数；L4 问“分类残差？”答：指定 logit 约定下 y-p；L5 问“GBDT 等于 XGBoost？”答：方法族与具体目标／实现不同。易错：所有损失都拟合 y-F。证据入口为本卡来源。

## 基础网络算子

### C05 二维卷积 Conv2d

任务／前提／状态：BCHW → BCoutHoutWout；核、通道组和 padding 必须匹配。演进：全连接参数多 → 局部共享权重 → 提取平移复用特征 → 有限感受野与计算成本 → 边界／stride 破坏严格等变。本地 EdgeNet、FocusNet 已定义，未执行；覆盖见协议；来源：[cite:2](#lc-source-2)[cite:7](#lc-source-7)。

- **L1 步骤**：按 padding 扩展输入；各输出位置按 stride 取带 dilation 支撑，对输入通道加权求和加 bias；所有位置完成后输出，训练反向累积共享核梯度。
- **L2 机制**：同核复用降低参数并编码局部模式；1×1 只混通道不直接扩大空间感受野。框架 Conv2d 常实现互相关而非翻核数学卷积，训练参数可适应但手工核需分清。
- **L3 工程**：kernel、stride、dilation 是像素网格数；先验证输出 stride 与最小目标尺度，再定通道和组。大 dilation 扩大感受野但可能栅格化；看激活形状及边界响应，不只参数量。
- **L4 推导**：一维尺寸 `out=floor((in+2p-d(k-1)-1)/s)+1`，二维逐轴使用。权重参数为 `Cout·(Cin/g)·kh·kw`，乘加约再乘 BHoWo；g 须整除两端通道。共享核给局部等变，边界和下采样有条件。
- **L5 实现**：本地 EdgeNet 用 3×3 padding=1，FocusNet 有 stride=2；权重布局 Cout×Cin/g×kh×kw。测试冲激、常量、groups、非方形与尺寸公式；优化卷积布局／融合时对照容差和确定性，不宣称所有后端逐位一致。

**分层面试答案**：L1 问“输出如何算？”答：滑动点积加 bias；L2 问“1×1 看邻居？”答：仅混当前点通道；L3 问“小目标没了？”答：先看 stride；L4 问“参数量？”答：与空间位置无关、与核和通道有关；L5 问“手写边缘核方向反？”答：卷积与互相关约定。易错：padding 永远保持原尺寸。证据入口为本卡来源。

### C06 ReLU

任务／前提／状态：实数激活 → 非负激活；保留张量形状。演进：线性层叠表达不足 → 分段非线性 → 稀疏激活与正区梯度 → 负区零梯度 → 死亡单元仍可能出现。本地已定义；覆盖见协议；来源：[cite:2](#lc-source-2)，源码已读、数学展开。

- **L1 步骤**：逐元素算 max(0,x)；反向对正输入乘 1、负输入乘 0；一次遍历结束，零点导数由实现约定。
- **L2 机制**：没有非线性，多层线性变换可合并，不能表达一般非线性边界；负区持续为负时梯度断开，不能用“ReLU 不饱和”掩盖死亡问题。
- **L3 工程**：无可学习门限参数；先查初始化、偏置、学习率和激活零比例，再考虑 LeakyReLU 等替代。输入缩放影响激活统计，inplace 节省部分内存但影响图的值复用。
- **L4 推导**：`f'=1(x>0)`，在 0 不可微可选次梯度；`|f(a)-f(b)|≤|a-b|`，单算子 1-Lipschitz，不推出整个网络梯度不会爆炸，因为线性层范数可大。
- **L5 实现**：EdgeNet `inplace=True`，FocusNet 普通 ReLU；复用 skip 张量时须检查原地修改。测试正负零、梯度和重复使用张量；融合 Conv＋ReLU 前核对值和 autograd 行为。

**分层面试答案**：L1 问“负值输出？”答：0；L2 问“为何需要它？”答：打破线性合成；L3 问“全零怎么查？”答：激活分布、学习率和偏置；L4 问“处处可微？”答：0 处不可微；L5 问“inplace 总安全？”答：依赖计算图复用。易错：ReLU 保证整个网络无梯度问题。证据入口为本卡来源。

### C07 Sigmoid

任务／前提／状态：单 logit → 二元或独立多标签概率；标签不是互斥 K 类时可逐通道用。演进：实数评分 → 有界概率链接 → Bernoulli 建模 → 饱和梯度 → 校准与阈值仍需验证。EdgeNet 通过 fused BCE 隐含此链接，未显式 sigmoid 前向；覆盖见协议；来源：[cite:2](#lc-source-2)[cite:8](#lc-source-8)。

- **L1 步骤**：逐点 `p=1/(1+exp(-z))`；推理按经验证门限输出标签；训练 BCEWithLogits 接收 z，不预先 sigmoid；一次映射结束。
- **L2 机制**：把 log-odds 映为概率，两端趋于饱和。多通道独立 sigmoid 不要求和为一，与 softmax 互斥假设不同。
- **L3 工程**：z 无量纲，门限在概率尺度；先查类别先验、pos_weight 和校准，再选阈值。高置信错误时不要通过再套 sigmoid 修复，重复映射会破坏分数范围和梯度。
- **L4 推导**：`log(p/(1-p))=z` 反解得 sigmoid；`dp/dz=p(1-p)≤1/4`。极端 z 的激活导数小，但与未加权 BCE 合成后对 logit 梯度为 p-y，不能混淆二者。
- **L5 实现**：推理可以阈值 z 与 `log(t/(1-t))` 等价比较，0<t<1；t=0.5 对应 z=0。测试极端 logits、有符号零和单 logit 通道；用稳定库避免直接 exp 溢出。

**分层面试答案**：L1 问“BCEWithLogits 前要 sigmoid？”答：不要；L2 问“类别和必须一？”答：独立通道不必；L3 问“阈值一定 0.5？”答：按代价和校准选；L4 问“导数？”答：p(1-p)；L5 问“可直接 logit 阈值？”答：用 log-odds 转换。易错：把一个通道 softmax 当二分类概率。证据入口为本卡来源。

### C08 Softmax

任务／前提／状态：K 个互斥类别 logits → 和为一的类别概率；类别轴须明确。演进：独立分数不可比较 → 归一指数竞争 → 互斥建模 → 指数和归约成本 → 不适合重叠多标签。本地未显式实现；覆盖见协议；来源：[cite:8](#lc-source-8)，官方 CE 摘要及模型推导。

- **L1 步骤**：沿类别轴减最大值，指数化、求和并相除；argmax 得类别；所有有效位置一次映射完成。用于注意力时归一轴改为 key 轴。
- **L2 机制**：类别竞争且平移不变，单通道结果恒为 1；不允许同像素两个类都独立高概率。去掉减最大值数学等价但可能数值溢出。
- **L3 工程**：温度 T 与 logit 同尺度，T 小分布尖锐但不增加信息。先核对 dim、标签协议和极端值，再考虑校准温度；关注熵与混淆矩阵。
- **L4 推导**：`pi=exp(zi-m)/Σexp(zj-m)`，公共 exp(-m) 约去；Jacobian `∂pi/∂zj=pi(δij-pj)`。概率对每个 logit 都耦合；整体加常量不可辨识，成本 O(K) 每位置。
- **L5 实现**：BKH W 类别轴为 1；训练 CrossEntropyLoss 直接接 logits，不重复 softmax。测试和为一、加常量不变、单通道和全屏蔽注意力行；全 -inf 行需定义策略，不能任由 NaN。

**分层面试答案**：L1 问“按哪个轴？”答：类别或指定 key 轴；L2 问“一通道为何全一？”答：归一分母相同；L3 问“更低温度更准？”答：只改置信尖锐度；L4 问“为何减最大值？”答：平移不变且稳定；L5 问“CE 前要做？”答：不。易错：互斥与独立多标签混用。证据入口为本卡来源。

### C09 最大池化 MaxPool2d

任务／前提／状态：特征图 → 局部最大及下采样；保留强响应但可丢位置。演进：局部信息冗余 → 极值聚合 → 扩大后层感受野 → 位置／细节损失 → 小目标可漏。本地 EdgeNet 已定义；覆盖见协议；来源：[cite:2](#lc-source-2)。

- **L1 步骤**：每窗口取最大，按 stride 输出；保存反向所需索引；反向把梯度送到被选位置，重叠窗口累加；窗口遍历结束。
- **L2 机制**：保留局部强特征、对小平移部分容忍；不是抗混叠滤波，噪声尖峰也可能保留。移除池化保持细节但增计算与后续设计成本。
- **L3 工程**：核和 stride 为网格 px；先看最小结构与输出形状，再考虑 ceil_mode／padding。EdgeNet 两级 2×2 会对奇数尺寸取整，导致后续相加不匹配。
- **L4 推导**：`y=maxi xi`，唯一最大处导数 1，其余 0；并列最大不可微，采用具体分派约定。无 padding、k=s=2 时尺寸 floor(H/2)，映射多对一，通常不可逆；O(Nk²) 朴素实现。
- **L5 实现**：本地 `MaxPool2d(2)`；测试奇数、并列最大、负输入和重叠梯度。padding 应按库的负无穷语义理解，不能随意填 0 改负区结果；优化需保持 tie 与尺寸约定。

**分层面试答案**：L1 问“梯度给谁？”答：选中最大位置；L2 问“是抗混叠吗？”答：不是；L3 问“奇数图怎么查？”答：逐级尺寸；L4 问“可逆吗？”答：信息多对一丢失；L5 问“负图零边界？”答：可能改变最大值。易错：池化严格平移不变。证据入口为本卡来源。

### C10 平均池化与全局自适应平均池化

任务／前提／状态：局部或整幅特征 → 平均响应；全局输出丢弃精确位置。演进：Flatten 尺寸依赖／参数多 → 均值汇聚 → 紧凑全局表示 → 位置信息丢失 → 不能单独输出像素 mask。本地 FocusNet 用 AdaptiveAvgPool2d(1)；覆盖见协议；来源：[cite:2](#lc-source-2)。

- **L1 步骤**：确定窗口或自适应 bin；累加有效元素除规定计数；全局版各通道变 1×1，接 Flatten；反向把梯度分摊到支持元素，一轮结束。
- **L2 机制**：平均代表区域统计，较最大值少受单尖峰主导，却可能稀释极小目标。全局平均去掉位置，适合全局回归，不直接适合精细区域定位。
- **L3 工程**：先看目标占特征图比例，再决定局部／全局；不同分辨率虽输出相同维数，内容分布仍可变。边界是否计 padding 影响均值，不能只对齐输出尺寸。
- **L4 推导**：全局 `yc=Σhw xchw/(HW)`，对每元素导数 `1/(HW)`；独立同方差噪声平均方差降为 σ²/(HW)，相关噪声须加入协方差项。计算 O(BCHW)。
- **L5 实现**：本地全局池化后 B×64×1×1，Flatten 得 B×64；测试常量、冲激、不同 H/W 和平均梯度。一般 adaptive bins 的取整／重叠需按库定义，不把全局公式套到任意输出格。

**分层面试答案**：L1 问“全局版输出？”答：每通道一个均值；L2 问“小缺陷为何被稀释？”答：面积占比低；L3 问“任意尺寸一定同分布？”答：不；L4 问“梯度？”答：均匀分摊；L5 问“Flatten 维度？”答：保 batch。易错：全局平均仍保留目标坐标。证据入口为本卡来源。

### C11 转置卷积 ConvTranspose2d

任务／前提／状态：低分辨率特征 → 可学习上采样；需要明确 stride、padding 和 output_padding。演进：固定放大表达不足 → 学习跨位置散射累加 → 可训练解码 → 重叠与参数成本 → 棋盘格和非逆性。本地 EdgeNet 已定义；覆盖见协议；来源：[cite:2](#lc-source-2)，源码与线性代数展开。

- **L1 步骤**：每输入点按核权重向输出支撑散射，重叠求和，按 padding／output_padding 设最终形状；完成全部累加输出，训练梯度回传。
- **L2 机制**：是对应卷积线性映射的转置作用，不是撤销下采样的逆。重叠覆盖不均可产生棋盘格，核宽可整除 stride 也不保证训练后无伪影。
- **L3 工程**：核、步长、padding 是像素格；先核尺寸与 skip 对齐，再看覆盖均匀性和边界，最后通道。必要时比较插值＋卷积，但两者参数化不相同。
- **L4 推导**：卷积写 y=Ax，则输入梯度为 Aᵀg；转置卷积采用相应散射结构。`Hout=(Hin-1)s-2p+d(k-1)+output_padding+1`；A 非方／有零空间时 Aᵀ≠A⁻¹。成本随输入位置、核和通道增长。
- **L5 实现**：EdgeNet k=2、s=2；低层尺寸乘二不一定等于奇数 skip。output_padding 解决形状歧义，不是给输出实质追加一圈零。测冲激覆盖、常量、奇数链和 shape；不声称旧输出像素可被恢复。

**分层面试答案**：L1 问“如何生成高分辨率？”答：核加权散射累加；L2 问“是反卷积逆？”答：不是；L3 问“棋盘格先查？”答：覆盖和核步幅；L4 问“为什么叫转置？”答：Aᵀ；L5 问“output_padding 填零？”答：主要确定形状歧义。易错：认为上采样可还原所有池化信息。证据入口为本卡来源。

### C12 插值上采样 Interpolation

任务／前提／状态：低分辨率 logits／特征 → 指定尺寸张量；必须区分连续值与离散标签。演进：可学习上采样复杂 → 固定几何插值 → 简单稳定尺寸恢复 → 不增加信息 → 半像素与标签污染风险。本地分割未接入；覆盖见协议；来源：[cite:1](#lc-source-1)，已有分割资料及几何推导。

- **L1 步骤**：建立输出中心到输入坐标映射；最近邻选一个点，双线性选四点加权；处理边界后返回目标尺寸。类别标签用最近邻，logits 可连续插值后再 argmax。
- **L2 机制**：插值是假设局部连续场而非语义重建；直接线性插类别编号会制造不存在的类。先 argmax 再插值与先插 logits 再 argmax 通常不等价。
- **L3 工程**：先查原图→网络→输出的尺度、中心和 padding，再选模式及 align_corners；不能通过任意 crop 消除偏移。更高输出分辨率不证明定位信息增加。
- **L4 推导**：线性半像素映射常写 `xin=(xout+0.5)Win/Wout-0.5`；align_corners 路径为 `xin=xout(Win-1)/(Wout-1)`，端点和单像素情况需专门处理。双线性权重非负且和一，保持常量但平滑高频；O(输出元素数)。
- **L5 实现**：参考 `torch.nn.functional.interpolate`，未本地执行；固定 mode、size、align_corners 及版本。测试常量、仿射图、单像素维度、标签集合不增及坐标往返；不同库 nearest 规则也需对照。

**分层面试答案**：L1 问“标签怎么缩放？”答：最近邻；L2 问“放大可恢复细节？”答：不能凭空；L3 问“半像素偏移？”答：中心与 align_corners；L4 问“两种坐标公式？”答：半像素与端点对齐；L5 问“先 argmax 一样吗？”答：一般不。易错：把像素编号当连续数值。证据入口为本卡来源。

### C13 跳跃连接：相加与拼接

任务／前提／状态：两路空间对齐特征 → 融合特征；相加还要求通道相容。演进：深层丢局部信息／梯度路径长 → 跨层旁路 → 保细节与梯度路线 → 显存和对齐成本 → 不能修复错误坐标。本地 EdgeNet 使用相加，未用原始 U-Net 拼接；覆盖见协议；来源：[cite:1](#lc-source-1)[cite:2](#lc-source-2)。

- **L1 步骤**：验证两路空间和通道；相加逐元素合并，拼接沿通道连接再卷积；若裁剪／投影要在图里明确；完成融合后继续解码。
- **L2 机制**：相加强制通道对齐并混合，拼接保留独立信息供后层选择；不能任意互换。残差 `x+F(x)` 提供恒等旁路，但不保证所有梯度都大或不爆炸。
- **L3 工程**：先查尺寸、坐标和语义尺度，再定 concat／add 及投影通道数。concat 增后续卷积输入通道和显存；add 便宜但通道对应有约束。奇数图失败不应盲目插值掩盖。
- **L4 推导**：concat 后线性层为 `Wa a+Wb b`，add 后为 `W(a+b)`，等价仅在权重约束成立时。残差导数 `I+JF`，JF 可能抵消 I，因此“有恒等项”不等于绝不梯度消失；融合操作 O(元素数)。
- **L5 实现**：本地 `u2(x3)+x2`、`u1(y)+x1`；广播可能掩盖错误 shape，测试前显式比较。测相加梯度两路一致、concat 梯度切片和坐标冲激；参考优化不可删除旁路而不改模型。

**分层面试答案**：L1 问“concat 沿哪轴？”答：BCHW 的 C；L2 问“和 add 等价？”答：一般不；L3 问“显存不够？”答：评估高分辨率 concat 与通道；L4 问“残差保证梯度？”答：I+JF 仍可抵消；L5 问“本地用哪种？”答：add。易错：把所有 skip 都叫原始 U-Net。证据入口为本卡来源。

### C14 Flatten 与 Linear

任务／前提／状态：高维特征 → 向量／标量；保持 batch 和固定特征顺序。演进：特征需要任务映射 → 展平＋仿射读出 → 混合全局通道 → 空间展平参数多 → 输入尺寸依赖。本地 FocusNet 在全局池化后使用；覆盖见协议；来源：[cite:2](#lc-source-2)。

- **L1 步骤**：保留 batch，将其余指定轴按顺序展平；以 `y=xWᵀ+b` 输出；多层间可插 ReLU；反向 reshape 回原维度并计算矩阵梯度。
- **L2 机制**：Flatten 本身不学习且不丢元素，Linear 学读出；若先全局池化则位置早已丢失。所有仿射层之间无非线性时可合成一个仿射层。
- **L3 工程**：先核对 Flatten 起止轴和输入尺寸，再选输出维度。直接展平 HWC 会增参数且固定尺寸；本地先全局池化避开此问题。输出离焦单位由标签决定。
- **L4 推导**：W 为 Dout×Din，参数量 Din·Dout+Dout，成本 O(BDinDout)；`∂L/∂x=gW`，`∂L/∂W=gᵀx`。有秩不足时映射不可逆，Flatten 可逆不使 Linear 可逆。
- **L5 实现**：FocusNet B64→B32→B1，末尾 `squeeze(-1)` 保 batch；禁止裸 squeeze 让 B=1 时维度消失。测 B=1／多 batch、非连续张量 reshape、读出单位和梯度；Flatten 是否复制需看 strides。

**分层面试答案**：L1 问“batch 展平吗？”答：不；L2 问“Flatten 学什么？”答：不学习；L3 问“为何先全局池化？”答：减尺寸依赖和参数；L4 问“参数量？”答：DinDout 加 bias；L5 问“单样本 shape 坏了？”答：查 squeeze 轴。易错：展平等于平均。证据入口为本卡来源。

### C15 BatchNorm

任务／前提／状态：训练／推理特征 → 按通道归一仿射变换；需明确训练统计与运行统计。演进：中间尺度变化 → mini-batch 统计变换 → 改善优化条件 → 批依赖与状态成本 → 小批次和域漂移。本地网络没有 BatchNorm；覆盖见协议；来源：[cite:1](#lc-source-1)，参考数学模型，外部原始资料本次未核。

- **L1 步骤**：训练在每通道 BHW 轴算 μ、v，标准化后乘 γ 加 β，更新 running statistics；推理通常用冻结 running 值；一次批处理结束，反向包括统计量依赖。
- **L2 机制**：约束激活尺度并允许学习仿射恢复；训练输出依赖同批其他样本。不能把 train／eval 忽略，也不能断言它保证某种唯一解释的分布不变。
- **L3 工程**：ε 是方差尺度稳定项，momentum 定义依库；先查有效批大小和 train/eval，再看运行统计与域偏移。极小 BHW 统计不稳，可考虑 GroupNorm／LayerNorm，但二者轴不同。
- **L4 推导**：`xhat=(x-μ)/√(v+ε)`，`y=γxhat+β`；无 ε 时批内标准化均值零、方差一，ε>0 时方差为 v/(v+ε)。γ、β 可恢复部分仿射表达，不等于整体可逆；计算 O(BCHW)。
- **L5 实现**：仅参考 BatchNorm2d，不加入当前骨架。核对库训练方差与 running_var 更新的有偏／无偏约定；eval 中可将 BN 融入前卷积，使用固定统计，不能照搬到训练。测 train/eval、batch 改组、常量通道和融合误差。

**分层面试答案**：L1 问“按哪些轴？”答：每通道聚合 BHW；L2 问“换同批样本会影响？”答：训练会；L3 问“小 batch 不稳？”答：查统计支持和替代归一化；L4 问“方差必一？”答：ε 使其不是严格一；L5 问“融合条件？”答：eval 固定统计。易错：本地 CNN 已有 BN。证据入口为本卡来源，外部核验状态为部分。

### C16 LayerNorm

任务／前提／状态：每样本／token 特征 → 指定尾轴归一化；normalized_shape 必须匹配布局。演进：批统计依赖 → 样本内部统计 → 降低 batch 影响 → 轴选择与仿射成本 → 并不自动保留全部幅值信息。本地未实现；覆盖见协议；来源：[cite:1](#lc-source-1)，参考模型、原始资料本次未核。

- **L1 步骤**：对每个独立样本块的指定尾轴求 μ、v；标准化后乘 γ 加 β；训练与推理按同种当前样本统计进行；一轮结束。
- **L2 机制**：序列 BTD 上常归一 d，不依赖同批其他序列；不同于 BatchNorm 的跨样本每通道统计。归一范围不同会改变模型，不可只换类名。
- **L3 工程**：先查 token／channel 轴，再 ε 和 pre-norm／post-norm 结构；BCHW 上 LayerNorm(C) 不自动等于按通道归一，需布局或 shape 设计。显存受激活影响而非仅归一层参数。
- **L4 推导**：对 d 个特征 `μ=Σx/d`、`v=Σ(x-μ)²/d`，输出同标准化公式；公共加性偏置被移除，正尺度在 ε 可忽略时近似抵消。共享统计使各特征梯度耦合，不能按独立缩放求完整反向。
- **L5 实现**：参考 LayerNorm(normalized_shape)，未接入；测 batch 置换不影响同样本、维度置换须同步参数、常量向量和极小方差。混合精度时统计累积精度需核查，不能只设更小 ε。

**分层面试答案**：L1 问“统计来自谁？”答：当前样本指定轴；L2 问“与 BN 同吗？”答：轴和状态不同；L3 问“BCHW 怎么选？”答：明确尾轴／布局；L4 问“梯度独立吗？”答：共享 μ、v 使其耦合；L5 问“改变 batch 输出变？”答：标准 LN 不应因其他样本变。易错：LayerNorm(C) 可无条件用于 BCHW 通道。证据入口为本卡来源，外部核验部分。

### C17 Dropout

任务／前提／状态：训练激活 → 随机稀疏激活；推理通常恒等。演进：共适应／过拟合 → 随机屏蔽 → 随机正则 → 方差和收敛成本 → 不能替代代表性数据。本地未实现；覆盖见协议；来源：[cite:1](#lc-source-1)，参考模型、原始资料本次未核。

- **L1 步骤**：训练采 Bernoulli mask，保留概率 q=1-p；输出 `mx/q`；推理不屏蔽不缩放；每次前向重新采样，反向复用本次 mask。
- **L2 机制**：阻止训练时永远依赖同一组激活；inverted dropout 保持条件期望，但某次输出不等于原值。eval 忘切换会导致推理随机波动。
- **L3 工程**：p 无量纲且需小于 1 的常规模型；先确认过拟合和 train/eval，再选 p 与元素／通道级模式。更大 p 可欠拟合；复现实验需保存 RNG 状态。
- **L4 推导**：m~Bernoulli(q)，`E[mx/q]=x`，`Var(mx/q)=x²p/q`；均值保持不保证后续非线性期望相等。p 趋 1 时方差发散，极端端点由实现另定义；O(N)。
- **L5 实现**：参考 nn.Dropout／Dropout2d，二者 mask 粒度不同。测 eval 恒等、训练期望／方差的独立验证设计、固定 RNG 和梯度 mask；不能把测试波动直接当模型不稳定。

**分层面试答案**：L1 问“推理还除 q？”答：inverted 约定不再除；L2 问“输出和原来一样？”答：仅条件期望；L3 问“p 越大越好？”答：会欠拟合增噪；L4 问“方差？”答：x²p/q；L5 问“推理每次变？”答：查 eval／RNG。易错：Dropout 保证全模型无偏输出。证据入口为本卡来源，外部核验部分。

## 注意力、梯度与优化

### C18 缩放点积与多头注意力 Attention

任务／前提／状态：token／图像特征和可选上下文 → 内容依赖聚合；须定义位置与有效 mask。演进：固定局部感受野 → QK 相似性动态权重 → 跨区域上下文 → 全局二次成本 → 不保证几何／语义正确。2017 Transformer 为代表，不是全部注意力首创；本地未实现；覆盖见协议；来源：[cite:9](#lc-source-9)，原始论文检索片段已核。

- **L1 步骤**：投影 Q、K、V；算 `S=QKᵀ/√dk`，加有效／因果 mask；沿 key 轴 softmax，再乘 V；多头各自计算、拼接并输出投影；处理全部 queries 完成。self 来自同序列，cross 的 Q 与 KV 来自不同源。
- **L2 机制**：内容相似度决定聚合范围，不再固定卷积邻域；位置编码／偏置提供位置证据。没有位置信息的自注意力主要具有置换等变性，不能从 token 顺序自然知道图像坐标。
- **L3 工程**：先看 token 数、mask 语义和位置，再调头数／维数／窗口；缩放无量纲。大图全局注意力显存随 T²，窗口化改变上下文，稀疏／线性变体不一定与原 softmax 等价。
- **L4 推导**：独立零均值单位方差 q、k 分量时 `Var(Σqiki)=dk`，除 √dk 后为 1；实际相关特征不满足精确前提。`A=softmax(S)` 行和一，AV 为 V 的凸组合，多头投影后不再简单凸组合；复杂度 O(TqTk dk+TqTk dv)。
- **L5 实现**：参考矩阵乘或 fused scaled_dot_product_attention，未接入；不同 API 的布尔 mask 可能 True=允许或 True=屏蔽，须逐个确认。测全屏蔽行、padding、不等长 cross、权重行和与梯度；高效核可不物化矩阵，但需核对 dropout、缩放及精度等价。

**分层面试答案**：L1 问“softmax 哪个轴？”答：keys；L2 问“位置从哪来？”答：编码／偏置等外加结构；L3 问“头数越多越快？”答：看维数和核，不必；L4 问“√dk 为什么？”答：独立分量方差模型；L5 问“mask 反了？”答：查具体接口语义。易错：LightGlue 名字出现在注释就说明本地已接入注意力。证据入口为本卡来源。

### C19 反向传播与自动微分

任务／前提／状态：标量损失与计算图 → 参数梯度；图中算子需有相应导数／约定。演进：逐参数差分昂贵 → 链式法则反向累积 → 一次反向得到多参数梯度 → 激活存储成本 → 梯度正确不保证任务正确。本地 FocusNet 有 backward；覆盖见协议；来源：[cite:2](#lc-source-2)。

- **L1 步骤**：前向记录依赖与必要中间量，标量损失梯度置 1；逆拓扑传播向量—Jacobian 积并累加分支；到叶参数结束；清梯度、反向、step 的顺序要明确。
- **L2 机制**：共享参数和多分支梯度相加；detach、argmax 或转 NumPy 会截断／丢失常规梯度。自动微分求的是所写程序，不会判断标签或广播是否正确。
- **L3 工程**：先看 loss 形状、计算图连接、非有限值与梯度范数，再学率和混合精度；累积多微批次需按总有效样本归一。训练显存常由前向激活主导。
- **L4 推导**：`y=f(x), L=g(y)` 得 `∇xL=Jfᵀ∇yL`，共享路径对参数的贡献求和；反向成本通常与前向同阶，但常数和保存状态依算子。分段不可微点采用约定，数值差分比较需避开这些点。
- **L5 实现**：本地循环 zero_grad→backward→step 已存在，但没有完善数据接线。测试少量 double 参数的中心差分、共享路径与 detached 分支；梯度检查不是训练收敛证明。checkpoint 以重算换显存，必须保持随机和状态语义。

**分层面试答案**：L1 问“从哪里反传？”答：标量损失；L2 问“分支梯度？”答：累加；L3 问“loss 降不了先查？”答：数据与图、梯度而非盲调学率；L4 问“链式法则？”答：Jacobian 转置乘上游；L5 问“autograd 正确等于模型正确？”答：只对当前程序。易错：多 batch 不清梯度却当独立更新。证据入口为本卡来源。

### C20 Adam

任务／前提／状态：参数、梯度和历史状态 → 更新参数；需可微训练目标及明确步数。演进：梯度噪声与尺度差 → EMA 一阶／二阶矩＋偏差修正 → 自适应步长 → 每参数额外状态 → 不保证非凸全局最优。本地 FocusNet train_loop 实际创建 Adam；覆盖见协议；来源：[cite:2](#lc-source-2)[cite:10](#lc-source-10)，源码与原论文片段已核。

- **L1 步骤**：取梯度 gt，更新 mt、vt；按 t 修正初始化偏差；用修正矩归一更新 θ；完成一个训练 step；整体按 epoch／验证早停。恢复训练需恢复 θ、m、v、t。
- **L2 机制**：m 平滑梯度方向，v 估计平方尺度，不是中心化方差；零初始化使早期矩偏低，偏差修正补偿。移除修正改变早期步长，不是无影响优化。
- **L3 工程**：学习率与参数更新尺度相关，β1／β2 为无量纲衰减率，ε 与分母量纲对应。先查数据和非有限梯度，再学习率／归一化，后 β 与 ε；额外状态约两份参数规模。Adam 与 AdamW 的衰减语义不可混用。
- **L4 推导**：`mt=β1 mt-1+(1-β1)gt`，`vt=β2 vt-1+(1-β2)gt²`；在恒定期望梯度模型下 `E[mt]=(1-β1^t)E[g]`，故 `mhat=mt/(1-β1^t)`，v 类似；`θt=θt-1-η mhat/(√vhat+ε)`。这是偏差修正推导，不是任意随机／非凸问题收敛证明。
- **L5 实现**：本地 lr 默认 1e-3，只有更新循环，无 optimizer checkpoint。参考测试第一步公式、零梯度、断点状态恢复、混合精度非有限跳步；不要每个 batch 重建 optimizer 清历史。foreach／fused 优化要比较数值容差而非假定逐位相同。

**分层面试答案**：L1 问“保存哪些状态？”答：参数、矩和步数；L2 问“v 是方差？”答：未中心化二阶矩；L3 问“发散先换优化器？”答：先查数据梯度和学习率；L4 问“修正分母来自哪？”答：EMA 几何级数；L5 问“只载模型可无缝续训？”答：缺矩和 t 不等价。易错：Adam 自动保证收敛。证据入口为本卡来源。

## 分类与区域损失

### C21 多类交叉熵 Cross-Entropy

任务／前提／状态：互斥类别 logits＋标签 → 负对数似然；每像素只能一个有效类，忽略区另定义。演进：硬分类无梯度 → 似然目标 → 稠密监督 → 背景／类频主导 → 不直接优化 IoU。本地未实现区域 CE；覆盖见协议；来源：[cite:8](#lc-source-8)，官方输入契约摘要已核。

- **L1 步骤**：输入 BKHW logits 和 BHW 整数标签；稳定 log-softmax，取真实类负值；应用 class weight／ignore，再按约定归约；标量反传。软标签路径必须显式匹配概率标签协议。
- **L2 机制**：惩罚对真实类低概率的预测；硬 argmax 后不能提供常规概率梯度。CE 与 softmax 合并稳定，提前 softmax 再交给 CE 改变目标和梯度。
- **L3 工程**：先核标签范围／ignore 与类别轴，再权重和平滑；权重无量纲但改变风险和归约分母。极小缺陷可被背景淹没，要看每类损失与召回，不只总 loss。
- **L4 推导**：categorical 概率 `py=exp(zy)/Σexp(zk)`，故 `ℓ=-zy+logΣexp(zk)`；单样本无权重时 `∂ℓ/∂zk=pk-1[k=y]`，Hessian 为 `diag(p)-ppᵀ` 半正定，因此对 logits 凸，不代表对网络参数凸。
- **L5 实现**：参考 CrossEntropyLoss，logits float、整数 target 通常 long；ignore_index 对整数标签路径生效。测试全 ignore 的显式跳过／零损失策略、极端 logits、非法标签、权重归约；先过滤有效像素再做空计数处理。

**分层面试答案**：L1 问“输入概率还是 logit？”答：该 API 接 logits；L2 问“argmax 后算可训练？”答：破坏常规梯度；L3 问“全背景高准确率？”答：看类频和召回；L4 问“梯度？”答：p-onehot；L5 问“全 ignore 怎么办？”答：显式处理空归约。易错：logit 凸推出整个网络凸。证据入口为本卡来源。

### C22 BCE 与 BCEWithLogits

任务／前提／状态：二值／独立多标签 logits＋目标 → Bernoulli NLL；目标应与预测同形。演进：概率似然 → 稳定 logit 融合 → 避免 log(0)／溢出 → 权重和标签契约成本 → 不自动解决类不平衡。本地 EdgeNet heat 分支已写；覆盖见协议；来源：[cite:2](#lc-source-2)[cite:8](#lc-source-8)。

- **L1 步骤**：取 heat logit `pred[:,0]`，与 BHW heat 对齐；逐点算稳定 BCEWithLogits；加权／过滤有效区后归约并反传；预测时另行阈值化。
- **L2 机制**：BCE 是独立 Bernoulli，单 logit 足够表达二分类；WithLogits 把 sigmoid 与对数合并，避免先极端饱和为 0／1 再取 log。它不是互斥多类 softmax。
- **L3 工程**：先查 target 的 0／1 或软标签范围和 shape，再选 pos_weight、采样与阈值。正类权重改变最优概率，不能仍假定未经校准输出等于真实频率；空监督与真实全背景不同。
- **L4 推导**：`ℓ=-y log p-(1-y)log(1-p)`，代 sigmoid 整理得 `max(z,0)-zy+log(1+exp(-|z|))`；无权重 logit 梯度 p-y。若真实正率 q、正项乘 a，则最优 `p*=aq/(aq+1-q)`，说明加权改变校准。
- **L5 实现**：本地 heat BCE 索引符合 BHW；真正问题在后续 offset 索引，不能把整个 loss 标运行通过。参考 unreduced loss×valid 后除有效数，避免仅乘零仍被 NaN 污染。测试 z 极大／小、全负、软标签、同形及 pos_weight 广播。

**分层面试答案**：L1 问“预先 sigmoid？”答：不要；L2 问“为何稳定？”答：softplus/log-sum-exp 形式；L3 问“pos_weight 只改召回？”答：还改最优概率和阈值关系；L4 问“梯度？”答：未加权为 p-y；L5 问“mask 乘零足够？”答：先处理无效值和有效分母。易错：多标签必须概率和一。证据入口为本卡来源。

### C23 Dice 损失与 Dice 指标

任务／前提／状态：概率／二值 mask＋真值 → soft Dice 训练目标或 hard Dice 指标；两种协议必须分开。演进：像素平均被背景主导 → 集合重叠目标 → 显式关注前景 → 全局梯度耦合与空类处理 → 不是概率校准。本地无实现；覆盖见协议；来源：[cite:1](#lc-source-1)，既有分割资料已读，损失变体为本篇明确选择。

- **L1 步骤**：hard 指标先阈值／argmax；soft 损失先 sigmoid／softmax；过滤忽略像素，按样本和类求交项与和，计算 `1-Dice`；明确 macro／micro、背景和空类规则后归约。
- **L2 机制**：以区域重叠而非总像素数度量前景，有助于减少背景支配；分母耦合所有像素，一个像素梯度受全图预测影响。软 Dice 高不说明概率校准好。
- **L3 工程**：先定逐图／逐类还是 batch 归约及空类，再选平滑 ε 和 CE／BCE 组合权重。ε 与求和项同为像素计数尺度，改变分辨率／归约可能改变影响；小前景可使梯度不稳。
- **L4 推导**：本卡选 `A=2Σpiyi+ε, B=Σpi+Σyi+ε, LD=1-A/B`，则 `∂LD/∂pj=(A-2yjB)/B²`。平方分母变体导数不同；硬集合非空时 Dice=2TP/(2TP+FP+FN)，不能拿平方版直接套此关系。全空时 ε 决定软值，但 hard 协议另定。
- **L5 实现**：参考 float32 或更高精度 sum，先过滤有效像素，K 类真值需合法 one-hot；未创建库实现。测 perfect、disjoint、空真值带假阳性、全 ignore、单像素前景及解析梯度；禁止对 argmax 结果训练 soft Dice。

**分层面试答案**：L1 问“soft 和 hard 一样？”答：输入及用途不同；L2 问“为何抗背景主导？”答：按前景重叠归一；L3 问“ε 随便加？”答：需尺度和空类协议；L4 问“梯度只依该像素？”答：A、B 耦合全域；L5 问“空真值默认满分？”答：预测非空不能满分，双空需约定。易错：所有 Dice 公式是同一损失。证据入口为本卡来源。

### C24 Focal Loss

任务／前提／状态：logits＋标签 → 降权容易样本的损失；需区分类别不平衡和标签噪声。演进：2017 密集检测易负样本主导 → CE 乘难度因子 → 聚焦难例 → 新超参和梯度变化 → 错标难例也会被关注。本地未实现；覆盖见协议；来源：[cite:11](#lc-source-11)，原论文检索摘要已核。

- **L1 步骤**：算真实类概率 pt；给类别权重 αt；计算 `FL=-αt(1-pt)^γ log(pt)`；过滤忽略区后归约反传。二元 sigmoid 与多类 softmax 版本应分开，训练结束按通常验证协议。
- **L2 机制**：pt 接近 1 时难度项小，大量容易样本贡献被压低；γ 控难易，α 调类权重，两者不等价。不加区分地强调难例也可过拟合错标。
- **L3 工程**：先验证标签质量和正负样本比例，再选 α、γ 及采样；二者无量纲。检查按难度／类别拆分的梯度和召回，不只 total loss；不能断言 focal 一定比 CE 优。
- **L4 推导**：γ=0 退化为加权 CE；`dFL/dpt=α[γ(1-pt)^(γ-1)log(pt)-(1-pt)^γ/pt]`，再乘概率对 logit 的导数。难度权重本身有梯度，不能把它当固定 sample_weight 后声称完全等价。
- **L5 实现**：参考 log_softmax／稳定 BCE 构造 logpt，再算调制项；有 α 时不能简单由“已加权 CE 的 exp(-loss)”恢复 pt。测 γ=0 等价性、极易／极难、极端 logit、ignore 与梯度；无本地运行结果。

**分层面试答案**：L1 问“核心公式？”答：CE 乘 αt(1-pt)^γ；L2 问“减谁贡献？”答：容易样本；L3 问“γ 解决类别权重？”答：和 α 作用不同；L4 问“γ=0？”答：加权 CE；L5 问“可 detach 调制权？”答：会改变梯度目标。易错：难例必是有价值真样本。证据入口为本卡来源。

## 回归损失与验收指标

### C25 L1 绝对误差与边缘偏移监督

任务／前提／状态：连续预测与真值偏移 → 绝对误差损失；偏移的通道、有效点及单位必须一致。演进：平方误差受异常点强影响 → 绝对残差 → 降低大残差影响 → 零点不可微 → 系统偏差仍在。本地有 L1 意图但索引存在静态错误；覆盖见协议；来源：[cite:2](#lc-source-2)。

- **L1 步骤**：按 heat 定义有效边缘点；对齐预测／真值 dx,dy；只取有效分量的绝对差并按明确分母平均；无边缘时返回可参与总损失的零分支，不能误报为整个模型无误差。
- **L2 机制**：梯度幅值不随大残差线性增长，比 MSE 少被异常点支配；按分量 L1 不是欧氏距离。若直接全图平均，背景量改变会稀释偏移监督。
- **L3 工程**：偏移单位为 px 或物理长度，L1 同单位；先核 XY 顺序与标签中心，再查有效区、分母和任务权重。提高 w_off 不会修正 shape 索引，需看有效边缘数量与梯度比例。
- **L4 推导**：独立 Laplace 残差假设的负对数似然为 `|r|/b+常数`；常量预测最小期望绝对误差得到条件中位数。非零处导数 sign(r)，零处用次梯度；这不是正态模型下的均值估计，也无通用物理误差上界。
- **L5 实现**：本地 `pred[:,1:]` 是 B2HW，m 是 BHW，`pred[:,1:][m]` 不对齐；参考路线是先将偏移变 BHW2，再用 m，真值需同布局；或把 m 扩为 B1HW 再按有效分量计数。测非空、空、单点、dx/dy 置换；本次只记录，不修改、不运行 torch。

**分层面试答案**：L1 问“监督哪里？”答：协议定义的边缘有效点；L2 问“比 MSE 鲁棒为何？”答：大残差梯度不持续变大；L3 问“offset 权重单位？”答：要与像素／物理残差尺度匹配；L4 问“估计均值还是中位数？”答：条件中位数；L5 问“本地具体问题？”答：B2HW 被 BHW mask 直接索引。易错：有 loss_fn 即训练可用。证据入口为本卡来源。

### C26 均方误差 MSE

任务／前提／状态：连续预测与真值 → 平方残差均值；同形、同坐标、同单位。演进：回归需可微误差目标 → 平方残差 → 平滑梯度和均值估计 → 异常点大权重 → 模糊标签可能回归平均。本地 FocusNet 实际调用 F.mse_loss；覆盖见协议；来源：[cite:2](#lc-source-2)，源码与统计推导。

- **L1 步骤**：前向预测 B 个离焦量；与 B 标签对齐，逐项平方差平均；zero_grad、backward、Adam step；训练按 epoch 或验证停。当前没有完整 Dataset／验证接线。
- **L2 机制**：大残差被平方放大，梯度随残差增大；多解或正负离焦外观近似时可能学均值，loss 下降不代表离焦可辨识。平均有符号残差不是 MSE。
- **L3 工程**：MSE 单位为标签单位平方；先核正负方向、标定与 shape，再检查离群点、目标标准化及学习率。归一化改变 loss 数值尺度，不能直接比较不同单位的曲线。
- **L4 推导**：固定方差独立高斯残差的 NLL 与 `Σr²/(2σ²)` 差常数；最小条件期望平方误差得到 `f*(x)=E[y|x]`。均值归约梯度 `2r/n`；对预测凸，不代表对 FocusNet 参数凸。RMSE=sqrt(MSE)，量纲回到标签单位。
- **L5 实现**：本地输出 `.squeeze(-1)` 为 B，标签必须也是 B；B1 与 B 广播可形成错误 B×B 损失。空 loader 会让末尾 loss 未定义，骨架未防护。测 B=1、多样本 shape、零残差、梯度和空 loader 策略；不把旧注释“一两帧收敛”当实测。

**分层面试答案**：L1 问“先怎样对齐？”答：预测与真值同形同单位；L2 问“异常点为何影响大？”答：平方惩罚；L3 问“换米为毫米？”答：MSE 随单位平方缩放；L4 问“估计什么？”答：条件均值；L5 问“无报错但 loss 异常？”答：查 B／B1 广播。易错：训练损失下降证明单帧离焦符号可辨识。证据入口为本卡来源。

### C27 IoU／Jaccard

任务／前提／状态：离散预测与真值区域 → 交并比；需要有效区、类别与实例匹配协议。演进：像素准确率受背景支配 → 集合交并归一 → 区域重叠验收 → 空集与聚合成本 → 边界／拓扑仍不完整。本地 tests/metrics.py 无实现；覆盖见协议；来源：[cite:1](#lc-source-1)[cite:2](#lc-source-2)，总览已读、历史原文未重访。

- **L1 步骤**：固定阈值／argmax、坐标恢复和 ignore；每类统计 TP、FP、FN；算 `TP/(TP+FP+FN)`，再按事先约定做 macro／micro；双空单独处理。实例任务先匹配对象，再计算／汇总，不与语义 IoU 混用。
- **L2 机制**：交集奖正确重叠，并集同时惩罚多报与漏报，TN 不参与；同类两实例合并可能语义 IoU 高但计数错，所以需实例和边界指标补充。
- **L3 工程**：IoU 无量纲；先定是否含背景、空类和图像／类别权重，再定验证门限。阈值在验证集确定后冻结，测试集不逐图调；按缺陷尺寸／设备分层避免均值掩盖小目标漏检。
- **L4 推导**：`|P∪G|=|P|+|G|-|P∩G|`，故 J=TP/(TP+FP+FN)。同一非空二值集合上 `D=2J/(1+J)`，但 `mean(D)` 一般不等于 `2mean(J)/(1+mean(J))`；hard IoU 不对阈值选择提供常规可微梯度。统计 O(N)。
- **L5 实现**：参考布尔交并或 int64 confusion matrix，先过滤 ignore 再计数。双空可约定记 1 或排除，但要报告规则和覆盖数；真值空、预测非空应为 0。测试 identical、disjoint、subset、双空、非法类和不同聚合；不能把 SAM 预测质量字段当真实 IoU。

**分层面试答案**：L1 问“分母是什么？”答：并集；L2 问“高 IoU 能计数准？”答：不能；L3 问“空类怎么做？”答：先约定并报告；L4 问“Dice 关系？”答：同集合 D=2J/(1+J)，均值不可直接换；L5 问“SAM pred_iou 是实测？”答：质量回归。易错：用大背景像素准确率替代前景 IoU。证据入口为本卡来源。

## 跨组件实施与验证边界

| 任务链 | 应接组件 | 不应混用 |
|---|---|---|
| 手工特征区域判别 | 分组训练 → scaler（按模型需要）→ SVM／RF／GBDT → 空间后处理 | HOG 候选重排不能直接冒充像素分割 |
| 互斥多类区域 | 卷积／上下文 → K logits → CE，可组合明确定义的 Dice | 单通道 softmax；标签线性插值 |
| 二值／多标签 | 各通道 logits → BCEWithLogits，可加 Dice／focal | 预先 sigmoid 后再 WithLogits；把独立标签强制互斥 |
| 边缘＋偏移 | heat BCE＋有效边缘 dx/dy L1 | heat 是边缘而非物体内部；mask 布局必须与偏移对齐 |
| 离焦回归 | FocusNet → 标量 → MSE＋Adam | 自动推出闭环一两帧收敛或分割精度 |
| 验收 | 冻结协议 → IoU／Dice＋边界／实例／物理量 | 将 soft 训练损失、质量预测和实测指标混成一个数字 |

测试设计遵循先契约、再数学、后业务：shape／dtype／坐标／有效 mask；解析梯度与不变量；分组验证、模型与统计持久化；最后真实业务独立验收。计时需包含预处理、设备传输与后处理，GPU 异步需同步后测，不在缺失依赖条件下提供性能数字。

本次完成的是文档与源码静态核验、组件覆盖、引用路径和文件变更范围检查。没有 torch／sklearn 训练或前向实测，没有新增可执行组件；测试清单仍是设计，C25 的索引问题也没有被本次修复。L3–L5 因此保持“部分”。
