## 2. 灰度、频域、形状与直接法

### 01. 匹配滤波

**任务／前提／演进／状态：R。** 已知非零有限能量信号、零均值加性噪声 → 线性检测响应及峰。North 1943 报告／1963 重印是早期理论来源，不是全部匹配的唯一起源。改进是最优汇集已知形状的信号能量，代价是依赖噪声模型；仓库没有独立匹配滤波检测器。[cite:1](#source-1)

**L1 步骤。** 固定支持和信号 → 确认白噪声协方差 → 取共轭反转核 → 滑动滤波 → 把采样延迟换为目标位置 → 根据背景标定阈值 → 输出或拒绝；合法候选扫描完停止。信号能量零时拒绝建模。

**L2 机制。** 与信号同向的权重使证据相干累加；任意亮背景不满足白噪声假设。ZNCC 分母随窗口变化，整个运算不再是固定线性滤波，不能直接继承匹配滤波最优性。

**L3 工程。** 响应单位由灰度、模板幅值和支持长度共同决定；先检查背景平稳性与协方差，再限定位置范围，最后选虚警阈值。有色噪声应考虑卡 37，而不是只调普通相关阈值。模板失配会降低输出 SNR。

**L4 推导。** \(x=s+n,E[nn^H]=\sigma^2I\)，输出 \(z=w^Hx\)。Cauchy–Schwarz 给出 \(|w^Hs|^2/(\sigma^2w^Hw)\le s^Hs/\sigma^2\)，等号当 \(w\propto s\)。卷积核为 \(h(t)=ks^*(t_0-t)\)。证明只用二阶矩，不要求高斯；固定虚警率的概率检测最优性另需分布与假设。直接滑动为 \(O(Pn)\)。

**L5 复现设计／数值与测试。** 复数须共轭，核延迟与 `valid` 原点须统一；用非对称已知信号核对峰方向，用单位协方差验证白化退化关系，用无信号背景评估虚警。未运行该检测器，也没有 North 全文逐项复现。

**面试追问与答案。** L1：滤波后直接读峰下标？答：先扣核与坐标延迟。L2：任何相关都最优？答：只限指定线性 SNR 模型。L3：条纹背景先调什么？答：先查有色噪声。L4：需要高斯吗？答：SNR 证明不需要，检测概率结论另论。L5：复杂数错误在哪？答：漏共轭。易错：把 ZNCC 当同一线性滤波器；证据为本节推导与来源 1。

### 02. SAD：绝对差和

**任务／前提／演进／状态：R。** 对齐同支持灰度块 → 最小差异位置。基础直接比较分支；以线性残差惩罚替代严格像素相等，代价是亮度敏感。两个 NCC 接口都没有 SAD 模式。[cite:2](#source-2)

**L1 步骤。** 先提升数值类型 → 遍历合法窗口 → 求绝对差并加和 → 取最小 → 阈值和空间抑制 → 返回位置；穷尽或合法严格界剪枝停止。无合法位置应报错。

**L2 机制。** 大残差只线性增长，相比 SSD 单个异常像素影响较小；仍不是任意遮挡鲁棒。常数亮度偏置使所有真实对应像素产生非零误差，不能靠增加搜索精度消除。

**L3 工程。** 总和单位为灰度且随 n 增长，均值 SAD 才去掉支持数量因子。先统一曝光／位深，再核对支持与噪声，再标定阈值；跨模板或尺度比较需固定归一口径。

**L4 推导。** 独立同尺度 Laplace 残差 \(p(e)=e^{-|e|/b}/(2b)\)，负对数似然为常数加 \(\sum|I_i-T_i|/b\)，故最小 SAD 是该模型下最大似然。非负部分和是完整误差下界。直接复杂度 \(O(Pn)\)；目标不可微点不能直接用 SSD 的导数。

**L5 复现设计／数值与测试。** `uint8` 相减前转宽类型；确定最大累积值不溢出；逐项参考与批量版逐窗比较，测试相等块、加偏置、单异常点、首尾窗口、并列最小。OpenCV 六种模板模式没有 SAD，本地未新增实现或测试。

**面试追问与答案。** L1：取最大还是最小？答：最小。L2：比 SSD 抗大残差为何？答：线性而非平方惩罚。L3：窗口变大阈值不变？答：总和尺度改变。L4：对应何种噪声？答：同尺度独立 Laplace。L5：先减再转 float？答：会先发生无符号回绕。易错：宣称天然抗光照；证据为卡 02 公式与来源 2。

### 03. SSD：平方差和

**任务／前提／演进／状态：R。** 同支持块 → 最小平方残差位置；直接法的基础目标，可导局部近似支持 LK，代价是大外点权重大。未作为本地匹配入口实现。[cite:2](#source-2)[cite:3](#source-3)

**L1 步骤。** 提升类型 → 求差 → 平方求和或用相关展开 → 最小化 → 候选验证；直接搜索穷尽停止，连续优化则须另外定义初值和停止条件。

**L2 机制。** 平方惩罚把大残差突出，适合同方差高斯噪声模型；亮度偏置、增益和遮挡会影响目标。删除窗口能量项会变成不同排序，并非无损提速。

**L3 工程。** 单位是灰度平方，增益 a 对纯差的误差尺度为 a²；先查残差空间分布，必要时换光度模型或鲁棒损失，不首先增迭代。直接法与 FFT 展开在小 ROI 上需实际比较成本。

**L4 推导。** 独立 \(e_i\sim N(0,\sigma^2)\) 时负对数似然是常数加 \(E/(2\sigma^2)\)，\(E=\sum(I_i-T_i)^2=Q_I+Q_T-2\sum I_iT_i\)。只有 \(Q_I\) 对所有候选相等，最小 E 才等价最大相关；异方差应使用加权 SSD。直接 \(O(Pn)\)。

**L5 复现设计／数值与测试。** 先转类型再平方，展开式可能发生相消而得到微负值；用直接残差和作为参考，对大偏置弱差、饱和、近相等块及亮斑干扰逐值核对。不能仅比较 argmin 后宣称评分等价；本地未实现独立 SSD。

**面试追问与答案。** L1：两条计算路径？答：逐差平方或三项展开。L2：相关为何不能直接替代？答：局部能量不恒定。L3：外点多怎么办？答：检查模型并考虑鲁棒目标。L4：高斯条件？答：独立同方差。L5：负 SSD 可能何来？答：展开大数相消。易错：删除 Q 项；证据为展开式及来源 3。

### 04. 原始互相关

**任务／前提／演进／状态：M。** 固定模板与图像 → 未归一化响应。连接匹配滤波与快速模板比较；保留亮度能量线索，也受其干扰。本地 ZNCC 分子用相关，但无独立原始相关定位 API。[cite:1](#source-1)[cite:3](#source-3)

**L1 步骤。** 固定支持、原点和实／复数约定 → 每位置内积或 FFT → 最大峰 → 阈值／拒识。遍历结束；零核须判为没有区分信息。

**L2 机制。** 对应符号同向时响应增加，但高能量错误窗口可胜过真窗口。相关与卷积核方向相反；删除翻转会把模板镜像信息带入计算。

**L3 工程。** 响应随模板长度、模板和图像幅值变化；先控制成像与支持，再看最大峰和竞争峰。不同模板不能直接共用响应阈值，FFT 不自动去均值或白化。

**L4 推导。** \(c(u)=\sum_i\overline{T_i}I_{u+i}\)，\(c\le\|T\|\|I_u\|\) 的实值版本解释能量依赖；变换域相关用一侧共轭。直接 \(O(Pn)\)，FFT \(O(F\log F)\)，不改变几何自由度。

**L5 源码／测试设计。** [ncc_matching.py](../../traditional/template_matching/ncc_matching.py) 35 行把中心化实核双轴反转传给 `fftconvolve`。测试非对称模板、全图等模板、边缘峰、复数共轭和强亮斑；现有测试只覆盖 ZNCC 链，独立相关检测未运行。

**面试追问与答案。** L1：卷积核如何构造？答：共轭反转。L2：亮斑为何高分？答：能量未控制。L3：FFT 能解决光照？答：不能。L4：与 SSD 等价条件？答：窗口能量恒定。L5：错峰镜像先查什么？答：翻转与裁剪原点。易错：把相关、相位归一和 ZNCC 混称；证据为源码与来源 3。

### 05. NCC：未去均值的归一化相关

**任务／前提／演进／状态：R。** 两个非零灰度向量 → 无量纲余弦相似度；从原始相关消除能量尺度，但保留常数偏置影响。这里明确定义 NCC；文献有将 ZNCC 也叫 NCC 的习惯。本地两个名为 NCC 的入口实际均去均值。[cite:2](#source-2)[cite:3](#source-3)

**L1 步骤。** 取同支持 → 求内积和两侧能量 → 零能量返回不可用 → 除范数 → 取最大及拒识。合法窗口评分完停止。

**L2 机制。** 单位化把比较转成夹角，消除正比例增益，但加常数会改变向量方向。全正高亮平坦块可以彼此接近，分数高不一定有可定位纹理。

**L3 工程。** 理论范围 [-1,1]，阈值不是概率；非负灰度可用分数分布常偏正。先看能量和纹理信息，再决定是否需要 ZNCC，而不是照搬去均值接口的阈值。

**L4 推导。** \(r_N=T^TI/(\|T\|\|I\|)\)。Cauchy–Schwarz 给范围；\(r_N(T,aI)=r_N(T,I)\) 对 a>0 成立。\(T^T(I+b\mathbf1)=T^TI+b\sum T_i\)，分母也变，故一般不具偏置不变性。常量非零 NCC 有定义，区别于常量 ZNCC。

**L5 复现设计／数值与测试。** 累积前缩放可防平方溢出；零能量单独标记，不以小分母制造有效分数。用正增益、反相、常数偏置、全零、非零常量和不同支持比较公式。可参考 `TM_CCORR_NORMED`，但本仓库未接入该模式。

**面试追问与答案。** L1：先去均值？答：本卡不去。L2：加偏置为何变？答：向量方向变。L3：高分有纹理吗？答：未必。L4：范围怎么证？答：Cauchy–Schwarz。L5：常量是否一律退化？答：NCC 仅零向量退化，ZNCC 非零常量也退化。易错：仅凭函数名判断公式；证据为来源 2、3。

### 06. ZNCC：共同数学契约

**任务／前提／演进／状态：K。** 固定同支持、两侧非恒定向量 → 去均值相关。由能量归一进一步消除常数偏置，代价是局部统计及退化处理。本地两实现共享此目标，不共享数值策略。[cite:2](#source-2)[cite:3](#source-3)

**L1 步骤。** 固定有效 Ω → 同支持求均值 → 两向量中心化 → 检查能量 → 点积除范数 → 取峰、抑制与拒识；输出位置或不可用评分。

**L2 机制。** 去均值删除常数子空间，适应正增益和统一偏置，同时丢失绝对亮度区分信息。饱和、反光、非均匀阴影和遮挡破坏该线性关系；取绝对分数匹配反相是另一个目标。

**L3 工程。** 固定支持后再设 [-1,1] 分数阈值；先查姿态、有效纹理、成像，最后用独立正负样本标定。不同姿态的 n 可能不同，同分不表示同统计置信度。阈值不能代替几何检查。

**L4 推导。** \(J=I_n-\mathbf1\mathbf1^T/n\)，\(r_Z=(JT)^T(JI)/(\|JT\|\|JI\|)\)。J 是正交投影，若 \(I=aT+b\mathbf1\)，则 \(JI=aJT\)；a>0 为 1，a<0 为 -1，a=0 退化。\(V=\sum I_i^2-(\sum I_i)^2/n\) 来自平方展开，范数不是除 n 的统计标准差。

**L5 源码／测试。** 两实现均为 `float64`；直接参考必须同一 mask，不能一侧标准差一侧能量而漏掉 \(\sqrt n\)。回归含正增益、偏置、掩膜及旧接口一致性；反相结论是代数，不冒充已有专项运行测试。极端输入差异见卡 07、08、45。

**面试追问与答案。** L1：均值在哪算？答：同一 Ω。L2：删去均值怎样？答：失去偏置不变性。L3：旋转低分先降阈值？答：先查网格与模板。L4：a<0 得多少？答：理想 -1。L5：负方差是真负能量？答：通常大数相消。易错：任意光照不变；证据为推导和来源 2。

### 07. 平移 ZNCC：FFT 分子＋矩形积分图

**任务／前提／演进／状态：K。** 二维图像、非恒定矩形模板 → 评分图或候选列表；Lewis 1995 快速归一化路线的本地实现，降低全窗口重复求和成本；没有掩膜、姿态搜索或分差协议。[cite:3](#source-3)

**L1 步骤。** 转 float64 → 二维／尺寸检查 → 模板减均值 → FFT 分子 → 两张积分图取和、平方和 → 方差下限 → 相除。`find_best_matches` 再阈值、排序、圆形 NMS、可选三点精化，达到数量上限停止。

**L2 机制。** 中心化模板和为零，分子无需逐窗减图像均值；矩形积分图使每位置统计为四角查询。把任意旋转 mask 仍按矩形统计会加入无效像素，改变目标。

**L3 工程。** 旧默认 `min_score=0.9,nms_radius=8,max_count=10`。先看原图量纲、窗口方差与负例，再调阈值；大偏置弱纹理可能使积分图相消。旧接口参数和空／非有限输入检查较弱，不承诺新接口相同异常协议。

**L4 推导。** \(t=T-\mu_T,\sum t=0\)，故 \(\sum(I-\mu_I)t=\sum It\)；\(r=(I\star t)/(\sqrt{Q-S^2/n}\|t\|)\)。FFT \(O(F\log F)\)，积分图 \(O(HW)\)，过阈值 C 个点排序另需 \(O(C\log C)\)。

**L5 源码／数值与测试。** [match_template_ncc](../../traditional/template_matching/ncc_matching.py#L16-L51) 把 `var<1e-12` 置为 `1e-12`，不做可靠性判别、局部兜底或结果裁剪；理想 [-1,1] 不是全部浮点输入保证。`test_legacy_ncc_interfaces` 检查评分图 (113,141)、输出键及两接口普通样例小数一致；本次回归和匹配冒烟通过。

**面试追问与答案。** L1：两张表用途？答：S、Q。L2：分子不减局部均值为何？答：t 零和。L3：极大偏置先查什么？答：方差相消。L4：复杂度降低在哪？答：相关和统计。L5：有直接兜底吗？答：旧版没有。易错：给旧版套新版数值保证；证据为所链源码与测试。

### 08. 姿态 ZNCC：掩膜 FFT 统计实现

**任务／前提／演进／状态：K。** 有限二维图、模板、可选 0/1 mask 和相似变换网格 → 拒识字典及模板到图像 H。由平移扩为离散角度／统一尺度，代价是多姿态、三路相关、支持变化及兜底；不是 LK、ECC 或透视配准。[cite:2](#source-2)

**L1 步骤。** 输入／配置检查 → 模板自评分 → 图像金字塔 → 每姿态画布预检与 warp → 搜索及原图复核 → 有限邻域平移精化 → 输出 H 和角点 → 跨姿态中心 NMS → 分数／分差拒识；所有网格姿态处理后结束。

**L2 机制。** 同 mask 的三次相关保持分子和分母支持一致；排除补边避免假黑纹理。画布必须完整落图，掩膜不赋予出画匹配能力；角度尺度只是离散值，输出小数平移不代表全姿态连续精化。

**L3 工程。** 默认角度 0、尺度 1；分数 0.8、分差 0.03、半径 8 px、3 层、8 候选、1 结果、复核开启。顺序是坐标／物理范围 → 网格 → 支持纹理 → 容量／半径 → 阈值。不能据金字塔推定加速。

**L4 推导。** \(n=\sum M,t=M(T-\mu_T),S=I\star M,Q=I^2\star M,N=I\star t\)，\(r=N/\sqrt{(Q-S^2/n)\sum t^2}\)。每姿态约 \(O(F\log F)\)，F 随画布变化；不可靠 U 个窗口直接计算再增加 \(O(Un)\)，不能把整个实现始终写成 FFT 成本。

**L5 源码／数值与测试。** [pose_ncc.py](../../traditional/template_matching/pose_ncc.py) 要求有效像素≥4；原模板常量抛错，变换后退化跳过。内部无效 `-inf`，诊断缺失 `None`；常量图可已搜索但无峰，区别于 `no_valid_pose`。回归 37 项本次通过；不覆盖真实工况、同中心角度歧义或任意浮点可靠性。

**面试追问与答案。** L1：x/y 是 bbox？答：原模板原点映射。L2：三路卷积为何？答：分子、S、Q 同支持。L3：多层必快？答：默认仍完整复核。L4：非均匀 mask 能用四角表吗？答：一般不能。L5：没峰和没姿态一样？答：不同失败原因。易错：把变换 H 当单应估计；证据为源码与来源 2。

### 09. SSDA：逐次相似性检测

**任务／前提／演进／状态：R。** 大量窗口比较 → 将算力留给有希望的候选。Barnea／Silverman 1972 为代表；Lewis 描述随机部分相关变体。收益依赖数据，统计早停可能漏峰；仓库没有候选内部 SSDA。[cite:1](#source-1)[cite:3](#source-3)

**L1 步骤。** 固定完整评分与支持 → 指定像素访问顺序 → 逐批累计误差或相关证据 → 判断能否继续 → 放弃该候选或算到完整 → 转下一窗口。必须说明用统计估计还是卡 48 的严格界。

**L2 机制。** 差候选少看像素，减少平均工作量；少数关键像素很晚出现时部分证据可误导。NMS、金字塔截断、LightGlue 早停和形状逐行 break 均不能仅因“少算”就叫 SSDA。

**L3 工程。** 参数为访问次序、批大小、早停阈值和种子。先保留完整评分作为参照，再记录访问像素量、漏掉最优峰频率、尾延迟，最后缩预算。困难／重复纹理可能全算，不能承诺固定倍数。

**L4 推导。** 均匀不放回抽样 k 项时，\(\hat c_k=(n/k)\sum_{i\in S_k}T_iI_i\) 是完整和的无偏估计；无偏不意味着每次估计可靠，反复查看并停止还涉及序贯统计。最坏仍 \(O(Pn)\)。非负误差部分和下界另有确定性保证，但不能用于带符号相关的原样剪枝。

**L5 复现设计／测试。** 保存停止点、次序、部分估计和完整真分，对每候选对照；验证窄峰、重复结构、晚出现大贡献以及并列峰。均值和归一化不能随部分样本改变后仍声称同目标。1972 全文获取缺口沿用原专题说明，本卡未运行任何 SSDA。

**面试追问与答案。** L1：退出位置？答：候选内部。L2：无偏就不漏？答：不是。L3：加速看什么？答：访问量及漏峰／尾延迟。L4：SAD 部分和为何能剪？答：非负项单调。L5：怎样证伪早停？答：对照完整分数。易错：所有 break 都是精确 SSDA；证据为来源 1、3 和卡 48。

### 10. 相位相关

**任务／前提／演进／状态：R。** 足够重叠、共享同一平移的两图 → 位移。Kuglin／Hines 1975 代表分支，用相位关系代替逐位移比较；代价是周期歧义和弱频率噪声。仓库无 `phaseCorrelate` 或相位谱归一。[cite:1](#source-1)[cite:4](#source-4)

**L1 步骤。** 约定参考／移动图 → 按需求加窗／补边 → FFT → 可靠频率互功率归一 → IFFT → 取峰并回绕解码 → 可选卡 38 精化 → 重叠与可信度验证。频谱能量不足或无可信峰时失败。

**L2 机制。** 平移变成频率线性相位；归一幅值可削弱增益影响，也会抬高弱谱噪声。加窗减边缘突变却改变严格平移模型；掩膜扩展不必仍是同一基础公式。

**L3 工程。** 位移单位 px，先核符号／回绕再调窗和频谱门限；多运动、低重叠、旋转缩放不靠减阈值修复。亚像素采样间隔不是真实准确度。相位归一与 ZNCC 窗口归一不同。

**L4 推导。** DFT 取负指数，\(B(x)=A(x-d)\) 则 \(F_B=F_Ae^{-i\omega d}\)。取 \(R=F_B\overline{F_A}/|F_B\overline{F_A}|\)，逆变换在 d 处有峰；交换两图得 -d。该式只在非零频率定义；丢失频带后不再严格冲激。复杂度 \(O(F\log F)\)，位移按图尺寸取模。

**L5 复现设计／测试。** 小谱先掩码再除法，不把零谱除 epsilon 后当可信；测试带方向平移、半尺寸回绕、周期纹理、无重叠、加窗前后。scikit-image 返回按数组轴排列的校正位移，通常与目标运动方向相反；未接入本仓库。

**面试追问与答案。** L1：峰后还做什么？答：回绕和方向转换。L2：为何不总抗噪？答：弱谱噪声等权化。L3：有旋转怎么办？答：另用卡 39 或换模型。L4：符号怎么定？答：DFT 与乘积顺序。L5：返回 yx 能直接当 xy？答：不能。易错：FFT-NCC 即相位相关；证据为来源 4 与推导。

### 11. Chamfer 与距离变换匹配

**任务／前提／演进／状态：R。** 模板轮廓点、图像边缘、允许变换 → 最小边缘距离姿态。Barrow 等 IJCAI 1977 从严格重合改为距离容忍；代价是杂边歧义与边缘提取。形状源码没有距离场，不是 Chamfer。[cite:1](#source-1)

**L1 步骤。** 提取图像边缘 → 边缘为零集合构建距离场 → 变换模板点 → 查距离并聚合 → 搜索最小值 → 阈值及覆盖检查；穷尽或局部求解终止。空边集、支持越界应拒绝。

**L2 机制。** 预计算最近边缘距离，避免每姿态逐点寻找最近邻；轻微错位仍有梯度趋势。但多条模板边可能被同一图像边吸引，背景越杂未必距离越大。方向和双向距离是额外约束。

**L3 工程。** 精确欧氏距离单位 px；离散 chamfer 权重是近似代价，应注明尺度。先检查边缘密度、极性和覆盖，再调截断距离与几何范围。截断增强遮挡容忍但也减少区分度。

**L4 推导。** \(D_E(x)=\min_{q\in E}\|x-q\|\)，\(C(p)=n^{-1}\sum_iD_E(W(p_i;p))\)。固定 E 时先构 D，之后每姿态只需 \(O(n)\) 查表；固定维度精确 EDT 可线性构建，但不是将 1977 离散近似称为精确欧氏实现。\(\min(D,\tau)\) 为另一个鲁棒目标。

**L5 复现设计／测试。** 确保库的零集合确实是边缘；连续点采样明确 xy 与 yx，越界不默默当零距离。用已知直线距离、空边缘、平行线、杂乱边、部分缺边检查单位和歧义；未运行本地 Chamfer。

**面试追问与答案。** L1：D 算几次？答：固定图像边集一次。L2：杂边为何危险？答：错误轮廓也有近边。L3：近似距离就是 px？答：需定义权重换算。L4：加速由来？答：最近邻变查表。L5：前景反了怎样查？答：验证零集合。易错：方向点积等于距离；证据为来源 1 和形状源码。

### 12. 稀疏梯度方向形状匹配

**任务／前提／演进／状态：K。** 灰度模板、图像 → 最佳整数平移三元组。用强梯度方向降低绝对亮度依赖，代价是丢失灰度幅值信息和 Python 扫描；是本地教学基线，不是商业 shape-based 系统等价复现。

**L1 步骤。** Sobel 3×3 → `mag>20` → 取前 `top_k=200` 点 → 单位方向和幅值归一权重 → 图像 Sobel → 扫描平移 → 完整点集正内积评分 → 每行后检查早停 → 返回当前最优。无特征抛错。

**L2 机制。** 正增益和偏置不改变理想非零梯度方向，负增益使方向反转被非负点积截断。提点阈值和模板权重依赖幅值，因此整个提点流程不对任意光度变化不变；零图像梯度贡献为零。

**L3 工程。** `min_mag` 是 Sobel 响应单位，归一到 0–1 后不能照搬 20。先看特征覆盖和极性，再调 top_k。`min_score` 仅用于行级 `max(min_score,0.98)` 早停，低分仍返回；调用侧应另设计拒识。

**L4 推导。** \(w_i=m_i/\sum m_i\)，\(S(u)=\sum_iw_i\max(0,d_i^Tg(u+p_i)/\|g(u+p_i)\|)\)。单位向量与凸权重给 \(0\le S\le1\)，零梯度定义贡献 0。梯度 \(O(HW)\)，评分 \(O(PK)\)；0.98 早停不能证明后续不存在更高峰。

**L5 源码／测试。** [shape_based.py](../../traditional/template_matching/shape_based.py#L18-L73) 用点集最大坐标算上界、`u_min/v_min>=1`，不是完整模板矩形全边界搜索；无旋转、尺度、亚像素或完整非法输入保护。本次形状冒烟断言通过；边界、非法 top_k 和早停最优性无专项覆盖。

**面试追问与答案。** L1：有亚像素？答：没有。L2：反相为何不稳？答：保留方向极性。L3：0.7 会拒绝 0.5？答：现接口不会。L4：上界 1 怎么来？答：单位点积凸加权。L5：为何零原点不搜？答：源码下界至少 1。易错：称为 Chamfer／完整 HALCON；证据为所链源码。

### 13. Lucas–Kanade（LK）前向局部配准

**任务／前提／演进／状态：R。** 两图、合理初值、局部亮度一致与足够梯度 → 局部变换。Lucas／Kanade 1981 用梯度线性化替代枚举；代价是局部捕获范围、孔径问题。逆组合另见卡 40，不全部归给 1981。仓库未实现匹配／跟踪 LK。[cite:1](#source-1)[cite:5](#source-5)

**L1 步骤。** 定义模板到移动图 warp → 采样 → 算残差、梯度及 Jacobian → 解小增量 → 更新参数 → 检查有效支持和目标改善；增量足够小、目标变化小或预算用尽停止，失败须与收敛分开。

**L2 机制。** 当前初值附近的一阶近似提供下降方向。单边缘的切向运动不可辨，平坦块无梯度；增加迭代不能创造信息。金字塔可扩大实用捕获范围，但不构成全局收敛保证。

**L3 工程。** 窗口 px、金字塔层、迭代数、停止 epsilon 不同量纲。先查初值与梯度最小特征值，再查多运动／遮挡和窗口，再调迭代。跟踪可用前后向误差检查失锁，但该扩展未接入。

**L4 推导。** \(E(p)=\frac12\sum[I(W(x;p))-T(x)]^2\)，\(r=I(W)-T,J=\nabla I(W)\partial W/\partial p\)。\(r(p+\delta)\approx r+J\delta\)，令导数零得 \(J^TJ\delta=-J^Tr\)。满列秩才局部可辨；线性同方差模型下协方差近似 \(\sigma^2(J^TJ)^{-1}\)，不是实际误差上界。每步约 \(O(nd^2+d^3)\)。

**L5 复现设计／测试。** 用 QR／SVD 而非盲求逆，有限差分核对 Jacobian 符号；插值梯度须与采样约定一致。测平坦、单边缘、小位移、远初值、遮挡和越界；预算耗尽不得伪装成功。NCC 抛物线峰拟合不是 LK。

**面试追问与答案。** L1：何时停？答：收敛或预算，但原因不同。L2：单边缘漂移为何？答：J 缺秩。L3：一直加迭代有效？答：先查初值和可观测性。L4：正规方程从哪来？答：线性化平方残差。L5：方向错怎么测？答：有限差分及已知位移。易错：把 LK 当无初值全局搜索；证据为来源 5 与推导。

### 14. ECC：相关系数连续参数配准

**任务／前提／演进／状态：R。** 两图、稳定支持、合理初值 → 连续几何参数。Evangelidis／Psarakis TPAMI 2008 最大化归一化相关，改善原始 SSD 光度敏感；代价是归一化和局部优化。仓库没有 ECC 更新或 `findTransformECC`。[cite:1](#source-1)[cite:6](#source-6)

**L1 步骤。** 选变换族及初值 → warp → 中心化图像 → 算一致的 Jacobian → 解局部 ECC 更新 → 检查有效支持／相关变化 → 停止或拒绝；不得无条件接受最后矩阵。

**L2 机制。** 比较中心化单位向量，消除正统一增益与偏置；不是任意阴影不变。连续优化不同于 ZNCC 网格取峰，三点平移精化也不是 ECC。自由度过多会把真实缺陷配准掉。

**L3 工程。** 先粗定位再选最小物理模型，检查支持、残差和投影形状，再改迭代预算。OpenCV 终止 epsilon 是相关变化，不是毫米精度。低纹理、低重叠、初值远时应回退，而不是只降低阈值。

**L4 推导。** 中心化向量 t、i(p)，\(\rho=t^Ti/(\|t\|\|i\|)\)，单位向量平方差为 \(2-2\rho\)。令中心化 Jacobian J，\(A=J^TJ,g_i=J^Ti,g_t=J^Tt\)，局部求解 \(\delta=A^{-1}(\lambda g_t-g_i)\)。由残差对 J 正交、对光度尺度驻定消去增量，得 \(\lambda=(i^Ti-g_i^TA^{-1}g_i)/(t^Ti-g_t^TA^{-1}g_i)\)。需 A 满秩及适用分支的分母为正、远离零；只是线性近似步，不是全局保证。

**L5 复现设计／测试。** 解线性系统、不显式求逆；检查去均值后的 J、warp 方向、非有限矩阵、停止异常。用正增益偏置、低纹理、远初值和不同 mask 支持对照；OpenCV 对齐常用 `WARP_INVERSE_MAP`，须区分返回几何方向和重采样。未运行本地 ECC。

**面试追问与答案。** L1：单位矩阵算初值吗？答：算，未必足够近。L2：比 SSD 抗亮度为何？答：中心化归一。L3：高相关就放行？答：还查模型、支持与覆盖。L4：解析步无条件？答：满秩和分母等条件。L5：最常错何处？答：方向、J 中心化、失败协议。易错：局部解析即全局最优；证据为来源 6 和本节推导。

## 3. 局部特征、鲁棒几何与学习组合

### 15. RANSAC

**任务／前提／演进／状态：R。** 含外点对应、几何模型和残差定义 → 模型及内点集合。Fischler／Bolles 1981 以小样本共识避免全部点最小二乘被外点拖偏；代价是随机预算和退化风险。学习源码仅文字提名，没有可执行 RANSAC。[cite:1](#source-1)

**L1 步骤。** 选择模型与最小样本数 → 抽不同对应 → 检查退化 → 拟合 → 全部点算残差 → 更新共识及预算 → 达停止条件后用内点重拟合 → 再验证几何；不足点或无有效模型返回失败。

**L2 机制。** 偶然全内点样本可产生合理模型；全内点也可能共线，或来自一个错误重复图案。内点率不等于目标存在概率；点匹配器和 RANSAC 职责不同。

**L3 工程。** 重投影阈值是所在坐标系的 px，缩图要换算。先选物理模型、检查覆盖与重复点，再按噪声定门限，最后设成功概率和最大预算；阈值过宽会把错配并入共识。

**L4 推导。** 理想单次全内点概率 q≈wˢ，N 次全失败概率 \((1-q)^N\le1-p\)，故 \(N\ge\lceil\log(1-p)/\log(1-q)\rceil\)。有限总体单次无放回概率为 \(\binom{N_{in}}s/\binom{N_{all}}s\)，且须考虑退化。w=0 无有限保证；w=1 且非退化可一次。成本主要是迭代次数乘对应数。

**L5 复现设计／测试。** 用 `log1p(-q)` 避免小 q 消减误差，设置硬预算；测共线、重复点、低内点率、错误一致图案和缩放坐标。内点重拟合后重新算残差。骨架 `min_inliers=30` 未执行，不能当有效门限；未运行本地 RANSAC。

**面试追问与答案。** L1：何时重拟合？答：选出共识后。L2：全内点必成功？答：还须非退化。L3：阈值怎么定？答：像素噪声与坐标尺度。L4：公式保证什么？答：理想至少一次全内点抽样。L5：矩阵有限够吗？答：还检查覆盖、投影和物理范围。易错：RANSAC 自动生成特征；证据为来源 1 和骨架。

### 16. SIFT

**任务／前提／演进／状态：R。** 有可重复局部纹理的图像 → 尺度／方向关键点及描述子。Lowe 1999 会议版／2004 期刊版解决局部尺度旋转适应，代价是尺度空间和浮点描述开销；不完全透视不变，仓库未接入。[cite:1](#source-1)[cite:7](#source-7)

**L1 步骤。** 高斯尺度空间 → DoG 三维极值 → 位置／尺度二次定位 → 去低对比及边缘响应 → 主方向 → 局部方向直方图描述 → 最近邻／ratio → 几何验证；尺度层遍历完停止，不可靠支持丢弃。

**L2 机制。** 自身尺度和主方向规范化采样，空间／方向分箱容许小变形；去边缘响应排除沿边定位差的点。完全无纹理无法通过尺度空间创造对应；部分遮挡仅使部分局部点仍可能可见。

**L3 工程。** 先看 octave 覆盖和点的空间分布，再调对比度／边缘门限及数量，最后调 ratio。标准描述为 4×4×8=128 维，L2 距离；库的层数及阈值换算不能盲搬论文常数。

**L4 推导。** \(L=G_\sigma*I,D=L(k\sigma)-L(\sigma)\approx(k-1)\sigma\partial_\sigma L=(k-1)\sigma^2\nabla^2L\)。局部二次模型驻点 \(\delta=-H^{-1}g\)。空间 Hessian 的正行列式条件下，曲率比门限可写 \((\mathrm{tr}H)^2/\det H<(r+1)^2/r\)。这些是特征稳定筛选，不是下游定位误差界。

**L5 复现设计／测试。** 极值比较 3×3×3 内其余 26 点；描述使用对应高斯尺度，归一前防零范数，论文限幅 0.2 后再归一不是 ratio 阈值。测平坦、单边缘、尺度层间极值、90°旋转和边界，固定 KeyPoint 坐标／角度约定。没有本地 SIFT 运行结果。

**面试追问与答案。** L1：四大阶段？答：极值、精定位、方向、描述。L2：为何删边缘点？答：定位条件差。L3：点多 H 仍差？答：查覆盖和重复纹理。L4：DoG 近 LoG 从哪来？答：尺度 Taylor 展开。L5：用 Hamming？答：标准浮点 SIFT 用 L2。易错：全仿射／透视不变；证据为来源 7。

### 17. FAST

**任务／前提／演进／状态：R。** 灰度图 → 角点候选，非描述子。Rosten／Drummond 2006 代表版本用圆周比较与学习决策树降低检测成本；代价是阈值、尺度和方向需外部处理。仓库未实现 FAST。[cite:8](#source-8)

**L1 步骤。** 对合法中心读取半径 3 的 16 像素圆 → 按中心±t 分亮／暗／相近 → 检验连续 n 个同亮或同暗 → 算角强度与 NMS → 输出位置；全图扫描后停止，空集合法。

**L2 机制。** 连续段测试比零散亮点约束强；快速必要条件可剔除明显非角点。FAST-12 四个正交检查点至少三同类的规则不能原样用于 FAST-9，学习树也须说明与完整测试的等价范围。

**L3 工程。** t 是灰度差、n 是连续段长。先检查位深和模糊，再调 t／NMS，最后增加外部尺度层；降低 t 会引入噪点。固定 FAST 变体与响应定义，不以同名推定同结果。

**L4 推导。** 令 \(b_j=[I_j>I_p+t],d_j=[I_j<I_p-t]\)，通过条件是存在 k 使 \(\prod_{j=0}^{n-1}b_{(k+j)\bmod16}=1\) 或暗段同式成立。连续 12 点必含四个等间隔检查点至少三个，得到必要条件而非充分条件。固定 16 点令全图最坏 \(O(HW)\)。

**L5 复现设计／测试。** 环形索引处理首尾跨越，明确等号落入哪类；先宽类型做强度差。测所有起点的连续段、交替亮暗、直边、常量和距边界不足 3 的点；不存在描述子时不得直接调用匹配。未运行该算法。

**面试追问与答案。** L1：检测后能直接匹配？答：还需描述。L2：四点通过够吗？答：只是必要条件。L3：0–1 图 t=20？答：量纲错。L4：为何三检查点？答：12 连段的覆盖关系。L5：漏跨零段怎么办？答：循环索引。易错：任意 n 个亮点就算；证据为来源 8。

### 18. BRIEF

**任务／前提／演进／状态：R。** 外部关键点及局部图像 → 二值描述子。Calonder 等 ECCV 2010 用平滑后点对比较减少计算／存储，代价是原始形式旋转敏感；本地未实现。[cite:9](#source-9)

**L1 步骤。** 取点和支持 → 平滑 → 使用固定点对模式采样 → 比较产生 bit → 打包 → Hamming 匹配；支持不够的点丢弃并同步描述子行号，点集处理完停止。

**L2 机制。** 平滑减少噪声翻 bit，固定模式使同一 bit 跨图有相同含义；每图重新随机抽点对会破坏可比性。原始 BRIEF 无主方向补偿，旋转后采样的结构改变。

**L3 工程。** 描述长度分 bit／byte，256 bit 是 32 byte；点对半径、平滑核和长度共同影响抗噪和区分度。先看方向差和模糊，再调描述参数及匹配阈值；不把二值串看成浮点向量哈希。

**L4 推导。** \(b_k=[\tilde I(p+a_k)<\tilde I(p+c_k)]\)，\(d_H=\sum_k[b_k^A\ne b_k^B]\)。比较差接近零时易被噪声翻转。严格单调光度映射对未经平滑的同位置比较保序，但一般非线性映射与平滑不交换，因此不能宣称实际 BRIEF 对任意单调变换严格不变。

**L5 复现设计／测试。** 固定模式、bit 顺序、边界平滑，XOR＋popcount 而非 byte L2；库可能丢边界点，使用返回的点列表对应描述子。测位打包、边界、反相、旋转和近零差；contrib BRIEF 不因已装 `opencv-python` 就一定可用，本地未运行。

**面试追问与答案。** L1：关键点谁给？答：外部检测器。L2：每图随机模式可否？答：不可。L3：32 指什么？答：核接口，常是 byte。L4：为何 Hamming？答：计二值测试不一致。L5：行数少了？答：可能边界点被删。易错：原始 BRIEF 天生旋转不变；证据为来源 9。

### 19. ORB

**任务／前提／演进／状态：R。** 图像 → 多尺度定向点及二值描述。Rublee 等 ICCV 2011 组合定向 FAST 和 rBRIEF，降低浮点特征开销；代价是有限尺度覆盖和模糊／视角敏感。仓库无 ORB 管线。[cite:1](#source-1)[cite:10](#source-10)

**L1 步骤。** 金字塔 → FAST → 响应排序／预算 → 强度质心方向 → 旋转固定选择的 BRIEF 测试 → 二值描述 → 距离过滤 → 几何验证；层和点预算处理完停止。

**L2 机制。** 方向补偿让描述跟随平面旋转，rBRIEF 偏好均衡且低相关测试以提高区分度；对称或低对比 patch 的一阶矩近零时方向不稳定。有限金字塔不是任意尺度不变。

**L3 工程。** 先看各层覆盖，再调特征数、scaleFactor、层数和边界；密集重复点只增成本。OpenCV `WTA_K=2` 对应 Hamming，3/4 对应 Hamming2，不能沿用同一距离阈值。论文耗时不是本地节拍。

**L4 推导。** \(m_{pq}=\sum x^py^qI(x,y),\theta=\mathrm{atan2}(m_{01},m_{10})\)；测试位置乘旋转矩阵。bit 为 1 的概率 p 时方差 p(1−p) 在 1/2 最大，解释均衡测试偏好，不证明实际 bit 独立。匹配复杂度仍随两图点数乘积增长。

**L5 复现设计／测试。** octave 坐标映回原图，检查图像 y 向下与 KeyPoint 角度约定，不能直接塞给 pose_ncc 的视觉逆时针参数。测旋转、对称 patch、边界、WTA 距离类型和空点；模式训练／选取不是每次推理重抽。未执行 ORB。

**面试追问与答案。** L1：仅 FAST＋BRIEF？答：还有尺度、选点、方向、测试选择。L2：为何选低相关 bit？答：减少冗余。L3：改 WTA 要改什么？答：距离类型。L4：方向何时退化？答：一阶矩近零。L5：角度能混用？答：先换约定。易错：ORB 永远比 SIFT 准；证据为来源 10。

### 20. SURF

**任务／前提／演进／状态：R。** 灰度图 → blob 类关键点及浮点描述。Bay／Tuytelaars／Van Gool ECCV 2006，后续 2008 扩展有 Ess；积分图盒滤波近似 Hessian 降成本，代价是核近似与离散尺度。仓库未实现。[cite:11](#source-11)

**L1 步骤。** 积分图 → 多尺寸盒滤波 Hessian → 空间尺度极值及定位 → Haar 主方向 → 定向 4×4 子区累积响应 → 64 维归一描述 → L2 匹配。upright 形式省略方向，仅用于方向受限场景。

**L2 机制。** 每个盒滤波由固定次矩形查询组成，与核面积无关；增大滤波器构尺度，而非只缩图。Haar 聚合容忍局部变化，但不对显著透视或无纹理自动有效。

**L3 工程。** 阈值依盒响应归一化，先看最小核是否漏小结构，再调层数和 Hessian 门限；64/128 维、upright 改变资源和不变性。库编译选项、代码与权重许可是独立问题，不能从 `import cv2` 推定可用或获商用授权。

**L4 推导。** \(\det H_{approx}=D_{xx}D_{yy}-(wD_{xy})^2\)，常见 w≈0.9 是盒核与导数核能量补偿，不是所有核布局通用常数。子区 \(v=(\sum d_x,\sum d_y,\sum|d_x|,\sum|d_y|)\)，16 子区得 64 维。每尺度过滤 \(O(HW)\)，全算法仍依尺度与点数。

**L5 复现设计／测试。** 明确盒核正负和面积归一，用直接卷积对积分表查询；检查 w 在平方内、Laplacian 极性、零范数和坐标回填。测亮暗 blob、近边界、大尺度和旋转。这里只核书目与机制，不声称取得 2006 全文或运行 SURF。

**面试追问与答案。** L1：64 怎样算？答：16×4。L2：为何盒核快？答：固定次四角查询。L3：upright 换来什么？答：速度但失旋转适应。L4：0.9 是普适吗？答：依核。L5：普通 OpenCV 必有吗？答：不保证。易错：精确高斯 Hessian；证据为来源 11。

### 21. SuperPoint

**任务／前提／演进／状态：R。** 合约一致的灰度图和权重 → 点、检测分数、描述子。2017 预印本／CVPR Workshops 2018；共享学习表示改善检测与描述，代价是训练域／权重依赖。仓库只有骨架。[cite:12](#source-12)

**L1 步骤。** 训练用合成形状预训 MagicPoint → Homographic Adaptation 生成真实图伪标签 → 联合检测／描述训练；推理用编码器 → 检测 softmax 重排 → 阈值、NMS、边界处理 → 描述图插值和归一 → 输出特征，非 H。

**L2 机制。** 共享表示结合几何监督；8×8 cell 的 65 通道是 64 像素位置加 dustbin。先 softmax 再去 dustbin 保留无点概率；softmax 本身不产生亚像素位置，描述子插值也不自动精化关键点。

**L3 工程。** 先固定权重、输入幅值／尺寸和坐标回填，再看点覆盖及域差，最后调阈值、NMS 半径、点预算。镜面边缘或重复网格上的大量点未必可重复；检测遗漏无法由后端稀疏匹配器恢复。

**L4 推导。** 检测为 cell 分类交叉熵 \(L_p=-N_c^{-1}\sum\log\mathrm{softmax}(z_c)_{y_c}\)。联合目标 \(L=L_p+L'_p+\lambda L_d\)，单应定义描述正负对，可写正对 \(\max(0,m_p-d^Td')\)、负对 \(\max(0,d^Td'-m_n)\) 的加权和；实际归一和权重以论文版本为准。伪标签错误会进入监督，非无条件自监督正确性。

**L5 复现设计／测试。** `B×65×Hc×Wc` 正确重排，描述布局与匹配器约定一致；固定插值、补边和归一化坐标。测非 8 倍数尺寸、空点、边界、零描述范数和双图缩放。没有本地权重／网络前向，骨架“直接亚像素配准”不是事实。

**面试追问与答案。** L1：训练监督哪来？答：合成几何、适应伪标签、单应对应。L2：为何 65？答：含无点类。L3：点越多越好？答：需看重复性和覆盖。L4：为何两类损失？答：检测与描述职责不同。L5：softmax 等于亚像素吗？答：不等于。易错：单独输出可靠 H；证据为来源 12。

### 22. SuperGlue

**任务／前提／演进／状态：R。** 两组兼容特征点、检测分数及描述子 → 部分对应与拒配。2019 预印本／CVPR 2020；上下文与可微分配改善独立最近邻歧义，代价是注意力／OT 开销。仓库未实现。[cite:13](#source-13)

**L1 步骤。** 位置编码与描述融合 → self/cross attention → 两图相似矩阵 → 增 dustbin 行列 → Sinkhorn 分配 → 互选与阈值 → 输出索引，后接独立几何验证；固定网络深度／分配迭代结束。

**L2 机制。** self 聚合同图结构，cross 引入另一图上下文；dustbin 允许遮挡／不可重复点不匹配，避免强制全配。分配一致性不证明物理几何一致，更不能创造前端未检测到的点。

**L3 工程。** 先核前端兼容和数据域，再看匹配数／覆盖，最后设点预算、阈值、Sinkhorn 次数。点数增大影响显存和延迟；当前没有本地模型默认值或测量数据，不移用论文 GPU 速度。

**L4 推导。** 注意力 \(\mathrm{softmax}(QK^T/\sqrt d)V\)；扩展相似度 Z 的熵正则 OT 为最大化 \(\langle Z,P\rangle+\epsilon H(P)\)，满足指定边缘质量。dustbin 可用未归一行质量 \([1_M,N]\)、列质量 \([1_N,M]\)。log 域交替 \(u=\log a-\mathrm{LSE}(Z+v)\)、\(v=\log b-\mathrm{LSE}(Z+u)\)，有限次迭代只得近似分配。

**L5 复现设计／测试。** logsumexp 防溢出；核对 `B×D×N` 与 `B×N×D`、空集、批处理 mask、拒配索引 -1。检查行列质量、交换两图后的对应方向、点顺序置换和高重复纹理。源码骨架无该路径，未加载权重或运行。

**面试追问与答案。** L1：直接接两张原图？答：核心匹配器接局部特征集。L2：dustbin 用途？答：允许拒配。L3：加迭代补检测漏点？答：不能。L4：等于行 softmax？答：不是，还约束列分配。L5：-1 能索引？答：先过滤。易错：网络置信度等于目标概率；证据为来源 13。

### 23. LoFTR

**任务／前提／演进／状态：R。** 两幅有足够上下文结构的图 → 筛选后的对应。Sun 等 CVPR 2021 绕过独立关键点检测，用粗到细条件化表示改善弱纹理匹配；代价是分辨率与匹配矩阵内存。仓库只列路线。[cite:14](#source-14)

**L1 步骤。** CNN/FPN 粗细特征 → 粗层位置编码、self/cross Transformer → 相似矩阵 → dual-softmax 或所选 OT 变体 → 互选和阈值 → 细窗口对应精化 → 原图坐标 → 几何验证；无粗匹配返回空集。

**L2 机制。** 大范围上下文使独立检测困难的弱纹理位置获得信息；完全平坦或周期歧义不消失。细层只处理已选粗对应，不是每个像素都有光流，也不能保证救回任意粗错配。

**L3 工程。** 先确认权重域、输入分辨率和有效重叠，再看粗置信／几何覆盖，最后改细窗口；窗口单位是特征像素。缩图损失小结构，降低阈值可能增加重复纹理错配，不以点数代替准确性。

**L4 推导。** \(S_{ij}=f_i^Tg_j/\tau\)，\(P_{ij}=\mathrm{softmax}_jS_{ij}\,\mathrm{softmax}_iS_{ij}\)。细层 \(p_k=\mathrm{softmax}(s_k),\hat\delta=\sum p_k\delta_k\)，通过粗正确对应负对数损失和细坐标损失训练。线性注意力用正核 \(\phi(Q)(\phi(K)^TV)\) 加归一降低注意力成本，但粗匹配 M×N 矩阵仍存在；不等于原 softmax 的严格等价变形。

**L5 复现设计／测试。** 固定粗细 stride、补边 mask、两图 resize 比例与细窗口原点；多峰期望可落在两峰之间，应检查分布集中程度。测无重叠、异尺寸、空匹配、单／双峰、弱纹理和镜面域；本地未执行，论文机制不等于现场精度。

**面试追问与答案。** L1：detector-free 是稠密流？答：不是。L2：弱纹理为何有帮助？答：条件化上下文。L3：扩大窗口总更准？答：也增加歧义和成本。L4：全算法都线性？答：粗匹配矩阵仍二次。L5：期望一定是真峰？答：多峰时未必。易错：完全无纹理也可唯一匹配；证据为来源 14。

### 24. LightGlue

**任务／前提／演进／状态：R。** 兼容稀疏特征 → 对应和分数。Lindenberger 等 ICCV 2023 通过匹配结构、自适应深度和点筛除减少容易图像对计算；代价是动态延迟与置信校准风险。学习骨架提名但未接入。[cite:15](#source-15)

**L1 步骤。** 描述初始化 → 相对位置 self/cross attention → 每层匹配及置信预测 → 达置信条件早停，否则筛除可靠判断为不可匹配的点 → 最终分配／互选／阈值 → 原始索引输出与几何验证；最大深度为硬停止。

**L2 机制。** 不再需要额外计算的容易点／图像对少算；matchability 与“当前判断是否已可靠”的 confidence 不同。有把握不可匹配也能停止处理，错误置信则会提前丢真对应。

**L3 工程。** 先核特征兼容、域和召回，再调深度／宽度置信、点数、匹配阈值；记录设备、推理精度及自适应开关。平均快不是固定最坏延迟，关闭自适应可作对照但仍需困难帧测量。

**L4 推导。** 匹配头可写 \(P_{ij}=\sigma_i^A\sigma_j^B\mathrm{softmax}_jS_{ij}\mathrm{softmax}_iS_{ij}\)，其中 σ 是可匹配性；正确对应和未匹配事件的负对数损失训练分配，层间置信目标训练何时足够确定。相对旋转编码使内积依赖位置差。与 SuperGlue 多次 Sinkhorn 不同，剪点也不是确定性剩余贡献界。

**L5 复现设计／测试。** 筛点维护原始下标映射，不能输出压缩索引；测空集、第一层停止、点置换、交换图像、固定深度与动态对照。记录权重哈希、许可证、冷启动／预热与超时回退。未读取当前作者源码默认值，也未运行本地网络。

**面试追问与答案。** L1：如何停止？答：置信满足或最大深度。L2：筛点是精确界？答：学习判断。L3：节拍看什么？答：困难帧尾延迟。L4：和 SuperGlue 相同 OT？答：匹配头不同。L5：筛点最易错？答：索引回填。易错：平均加速等于硬实时；证据为来源 15。

### 25. HOG 特征

**任务／前提／演进／状态：K。** 灰度 patch → 空间方向直方图向量。Dalal／Triggs CVPR 2005 为代表，用局部梯度分布及块归一提升形状表征，代价是细节／旋转信息损失；本地 `hog_features` 调 OpenCV。[cite:16](#source-16)

**L1 步骤。** 本地先转 uint8 → resize 到 64×64 → 梯度方向分箱 → cell 聚合 → 重叠块归一 → 展平为 float32；处理一个 patch 后返回特征，不输出位置或类别。

**L2 机制。** cell 保留粗空间关系，方向分箱降低像素错位敏感度，块归一缓解局部对比差。丢掉 block 归一会增强照明依赖；HOG 本身不检测关键点，也不提供旋转不变性。

**L3 工程。** 本地 block 16×16、stride 8×8、cell 8×8、9 bins；win_size 参数是 `(w,h)`。先查 resize 拉伸、位深与 patch 裁剪，再考虑更细 cell；细 cell 增维与噪声。改变布局必须重训分类器。

**L4 推导。** cell 的 \(h_b=\sum_xm(x)w_b(\theta(x))\)；块 L2 归一近似 \(v/\sqrt{\|v\|^2+\epsilon^2}\)，L2-Hys 还有限幅及再归一。本布局块数 \(7\times7\)，每块 \(2\times2\times9\)，总维 1764。维数与规范化公式不等于分类泛化保证。

**L5 源码／数值与测试。** [hog_features](../../ml/hog_svm_matching.py#L20-L30) 在 resize 前直接 `np.asarray(...,dtype=np.uint8)`，没有显式裁剪 0–255，不能称安全饱和转换。空 patch 会使库失败。应测恒定块、有限值、维数、越界灰度和训练推理同预处理；当前缺 sklearn 导致该模块导入门槛，未运行 ML 路径。

**面试追问与答案。** L1：输出什么？答：向量。L2：块归一做什么？答：减对比度依赖。L3：改变 cell 后呢？答：维度与模型都变。L4：1764 怎么算？答：49×36。L5：astype 自动裁剪？答：不保证安全饱和语义。易错：HOG 自动定位或旋转不变；证据为来源 16 与源码。

### 26. SVM／RBF SVC 与概率

**任务／前提／演进／状态：K。** 已标注 HOG 训练集与候选向量 → 分类决策／概率估计。最大间隔用正负样本学习边界，代价是训练成本、域偏移与校准。本地不是经典 HOG 论文线性 SVM，而是 StandardScaler＋RBF SVC。[cite:17](#source-17)

**L1 步骤。** 训练集拟合标准化器 → RBF SVC 拟合 → 概率估计训练 → 同一变换处理候选 → `predict_proba` → 取目标类别分数。训练收敛／求解器停止和概率有效性是不同问题。

**L2 机制。** 标准化使各维对核距离的贡献可比，RBF 允许非线性边界；没有真实混淆负例时，训练间隔不能保证现场拒识。分类距离也不等于概率，概率校准有单独统计假设。

**L3 工程。** 本地 C=10、kernel='rbf'、probability=True，gamma 未显式给定。先按批次拆数据、收困难负例，再交叉验证 C/gamma，最后独立校准阈值。不能把增广样本和同源验收样本混在一起。

**L4 推导。** \(\min\frac12\|w\|^2+C\sum\xi_i\)，约束 \(y_i(w^T\phi(x_i)+b)\ge1-\xi_i\)，其中 y∈{−1,1}，本地 0/1 标签由库内部编码。核 \(K(x,z)=e^{-\gamma\|x-z\|^2}\)，对偶决策由支持向量展开；概率常为拟合 sigmoid，而不是 margin 的恒等映射。现代 gamma='scale' 为 \(1/(D\operatorname{Var}(X))\)。

**L5 源码／测试设计。** [verify_candidates](../../ml/hog_svm_matching.py#L57-L80) 没给 SVC `random_state`，生成数据 seed 不固定概率训练全部随机性。概率列应核 `classes_`，本例标签 0/1 才使 `[0,1]` 对应正类。测空／单类训练、零方差列、类别次序和校准；本次仅源码核验，未安装或运行 sklearn。

**面试追问与答案。** L1：先标准化谁？答：只用训练集拟合，再用于验证。L2：margin 是概率？答：不是。L3：先调 C？答：先查数据和负例。L4：RBF 如何进入 SVM？答：通过核内积及支持向量展开。L5：seed 固定就完全复现？答：SVC 概率随机性还须固定。易错：线性 HOG-SVM 与本地 RBF 等同；证据为来源 17。

### 27. NCC＋HOG＋SVM 候选重排序组合

**任务／前提／演进／状态：K。** 旧 NCC 位置候选、图像与模板 → 增加 `svm_score` 的排序列表。用外观分类区分相关假峰，代价是候选召回上限与每次训练；当前只是教学组合，不是已验收拒识器。

**L1 步骤。** 外部低阈值 NCC 提候选 → 本地每次生成 60 正／120 负例 → HOG＋标准化＋RBF SVC 训练 → 四舍五入候选原点 → 裁原模板大小轴对齐 patch → 尺寸不符跳过 → 预测概率并排序；没有分类阈值删除步骤。

**L2 机制。** 后端可将已有真候选排前，但无法补回 NCC 没召回的位置，也不修正位置。随机模糊负纹理不代表真实错误零件；函数名 verify 不构成实际过滤保证。

**L3 工程。** 先评候选 recall，再看条件分类能力；训练应移出推理、补真实困难负例、固定预处理后才有部署意义，这些是建议不是现状。旋转 pose_ncc 的 x/y 不可直接按旧轴对齐 patch 裁剪语义套入。

**L4 推导。** 对必须先进入候选集 C 的事件，最终正确检出概率不超过 \(P(真目标\in C)\)。按分类分数排序只改变 C 的顺序；对所有尺寸合法候选返回同数量，不会单靠排序提高集合级 precision。此结论由集合关系推出，不是本地实验数据。

**L5 源码／数值与测试。** [hog_svm_matching.py](../../ml/hog_svm_matching.py) 正例增益 0.7–1.3、偏置 −20–20、噪声标准差 5，负例随机灰度后 sigma=2 模糊；只是代码参数。空候选仍先训练，负坐标需额外防护。缺 sklearn，本次未跑训练；应测空候选、边界、排序、位置不变、概率校准与真负例。

**面试追问与答案。** L1：实际过滤了吗？答：仅跳过尺寸错窗口，其余排序。L2：可补漏检吗？答：不行。L3：先调概率阈值？答：先核候选召回／负例。L4：排序能提高集合精度吗？答：不截断或拒绝则不能。L5：姿态框直接裁？答：不符合现有语义。易错：已训练通用验证器；证据为源码。

### 28. 角度／尺度闭区间网格

**任务／前提／演进／状态：K。** 有物理依据的范围和正步长 → 离散姿态集合。将平移搜索扩展为有限相似变换枚举，代价随组合数增长；不是自动连续优化。来源为 [_grid](../../traditional/template_matching/pose_ncc.py#L19-L32) 和主搜索。

**L1 步骤。** 校验有限有序边界和正步长 → 从 lo 顺序采样 → 必要时加 hi → 角度尺度笛卡尔积 → 画布预检 → 对可评分姿态搜索 → 合并候选；组合处理完停止。

**L2 机制。** 补 hi 避免漏范围端点，但末间隔不必等长；相差 360°未去重。细网格减少离散错配，不解决对称、透视或非刚性；默认 (0,0)/(1,1) 只平移。

**L3 工程。** 角步长为度，尺度步长无量纲；先限制物理范围，再依据模板半径和容许外围位移细化，最后评成本。最多 10000 姿态；searched_poses 是完成评分数，不是有峰数。

**L4 推导。** \(k=\lfloor(hi-lo)/step+10^{-10}\rfloor\)，生成 k+1 项，距 hi 超 `1e-10` 才追加。半径 r 的角误差造成 \(2sr|\sin(\Delta\theta/2)|\approx sr|\Delta\theta|\)，尺度误差造成 \(r|\Delta s|\)。这是几何离散化关系，不是实际定位误差上界。

**L5 源码／测试。** 参数计数拒绝 bool；画布过大跳过，非整除端点测试产生 9 姿态，旋转尺度测试产生 15 姿态。`test_grid_includes_nondivisible_upper_bounds`、配置和尺寸测试本次通过；off_grid 的粗细对照基准本次未重跑。

**面试追问与答案。** L1：端点怎么算？答：容差追加。L2：增密能消对称？答：不能。L3：大模板为何细角度？答：位移随 r 增长。L4：角公式来源？答：弦长。L5：searched_poses 是结果数？答：不是。易错：默认自动旋转尺度；证据为源码和回归。

### 29. 空间金字塔与候选传播

**任务／前提／演进／状态：K。** 单姿态模板和图像 → 粗到细位置候选。以低分辨率初筛减少局部搜索，代价是高频损失／候选截断；本地不是角度尺度金字塔。[cite:2](#source-2)[cite:3](#source-3)

**L1 步骤。** 先生成原图姿态画布 → 用 INTER_AREA 缩图与有效支持 → 顶层全图取 K 峰 → 上层坐标乘 2 → ±4 该层像素局部评分 → 每窗口最多 2 峰 → 合并截到 K，直到原图。复核是卡 30 的独立步骤。

**L2 机制。** 粗层缩小位置数但会平均掉高频特征；奇数尺寸真实缩放不完全为 1/2，乘 2 只是传播近似。没有合法评分上界支持“粗层差则原图也差”。

**L3 工程。** 最大层数含原图，最多 8；当前模板最短边<16、下一层有效点<16或退化停止下降。先比单层和默认复核，再试关闭复核；增 K 不能恢复已丢失的低频信息。

**L4 推导。** 理想面积和 \(A+A/4+\cdots<4A/3\)，只描述像素量而非总耗时。每个细层局部中心允许最多 9×9 平移，实际还需模板支持参与评分；奇数 W 的比例 \(\lceil W/2\rceil/W\ne1/2\)。未复核时没有最优峰召回保证。

**L5 源码／测试。** [_search_pose](../../traditional/template_matching/pose_ncc.py#L110-L156) 同时保存全图坐标与 local/ly/lx；亚像素必须用局部分数索引。本次小模板回退、奇数高频、单层一致及近似可运行测试通过；最后一项不证明近似模式普遍等价。

**面试追问与答案。** L1：先缩模板再姿态？答：本地先姿态再建层。L2：粗层为何漏？答：低频不足／截断。L3：多层必快？答：需含复核实测。L4：4/3 是速度界？答：不是。L5：局部分数用全局下标？答：错误。易错：空间粗细等于姿态连续精化；证据为源码。

### 30. 全分辨率完整复核

**任务／前提／演进／状态：K。** 粗到细搜索后的单姿态 → 原图完整评分候选。用原图重新取峰降低粗层漏峰风险，付出完整计算；默认 `exhaustive_verification=True`。[cite:2](#source-2)

**L1 步骤。** 若 top>0 且开关真 → 对当前姿态原图全部合法位置评分 → 原图提 K 峰 → 替换传播结果；top=0 的初始评分已是原图，不重复执行。

**L2 机制。** 复核不仅重算已保留位置，而是恢复遗漏的原图候选搜索。它不恢复被每姿态容量 K 或跨姿态中心 NMS 丢掉的多目标，因此“完整复核”不等于穷尽全部竞争假设。

**L3 工程。** 安全敏感定位先保持默认；若关闭，必须同时评漏目标和漏第二峰导致错误唯一性放行。先缩 ROI 和物理网格，再考虑拿召回换速度；开关在无粗层时没有近似含义。

**L4 推导。** 复核输出是 \(\mathrm{Peaks}_K(R_0)\)，而非 \(\mathrm{score}(\mathrm{propagate}(R_L))\)。在同一评分／取峰规则下不依赖粗层候选，但仍是有容量的提峰算子。原图评分成本保留，故不能只依据粗层面积宣称加速。

**L5 源码／测试。** `_search_pose` 153–155 行直接替换 final。本次默认值检查、单层／多层一致、高频奇数相位恢复测试通过。阈值边缘的逐位一致受浮点库版本影响，不能推广为任意输入精确等价；无关闭开关的系统性能基准。

**面试追问与答案。** L1：复核哪些点？答：该姿态全部合法平移。L2：为何比局部重算强？答：能恢复粗层漏候选。L3：False 总近似吗？答：top=0 仍全图。L4：等价哪一算子？答：原图有界提峰。L5：还会漏多目标？答：K／NMS 仍限制。易错：复核只验证已选峰；证据为源码。

### 31. Top-K／候选容量

**任务／前提／演进／状态：K。** 评分峰流 → 有限候选集合。控制后续内存与合并成本，代价是弱真目标和次优竞争峰可能被截断；本地 candidate_limit 不是目标总数估计。

**L1 步骤。** 每姿态在抑制后逐次取最多 K 峰 → 逐层传播时排序／空间合并再截 K → 跨姿态合并 → 最后按 max_count 限制输出；无有限峰提前停止。

**L2 机制。** 限额避免大量旁瓣耗尽资源，但重复结构可占满容量。增 max_count 不增每姿态 K，漏第二竞争者会使分差过乐观，故容量也是拒识正确性的条件。

**L3 工程。** `K>=max_count`；启用分差至少 2，否则至少 1。先看目标数、峰宽和周期干扰，再联合设 K／半径。比较完整候选分布与截断结果，而不是只看最终返回数。

**L4 推导。** 若真实候选在既定抑制序列中排名>K，则此姿态截断必丢失；后端排序不可能恢复。每姿态存储 \(O(K)\)，G 个姿态最多 GK 个候选，但每项关联评分图时内部内存还受实现引用影响，不能仅按数值字段估算。

**L5 源码／测试。** `_peaks` 的 count 与 `_search_pose` 的截断共同执行；主函数检查非法容量。多目标上限、近邻双目标和配置测试本次通过，未全面量化真实场景容量召回曲线。优化堆／索引前必须保持 NMS 顺序，不是简单取原图 K 个最大像素。

**面试追问与答案。** L1：K 在哪生效？答：每姿态及每传播层。L2：为什么影响拒识？答：可能漏次优。L3：只增 max_count？答：不够。L4：为何后端救不回？答：候选已不在集合。L5：全图最大 K 像素等价？答：不等价抑制后 K 峰。易错：K 就是真实目标数；证据为源码。

### 32. 中心距离 NMS

**任务／前提／演进／状态：K。** 密集位置／多姿态候选 → 空间分离候选。降低重复响应，代价是合并相邻真目标；不是 IoU NMS 或几何共识估计。

**L1 步骤。** 每姿态贪心 argmax → 抑制半径圆盘 → 重复至容量；跨姿态按分数排序，只有中心与全部已选中心都足够远才保留。旧入口先阈值后排序，新入口最终阈值在合并后。

**L2 机制。** 同一目标附近峰被去重；平台响应也可被贪心选取，不额外验证严格局部极大。同中心不同角度／尺度互相抑制，所以无法检测同心对称姿态歧义。

**L3 工程。** 半径原图 px，粗层除 \(2^{level}\)；先看峰宽和目标间距，再设半径／K。半径大漏邻目标，小会把旁瓣当目标；亚像素开关可改变最终中心距离边界。

**L4 推导。** 抑制条件 \((x-x_p)^2+(y-y_p)^2\le r^2\)，保留为严格 >r。以冲突图理解，贪心不保证最大总分独立集。`_peaks` 每次全图 argmax 为 \(O(KP)\)，跨姿态最坏两两检查为候选数平方级。

**L5 源码／测试。** [_peaks](../../traditional/template_matching/pose_ncc.py#L93-L107) 复制图，非有限最大值结束；跨姿态用精化中心，旧接口用整数位置。本次近邻双目标、替代姿态抑制通过；精确半径等号及所有 tie 未单独穷举。改空间索引需保留 tie 与输出顺序。

**面试追问与答案。** L1：抑制区域什么形状？答：距离圆盘。L2：和 RANSAC 区别？答：去重复峰而非拟合共识。L3：相邻目标少了查什么？答：半径及 K。L4：等于半径保留？答：不保留。L5：精化影响 NMS？答：最终中心会影响。易错：默认 IoU；证据为源码。

### 33. 分数阈值、空间分差与多目标拒识

**任务／前提／演进／状态：K。** 空间候选 → matched/reason。高分之外增加唯一性检查，代价是重复目标拒识、截断导致漏竞争者；只适用新接口。

**L1 步骤。** 取合并后 b1/b2 → gap → 分数过滤 → 没评分姿态为 no_valid_pose → 没过阈值为 below_min_score → 有 gap 且小于门限为 ambiguous → 否则 matched。非法输入此前抛 ValueError。

**L2 机制。** 分差只比较保留的两个空间峰；次优低于分数阈值仍参与 gap。同中心旋转对称已被 NMS 合并，不受保护；没次优是信息缺失，不是已经证明唯一。

**L3 工程。** 分数 [-1,1]，分差 [0,2]；多目标显式 `max_count>1,min_score_gap=0`，不等于关闭评分阈值。先定义任务数量，检查 mask／姿态／容量／NMS，再用独立负例标定，不能一张正例定阈值。

**L4 推导。** \(g=b_1-b_2\in[0,2]\) 仅当两峰有效；无 b2 为 None。分数接受 \(s\ge\tau\)，歧义为已有过分候选且 \(\gamma>0,g\ne None,g<\gamma\)。等号通过；搜索候选数改变无目标最大分数分布，g 不是存在概率。

**L5 源码／测试。** [返回分支](../../traditional/template_matching/pose_ncc.py#L243-L264) 失败清空 matches，保留诊断；先看 matched 再索引。本次等目标歧义、常量／噪声无目标、多目标、容量非法通过；未穷举所有浮点等号。JSON 缺失值为 None，不外泄内部 -inf。

**面试追问与答案。** L1：失败为何不同原因？答：区分无姿态、低分、歧义。L2：None gap 是无限大？答：不是。L3：双目标拒识怎么办？答：先确认任务再关闭唯一性。L4：次优低于阈值还比？答：比。L5：失败能拿 matches[0]？答：不能。易错：低分证明物理无目标；证据为源码。

### 34. PSR：峰旁瓣比

**任务／前提／演进／状态：R。** 原始响应图、主峰、旁瓣定义 → 相对背景峰显著度。MOSSE 2010 为应用来源，用一组旁瓣统计补充双峰分差；代价是统计 ROI／方差敏感。仓库文档提名，未计算 PSR。[cite:2](#source-2)

**L1 步骤。** 选主峰 → 排除主瓣邻域 → 限定旁瓣 ROI 并过滤无效值 → 求均值／标准差 → 非退化时算 PSR → 独立标定拒识；样本不足或标准差零返回不可用。

**L2 机制。** 比较主峰与背景响应分布，而非只比第二峰；低旁瓣方差可放大普通峰，重复纹理也可能有多个尖峰。NMS 后的 -inf 不能直接当背景样本，PSR 不能替代几何验证。

**L3 工程。** 主瓣排除窗口 px，PSR 无量纲；先固定统计 ROI、有效数和标准差定义，再选阈值。每姿态与跨姿态统计不是同一分布，不能照搬 MOSSE 跟踪阈值到模板定位。

**L4 推导。** \(\mu=m^{-1}\sum r_i,\sigma^2=m^{-1}\sum(r_i-\mu)^2\)，\(PSR=(r_{peak}-\mu)/\sigma\)。本卡用总体标准差，改样本分母 m−1 会变值。同一支持下正仿射响应变换保持 PSR；旁瓣相关且峰经过最大化选择，不能当标准正态 p 值。

**L5 复现设计／测试。** 在完整有限原图响应上建排除 mask；零 σ 不通过加小分母制造无穷可信度。测常量、全无效、边界峰、双峰和 ROI 改变，记录 m；当前无实现／专项运行，旧分差字段不是 PSR。

**面试追问与答案。** L1：先排除什么？答：主瓣邻域。L2：与 gap 相同？答：统计集合不同。L3：论文阈值直接搬？答：不可以。L4：为什么不是概率？答：不满足简单独立正态且峰经选择。L5：σ=0 怎么办？答：不可用／拒识。易错：已有 PSR 返回值；证据为来源 2。

### 35. 最近邻与互近邻

**任务／前提／演进／状态：R。** 两组同定义描述子 → 初始对应；互近邻在单向最近邻上增加双向一致性，代价是召回下降。学习骨架提及但未执行。[cite:7](#source-7)[cite:13](#source-13)

**L1 步骤。** 核维数、类型与距离 → A 对 B 最近邻 → 若需要再 B 对 A → 保留双向索引互指者 → 绝对距离／ratio／几何检查；空集直接返回空，不构造假索引。

**L2 机制。** 单向即使全错误仍会选一个；互检可减少多个点争同一点，但重复图案可稳定地互相错配。互近邻不是一对一最优总距离分配，更不是 RANSAC。

**L3 工程。** SIFT／SURF 浮点通常 L2，二值用 Hamming 类。先核描述尺度与距离，再看覆盖和过滤损失。近似索引若漏真近邻会改变互检；应与精确搜索对照而非宣称无损。

**L4 推导。** \(j(i)=\arg\min_jd(a_i,b_j),i(j)=\arg\min_id(a_i,b_j)\)，互检为 \(i(j(i))=i\)。单位描述子 \(\|a-b\|^2=2-2a^Tb\) 使 L2 和余弦排序等价；非单位不成立。暴力 \(O(MND)\)，分块能降存储而保精确最小值。

**L5 复现设计／测试。** 定义并列最近邻规则；分块同步全局下标，过滤 -1 再索引。测空集、重复描述、点重排、非单位向量和距离切换。KD-tree／FLANN 与互近邻均未接入；不存在本地匹配召回结果。

**面试追问与答案。** L1：双向多做什么？答：反向最邻检验。L2：通过就几何对？答：不保证。L3：ANN 可直接替换？答：需评近邻召回。L4：余弦等价 L2 条件？答：单位范数。L5：并列怎么办？答：固定确定性策略。易错：互近邻等于全局最优分配；证据为定义和来源 7。

### 36. ratio test

**任务／前提／演进／状态：R。** 最近与次近描述距离 → 相对歧义过滤。Lowe SIFT 体系用次近竞争者衡量独特性；代价是拒绝重复结构中的真实对应。骨架仅文字提名。[cite:7](#source-7)

**L1 步骤。** 对每点求至少两个近邻 → 检查 d2 有效且非零 → 比 d1/d2 与阈值 → 可选互检 → 几何验证；另一图不足两点时按协议不可计算而非补零。

**L2 机制。** 真相似与重复纹理都可绝对距离小，ratio 引入第二名竞争；它不约束空间几何。近似索引漏第二近邻会增大分母，可能错误放行；互检也不能取代 ratio 的歧义测试。

**L3 工程。** ratio 阈值无量纲但依描述分布；先查距离类型、近邻质量和重复模式，再定阈值，记录误删真匹配。不能直接套 NCC 分差 0.03，也不能把论文常用值当所有工件最优。

**L4 推导。** 接受 \(d_1/d_2<\tau\)。若库返回平方 L2，应 \(d_1^2<\tau^2d_2^2\)，不是仍乘 τ；单调平方保留排序但不保留比值数值。d1=d2 表竞争等价，d1=d2=0 不是“完美唯一”。

**L5 复现设计／测试。** 用乘法避免除法前仍须定义 0/0 与非法距离；测不足两点、同距离并列、平方／非平方一致性和 ANN 第二近邻遗漏。匹配后点索引应同步边界过滤；未运行本地 ratio 管线。

**面试追问与答案。** L1：为何两个邻居？答：量化相对歧义。L2：两者都近就通过？答：比例接近 1 应拒绝。L3：近似检索风险？答：漏次近会过乐观。L4：平方距离阈值？答：τ²。L5：0/0 怎么办？答：显式拒配或定义并列协议。易错：ratio 与互检完全等价；证据为来源 7 和代数。

### 37. 噪声白化

**任务／前提／演进／状态：R。** 正定噪声协方差 C、信号与观测 → 白化空间匹配响应。有色噪声中普通相关不最优，白化降低高方差方向权重，代价是协方差估计和求解。仓库无白化链。[cite:1](#source-1)

**L1 步骤。** 从代表性无信号数据估 C → 检查特征值／条件数 → 因式分解 → 对观测和模板施同一白化 → 匹配 → 标定拒识；C 不可靠则失败或明确使用正则模型。

**L2 机制。** 白化使各方向噪声方差相等，但同时必须变换信号；只白化图像不白化模板会改变相似目标。去均值仅删除常数方向，ZNCC 能量归一也不等于协方差白化。

**L3 工程。** 先验证背景平稳性、训练覆盖和小特征值，再选收缩／对角或谱模型，最后调阈值。正则 λ 与 C 同方差量纲；小特征值直接求逆会放大估计误差，不应当作真实低噪声通道。

**L4 推导。** \(C=LL^H\)，取 \(x'=L^{-1}x,s'=L^{-1}s\)，有 \(E[n'n'^H]=I\)。白化内积 \(s'^Hx'=s^HC^{-1}x\)，故 \(w\propto C^{-1}s\)，SNR 上界 \(s^HC^{-1}s\)。用 \(C+\lambda I\) 改变模型与最优解。一般分解 \(O(n^3)\)，结构谱模型可降低成本。

**L5 复现设计／测试。** 用三角求解替代显式逆，复数保持共轭；测试 C=σ²I、病态／奇异 C、样本不足及训练测试背景不一致。对比白化噪声协方差而非只展示高峰；本地未估计 C 或运行白化。

**面试追问与答案。** L1：两边都白化？答：是。L2：去均值是否白化？答：不是。L3：小特征值先怎么处理？答：评估估计可靠性与正则。L4：为何 C⁻¹s？答：白化后匹配内积。L5：直接求逆最佳？答：优先分解求解。易错：普通相关对有色噪声仍最优；证据为推导与来源 1。

### 38. 局部上采样 DFT 亚像素配准

**任务／前提／演进／状态：R。** 已有频域相关及整数位移峰 → 局部细网格峰。Guizar-Sicairos 等 Optics Letters 2008 降低整幅高倍补零 IFFT 开销；代价是局部捕获范围、频率约定和噪声敏感。仓库只有抛物线，没有局部 DFT。[cite:18](#source-18)

**L1 步骤。** 整数相关峰 → 定义峰周围细位移格 → 构频率指数矩阵 → 矩阵乘法只算局部相关 → 选峰／回绕 → 检查重叠与置信；格点算完停止。

**L2 机制。** 已知峰附近才需密采样，无须把整幅图扩到高倍；只是更精细评价同一带限相关面，不创造原图丢失的高频。整数峰错位超局部区域时无法恢复全局正确峰。

**L3 工程。** 上采样因子 κ 给位移网格间隔 1/κ px，局部半径须涵盖初峰不确定性。先核频率符号、FFT shift 和窗口，再增 κ；超大 κ 可能只更密采噪声，不等于 1/κ 的实际误差保证。

**L4 推导。** 对互谱 R，连续周期插值 \(c(\delta_y,\delta_x)=\frac1{HW}\sum_{k,l}R_{kl}e^{2\pi i(\nu_k\delta_y+\nu_l\delta_x)}\)，ν 为与 FFT 约定一致的有符号频率。指定细坐标集合后写 \(C_{local}=E_yRE_x^T/(HW)\)。避免 κH×κW 的整图 IFFT 内存，但局部矩阵乘法仍有频率维成本。

**L5 复现设计／测试。** 使用与库一致的 `fftfreq` 排列，尤其偶数 Nyquist、奇偶尺寸、共轭方向、复值幅值取峰约定。与高倍补零全相关的小规模参考对照；测已知小数平移、边界、回绕和噪声。仅检索到原论文入口／官方说明，未在本地复现。

**面试追问与答案。** L1：哪里上采样？答：相关峰局部。L2：和图像插值一样？答：不是。L3：κ=100 就准确 0.01 px？答：只是网格间隔。L4：怎样变矩阵乘？答：分离两轴指数。L5：整数频率直接套非整数位移？答：须一致处理负频率排列。易错：与三点抛物线等价；证据为来源 18。

### 39. 傅里叶幅度＋对数极坐标旋转尺度估计

**任务／前提／演进／状态：R。** 共享近似相似变换的两图 → 旋转尺度初值，再估平移。将旋转／缩放化为极坐标平移，代价是重采样、中心和频谱对称歧义。仓库姿态枚举不是该扩展。[cite:19](#source-19)

**L1 步骤。** 控制边界与有效支持 → Fourier 幅度／中心化 → 排除直流附近 → 采样 `(log r,φ)` → 相位相关估角向／径向位移 → 换算角度与尺度 → 校正后估原图平移 → 几何与评分复核。

**L2 机制。** 理想平移只改变相位，幅度去掉平移影响；旋转变角向平移，尺度变 log 半径平移。但有限裁剪、窗和低重叠破坏理想幅度关系；实图频谱中心对称带来 180°歧义，不能直接驱动设备。

**L3 工程。** 明确频谱中心、径向上下限、角采样数和 log 底。先核原图模型与频率轴，再调范围／分辨率，最后验证歧义分支；r=0 不可取 log。空间极坐标要求旋转中心已知，频谱方案也有采样中心约定。

**L4 推导。** 若 \(B(x)=A(s^{-1}R^{-1}(x-t))\)，二维 Fourier 有 \(|F_B(\omega)|=s^2|F_A(sR^T\omega)|\)。令 \(\rho=\log r\)，则 B 的谱在 log 半径自变量加 log s、角变量按 R 平移。若定义 \(L_B(\rho,\phi)=L_A(\rho-d_\rho,\phi-d_\phi)\)，对应 \(d_\rho=-\log s\)、角向符号依旋转坐标定义；绝不能忽略参考／移动顺序直接套指数符号。

**L5 复现设计／测试。** 把采样位移乘物理轴间隔再指数换尺度；区分输出数组行列代表角还是半径，固定中心像素约定。测只旋转、只尺度、复合、180°、奇偶尺寸、平移裁剪与圆对称目标。未实现／运行，最终仍需原图验证而非仅接收 log-polar 高峰。

**面试追问与答案。** L1：估角尺度后还做什么？答：校正并估平移／复核。L2：为何幅度减平移影响？答：平移只加相位，理想支持下成立。L3：为何 180°歧义？答：实图幅谱中心对称。L4：尺度为何取 log？答：乘法变加法。L5：指数正负怎么定？答：按推导和 API 方向测试。易错：基础相位相关一次估任意姿态；证据为来源 19。

### 40. 逆组合（Inverse Compositional）

**任务／前提／演进／状态：R。** 可逆可组合 warp、固定模板支持、近初值 → 局部对齐。Baker／Matthews 的 LK 统一框架为代表说明，以模板侧增量复用梯度与 Hessian，代价是支持／权重固定等条件。仓库未实现。[cite:5](#source-5)

**L1 步骤。** 模板梯度与单位 warp Jacobian 预计算 → Hessian／分解缓存 → 每轮采样 I(Wp) → 解模板增量 → 用逆增量组合更新 Wp → 检查残差及停止；非可逆或支持不足失败。

**L2 机制。** 增量加在固定模板侧，使一阶导与 Hessian 不必每轮重建。不是把前向 LK 的参数增量简单取负相加；仿射／单应组合是矩阵运算，变权鲁棒损失和变支持会破坏恒定 Hessian 条件。

**L3 工程。** 先核 warp 族、初值、支持和可观测性，再评缓存收益；图像采样通常仍是成本。高自由度、低纹理要限制模型，不能为复用 Hessian 忽略遮挡或边界变化。

**L4 推导。** 最小化 \(\|T(W(x;\delta))-I(W(x;p))\|^2\)。在单位增量处 \(T(W_\delta)\approx T+J_T\delta\)，设 \(r=I(W_p)-T\)，得 \(J_T^TJ_T\delta=J_T^Tr\)。更新 \(W_p\leftarrow W_p\circ W_\delta^{-1}\)，矩阵为 \(H_pH_\delta^{-1}\)。固定 J 时 Hessian 可缓存；秩不足仍不可辨。

**L5 复现设计／测试。** 不显式逆矩阵时用线性求解实现组合，检查齐次归一和行列方向；有限差分验证模板 Jacobian。测平移与前向小步一致、仿射组合非交换、奇异增量、边界及动态 mask；未执行本地 IC。

**面试追问与答案。** L1：更新方向？答：右组合逆增量。L2：为何缓存？答：导数在固定模板单位 warp。L3：动态权重还缓存不变 H？答：一般不行。L4：正规方程符号？答：由 r=I−T 与模板展开决定。L5：直接 p-=δ 行吗？答：一般变换不行。易错：所有 LK 都是逆组合；证据为来源 5。

### 41. Homographic Adaptation

**任务／前提／演进／状态：R。** 真实训练图、初始检测器与采样单应 → 聚合检测伪标签。SuperPoint 体系以多尺度／多单应视图改善合成到真实的检测适应；代价是多次前向、插值和伪标签偏差。不是 RANSAC，也不是推理时必做步骤。[cite:12](#source-12)

**L1 步骤。** 采样有界可逆 H → warp 输入 → 检测热图 → 用 H 的对应关系拉回原图 → 同时拉回有效支持 → 累积并按有效观测次数归一 → 阈值／NMS 形成伪标签 → 训练检测器；变换预算处理完停止。

**L2 机制。** 同一结构在不同投影／尺度下重复出现，聚合提高一致性；不是凭空产生人工真值，初始检测器系统偏差也可能被强化。随机单应生成训练对应，不证明真实三维两视图可由单一 H 描述。

**L3 工程。** H 的角度、尺度、透视范围先与真实工况相符，再设变换数和伪标签阈值。视域边缘有效次数少，不能按总变换数平均把边界系统压低；过强变换会使纹理不可见、训练偏离场景。

**L4 推导。** 令 \(I_k(y)=I(H_k^{-1}y)\)，检测器 f，在原图 x 对应 \(q_k(x)=f(I_k)(H_kx)\)。有效指示 v 后，\(\bar q(x)=\sum_kv_k(x)q_k(x)/\sum_kv_k(x)\)。对采样变换分布这是 Monte Carlo 聚合，但各预测相关、有偏，不提供真实角点正确概率或随 K 独立下降的误差界。

**L5 复现设计／测试。** 对图像使用逆采样、对热图返回原坐标查询 Hx，不能误把两个方向混用；分母零返回无标签。记录 H、边界 mask、随机状态，避免训练／验收原图泄漏。测试单位 H、变换再回拉、部分出视域和重复结构；本地没有训练流程／权重，未运行。

**面试追问与答案。** L1：输出配准矩阵吗？答：主要输出伪标签。L2：为什么多单应？答：聚合视图一致性。L3：边界怎么平均？答：除有效观测次数。L4：回拉取 Hx 还是 H⁻¹x？答：按本卡定义取 Hx。L5：算零次数怎么办？答：无有效标签。易错：自监督等于无需数据／无偏真值；证据为来源 12。

## 6. 实现、组合与验证组件

### 42. 二值掩膜与归一化重采样

**任务／前提／演进／状态：K。** 同形有限模板与 0/1 支持 → 变换亮度和可靠支持。由补零矩形扩为有效区域统计，代价是旋转／缩放后边界收缩；当前不是软权重 NCC。[cite:2](#source-2)

**L1 步骤。** 检查 mask 形状、有限性、二值性 → 同 warp 分别采样 TM 与 M → 支持>1e-9 处相除 → 支持≥1−1e-6 才保留 → 核有效数和方差 → 同支持评分。降采样沿用该机制。

**L2 机制。** 先乘 mask 再插值使无效灰度不污染有效亮度，除支持避免补零造成亮度衰减；满支持阈值进一步排除混合边界。薄线支持可能消失，mask 不等于任意遮挡鲁棒。

**L3 工程。** 两个无量纲容差分别服务安全除法和有效性，不能混成同一阈值。先看变换后有效面积、灰度对比和剩余结构，再调搜索或拒识。原 mask 外也须有限，NaN×0 仍是 NaN。

**L4 推导。** 非负插值权重 a 下 \(\hat T=\sum a_jM_jT_j/\sum a_jM_j\)；有效区 T=c 时分子是 c 倍分母，故恢复 c。分母零不可定义，完整支持门限不恢复连续成像信号；不同姿态 n 改变，不能把同分当同统计可信度。

**L5 源码／测试。** [_warp](../../traditional/template_matching/pose_ncc.py#L35-L47) 用 INTER_LINEAR，金字塔用 INTER_AREA；要求完整变换画布落图。all-ones 等价、排除损坏像素、旋转尺度 mask、非法 mask 测试本次通过；没有任意软 mask 验证。

**面试追问与答案。** L1：为何采两次？答：亮度分子和支持。L2：补零直接匹配无害？答：会成伪纹理。L3：薄 mask 低分先调阈值？答：先看有效支持消失。L4：常量如何恢复？答：比值抵消支持权重。L5：mask 外可 NaN？答：不可以。易错：mask 允许目标出画；证据为源码。

### 43. FFT 相关、补边和缓存

**任务／前提／演进／状态：K。** 图像及核 → 线性相关图。FFT 改计算方式而非目标或几何模型；两套 ZNCC 用 SciPy，未自写 FFT、GPU 或跨姿态缓存。[cite:3](#source-3)[cite:20](#source-20)

**L1 步骤。** 选实／复相关约定 → 核共轭反转 → 线性卷积补边 → FFT／频域乘 → IFFT → valid 裁剪 → 按评分函数归一。库内部完成变换，不可省翻转仍期待同坐标。

**L2 机制。** 卷积定理减少重复乘加，补边消除循环回绕；小模板／小 ROI 可能直接法更快。FFT 不自动完成去均值、相位归一或噪声白化，缓存不同支持的核会改变结果。

**L3 工程。** 先记录形状、输出数量、补边面积和内存，再选直接／FFT；现代 FFT 不必全补到 2 的幂。缓存键须含图像内容、核／mask、姿态、精度和补边形状，本地三个独立 fftconvolve 调用不能称已经共享谱。

**L4 推导。** \(c(u,v)=\sum I(u+x,v+y)t(x,y)\) 是反转实核的卷积对应片段。各轴长度至少输入长度之和减 1 才得到线性卷积；时间 \(O(F\log F)\)、存储 \(O(F)\)。FFT 浮点求和顺序不同，数学等价不意味着逐位相等。

**L5 源码／测试。** 旧分子和新 S/Q/N 均 `fftconvolve(...,mode='valid')`。测试设计包括非对称核、脉冲、等尺寸、首末窗口、非连续数组和直接参考逐值对照；已有非连续回归针对姿态入口。任何缓存优化要逐分数验证，不只是峰位置。

**面试追问与答案。** L1：为何反转两轴？答：卷积变相关。L2：补边做什么？答：避免回绕。L3：小窗口一定快？答：不一定。L4：复杂度为何依 F？答：是补边后的变换规模。L5：缓存怎么验？答：不同支持／姿态对直接参考。易错：FFT 天然旋转不变；证据为源码与来源 20。

### 44. 积分图与局部矩统计

**任务／前提／演进／状态：K。** 图像 → 轴对齐矩形和／平方和。将每窗口面积级计算变四角查询，代价是大表内存和累积舍入；旧 ZNCC 使用，新 mask 版本不用矩形积分图。[cite:3](#source-3)

**L1 步骤。** 转宽类型 → 加前导零边 → 两轴前缀和 → 用右开矩形四角容斥取 S → 对平方图同样得 Q → 求 V。所有合法窗口完成即返回统计图。

**L2 机制。** 包含排除消去矩形外贡献，查询次数不依面积；旋转／任意形状 mask 不是单个矩形，不能直接套四角。S 和 Q 很大时 V 可能因相消丢掉真实小纹理。

**L3 工程。** 先查最大幅值、图像面积和期望方差，再考虑中心化或直接参考；float64 不免疫相消。前导零和右开边界必须一致，尤其首行首列；平方之前就要转类型。

**L4 推导。** \(A(y,x)=\sum_{j<y,i<x}I(j,i)\)，矩形和 \(S=A(y+h,x+w)-A(y,x+w)-A(y+h,x)+A(y,x)\)。展开 \(\sum(I-\mu)^2\) 得 \(V=Q-S^2/n\)。构表 \(O(HW)\)、单窗 \(O(1)\)，两大表存储 \(O(HW)\)。

**L5 源码／测试。** [ncc_matching.py](../../traditional/template_matching/ncc_matching.py#L38-L49) 没新接口可靠性兜底；数学非负不阻止浮点负方差。应测单像素宽、全图窗、边角、常量、大偏置，对直接和核四角符号；现有旧接口回归只验证指定普通场景。

**面试追问与答案。** L1：表为何多一行列？答：统一零边界。L2：任意 mask 能四角？答：不能。L3：负方差先查什么？答：量纲和相消。L4：O(1) 何来？答：固定四角。L5：平方后转 float？答：太迟，已可能溢出。易错：双精度永不失稳；证据为源码和推导。

### 45. 稳定 ZNCC 与分块直接兜底

**任务／前提／演进／状态：K。** 有限极端量纲图像和有效模板 → 稳定分数或不可用窗口。新实现降低平方溢出与方差相消，代价是直接路径可能显著变慢；不恢复量化前已消失纹理。

**L1 步骤。** 模板最大幅值缩放 → 减参考像素／去均值 → 再缩幅 → 图像全局缩幅／去均值 → FFT S/Q/N → 可靠性判别 → 非可靠窗从原始数组每批最多 128 窗直接评分 → 有限结果裁到 [-1,1]。

**L2 机制。** 正比例和加常数理论不改 ZNCC，缩幅防溢出，局部中心化避免两个大数之差；从 original 取像素而非全局缩放后图像可保留局部信息。若表示精度已丢差异，算法不能补回。

**L3 工程。** `V>256*eps*max(1,abs(Q))` 是归一化数值可靠性门槛，不是现场对比度阈值；eps 是 float64 机器精度。先记录进入兜底比例、完整画布面积、动态范围，再查时延；不能为速度盲降门限。

**L4 推导。** \(\rho(\alpha t,\beta i)=\rho(t,i)\) 对正 α、β 且中心化非零成立。\(Q-S^2/n\) 的绝对误差可能与真实小 V 同级，直接中心化和平方减少主要相消来源，但不消除所有舍入／下溢。U 窗兜底增加 \(O(Un)\)。

**L5 源码／测试。** [_score](../../traditional/template_matching/pose_ncc.py#L50-L90) `sliding_window_view` 是视图，但 `windows[yy,xx]` 会物化最多 128 个完整画布再选 mask，内存不只是 128n；减首列用 copy 防别名。本次 1e10 偏置、1e-10 增益、1e100 自匹配与极亮背景、常量邻窗通过；这是固定案例而非任意浮点保证。

**面试追问与答案。** L1：何时兜底？答：FFT 方差不可靠且整图非恒定。L2：为何 original？答：避免全局处理丢局部信息。L3：突然慢查什么？答：U 和完整 patch 大小。L4：加 epsilon 就解决？答：可能造假高分。L5：滑窗零内存？答：后续高级索引复制。易错：全部路径始终 FFT 复杂度；证据为源码与极值回归。

### 46. 相似变换、包围画布与 ROI 坐标链

**任务／前提／演进／状态：K。** 原模板像素中心、姿态与评分峰 → 一致 H／原点／中心／角点。统一坐标避免匹配正确却画框偏移；本地 H 是相似变换，不是标定或毫米测量。[cite:2](#source-2)

**L1 步骤。** 原中心 c → 绕 c 旋转缩放 → 变换四角求最小值 ℓ → 移画布原点 → 加评分平移及亚像素量 → 同一 H 作用所有输出点。ROI 调用侧左乘平移矩阵回整图。

**L2 机制。** 像素从 0 编号，中心不是 w/2；旋转后原模板原点、中心、bbox 不重合。warp 的逆向采样只是计算方式，不把声明的模板到图像几何方向反转。

**L3 工程。** 输入角度度、计算弧度，正角视觉逆时针，统一尺度正值；画布 ceil 前减 1e-9 避免几乎整数多一列。先用零角、非方模板、图像边角、ROI 偏移排错；角点为像素中心而非外边界。

**L4 推导。** \(c=((w-1)/2,(h-1)/2)^T,A=s\begin{bmatrix}\cos\theta&\sin\theta\\-\sin\theta&\cos\theta\end{bmatrix}\)。\(\ell=\min_{corners}(A(p-c)+c)\)，\(b=(u+\delta_x,v+\delta_y)^T\)，\(t=c-Ac-\ell+b,H=\begin{bmatrix}A&t\\0&1\end{bmatrix}\)。画布宽 \(\lceil s(|\cos\theta|(w-1)+|\sin\theta|(h-1))-10^{-9}\rceil+1\)，高交换宽高。

**L5 源码／测试。** `x/y=t`，`center=A*c+t`，`bbox=b`，corners 次序左上、右上、右下、左下。整图 H 为 `T_roi @ H_roi`，所有坐标同步回填。姿态、边角和全图等模板测试本次通过；ROI 组合为代数核对，无现有专项运行断言。

**面试追问与答案。** L1：x/y 是谁？答：原模板原点映射。L2：为何 `(w−1)/2`？答：像素中心零编号。L3：固定偏移先查什么？答：参考点与 ROI。L4：ROI 左乘还是右乘？答：左乘图像平移。L5：只更新中心行不行？答：H／角点也要一致。易错：亚像素坐标直接是物理准确度；证据为源码和来源 2。

### 47. 三点抛物线平移精化

**任务／前提／演进／状态：K。** 整数响应峰轴向三个样本 → 小数平移。以局部二次模型降低整数格量化，代价是峰形近似偏差；两个 NCC 共用，非 LK／ECC，角度尺度不精化。

**L1 步骤。** 取每轴 f−/f0/f+ → 二阶差 → 近零则偏移 0，否则二次顶点 → 裁 ±0.5 → 返回 dy/dx → 更新坐标。边界缺邻点的轴保持 0，新接口另外检查最多 3×3 全有限。

**L2 机制。** 孤立平滑峰可由二次曲线近似；分轴忽略 xy 交叉项，平台、多峰和斜脊不可靠。新接口即使只对角点非有限也放弃两轴精化；这是保护，不是曲率认证。

**L3 工程。** 二阶差阈值 `1e-12` 是评分量纲，±0.5 是像素；先看峰形、局部边界与姿态网格，再决定开关。精化后 score 不重算，分数阈值／排序仍基于整数峰。

**L4 推导。** \(f(z)=az^2+bz+c\)，\(a=(f_- -2f_0+f_+)/2,b=(f_+-f_-)/2\)，顶点 \(\delta=-b/(2a)=(f_- -f_+)/[2(f_- -2f_0+f_+)]\)。a<0 才为极大；小分母对噪声敏感，坐标小数位不提供误差界。每峰为常数算术。

**L5 源码／测试。** [parabolic_subpixel](../../traditional/template_matching/ncc_matching.py#L54-L71) 检 `abs(d)` 不检 d<0；旧接口没有新接口完整有限邻域检查。本次小数平移对整数结果改善、边缘与常量邻窗通过；没有所有耦合峰形验证。返回次序 dy/dx 不可反用。

**面试追问与答案。** L1：返回顺序？答：dy、dx。L2：二次顶点总最大？答：需 a<0。L3：精化仍整数是 bug？答：可因边界／平坦／保护。L4：公式如何推？答：三点解二次项取顶点。L5：score 不变为何？答：协议不重评。易错：同时精化全部姿态；证据为源码。

### 48. 非负部分和严格界与启发式早停

**任务／前提／演进／状态：M。** 固定目标与当前最优完整值 → 安全剪枝或明确标注的近似早停。以界减少差候选工作量，代价是界计算；本地仅形状行级启发式，没有严格 SAD／SSD／ZNCC 剪枝。[cite:1](#source-1)

**L1 步骤。** 完整评一个候选取得 B → 新候选逐项累计 → 用合法下界／上界证明无改进再退出 → 否则算完更新 B。形状现状是在每行后最佳分≥max(min_score,0.98) 即跳过后续行，是另一流程。

**L2 机制。** 非负残差项的部分和不减，可证明候选最终不优；相关项有正负，部分和低不代表最终低。形状上界 1 而当前 0.98 时，后面仍可能有 1，故启发式不保最优。

**L3 工程。** 先固定支持、权重、归一分母及保留并列策略，再设计次序和浮点裕量。若需保留全部并列最优，用严格 >B；允许丢并列可用 ≥B。界舍入需保守，不能无量纲固定 epsilon 强剪。

**L4 推导。** \(E_k=\sum_{i=1}^ke_i\le E_n\) 对固定 e≥0，E_k>B 可剪。对完整中心化向量 t、i，未算集合 R 由 Cauchy–Schwarz 有 \(c\le c_k+\|t_R\|\|i_R\|\)；已知完整非零分母时得到 ZNCC 上界。部分样本均值改变目标，不能套此界。

**L5 源码／测试设计。** [形状行级早停](../../traditional/template_matching/shape_based.py#L59-L73) 不是逐像素 SSDA。未来严格版需与无剪完整搜索逐候选／并列集合对照，测负相关、晚强贡献、近等值、遍历次序和溢出。当前冒烟不验证启发式全局最优性。

**面试追问与答案。** L1：B 从哪来？答：可信完整候选。L2：部分相关低能丢？答：需剩余上界。L3：等于 B 能剪？答：取决并列协议。L4：ZNCC 界从哪来？答：剩余向量范数界。L5：0.98 早停精确？答：不是。易错：统计、启发式、确定性界混称无损；证据为推导和源码。

### 49. 几何模型、DLT 与重投影验证

**任务／前提／演进／状态：M。** 分散对应和物理模型 → 平移／相似／仿射／单应。增加整体几何约束可剔除局部相似错配，代价是模型失配和外推风险；本地只构造相似 H，点对 DLT 未实现。[cite:1](#source-1)

**L1 步骤。** 定模板到图像方向 → 选择最小物理模型 → 对应归一化 → 最小二乘／DLT（可作为 RANSAC 内核）→ 反归一化 → 内点重拟合 → 重投影、覆盖、四角和物理范围验证；模型退化失败。

**L2 机制。** 对应集合的统一几何避免仅描述子相似；多自由度降低训练残差不等于外推更准。单一平面 H 不适合一般三维视差，变形自由度也可能把缺陷“对齐掉”。

**L3 工程。** 自由度平移 2、相似 4、仿射 6、单应 8；先查点分布和模型残差结构，再调阈值。点归一化去质心、平均距离调 √2 改善条件；阈值须与图像缩放同步。

**L4 推导。** \(\tilde q\sim H\tilde p\)，\(\tilde q\times H\tilde p=0\) 消去齐次比例，每对两条独立约束构 \(Ah=0\)。在 \(\|h\|=1\) 下取最小奇异向量；归一化坐标矩阵为 Tp/Tq，原 H 为 \(T_q^{-1}H_nT_p\)。单应至少四对非退化，仿射三对非共线，相似两对不同点，平移一对；代数残差不是重投影误差。

**L5 源码／测试设计。** 最小 8×9 DLT 系统若用精简 SVD，可能没有返回零空间最后向量，须确保取得完整右零空间；检查 H 齐次分母、近奇异、投影面积与翻折。测共线、聚集、重复点、缩放坐标及三维模型错配。pose_ncc 的底行 [0,0,1] 不证明单应估计已实现；本地 DLT 未运行。

**面试追问与答案。** L1：先选 H 吗？答：先选物理模型。L2：自由度多更准？答：可能过拟合。L3：点多仍坏查什么？答：覆盖、条件数、模型。L4：四对必可求 H？答：还需非退化。L5：8×9 精简 SVD 风险？答：缺零空间向量。易错：3×3 输出等于透视能力；证据为显式推导与源码。

### 50. 特征前端＋匹配器＋RANSAC＋局部精化组合

**任务／前提／演进／状态：R。** 两图及各阶段兼容模型 → 带验证的粗到细配准。可选 SIFT／ORB＋近邻，SuperPoint＋SuperGlue／LightGlue，或 LoFTR；随后按需要接 RANSAC、LK／ECC。组合互补表示、几何和连续精度，增加接口／失败传播成本，仓库未实现端到端链。[cite:1](#source-1)

**L1 步骤。** 固定预处理坐标 → 前端提点或 LoFTR 对应 → 对应过滤 → 按物理模型 RANSAC → 查内点覆盖和投影 → 条件满足才局部精化 → 独立拒识 → 同一方向输出 H；任一关键阶段失败则停止或回退。

**L2 机制。** 特征给大运动初值，RANSAC 剔粗差，局部直接法细化；已经对齐小 ROI 不必全链。网络分数、内点率、ZNCC 和 ECC 相关系数不同，不能串联同一个阈值解释为目标概率。

**L3 工程。** 先定义平移／相似／仿射／单应与场景，固定权重和点尺度，再设分阶段预算与超时。精化前记录粗 H，精化后若支持变小、投影失真或残差恶化则回退；不能只看相关上升放行。

**L4 推导。** 若点坐标经缩放／补边齐次映射 A、B 后估得 \(H'\)，原坐标 \(H=B^{-1}H'A\)。若直接残差变换 Δ 作用于图像侧则 \(H_{new}=\Delta H\)，作用模板侧则 \(H\Delta\)；两者一般不交换。级联召回受前序可见对应限制，不能由后端更强推导无漏检。

**L5 复现设计／测试。** [learned_matching.py](../../dl/learned_matching.py#L18-L30) 直接 NotImplementedError；文档元组与签名 dict 尚未形成可执行协议。需定义空点、拒配 -1、几何失败、精化失败和超时，测试图像交换、缩放回填、无重叠、重复图案及模型不适用；本地未运行该组合。

**面试追问与答案。** L1：每步必需？答：按任务可删，不是固定链。L2：网络后为何几何验证？答：对应置信不保证物理一致。L3：ECC 变好就接受？答：还查支持与模型。L4：H 怎样回原图？答：B⁻¹H′A。L5：失败怎样传播？答：明确原因，禁止用假单位阵当成功。易错：骨架文字即实现；证据为源码。

### 51. 一对一评测、误差、重复性与计时

**任务／前提／演进／状态：K。** 预测集、独立真值及计时调用 → 检出／漏检／误报／误差。由仅报成功样例误差扩为集合验收，代价是明确真值和任务口径；基准分配是评测组件，不是匹配器内 RANSAC。

**L1 步骤。** 每场景三个固定种子 → 每种子预热一次、计时三次 → 最后结果用于检测 → 按中心距离一对一分配 → 位置／角度／尺度门控 → 汇总漏检和误报 → 汇总 9 次时延中位数；ambiguous 任务期望拒识，expected 置空。

**L2 机制。** 一对一防一检出多次命中，但先最小中心距离再门控不必最大化最终合法命中数。只报命中误差有选择偏差，必须同时报告漏检／误报；同数组重复运算是计算可复现性，不是重采集重复性。

**L3 工程。** 基准门控为中心≤2 px、圆周角差≤7.5°、尺度差≤0.1，不是现场精度。现场按工件／批次隔离，保留无目标、对称、低重叠、遮挡、离焦；报告硬件、版本、预热和尾延迟，像素与毫米需标定区分。

**L4 推导。** 分配 \(\min_X\sum C_{ij}X_{ij}\)，X 为 0/1、行列最多一次且总分配数固定为两集合大小的较小值；否则非负代价下空分配就会退化为最优。角差 \(|((\theta_p-\theta_g+180)\bmod360)-180|\)。RMSE \(\sqrt{\sum\|p_i-g_i\|^2/N}\) 含偏差，重复坐标样本标准差用 N−1 分母，两者不互代。只有成功帧的误差条件分布不代表全帧可靠性。

**L5 源码／测试。** [benchmark_pose_ncc.py](../../tests/benchmark_pose_ncc.py) 用 `linear_sum_assignment`，三次重复不算三个新采集；真值在 [test_pose_ncc.py](../../tests/test_pose_ncc.py) 用独立矩阵和 SciPy map_coordinates 构造，不全靠待测 `_warp` 自证。本次只跑回归／冒烟，不跑完整基准；off_grid 故意留粗网格失败，正常退出不等于全场景检出。

**面试追问与答案。** L1：9 次耗时等于 9 独立场景？答：不是。L2：误差小就检得好？答：须看漏检与拒识。L3：现场补什么？答：独立采集、批次和困难负例。L4：先分配后门控总最优？答：不保证最大合法命中。L5：真值能复用待测 warp 全生成？答：会有自证风险。易错：测试容差当精度认证；证据为测试／基准源码。
