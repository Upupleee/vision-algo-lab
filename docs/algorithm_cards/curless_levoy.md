## 范围、状态与证据口径

核验日期：**2026-11-05**。本文件只有一张卡，唯一键 `curless_levoy.md:CL01`，承接 **G37／10-03／三维 E03**。历史对象为 Brian Curless、Marc Levoy，*A Volumetric Method for Building Complex Models from Range Images*，**SIGGRAPH 1996**；作者后续发布的 **VripPack 0.31** 是实现对照，不冒充1996年提交源码。本文不另建现代 TSDF、Marching Cubes、空间雕刻或 KinectFusion 卡。[cite:1](#source-1)[cite:2](#source-2)

核心结论：以**已经对齐的距离图及传感器视线**为输入，把沿视线到测得表面的有符号距离和置信权重累积到体素网格，再提取零等值面；可利用已见为空与未见空间的边界补洞。它不是最近表面的欧氏距离变换，不负责配准，也不是自动恢复不可见真实几何的占据概率模型。[cite:1](#source-1)[cite:3](#source-3)

## CL01 沿视线带权距离累积与等值面重建

### 任务契约与三维分支定位

**输入：**若干距离图或由距离图构成的局部三角网格；每视图从扫描坐标到统一世界坐标的已知刚体变换；传感器射线模型、有效观测掩膜、置信信息；体积边界、体素间距、距离及权重带宽。单位必须统一。仅给无序点云而不给视点／射线，不能无损复现此方法的可见性与雕刻部分。[cite:1](#source-1)[cite:3](#source-3)

**输出：**累积距离场与支持权重、未知／已见为空的可区分状态、观测支持的三角网格；若启用补洞，还必须保留补全顶点／三角形标签。输出不是体素占据概率，不直接给尺寸合格判定，也不自动给位姿、尺度标定或每点统计置信区间。

**前提：**静态、配准可靠、射线几何正确、深度不连续没有被错误连接，局部表面有足够采样。原文使用扫描器视线表达主方向不确定性；依所用三角测距处理，方向可能对应激光或相机，不能一律替换成普通针孔相机光轴。作者指南支持的扫描模型与任意 RGB-D 内参接口也不能画等号。[cite:1](#source-1)[cite:3](#source-3)

本卡位于“三维总览：获取／对应 → 配准 → **融合 F**”的后端。[G02 ICP](remaining_domains.md#g02-刚性-point-to-point-icp)可以提供局部配准，但不包含本卡；融合不修复米／毫米、变换方向、低重叠或动态物体问题。与最近点隐式重建相比，本法保留扫描可见性；与多边形拼接相比，拓扑由体积等值面形成，代价是离散化、细结构损失与内存。[cite:1](#source-1)

### L1 步骤：从一幅扫描到融合表面

1. **固定坐标与网格。**定义世界坐标中的采样位置，核对每视变换方向与扫描射线。初始化所有支持权重为0，场值为“未见”编码；不要把初始数值当测量。
2. **距离图网格化并拒绝跨深度边的三角形。**原文按距离图邻接连三角形，按边长阈值丢弃跨跃；不能对前景与背景任意双线性插值得到不存在的表面。
3. **计算并插值置信。**原文降低斜视及网格边缘权重；每个三角形顶点有置信，沿射线的交点采用重心线性插值。具体指数／偏置属于源码配置，而不是1996原文给出的普适噪声标定。
4. **沿传感器视线采样距离。**对候选体素，将其映射到该扫描的射线并与该视图可见距离表面相交，计算体素与交点的有符号视线距离。遇无有效观测、投影越界、遮挡后的远处或被拒绝三角形，不制造距离数据。
5. **截断距离、裁定权重支持。**距离值可饱和到有限范围；权重在表面后侧较快归零以免与物体另一侧干扰，前侧也可有限延伸节省计算。距离饱和与“不更新”是两件事。
6. **逐体素加权累积。**对有效非负权重更新分子与分母，保持零权重状态不参与除法。每视只有预先定义的可见交点提供支持；不把同一帧重采样的重复片元当多次独立测量。
7. **可选空间雕刻。**沿有效观测的视线向传感器回溯，标记确实看穿的前方空间为空；原文也使用体积外的背景板提供穿孔视线。无返回值、图像外或表面背后的空间不能因此被雕空。
8. **提取及停止。**完成有限扫描集合后停止，也可在任一累计阶段提取。观测模式跳过零权重采样；补洞模式还连接空／未见边界并保留补全标签。采用消歧义的 Marching Cubes 查表、边插值与共享顶点，不把二值阈值后体素立方体外壳称作同一提取器。

步骤2–6对应原文§3，步骤7–8对应§4及§5.2。原文优化为重采样对齐扫描线、RLE压缩与双缓冲、深度极值树剪枝；这些改变遍历，不授权改变扫描几何或距离语义。[cite:1](#source-1)[cite:4](#source-4)

**可走通的输入契约：**同一固定射线的两个有限有效距离观测，带各自正权重，且最终交点位于两者未截断区。将扫描顺序依次送入步骤4–6，场的零点即L4的一维带权平均；该解析输入只验证融合核心，不代表已运行距离图网格化与三维提取。

### L2 机制：距离、权重、可见性与状态不能混用

#### 距离及符号约定

设射线为 \(x=o+t\hat v\)，\(\hat v\) 从传感器指向场景且为单位向量；有效可见交点 \(p=o+r\hat v\)。本卡沿用原文“空侧负、后侧正”的约定：

\[
d_i(x)=t-r=(x-p)^T\hat v.
\]

其绝对值是在**指定射线的交点**之间量长，不是在整个表面寻找最近点。原文§4把空状态编码为 \(D_{\min}<0\)、未知为 \(D_{\max}>0\)，两者权重均为0；因此符号也必须连同有效性解释。常见现代 TSDF 用相反符号 \(s_i=-d_i\)，空侧正；统一翻转场值和法向方向不改变零点，但混用会破坏雕刻与可见面判断。[cite:1](#source-1)[cite:5](#source-5)

“投影距离”不能不说明坐标：若针孔接口输入光轴深度 \(Z(u)\)，体素在相机坐标为 \(x_c=(X,Y,Z_x)\)、投影为 \(u\)，令 \(\lambda(u)=\|K^{-1}\tilde u\|\)，则同射线上

\[
d_z=Z_x-Z(u),\qquad d_{\rm ray}=\lambda(u)d_z.
\]

\(d_z\) 是光轴深度差，\(d_{\rm ray}\) 才是有单位射线长度；离轴时不相等，两者都不是一般欧氏最近表面距离。传感器直接输出射线距离时，不得再乘一次 \(\lambda\)。这是针孔几何的条件推导，不是说1996系统就是针孔 RGB-D。[cite:1](#source-1)[cite:5](#source-5)

#### 截断、置信与占据语义

| 对象 | 原方法含义 | 常见错误及后果 |
|---|---|---|
| 距离截断 | 距离斜坡在有限动态范围外饱和；正负值围住零面 | 把整个物体背后都赋有正权重的饱和值，会与背面扫描相互抹除 |
| 权重窗 | 决定一视图在该位置是否影响融合；表面后側衰减用于避免对侧干扰 | `clip`之后无条件加权，不等于原方法的可见性处理 |
| 观测置信 \(q\) | 与扫描器、法向斜视、网格边缘相关；交点插值 | 把数值当校准过的“正确概率”，或把重复扫描权重当独立样本数 |
| 未知／unseen | 未观测或无有效支持；\(W=0\)，原编码 \(D=D_{\max}\) | 仅凭正值称为实体占据；会把无数据外部空间也填实 |
| 空／empty | 有有效视线证明位于表面前方；远离斜坡时可为 \(W=0,D=D_{\min}\) | 将所有 \(W=0\) 视为未知，丢掉雕刻信息；或把无深度返回当空 |
| 近表面 | \(W>0\) 的连续距离支持，含零面的两侧 | 将原文三状态改写成“未知／空／已证实实心”；单次扫描不能证实内部材质 |
| 占据侧 | 本卡 \(D>0,W>0\) 可作局部“表面后／可能内部”解释 | 距离场不是Bayesian occupancy grid；薄片、空腔与未见后方不能据此可靠分类 |

原文三态实际是 **unseen／empty／near the surface**，不是完整的概率占据三分类。保存未知的正端编码只是让空／未知边界能由同一等值面算法连接。补洞面是可解释的几何推断，不是新观测；其锯齿可局部平滑，但仍必须排除出实测尺寸验收。[cite:1](#source-1)

#### 为什么必须保留扫描可见性

同一射线的首个有效表面遮挡其后空间；只在不确定带内允许后侧距离贡献，远后方保持未知。斜坡很宽时，薄物两侧会同时影响同一体素；很窄时，不同噪声观测在最终零点处可能没有共同支持。不存在同时适合所有噪声与薄结构的通用截断宽度。

删掉配准先验会把位姿误差当距离噪声融合成双层／厚表面；删掉边缘拒绝会在遮挡轮廓生成虚构三角形，进一步把空区误雕或补错；删掉 \(W\) 会让未知编码参与平均。原文强调稳健不等于使用了具有高击穿点的鲁棒损失，固定权重最小二乘仍可能被高权外点拖动。[cite:1](#source-1)

#### 原方法与现代 TSDF 的准确关系

| 维度 | Curless–Levoy 1996／VRIP对照 | 现代对照：KinectFusion 2011 |
|---|---|---|
| 共有核心 | 沿视线的带权距离累积、截断支持、零等值面 | 继承这一核心，并不因叫TSDF就变成精确欧氏SDF |
| 输入与位姿 | 已对齐距离图；VRIP明确只合并、不对齐 | 深度流、模型预测与多尺度ICP形成跟踪／建图系统 |
| 距离与符号 | 原文空侧负；VRIP为偏置定点编码、扫描视线长度修正 | 原文正文采用空侧正的projective TSDF，并讨论光轴与射线度量 |
| 截断／置信 | 原文已有距离和权重截断；源码有非对称权重斜坡、边缘置信 | 不可写“直到KinectFusion才有截断”；其§3.3采用投影查深度、后侧无测量判据，讨论视角／深度权重及单位权重 |
| 累积策略 | 原文无限制加法在精确算术、固定权重下顺序无关；固定码另有量化限制 | 式(13)允许权重封顶形成移动平均；此时不能再保证全历史等权或顺序无关 |

### L3 工程权衡：先查几何，再调带宽

| 参数／政策 | 单位、来源与初值依据 | 代价、症状与诊断 |
|---|---|---|
| 体素间距 \(h\) | 物理长度；按最小需保留结构与输入采样密度选择，并做分辨率收敛对照 | 固定体积下稠密存储约随 \(h^{-3}\) 增长；更细不补足传感器信息 |
| 距离斜坡全宽 \(L\) | 与深度同单位；VRIP `OccupancyRampWidth=0.002`，端点为 \(\pm L/2\) | 若单位为米，该默认对应2毫米全宽，不是通用2毫米精度保证，更不是半宽0.002 |
| 权重端点 \(C_1\ldots C_5\) | VRIP坐标差默认 `0.003, 0.0025, -0.001, -0.0015, -0.002`；前方较长、后方快速下降 | 宽窗抹薄物、窄窗缺共同支持；检查沿射线的逐视距离／权重剖面而非只看平整度 |
| 斜视与边缘置信 | 固定源码 `ConfidenceExponent=2`、`EdgeConfSteps=8`、`EdgeConfExponent=1`、`ConfidenceBias=1`；步数是网格拓扑距离而非毫米 | 降权能抑制边缘误差但减少有效覆盖；视线／法向反向可能把全部支持打低 |
| 连接阈值与采样 | 原文边长拒绝；指南还提供法向朝向判据 | 过宽跨前背景，过严打碎网格；无效像素不能靠插值变有效 |
| 雕刻与补洞 | 显式开关、有效视线、背景板及独立标签 | 错射线会不可逆地改变空区解释；开启后“更完整”不等于“更准确” |
| 累积精度／权重上限 | 原文无界加法；源码定点及现代封顶分别记录 | 溢出、量化、封顶或依赖当前场的门控都可能破坏顺序无关 |

上述数字只来自0.31源码及作者指南，未作为现场推荐值。原文§3以测距最大不确定区间讨论后侧权重衰减；指南§3以约两倍最大不确定度说明**距离斜坡全宽**，并要求权重至少覆盖斜坡、两端渐消。这些不是同一参数的两个相等公式，且“不确定区间”的全宽／半宽应依原图及设备定义落实，不能把统计标准差直接当最大误差。[cite:1](#source-1)[cite:3](#source-3)[cite:6](#source-6)

**排障顺序：**检查单位、扫描模型、变换和同步 → 对比单视重投影与重叠面错位 → 检查跨边三角形、无效码、法向与置信 → 查看逐视距离／权重及空／未知剖面 → 再调整 \(h\)、斜坡和权重窗 → 最后检查提取阈值与补洞标签。双层面先查位姿，薄壁消失先查两侧权重支持，空腔被填先查视线雕刻与缺失观测，而不是统一增大体素掩盖错误。

**待执行验收：**固定原始扫描、位姿和参数，按距离／入射角／材质／薄结构／遮挡分组；分别报告观测面误差、覆盖率、补全面积、失败率和资源消耗。真实尺寸需可追溯参考及独立误差预算；不以删除困难点后的低RMSE或补洞后的水密性代替测量准确度。

### L4 数学推导与成立范围

#### 累积更新、顺序无关与标量最小二乘

对固定体素 \(x\)，令每视的有效截断距离为 \(f_i\)、非负权重为 \(w_i\)。原文式(1)–(4)可写为

\[
A_n=\sum_{i=1}^n w_i f_i,\quad W_n=\sum_{i=1}^n w_i,
\quad F_n=A_n/W_n\quad(W_n>0),
\]
\[
A_{n+1}=A_n+w_{n+1}f_{n+1},\quad W_{n+1}=W_n+w_{n+1},
\quad F_{n+1}=\frac{W_nF_n+w_{n+1}f_{n+1}}{W_n+w_{n+1}}.
\]

当 \(W_n=0\) 且新权重为正时直接取 \(F_{n+1}=f_{n+1}\)；两者都为0就不除法。加法的交换律给出精确算术下、输入权重固定且无封顶的顺序无关；浮点规约顺序与定点逐步量化只近似满足。若按当前融合残差拒绝新帧，连支持集都依赖顺序，不能沿用此证明。[cite:1](#source-1)

这也可由每体素标量目标推导：

\[
J(F)=\sum_i w_i(F-f_i)^2,\quad
J'(F)=2(WF-A),\quad J''(F)=2W.
\]

\(W>0\) 时有唯一最优 \(F=A/W\)；\(W=0\) 时不可辨识。注意是 \(w_i\) 乘平方残差，不是将 \(w_i f_i\) 当观测后做无权最小二乘。此标量证明不自动证明一般三维融合零面的几何最优性。

同方向一维、最终零点周围没有截断且权重沿该射线不变时，\(f_i(t)=t-r_i\)，故

\[
F(t)=t-\frac{\sum_i w_i r_i}{\sum_i w_i},\qquad
t^*=\frac{\sum_i w_i r_i}{\sum_i w_i}.
\]

它正好最小化 \(\sum_i w_i(t-r_i)^2\)，对应原文式(5)。若最终零点落在斜坡饱和区或权重渐消区，则不能把整条融合函数继续写成此直线。[cite:1](#source-1)

#### 一般三维：不能省掉视线与面积变换

原附录A对正交扫描、沿射线独立误差以及各视共同可见的局部表面片，考虑射线参数域上的目标

\[
E(S)=\sum_i\iint_{\Omega_i}w_i(s,t,S)\,d_i(s,t,S)^2\,ds\,dt.
\]

转到局部图面 \(z=f(x,y)\) 的公共参数域时，必须带上投影面积雅可比，例如取向一致区域的 \(J_i=|\hat v_i\cdot(-f_x,-f_y,1)|\)。不能把各视相同像素面积直接当相同曲面面积。原文通过变分给出方向导数条件，并使用“沿视线权重不变、距离导数为1”简化：

\[
\sum_i\partial_{\hat v_i}(w_i d_i^2)=0,
\quad \partial_{\hat v_i}w_i=0,
\quad \partial_{\hat v_i}d_i=1
\quad\Longrightarrow\quad \sum_i w_i d_i=0.
\]

当总权重为正，分母不改零点，便连接到融合等值面。这里保留原附录式(6)–(9)的证明草图，不声称独立完成全部Euler–Lagrange推导。特别是实际窗函数沿射线变化时，多出 \((\partial_{\hat v_i}w_i)d_i^2\) 项；遮挡、透视、饱和距离、视图相关配准误差及不共视区域也不满足全部前提。因此“任意截断场的零面是全局几何最小二乘最优”是错误推广。[cite:1](#source-1)

#### 视线距离与欧氏距离的反例

局部平面上，交点 \(p\) 的单位法向为 \(n\)。体素仍沿同一射线，\(x-p=d_{\rm ray}\hat v\)，于是其有向点到平面距离为

\[
d_{\perp}=n^T(x-p)=(n^T\hat v)d_{\rm ray}.
\]

仅当法向与射线平行时，两种距离绝对值相等；斜视时差异由余弦决定，掠射时可很大。曲面或多个表面下，连这个局部平面关系也不能作为全局最近点公式。置信乘余弦与距离乘余弦是不同操作，不能互相替代。[cite:1](#source-1)[cite:5](#source-5)

#### 截断与参考权重窗

为使教学伪代码可执行，采用**参考设计**：统一射线物理单位，距离半宽 \(\mu>0\)，\(f(d)=\operatorname{clip}(d/\mu,-1,1)\)；设 \(a_1>a_0\ge\mu>0\)、\(b_1>b_0\ge\mu\)，并定义

\[
g(d)=\begin{cases}
0,&d\le-a_1\text{ 或 }d\ge b_1,\\
(d+a_1)/(a_1-a_0),&-a_1<d<-a_0,\\
1,&-a_0\le d\le b_0,\\
(b_1-d)/(b_1-b_0),&b_0<d<b_1.
\end{cases}
\qquad w_i=q_i g(d_i).
\]

它保留前后支持不对称、零面附近线性斜坡与置信乘窗，但**不是VRIP全部分支的逐行翻译**：不包含其第五端点历史尾段、最低权重、边缘扩展、假数据位与精确端点分支。距离归一化尺度在同一次融合中必须一致；若每视不同 \(\mu_i\)，直接平均 \(d_i/\mu_i\) 会改变相对贡献，不能称为同一个物理距离目标。

#### 等值面插值、误差与复杂度

若边端点 \(x_a,x_b\) 的有效场值 \(F_a,F_b\) 异号，线性边插值为

\[
\alpha=\frac{F_a}{F_a-F_b},\qquad x_0=(1-\alpha)x_a+\alpha x_b.
\]

等值面拓扑由单元各端点符号及消歧义策略决定；只有端点插值不能证明整网格水密或无自交。同一条边插值 \(F=A/W\) 与直接插值 \(A\)，当两个端点 \(W\) 不等时，**离散零点一般不同**，尽管连续函数 \(A\) 与 \(A/W\) 的零集相同。VRIP另有 `-vw` 模式，比较时须固定它。[cite:6](#source-6)

一维独立、无偏测距且权重为逆方差时有 \(\operatorname{Var}(t^*)=1/\sum_i1/\sigma_i^2\)；一般固定权重的方差为 \(\sum_iw_i^2\sigma_i^2/(\sum_iw_i)^2\)。相关误差须保留协方差，统一偏差不会随扫描数平均消失；启发置信未标定时不能从 \(W\) 读出该方差。

设N幅扫描、V个体素，朴素遍历是 \(O(NV)\) 次投影／采样和 \(O(V)\) 空间；距离图网格化另按输入点数计。实际RLE成本与运行段数及变化带大小相关，最坏仍可接近稠密；重采样、深度树和双缓冲另有成本，不能保证固定压缩比。网格提取按访问单元与输出三角形计。**未提供通用理论误差界或无条件全局收敛保证**：有限增量处理本身不需要优化迭代收敛；体素、插值、量化及配准引入的误差仍须验证。

下列Python只使用标准库，检查**解析构造的标量契约**，不是合成扫描实验、论文性能复现或仓库算法实现。采用float64算术；用参考窗四个端点均有定义的写法，避免源码的严格不等号落错分支。

```python
import math
from itertools import permutations

def sample(d, q, mu, a1, a0, b0, b1):
    values = (d, q, mu, a1, a0, b0, b1)
    if not all(math.isfinite(v) for v in values):
        raise ValueError("NONFINITE")
    if not (a1 > a0 >= mu > 0 and b1 > b0 >= mu and 0 <= q <= 1):
        raise ValueError("BAD_CONTRACT")
    if d <= -a1 or d >= b1:
        g = 0.0
    elif d < -a0:
        g = (d + a1) / (a1 - a0)
    elif d <= b0:
        g = 1.0
    else:
        g = (b1 - d) / (b1 - b0)
    f = max(-1.0, min(1.0, d / mu))
    return f, q*g

def accumulate(observations):
    A = W = 0.0
    for f, w in observations:
        if not (math.isfinite(f) and math.isfinite(w) and w >= 0):
            raise ValueError("BAD_OBSERVATION")
        A, W = A + w*f, W + w
        if not (math.isfinite(A) and math.isfinite(W)):
            raise ValueError("OVERFLOW")
    return (None if W == 0 else A/W), W

def edge_root(fa, fb):
    if not all(math.isfinite(v) for v in (fa, fb)):
        raise ValueError("NONFINITE")
    if fa == fb or (fa > 0 and fb > 0) or (fa < 0 and fb < 0):
        raise ValueError("NO_UNIQUE_BRACKET")
    scale = max(abs(fa), abs(fb))
    a, b = fa / scale, fb / scale
    return a / (a - b)

def must_reject(call):
    try:
        call()
    except ValueError:
        return
    raise AssertionError("expected rejection")
```
