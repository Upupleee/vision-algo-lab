## 演进主线与实现边界

持续优化的维度是退化／噪声模型、先验、保真目标、恢复求解、下游影响和计算成本。**工程线**：检查采集 → 暗平场 → 必要去噪 → 可选增强 → 尽量一次几何采样 → 用原图对照下游验收。不是所有步骤都应启用。

**历史线**：基础局部平滑 → 1998 双边的值域约束 → 2005 NLM 的块自相似 → 2007 BM3D 的分组变换；另一分支为 2010 引导局部线性模型 → 2015 Fast Guided 的低分辨率系数近似；2017 DnCNN 改变图像先验，2018 Noise2Noise 改变监督条件。后两者可组合，不是替代关系。暗平场、对比度、反卷积和重采样仍是并行分支。基础方法未追溯唯一首创年，不编造日期。

源码核对入口：高斯见 [edge_subpixel.py](../../traditional/subpixel/edge_subpixel.py) 的 `devernay_edges` 和 [caliper.py](../../traditional/caliper_measurement/caliper.py) 的 `Caliper.measure`；双线性见后者 `_sample_points` 及 [pose_ncc.py](../../traditional/template_matching/pose_ncc.py) 的 `_warp`；面积见 `_search_pose`、`match_pose_ncc`；最近邻／双三次见 [synthetic.py](../../data/synthetic.py) 的 `make_template_scene`；灰度见 [focus_measures.py](../../traditional/autofocus/focus_measures.py) 的 `_prep`。数据生成不等于去噪实现；匹配输入检查不等于相机校正。

[requirements.txt](../../requirements.txt) 声明 NumPy、OpenCV、SciPy 等最低版本，未锁版本。原稿记录的解释器环境为 Python 3.13.14、NumPy 2.5.4、OpenCV 5.0.0；这些是历史记录，不是本次扩充重新确认的环境。本次命令行 `python` 指向不可执行的商店入口、`py` 不可用，未重跑原 Python 检查器。外部源码引用固定 **OpenCV 4.10.0**，与原稿运行环境不是同一版本，不能声称逐位一致。无新增依赖、模型或算法源码。

## P01 暗场校正

任务／输入输出／前提：工作帧 I 与同温度、曝光、增益的 M 张遮光帧，输出去偏置浮点图与掩膜。演进定位：固定偏置不能靠空间平滑消除 → 加性响应建模 → 时间平均估偏置；代价是参考采集，遗留温漂和随机读出噪声。实现：未实现。来源：[cite:1](#p-source-1)。

### L1 步骤
核对配置 → 剔除坏参考 → 逐像素求暗场均值 D → 浮点计算 I−D → 输出；参考无有效帧或配置不一致则拒绝。处理一次工作帧即停止。

### L2 机制
遮光保留电子偏置与暗电流，平均减小参考噪声。不减 D 会污染后续平场比值；只减全局常数无法消除列／像素偏置。当前帧的随机噪声仍在。

### L3 工程权衡
先固定热状态、曝光和增益，再由参考均值标准误决定 M，而非照搬固定帧数。DN 负残差应保留到统计完成；截零使暗区均值上移。条纹随温度变时先换参考，不先加大去噪核。

### L4 推导
设 \(I=gR+d+n\)，\(D=M^{-1}\sum_m(d+e_m)\)。零均值噪声给 \(E[I-D]=gR\)。工作帧与各参考独立时，\(\operatorname{Var}(I-D)=\sigma_I^2+\sigma_D^2/M\)；有相关性则需加协方差项，温漂还引入偏差。这是统计方差而非确定性上界。建参考 O(MN)，在线 O(N)。

### L5 伪代码与数值测试
```text
require config(I) matches config(dark_frames)
D = zeros_float64(shape(I)); count = zeros_int(shape(I))
for frame in dark_frames:
    update_mean(D, count, float64(frame), valid(frame))
valid_out = valid(I) and count > 0
out[valid_out] = float64(I)[valid_out] - D[valid_out]
return out, valid_out
```
数值测试：暗帧 `[8,12]` 的单像素均值 10，I=7 输出 −3；σ_I=2、σ_D=2、M=4 时方差为 5。额外测试配置拒绝、全无效和 uint16 下溢。在线均值节省内存，必须与 float64 批均值比较；非现场测试。

五层追问答案：L1“输出只有图吗？”→图及有效掩膜；L2“减一次便无噪声？”→只去稳定加性项；L3“热机后变差？”→先查参考温度；L4“为何还加 σ_D²/M？”→参考估计也随机；L5“7−10 得亮点？”→无符号下溢。易错：以截零掩盖计算错误。

## P02 平场校正

任务／前提：I、暗场 D、均匀亮场 F → 相对增益校正图；光路固定、参考未饱和。演进定位：减偏置后仍有暗角／响应差 → 乘性建模 → 除响应；代价为参考维护，遗留低响应噪声放大。实现：未实现。来源：[cite:1](#p-source-1)。

### L1 步骤
平均有效亮场 → G=F−D → 根据噪声门限建立 G 有效掩膜 → 固定 m=有效 G 均值 → 计算 m(I−D)/G；无有效响应则失败。

### L2 机制
减暗后比值消掉共同增益 g。直接 I/F 残留偏置误差；非均匀参考会把其纹理反向写入图像。epsilon 只能防计算除零，不能恢复死像素。

### L3 工程权衡
G 门限用 DN，按允许增益放大和参考噪声定；先查平场均匀、曝光、焦距和饱和，再增参考数。预先缓存 gain=m/G 可提速，但校正帧版本与光路必须一起管理。

### L4 推导
由 \(I=gR+d,F=gR_f+d\)，得 \((I-D)/(F-D)=R/R_f\)。令 A=I−D、G=F−D，固定 m 时 \(J_I=m/G,J_F=-mA/G^2,J_D=m(I-F)/G^2\)，所以小噪声传播为 \(\operatorname{Var}(q)\approx J\Sigma J^T\)。同一个 D 出现在分子分母，不能当独立误差两次相加；若 m 也随机，须扩展 Jacobian。G→0 病态，无通用恢复界。在线 O(N)。

### L5 伪代码与数值测试
```text
I, F, D = float64(I), float64(F), float64(D)
G = F - D
ok = finite(I, F, D) and not_saturated(F) and G > response_threshold
require any(ok)
m = mean(G[ok])
gain[ok] = m / G[ok]
q[ok] = gain[ok] * (I[ok] - D[ok])
return q, ok
```
测试：I=[30,50]，D=[10,10]，F=[50,90]，m=60 → q=[30,30]；F=D 的像素必须无效，不应输出巨大数字。缓存乘加与直接除法用同掩膜比较，float64 算术容差 1e−12。

五层追问答案：L1“先减还是除？”→减 D 后除 G；L2“任意白墙可作真值？”→均匀性未知会污染增益；L3“角落颗粒重？”→检查小 G；L4“误差仅来自 I？”→F、D、m 也可能随机；L5“如何优化？”→缓存有效增益并保留掩膜。易错：把大增益像素视为修复完成。

## P03 高斯滤波

任务／前提：图像、空间 σ_s、边界 → 同尺寸低通图；目标尺度大于核宽。演进定位：均匀平均的频响和距离权重不足 → 高斯局部先验 → 可分离平滑；代价为细节衰减，遗留窄边缘混合。实现：任务局部已有，非统一接口；来源：[cite:2](#p-source-2)。

### L1 步骤
确定 σ_s、截断半径 r 和边界 → 采样归一化一维核 → 行卷积 → 列卷积；所有像素完成即停。σ_s=0 的旁路明确处理，勿与 API 自动推断混淆。

### L2 机制
近邻大权重抑制随机高频；核和为 1 才保常量。跨越阶跃仍会混合，高斯不是保边模型。删掉边界定义会造成 ROI 与整图结果不一致。

### L3 工程权衡
σ_s 和 r 为 px；可从 r=ceil(3σ_s) 的截断近似起步，再按截断误差与最小结构宽度验证，非通用最优。先检查核宽相对细线，再查边界和定位偏移；不要只看图像变平滑。

### L4 推导
\(G(x,y)=c\exp[-(x^2+y^2)/(2\sigma_s^2)]=g(x)g(y)\)，由指数拆分获得可分离性，O(Nk²) 降为 O(Nk)。连续频响 \(\widehat G(f)=\exp[-2\pi^2\sigma_s^2\|f\|^2]\)；离散截断仅近似。独立噪声输出方差为 \(\sigma_n^2\sum_jw_j^2\)，由加权和方差得到；没有通用边缘位移上界。

### L5 伪代码与数值测试
```text
u = arange(-r, r + 1)
w = exp(-u*u/(2*sigma_s*sigma_s)); w = w / sum(w)
q = convolve_columns(convolve_rows(float64(I), w, border), w, border)
```
测试：r=1、σ_s=1 的核约 `[0.27406862,0.45186276,0.27406862]`；常量 10 保持 10，一维独立噪声方差倍数约 0.35440717。二维倍数是该值平方。现有卡尺采用 `getGaussianKernel` 与 `BORDER_REFLECT`，边缘函数默认边界不同，不能照搬旧笔记中的另一种卷积描述。优化前比较同核全二维与分离路径。

五层追问答案：L1“σ 是什么？”→空间像素尺度；L2“为何核归一？”→保持 DC；L3“细线消失？”→先减核宽并对照原图；L4“为什么可分离？”→指数变量相加；L5“库结果不同？”→检查 σ、核、dtype、边界。易错：对称核保证任何边缘不偏。

## P04 中值滤波

任务／前提：图像与奇数窗口 → 局部中位数；脉冲稀疏。演进定位：均值对极端值敏感 → 秩统计 → 绝对偏差估计；代价为排序，遗留细线和角点损伤。实现：未实现；来源：[cite:2](#p-source-2)。

### L1 步骤
按复制边界或明确的有效支持收集窗口 → 排序／选择中间秩 → 写入独立输出；无有效样本则标无效，遍历后停止。

### L2 机制
极端值的幅度不影响中间秩；但真细线在邻域也可能是少数，不能把全部小结构当噪声。彩色逐通道中值可能产生原图没有的颜色。

### L3 工程权衡
窗口宽用 px，先区分固定坏点与随机脉冲，再选最小能压脉冲的奇数核。3×3 可作起始对照而非默认正确；以最小缺陷召回决定是否扩大。API 支持的浮点类型随核大小受限。

### L4 推导
设 \(F(z)=\sum_j|z-x_j|\)。非样本处导数为左侧样本数减右侧样本数，零点满足两侧均不超过一半，即中位数。局部异常不足半数只说明秩鲁棒性，不等于真实边界无偏。排序基线 O(Nk² log k)，整数直方图可降低更新代价，算法非线性、无固定卷积频响。

### L5 伪代码与数值测试
```text
for y, x in image_indices:
    v = finite_values(read_window(I, y, x, k, border="replicate"))
    if len(v) == 0: mark_invalid(y, x)
    else: q[y,x] = select_middle(v, even_policy="mean_of_two")
```
测试：`[10,10,255,10,10] → 10`；二值 3×3 窗仅中列为 1，则中值为 0，明确展示细线损失。含 NaN 时使用上面的自定义策略不等于 OpenCV 原接口。滑动直方图优化需逐像素比较参考结果。

五层追问答案：L1“偶数有效数？”→声明取两中间数均值等策略；L2“脉冲很大为何不怕？”→只影响秩；L3“线被吃掉？”→缩核或坏点表；L4“最小化何损失？”→绝对偏差；L5“大核浮点报错？”→核对库类型约束。易错：中值永远保边。

## P05 双边滤波

任务／前提：图像、空间 σ_s、值域 σ_r → 保边平滑图；噪声与需保边缘对比度可区分。演进定位：1998 代表论文，空间平均跨边 → 增加值域权重；代价 O(Nk²)，遗留噪声污染权重。实现：未实现；来源：[cite:3](#p-source-3)、[cite:2](#p-source-2)。

### L1 步骤
每中心枚举邻域 → 空间与灰度差转权重 → 相乘 → 求归一化加权和；包括中心自身，固定遍历结束。

### L2 机制
强边缘两侧灰度差大，跨边权重小。σ_r→∞ 退为截断空间高斯，σ_r 很小时趋近保留噪声。归一化避免权重总量变化造成亮度漂移。

### L3 工程权衡
σ_s 用 px，σ_r 用 DN 或归一化强度。先估重复帧噪声，再寻找允许同区平均但排斥目标边缘的 σ_r；两者分布重叠时无完美参数。图像从 255 改为 1，σ_r 必须同除 255。

### L4 推导
令 \(w_{ij}=e^{-\|i-j\|^2/(2\sigma_s^2)}e^{-(I_i-I_j)^2/(2\sigma_r^2)}\)。冻结权重后，\(\partial_z\sum_jw_{ij}(z-I_j)^2=2z\sum_jw_{ij}-2\sum_jw_{ij}I_j=0\)，故 \(q_i=\sum wI/\sum w\)。这是局部加权平方目标，不是数据相关权重下的全局凸恢复证明；没有通用误差界。

### L5 伪代码与数值测试
```text
for i in pixels:
    numerator = 0.; denominator = 0.
    for j in neighborhood_including_self(i):
        w = exp(-distance2(i,j)/(2*ss*ss) - (float(I[i])-float(I[j]))**2/(2*sr*sr))
        numerator += w * I[j]; denominator += w
    q[i] = numerator / denominator
```
测试：中心 0、邻点 10，距离 1，σ_s=1、σ_r=10，邻权重 e⁻¹，输出 `10/(e+1)=2.68941421`。这是两点支持测试，不声称对应默认库窗口。查表加速需要比较权重近似和下游误差；整型减法须先转浮点。

五层追问答案：L1“权重哪两种？”→空间和值域；L2“强噪声残留？”→相似权重被噪声破坏；L3“缩放灰度后调谁？”→σ_r 同比；L4“为何除总权？”→求导及保常量；L5“怎么验 LUT？”→同支持逐像素差及边缘差。易错：把 σ_s 与 σ_r 单位互换。

## P06 非局部均值 NLM

任务／前提：图像、块宽 k、搜索宽 S、h → 像素版 NLM 图；有块自相似。演进定位：CVPR 2005，近邻样本不足 → 用远处相似块；代价为搜索，遗留孤立缺陷被错误平均。实现：未实现；来源：[cite:4](#p-source-4)。

### L1 步骤
取中心块 → 搜索窗各候选块计算归一化距离 → 指数转权重 → 平均候选中心像素。完成有限搜索停止；块版聚合是另一实现，需另写输出规则。

### L2 机制
块描述比单灰度更能区分纹理，相似区域提供重复观测。扩大窗也引入误匹配；自权重防止无候选时失效，但过大自权重会残噪。

### L3 工程权衡
h 与灰度同量纲，k、S 用 px；先固定距离是否除块面积，随后依据噪声选 h、依据结构选 k，最后扩大 S 并计时。参数相同但距离采用“和”或“均值”时结果完全不同。

### L4 推导
\(d_{ij}=k^{-2}\sum_a(I_{i+a}-I_{j+a})^2\)，\(w_{ij}=e^{-d_{ij}/h^2}\)。若两对应位置噪声独立同方差，\(E[(n_i-n_j)^2]=2\sigma^2\)，可形成 \(\max(d-2\sigma^2,0)\) 修正；自比较不能机械套该值。归一化平均仍为固定权重平方损失解。朴素 O(NS²k²)，按位移累积块差可接近 O(NS²)；无普适无偏或恢复界。

### L5 伪代码与数值测试
```text
for displacement in search_offsets:
    delta2 = (float64(I) - shifted_with_border(I, displacement))**2
    d = box_mean(delta2, patch_width)
    w = exp(-d/(h*h))
    numerator += w * shifted_with_border(I, displacement)
    denominator += w
q = numerator / denominator
```
测试：块 A=[0,2]、B=[2,4]，均方距离 4；h=2 时相似权 e⁻¹。两候选中心 2、4、自权 1，则输出 `2.53788284`。该算例不启用噪声底修正。位移实现须和逐块参考对照边界；OpenCV fast NLM 不保证与此定义逐位相同。

五层追问答案：L1“平均块还是像素？”→本卡平均候选中心；L2“非局部优势？”→利用重复结构；L3“窗越大越好？”→误配与耗时增加；L4“2σ² 如何来？”→独立差的方差相加；L5“内存优化？”→按位移差图，不建全部块对。易错：任意噪声均能减 2σ²。

## P07 BM3D

任务／前提：图像、AWGN σ、块与分组参数 → 两阶段恢复图。演进定位：TIP 2007，NLM 只平均不足 → 三维组稀疏变换及协同收缩；代价为搜索／变换／聚合，遗留模型与匹配偏差。实现：未实现、无专用依赖；来源：[cite:5](#p-source-5)。

### L1 步骤
噪声图分组 → 三维变换 → 硬阈值 → 逆变换与重叠聚合得到 basic；在 basic 上重分组 → basic 算维纳增益 → 对同位置原噪声组系数滤波 → 聚合 final，两阶段后停止。

### L2 机制
相似块堆叠提高可压缩性；basic 提供较可靠分组和信号幅度，原噪声图保留第二阶段的观测。仅给 basic 再做平滑不是完整 BM3D。重叠聚合避免块边界独立重建。

### L3 工程权衡
先核对 σ 与幅度、噪声白性，再调块宽、最大组数、搜索步长。缩小组数可省时但减冗余；过阈值会抹细缺陷。作者软件许可须单独核对，论文公开不等于可直接商用。

### L4 推导
固定组且正交 T 时，\(y=Tg=s+\eta\)，白噪声协方差仍为 σ²I。硬阈值为 \(\hat s=y\mathbf1(|y|>\lambda\sigma)\)。单系数线性估计 wy 的 MSE 为 \((w-1)^2s^2+w^2\sigma^2\)，求导得 \(w=s^2/(s^2+\sigma^2)\)，实际用 basic 系数代 s。聚合 \(q_i=\sum_g a_{gi}\hat x_{gi}/\sum_g a_{gi}\)。数据相关分组和重叠破坏简单独立性，无整算法通用界。成本含 R 个参考块的 O(RS²k²) 搜索及组变换，不能只报 O(N log N)。

### L5 伪代码与数值测试
```text
basic = aggregate(stage="hard", image=I, guide=I, sigma=sigma)
num, den = zeros_like_float(I), zeros_like_float(I)
for reference in reference_grid_with_edge_coverage:
    ids = match_blocks(basic, reference, max_group, search_window)
    S = transform3d(stack(basic, ids))
    Y = transform3d(stack(I, ids))
    W = S*S / (S*S + sigma*sigma)
    blocks = inverse_transform3d(W * Y)
    weight = 1 / max(sigma*sigma*sum(W*W), aggregation_floor)
    overlap_add(num, den, blocks, ids, weight, spatial_window)
return divide_where_covered(num, den, fallback=I)
```
第一阶段 `aggregate` 明确定义为同样分组／变换／逆变换／聚合，将 W*Y 换为硬阈值系数，组权重按非零系数数目与变换归一化计算。σ=0 单独旁路。

数值测试：系数 `[4,0.5]`、阈值 1 → `[4,0]`；basic 幅度 3、σ=1 得 W=0.9，原观测系数 4 输出 3.6；像素两估计 2、4，权重 1、3，聚合 3.5。未运行完整分组和图像复现。优化缓存变换，需比较 basic、分组 ID、final 三阶段，不只比较最终均值。

五层追问答案：L1“第二阶段滤谁？”→原噪声图，basic 给匹配和增益；L2“为何堆块？”→组稀疏性；L3“σ 错怎么办？”→先统一强度单位；L4“增益公式来源？”→MSE 对 w 求导；L5“块缝？”→查覆盖、权重、变换归一化。易错：三维组就是空间三维图像。

## P08 引导滤波 Guided Filter

任务／前提：对齐引导 I、待滤 p、半径 r、ε>0 → q。演进定位：ECCV 2010／TPAMI 2013，局部保边大窗代价 → 线性模型与盒式统计；代价为二阶统计，遗留错误结构转移。实现：未实现；来源：[cite:6](#p-source-6)。

### L1 步骤
求每窗 I、p、I²、Ip 均值 → 求 a、b → 平均覆盖像素的 a、b → q=āI+b̄。两轮统计后停止，不能省略系数平均。

### L2 机制
引导结构决定局部输出梯度；ε 抑制平坦区不稳定斜率。引导与 p 错位会复制错误边缘；常量引导时仍会平滑 p，而不是无条件原样输出。

### L3 工程权衡
r 用 px，ε 用引导强度平方。I 从 255 归一化到 1，ε 除以 255²；先查引导配准，再按噪声／局部方差选 ε，最后调 r。盒式统计可 O(N)，大偏置小方差需防相消。

### L4 推导
每窗最小化 \(E(a,b)=\sum_i[(aI_i+b-p_i)^2+\epsilon a^2]\)。对 b 求导得 \(b=\bar p-a\mu\)，代入得 \(E/|\omega|=a^2(\sigma_I^2+\epsilon)-2a\operatorname{cov}(I,p)+\text{常数}\)，故 \(a=\operatorname{cov}(I,p)/(\sigma_I^2+\epsilon)\)。平均重叠模型得 q。彩色引导解 \((\Sigma_I+\epsilon I_3)a=\operatorname{cov}(I,p)\)。ε>0 保局部可解，不保证恢复真实边缘；固定通道数盒式实现 O(N)。

### L5 伪代码与数值测试
```text
muI, mup = boxmean(I,r), boxmean(p,r)
varI = boxmean(I*I,r) - muI*muI
covIp = boxmean(I*p,r) - muI*mup
require no_significant_negative_variance(varI)
a = covIp / (max(varI,0) + epsilon)
b = mup - a*muI
q = boxmean(a,r)*I + boxmean(b,r)
```
测试局部回归：I=p=[0,1]，方差 0.25、ε=0.25，a=0.5、b=0.25，局部 q=[0.25,0.75]；这是单窗模型，不冒充全图边界输出。p 恒为 7 则整幅 q=7。彩色用小线性求解而非逆矩阵。积分图优化保持窗口有效计数与边界一致。

五层追问答案：L1“为何两次均值？”→统计回归，再融合窗口；L2“为何不能 ε=0？”→平坦窗不可辨；L3“ε 随空间缩放吗？”→不随空间、随强度平方；L4“如何推 a？”→消去 b 后求导；L5“负方差？”→相消／精度或实现错误，不能全靠截零。易错：可信引导可省配准。

## P09 Fast Guided Filter

任务／前提：P08 输入加空间下采样倍率 s≥1 → 近似引导输出；系数变化较慢。演进定位：2015 技术报告，统计成本 → 低分辨率回归 → 全分辨率引导重建；代价为近似偏差，遗留细结构系数丢失。实现：未实现；来源：[cite:7](#p-source-7)。

### L1 步骤
同步缩小 I、p → r′ 按 r/s 取整 → 低分辨率求 a、b 及其均值 → 上采样均值系数到准确原尺寸 → 使用 I_full 输出；完成即停。

### L2 机制
放大的是慢变系数，而非低清结果；最后一步依然利用全尺寸引导边缘。丢失的系数变化不会因保留引导而自动恢复。

### L3 工程权衡
先以 s=1 做完整算法基线，再增加 s，以细线／边缘误差而不是肉眼选择。s 无量纲，ε 不随空间 s 改；奇数尺寸需用实际横纵缩放比确定 r′ 和采样协议。

### L4 推导
\(q_s-q=(\bar a_s-\bar a)I+(\bar b_s-\bar b)\)。若已知 \(|I|\le M,|\Delta a|\le e_a,|\Delta b|\le e_b\)，三角不等式给 \(|\Delta q|\le Me_a+e_b\)；本文未估 e_a、e_b，不声称通用误差界。统计 O(N/s²)，上采样和重建 O(N)，整体仍 O(N)，不是总成本 O(N/s²)。

### L5 伪代码与数值测试
```text
small_size = chosen_integer_size(full_size, s)
Is, ps = area_resize(I,small_size), area_resize(p,small_size)
rs = max(1, round(r/s))
a, b = local_guided_coefficients(Is, ps, rs, epsilon)
A = linear_resize(boxmean(a,rs), full_size)
B = linear_resize(boxmean(b,rs), full_size)
q = A*I + B
```
r=0 要另作旁路，不能使用上述最小半径 1。测试：上采样后恒系数 A=0.5、B=0.25，全尺寸 I=[0,0.2,1] → [0.25,0.35,0.75]；s=1 且采样、r 相同应与 P08 相同。另测奇数宽高与分块 halo。性能计时须包含 resize 和最终乘加。

五层追问答案：L1“放大谁？”→系数；L2“为何仍保部分高频？”→全尺寸引导重建；L3“s 如何定？”→完整基线上约束下游误差；L4“整体复杂度？”→O(N)；L5“边缘错半像素？”→核对 resize 坐标。易错：快速版与完整版严格等价。

## P10 DnCNN

任务／前提：有噪图 y、对应已训练权重 → 预测干净图；训练退化匹配测试域。演进定位：2016 预印本／TIP 2017，手工先验不足 → CNN 残差学习与批归一化；代价为训练及部署，遗留域偏移和细缺陷抹除。实现：未实现，无 DnCNN 权重；来源：[cite:8](#p-source-8)。

### L1 步骤
训练：构造干净 x 与有噪 y，目标残差 y−x，批训练并用留出集早停；推理：范围归一化 → NCHW → 网络预测残差 Rθ(y) → y−Rθ(y) → 裁回原尺寸。无匹配权重则拒绝，不能随机初始化后声称去噪。

### L2 机制
直接学习噪声残差使恒等旁路显式存在，但不保证网络只预测噪声。推理必须固定 BN 统计；误用 train 模式会随 batch 改变输出。

### L3 工程权衡
先核对噪声类型、σ、灰度范围及权重版本，再考虑深度／分块。DnCNN-S 的 17 层灰度网络与其他变体不能混称统一配置。按设备／批次留出，既报告恢复指标也报告边缘和缺陷召回；未提供本站结果。

### L4 推导
\(L=\frac1{2M}\sum\|R_\theta(y)-(y-x)\|^2\)。逐输入最小化平方风险，令对预测 r 的导数为零，得 \(r^*(y)=E[y-x\mid y]\)，因此 \(y-r^*(y)=E[x\mid y]\)。条件期望可能平滑多解细节，训练有限容量且非凸，未保证达到全局最优。卷积成本 \(O(N\sum_l k_l^2c_{l-1}c_l)\)，无通用域外误差界。

### L5 伪代码与数值测试
```text
model = Conv3x3(1,64) + ReLU
repeat 15 times: model += Conv3x3(64,64) + BatchNorm64 + ReLU
model += Conv3x3(64,1)
for epoch until validation_stop or epoch_limit:
    y, x = aligned_training_batch_in_fixed_range()
    residual = model.train_forward(y)
    optimizer_step(mean((residual - (y-x))**2))
load_verified_checkpoint(); model.eval()
prediction = y - model.inference(y)
```
数值测试：y=[0.2,0.8]、固定残差输出 [0.1,−0.1] → [0.1,0.9]；它只检查输出符号与范围，不测试任何训练权重。17 个 3×3、步长 1 的感受野为 35，内区分块需每侧至少 17 px 上下文；边界 padding 必须与整图一致。测批大小不变性、权重哈希、混合精度误差后再优化。

五层追问答案：L1“网络输出干净图吗？”→本方案输出残差再相减；L2“为何有 BN 状态？”→训练／推理统计不同；L3“真实噪声失效？”→查训练域不先换大网络；L4“MSE 的最优解？”→条件均值；L5“块接缝？”→感受野 halo、padding 与 eval 模式。易错：条件均值保证细缺陷真实恢复。

## P11 Noise2Noise

任务／前提：同潜在信号的对齐有噪输入 y₁、目标 y₂ → 训练恢复器；平方损失要求目标噪声条件均值合适。演进定位：ICML 2018，干净目标难采 → 更换监督条件；可与 DnCNN 组合，代价是重复采集和对齐，遗留相关噪声偏差。实现：未实现；来源：[cite:9](#p-source-9)。

### L1 步骤
采集同场景独立噪声对 → 检查曝光／几何对应 → 按场景划分训练验证 → 最小化 f(y₁) 与 y₂ 的损失 → 验证早停；推理只需单幅输入。运动／未对齐对拒绝。

### L2 机制
不是“两张随便的噪声图”。独立目标噪声在期望里不改变最优目标，但有限数据的优化方差更大。相同固定图样或目标泄漏会成为可预测信号并被网络保留。

### L3 工程权衡
先检验目标噪声与输入条件关系及运动，再增加样本和网络。平方损失对应均值；换 L1 后对应条件中位数，条件不能照抄。曝光不同导致信号尺度不等，需标定后配对。

### L4 推导
令 y₂=x+n₂。展开 \(E\|f(y_1)-y_2\|^2=E\|f(y_1)-x\|^2+E\|n_2\|^2-2E[(f(y_1)-x)^Tn_2]\)。若 \(E[n_2\mid x,y_1]=0\)，交叉项为零，两个风险只差与 f 无关的常数；更弱条件可保证条件均值最优点相同。目标有条件偏置则学到偏置。网络复杂度取决于架构，无有限训练普适性能界。

### L5 伪代码与数值测试
```text
for y1, y2, scene_id in paired_dataset:
    require aligned(y1,y2) and same_signal_scale(y1,y2)
    require split_by_scene(scene_id)
    pred = f_theta(y1)
    optimizer_step(mean((pred-y2)**2))
stop_if_validation_plateaus_or_epoch_limit()
output = f_theta(single_noisy_frame)
```
数值测试：固定潜在 x=3、等概率目标值 2 和 4，则 \(L(a)=((a-2)^2+(a-4)^2)/2=(a-3)^2+1\)，最优 a=3；目标改为 3、5，则最优 4，展示条件偏置。是损失函数验算，不是训练实验。测试配对 ID、空间错位、场景泄漏，优化数据读取不得改变配对。

五层追问答案：L1“推理需两张吗？”→不需；L2“何种噪声能抵消？”→目标条件均值为零等条件；L3“固定纹理残留？”→查相关／固定噪声；L4“等价如何证明？”→展开平方并消交叉项；L5“训练很好上线差？”→查配对泄漏与场景划分。易错：无干净图等于无监督约束。

## P12 线性拉伸

任务／前提：I、固定 a<b、目标范围 [0,1] → 裁剪归一化图。演进定位：码值范围利用不足 → 仿射点映射；代价为裁剪，遗留信息丢失和跨帧不一致。实现：无统一增强接口；来源为[总览](../preprocessing.md)灰度路线与下述代数推导，不声称原始首创论文。

### L1 步骤
在可信参考 ROI 定 a、b → 固定并版本化 → (I−a)/(b−a) → 按协议裁剪 → 输出；a≥b 则失败或显式旁路，不自动除 epsilon。

### L2 机制
增加显示对比度但噪声同比放大。每帧重新取极值会让相同 DN 映射不同值；一个坏点就能压缩所有正常灰度范围。

### L3 工程权衡
a、b 为 DN，可由冻结参考分位数估计而非单帧极值。先看饱和和坏点再调分位数；记录裁剪比例。下游使用固定阈值时优先固定映射。

### L4 推导
求过两端点的直线 \(q=\alpha I+\beta\)，由 q(a)=0、q(b)=1 得 \(\alpha=1/(b-a),\beta=-a/(b-a)\)。未裁剪、未量化时信号差与标准差同乘 α，SNR 不会凭空提高。b−a→0 放大不确定度；应用 O(N)，分位数估计另计。

### L5 伪代码与数值测试
```text
require finite(a,b) and b > a
q = clip((float64(I)-a)/(b-a), 0, 1)
return q, isfinite(I), count_clipped(q)
```
测试：a=10、b=30，I=[0,10,20,30,40] → [0,0,0.5,1,1]。另测 a=b 必须拒绝。LUT 优化只适用于固定离散输入域，和浮点公式比较量化结果。

五层追问答案：L1“常量图如何？”→不能估有效跨度；L2“为何噪声也明显？”→仿射同倍放大；L3“阈值漂？”→查逐帧估界；L4“SNR 增加吗？”→理想线性映射不增加；L5“回绕？”→先转浮点再减。易错：拉满范围就是恢复信息。

## P13 gamma 变换

任务／前提：归一化非负 I、γ>0 → q=I^γ；明确本卡不是 1/γ 约定。演进定位：线性拉伸不能独立分配暗亮码值 → 幂点映射；代价是非线性光度，遗留暗区噪声放大。实现：未实现；来源为[总览](../preprocessing.md)颜色／灰度原理及本项微分。

### L1 步骤
明确线性／编码输入 → 固定黑白点归一化 → 幂映射 → 必要时一次量化；γ≤0 或负输入拒绝，不静默生成 NaN。

### L2 机制
0<I<1 时 γ<1 抬暗，γ>1 压暗。饱和仍无法恢复。sRGB 是分段传递函数，不等于任意一个纯 gamma 幂；不自动解码再重编码会改变光度意义。

### L3 工程权衡
γ 无量纲，从 γ=1 旁路比较后再调。先确认输入是否已 gamma 编码，再检查暗区噪声和缺陷判定；不要对编码灰度直接套光子泊松噪声模型。

### L4 推导
由 \(\log q=\gamma\log I\)，可见对数域斜率为 γ；微分 \(dq/dI=\gamma I^{\gamma-1}\)，故小扰动方差近似 \(\gamma^2 I^{2\gamma-2}\sigma_I^2\)。γ<1、I→0 时敏感度高，线性近似可能失效。未量化 I>0 可逆，量化／裁剪后不保证；O(N)。

### L5 伪代码与数值测试
```text
require gamma > 0 and all_valid_pixels_in_0_1(I)
q = power(float64(I), gamma)
```
测试：γ=0.5，I=[0,0.25,1] → [0,0.5,1]；γ=1 恒等；[0.5] 经 γ=2 得 0.25。整数 LUT 检查单调性和端点；不得把 LUT 往返量化误差当理论可逆证明。

五层追问答案：L1“定义 γ 还是倒数？”→本卡 q=I^γ；L2“为什么抬暗？”→区间内幂指数性质；L3“先调什么？”→先查编码域；L4“噪声传播？”→用导数平方；L5“NaN？”→负输入及非法指数。易错：sRGB 就是统一 2.2 幂。

## P14 直方图均衡

任务／前提：离散灰度图 → 全局 CDF 重映射图；增强而非恢复。演进定位：固定映射不适应分布 → 累积分布映射；代价为统计和非线性，遗留噪声放大与灰度可比性损失。实现：未实现；来源：[cite:10](#p-source-10)。

### L1 步骤
计数直方图 → 累加 CDF → 找首个非空桶计数 C_min → 建 LUT → 查表；常量图在本文 OpenCV 风格约定下保持原值。

### L2 机制
理想连续变量 U=F_X(X) 可均匀化分布；离散图像有并列值，不能使直方图严格均匀。减 C_min 让最低有效灰度落到黑点，与不减的纯 CDF 版本不同。

### L3 工程权衡
输入通常为 uint8 单通道，桶数 256；16 位需明确另行映射或实现。先测噪声与目标灰度分离，不在 RGB 三通道各自均衡而忽略颜色变化。跨帧自适应映射会漂移阈值。

### L4 推导
连续单调 F 下 \(P(F_X(X)\le u)=u\)。离散工程映射为 \(T(k)=\operatorname{round}[(L-1)(C(k)-C_{min})/(N-C_{min})]\)，由将 [C_min,N] 仿射映到 [0,L−1] 得到，不是连续定理的精确实现。N=C_min 为常量退化。O(N+L)，无通用恢复误差界。

### L5 伪代码与数值测试
```text
h = histogram_uint8(I); cdf = cumsum_int64(h)
first = first_nonzero(h)
if h[first] == size(I): return copy(I)
lut[k] = round(255 * max(cdf[k]-h[first],0)/(size(I)-h[first]))
q = lut[I]
```
测试：I=[0,0,1,3]，有效 CDF=[2,3,4]，映射期望 [0,0,128,255]（127.5 按声明舍入到 128）；常量 17 保持 17。测试 LUT 单调性、计数累加溢出，优化直方图并行合并应保持计数精确。

五层追问答案：L1“为何特判常量？”→分母为零；L2“直方图必均匀？”→离散并列值不允许；L3“颜色变了？”→独立通道映射破坏比例；L4“C_min 来源？”→有效 CDF 端点拉伸；L5“127 或128？”→显式舍入约定。易错：增强等于降噪。

## P15 CLAHE

任务／前提：单通道图、网格数、clipLimit → 局部限幅均衡图。演进定位：全局均衡无法适应空间照明 → 局部直方图；AHE 放大噪声 → 裁剪与再分配；代价为 tile/LUT，遗留光晕。实现：未实现；来源：[cite:11](#p-source-11)，不追溯唯一首创年。

### L1 步骤
按 tile 划分并扩展边界 → 每 tile 直方图裁剪 → 溢出计数均匀及余数再分配 → CDF LUT → 以 tile 中心为位置插值四张 LUT。完成一帧即停。

### L2 机制
裁剪约束集中桶对局部对比度的放大，空间插值减少块缝。再分配后桶可再次超过裁剪值，因此不能说最终桶计数绝不越界。

### L3 工程权衡
OpenCV `tileGridSize` 是横纵 tile 数而非像素宽；正 clipLimit 映射为 \(\max(1,\lfloor clipLimit\,A/L\rfloor)\)，A 为 tile 像素数。先选大于关键结构的 tile 尺度，再按噪声调整 clipLimit；8 位与16位桶数不同，不能机械复用。clipLimit≤0 在所引源码中关闭裁剪。

### L4 推导
令 \(h'_k=\min(h_k,C)\)，溢出 \(E=\sum(h_k-h'_k)\)，每桶加 \(\lfloor E/L\rfloor\)，余数按固定桶步进分配，保证总计数 A 不变。源码 LUT 为 \(T(k)=\operatorname{round}[(L-1)\sum_{j\le k}h'_j/A]\)，**不减 C_min**。输出 \(q=\sum_{t=1}^4w_tT_t(I)\)，权重和 1；只保证邻 tile 混合，非噪声恢复界。成本 O(N+tiles·L)。

### L5 伪代码与数值测试
```text
for tile in padded_tiles(I):
    h = histogram(tile,L); C = max(1,floor(clipLimit*area(tile)/L))
    excess = sum(max(h-C,0)); h = min(h,C)
    h += excess // L; residual = excess % L
    if residual > 0:
        step = max(L // residual,1)
        increment_first_residual_bins_at_step(h,step,residual)
    LUT[tile] = round((L-1)*cumsum(h)/area(tile))
q = interpolate_neighbor_LUT_values_at_tile_centers(I,LUT)
```
测试简化为四桶：h=[8,0,0,0]、C=2 → E=6，均分后 [3,1,1,1]，余数加第 0、2 桶得 [4,1,2,1]，和仍 8；未量化 LUT=[1.5,1.875,2.625,3]。这不是 256 桶完整图像测试。另测非整除宽高、tile 接缝和线程前后 LUT 一致；所引源码的边界扩展也须一致。

五层追问答案：L1“溢出丢掉？”→不能，需再分配保计数；L2“为什么插 LUT？”→平滑空间映射差异；L3“tile=8 表示8px？”→API 中为8个 tile；L4“最终桶≤C？”→再分配后不一定；L5“和均衡结果不同？”→CDF_min、边界、量化和 tile 坐标均不同。易错：CLAHE 固定保灰度均值。

## P16 同态滤波

任务／前提：正值图 I、频率传递函数 H → 光照抑制图；照明慢变、反射较快变。演进定位：加性滤波不匹配乘性照明 → 对数线性化 → 频域处理；代价为 FFT 和边界处理，遗留光晕和模型失配。实现：未实现；来源为[总览](../preprocessing.md)同态路线及本项模型推导；具体 H 是参考设计，不冒称某论文唯一算法。

### L1 步骤
检查正值与黑电平 → 明确 ε → log(I+ε) → 扩展边界 FFT → 乘 H → 逆 FFT → exp−ε → 裁回。H=1 为旁路；严重负值应拒绝而非截成 epsilon。

### L2 机制
乘法照明变加法，低频抑制照明。物体本身的缓变结构也在低频；不存在仅凭频率完美区分照明与反射的保证。log 后噪声不再原来的加性白噪声。

### L3 工程权衡
ε 与 I 同量纲，截止频率用周期／像素，低频增益 γ_L、高频增益 γ_H 无量纲。先查黑电平／零值，再从 H=1 基线改变低频增益，最后提高高频；先扩大频率而非检查边界容易制造振铃。

### L4 推导
理想 \(I=LR>0\)，故 \(z=\log I=\log L+\log R\)，\(q=\exp[\mathcal F^{-1}(H\mathcal Fz)]\)。可选 \(H(f)=\gamma_L+(\gamma_H-\gamma_L)(1-e^{-c\|f\|^2/f_c^2})\)。ε>0 时 log(I+ε) 不再精确分解，属于稳定化偏差。常量图 A 在 ε=0 时输出 \(A^{\gamma_L}\)，说明均值不保持。O(N log N)，无通用恢复界。

### L5 伪代码与数值测试
```text
require valid_positive_domain(I,epsilon)
z = log(float64(I)+epsilon)
zp, crop = reflect_pad(z)
fy, fx = fftfreq(height(zp)), fftfreq(width(zp))
H = gammaL + (gammaH-gammaL)*(1-exp(-c*(fx*fx+fy*fy)/(fc*fc)))
q = exp(real(ifft2(H*fft2(zp)))) - epsilon
return crop(q), valid(I)
```
测试：ε=0、I 恒为 16、H(0)=0.5 → q 恒为 4；H≡1、I=[1,4,16] 必须往返原值。频率坐标不使用 `fftshift` 时 H 也不得 shift。优化复用 H 与 FFT 计划，保持补边和裁剪相同。

五层追问答案：L1“为何先取 log？”→将乘性变加性；L2“会不会去掉大目标？”→会，频谱可能重叠；L3“暗部异常？”→查黑电平和 ε；L4“均值保持吗？”→常量变 A^γ_L，通常不；L5“棋盘伪影？”→核对 FFT 频率布局及边界。易错：高通只去照明不伤结构。

## P17 维纳恢复

任务／前提：模糊图 y、可信 PSF h、信号／噪声谱比 → 线性恢复图；线性平移不变、二阶平稳且信号噪声不相关。演进定位：直接逆滤波在小频响处放噪 → MMSE 正则增益；代价为谱估计，遗留 PSF 错配和振铃。实现：未实现；来源：[cite:12](#p-source-12)。

### L1 步骤
估 PSF 及噪声谱 → 正确放置 PSF 原点 → FFT → 构造 Wiener 增益 → 乘观测谱 → 逆变换并裁剪；谱无定义处明确置零或报无效。

### L2 机制
不是直接除 H。观测不可信的频率被收缩；H=0 的成分不能从观测唯一恢复。错误的 PSF 相位会造成位移，正则并不修复模型错配。

### L3 工程权衡
S_n/S_x 与 |H|² 可比较，标量 K 仅在假设成立时作谱比近似。先查 PSF 方向、归一化、中心和边界，再调 K；K 增大减噪但增加偏差。scikit-image 的正则化接口含额外正则算子，不与本卡标量谱比公式混称同一参数。

### L4 推导
逐频 \(Y=HX+N\)，估计 \(\hat X=WY\)。风险 \(E|WY-X|^2=|WH-1|^2S_x+|W|^2S_n\)。对复变量 W* 求导为零，得 \(W=H^*S_x/(|H|^2S_x+S_n)=H^*/(|H|^2+K)\)。要求二阶矩存在且互不相关；保证限于线性估计类与给定谱。FFT O(N log N)，无通用 PSF 失配误差界。

### L5 伪代码与数值测试
```text
Hp = fft2(pad_and_roll_psf_to_origin(psf, padded_shape))
Y = fft2(pad_image(y))
den = abs(Hp)**2 + noise_signal_ratio
W = divide(conj(Hp), den, where=den>0, otherwise=0)
x = crop(real(ifft2(W*Y)))
```
测试：单频 H=0.5、K=0.25 → W=1，Y=2 → 输出2；H=1、K=0 → 恒等。另测 delta PSF 原点、零频 DC、零分母及复共轭。缓存 W 可加速固定 PSF 序列，但不能用于已变化的曝光／运动核。

五层追问答案：L1“需要哪些先验？”→PSF 及谱；L2“为何不直接逆？”→小 H 放噪；L3“重影先调 K？”→先查 PSF；L4“共轭哪里来？”→复 MSE 求导；L5“整体移位？”→PSF 原点放错。易错：维纳可恢复所有被模糊抹掉的频率。

## P18 最近邻插值

任务／前提：离散图与目标到源的坐标映射 → 重采样图；适合类别标签。演进定位：最简单离散选点 → 不混合标签；代价低，遗留锯齿与混叠。实现：仅 `synthetic.py` 掩膜变换调用；来源：[cite:13](#p-source-13)。

### L1 步骤
目标像素反投影到源 (x,y) → 按明确舍入规则选最近像素 → 按边界策略读值；无映射则无效，所有目标点完成停止。

### L2 机制
不产生新标签，但几何边界量化到整数。反向采样避免前向投点的空洞。最近邻本身不做抗混叠，縮小时细结构可能消失。

### L3 工程权衡
坐标用 px，需区分 resize 与 warp 的坐标规则。本文数学约定 floor(x+0.5)；OpenCV `INTER_NEAREST` 的 legacy resize 路径不保证同此约定，标签迁移应固定版本／精确模式。负半整数的平局规则必须声明。

### L4 推导
选 \(j^*=\arg\min_{j\in\mathbb Z}|x-j|\)，非平局误差 ≤0.5 px；二维位置量化距离 ≤√2/2 px，仅为采样位置误差，不是图像灰度误差或测量误差界。每点常数时间 O(N_out)。

### L5 伪代码与数值测试
```text
for v,u in output_indices:
    x,y = inverse_map(u,v)
    ix,iy = floor(x+0.5),floor(y+0.5)
    q[v,u] = read_with_explicit_border(I,iy,ix)
```
测试：源 [10,20,30]，x=0.49→10、0.51→20；x=0.5 在本文规则下取20。标签输出集合应为输入标签加约定背景标签。优化批量索引前先做边界掩膜。

五层追问答案：L1“为何反向映射？”→每个目标点都有采样规则；L2“标签为什么选它？”→不混类别；L3“缩小锯齿？”→无抗混叠；L4“0.5 是何界？”→一维位置量化；L5“库差一格？”→坐标／舍入规则。易错：INTER_NEAREST 在所有 API 中坐标完全相同。

## P19 双线性插值

任务／前提：连续源坐标及有效四邻点 → 标量采样值；像素域重采样。演进定位：最近邻不连续 → 两轴线性基函数；代价为平滑，遗留高频衰减。实现：匹配、卡尺局部已有；来源：[cite:13](#p-source-13)。

### L1 步骤
反投影 → floor 得左上点 → 求小数权重 α、β → 有效边界检查 → 四邻加权，遍历输出结束。

### L2 机制
先横向两次线性插值，再纵向一次；非负权重和 1，不会超出四点范围。仍不是足够的缩小抗混叠，也不适合离散类别 ID。

### L3 工程权衡
明确像素中心：常见 resize 半像素公式为 x=(u+0.5)/s−0.5；warp 则按几何矩阵。边界取复制、镜像、无效应由任务决定。OpenCV 查表插值与手写 float64 可有数值差，先统一坐标再比较。

### L4 推导
对 x 线性基 `[1−α,α]` 与 y 基 `[1−β,β]` 做张量积，\(q=(1-\alpha)(1-\beta)I_{00}+\alpha(1-\beta)I_{10}+(1-\alpha)\beta I_{01}+\alpha\beta I_{11}\)。因此再现常量、平面及 xy 双线性项；一般曲面有二阶插值误差，边缘不满足光滑假设。O(N_out)。

### L5 伪代码与数值测试
```text
x0,y0 = floor(x),floor(y); a,b = x-x0,y-y0
if not four_neighbors_valid(x0,y0): return invalid
return (1-a)*(1-b)*I[y0,x0] + a*(1-b)*I[y0,x0+1] + (1-a)*b*I[y0+1,x0] + a*b*I[y0+1,x0+1]
```
测试：I=[[0,10],[20,30]]，(x,y)=(0.25,0.5)→12.5。现有 `_sample_points` 在取索引后才处理 `ok`，故不能当作安全越界参考；本文不改源码，也不宣称边界已通过。优化向量化应先筛有效点，比较整图／ROI 内区和输出掩膜。

五层追问答案：L1“数组坐标？”→访问 `[y,x]`；L2“会过冲？”→有效四点非负权重时不会；L3“缩小糊／混叠？”→另选抗混叠；L4“为什么四项？”→一维线性基张量积；L5“边界崩溃？”→掩膜必须在索引前。易错：算过有效掩膜就一定不会越界。

## P20 双三次插值

任务／前提：连续坐标、明确 cubic 核参数 a → 4×4 邻域采样。演进定位：双线性较钝 → 更宽的分段三次核；代价是16点及负权，遗留过冲。实现：数据生成调用，不是统一接口；来源：[cite:13](#p-source-13)。

### L1 步骤
反投影 → 每轴取 floor(x)−1 至 floor(x)+2 四点 → 计算三次核权 → 两轴可分离加权 → 边界处理，遍历结束。

### L2 机制
负侧瓣补偿部分高频衰减，但使边缘超出原灰度范围；随后 clip 会非线性改变峰形，影响亚像素测量。不同 a 的“三次插值”不等价。

### L3 工程权衡
固定版本与核参数；所引 OpenCV resize 源码 a=−0.75。测量任务优先测试阶跃过冲和边缘偏移，不因“阶数高”就选它。缩小仍需明确抗混叠滤波。

### L4 推导
令 t=|x|，核 \(h(t)=(a+2)t^3-(a+3)t^2+1\)（0≤t≤1），\(h(t)=at^3-5at^2+8at-4a\)（1<t<2），其余0。分段系数满足 h(0)=1、h(1)=h(2)=0 及连接处一阶连续，保留参数 a 调侧瓣。二维 \(q=\sum_{m,n}h(x-m)h(y-n)I_{nm}\)。负权不保凸包；O(16N_out)，无任意非光滑图精度保证。

### L5 伪代码与数值测试
```text
ix,iy = floor(x),floor(y)
wx = [cubic(x-j,a) for j in range(ix-1,ix+3)]
wy = [cubic(y-j,a) for j in range(iy-1,iy+3)]
q = sum(wy[n]*wx[m]*read_border(I,iy-1+n,ix-1+m) for n,m in grid4x4)
```
测试 a=−0.75、半像素权 `[-0.09375,0.59375,0.59375,-0.09375]`，和为1；一维样本 [0,1,1,1] 输出1.09375，展示过冲。二维常量应保持。缓存权表需比较负侧瓣、定点精度与最终裁剪前输出。

五层追问答案：L1“几邻点？”→二维16点；L2“为什么过冲？”→负权；L3“为何三次不一定更准？”→边缘非光滑、clip 引偏；L4“a 控制什么？”→侧瓣与连接导数；L5“不同库差异？”→核参数、坐标、量化。易错：三次比双线性始终更适合测量。

## P21 面积重采样

任务／前提：源图、目标像素覆盖区间 → 区域积分平均；主要面向缩小。演进定位：点采样缩小混叠 → 像素面积模型 → 重叠面积加权；代价为覆盖计算，遗留盒式低通的有限阻带抑制。实现：匹配金字塔有 `INTER_AREA`；来源：[cite:13](#p-source-13)。

### L1 步骤
把目标像素边界反映到源像素边界坐标 → 枚举重叠像素 → 累加交叠面积×灰度 → 除目标覆盖面积；完整覆盖后停止。此处边界坐标不同于像素中心坐标。

### L2 机制
对高频做面积平均可减轻缩小混叠，不是理想砖墙抗混叠。均值保持依赖完整面积和边界策略；放大不应把 API 行为等同真实面积恢复。

### L3 工程权衡
使用实际横纵缩放比例，奇数尺寸减半并非精确 0.5。金字塔掩膜要跟随加权图同样重采样，再作支持判定，不能先二值化再假装面积未变。比例越小损失越多细线。

### L4 推导
将源图视为分片常数场，\(q_j=|A_j|^{-1}\int_{A_j}I(x,y)dxdy=\sum_i |A_j\cap A_i|I_i/|A_j|\)。完全覆盖时权重和1；由积分可加性推出。整倍缩小 s×s 时退为 s² 块平均。复杂度为总相交项数，规则缩小可 O(N_in+N_out)，不能把任意仿射面积积分当 resize API 已支持。

### L5 伪代码与数值测试
```text
for output_pixel in target_grid:
    box = map_target_pixel_edges_to_source(output_pixel)
    value, area = 0., 0.
    for source_pixel in overlaps(box):
        w = intersection_area(box, source_pixel.box)
        value += w*I[source_pixel]; area += w
    q[output_pixel] = value/area
```
测试：[[0,2],[4,6]] 缩为1点→3；一维 [0,6,12] 从3缩2，覆盖 [0,1.5]、[1.5,3] → [2,10]。另测奇数尺寸、掩膜加权与常量保持；优化整数倍块均值不得被推广到非整数倍不等权平均。

五层追问答案：L1“权重从哪来？”→覆盖面积；L2“能完全消混叠？”→盒式核不能；L3“奇数尺寸错位？”→实际比例与像素边界；L4“何时普通平均？”→整倍全覆盖；L5“掩膜怎么处理？”→同采样后按协议阈值化。易错：任意缩放直接等权平均几个点。

## P22 灰度转换

任务／前提：明确通道顺序和范围的彩色图 → 灰度图；本卡对应 OpenCV BGR2GRAY 的加权码值。演进定位：彩色任务简化为亮度结构 → 通道投影；代价低但丢色，遗留等灰异色不可分。实现：`focus_measures._prep` 已有局部调用；来源：[cite:14](#p-source-14)。

### L1 步骤
检查 BGR／RGB、通道数与 dtype → 必要时 float64 彩色转 float32 → 调灰度转换 → 按下游协议转 float64；灰度输入直接检查后传递。

### L2 机制
按视觉相关权重保留部分亮度结构，不能保留所有颜色区别。该线性加权码值不自动等于线性光亮度；RGB/BGR 误用对红蓝最明显。

### L3 工程权衡
权重无量纲，输出幅度沿用输入单位。先查通道顺序和数据范围，再评估颜色是否为缺陷主特征；有判别价值的色差不可先丢掉。不要把所有浮点输入都误缩至 [0,1]。

### L4 推导
线性投影 \(Y'=0.299R'+0.587G'+0.114B'\)，系数和1使中性灰 R′=G′=B′保持；从三维投影到一维有二维零空间，因此不可能逆恢复一般颜色。误差传播为 \(\sigma_Y^2=w^T\Sigma_{RGB}w\)，不能忽略相关通道项。O(N)，该投影不保证颜色缺陷召回。

### L5 伪代码与数值测试
```text
if I has 3 channels:
    src = float32(I) if dtype(I)==float64 else I
    gray = cvtColor(src, COLOR_BGR2GRAY)
else:
    require I is a valid 2D image
    gray = I
return float64(gray)
```
测试：BGR=[0,0,100] → 浮点灰度约29.9，BGR=[100,0,0]→11.4；[100,100,100]→100。实际 float32 容差1e−5；整数输出另考虑定点舍入。对 `_prep` 的局部测试不证明整个对焦或颜色检测管线正确。

五层追问答案：L1“先转 double？”→彩色 double 先降支持类型后转灰；L2“信息还在吗？”→丢失色度自由度；L3“红缺陷消失？”→先确认是否不该转灰；L4“噪声公式？”→wᵀΣw；L5“红蓝互换？”→查通道顺序。易错：灰度值就是光子线性响应。

## P23 坏点表与坏点替换

任务／前提：重复暗亮帧、CFA 相位、原图 → 固定坏点表、修复图及 repaired/valid 两种掩膜。演进：全图中值误伤细节 → 仅修稀疏持续异常；代价为坏点表维护。未实现。来源：旧稿 P03 的工程设计及本文 P04 秩统计，不冒称厂商统一检测标准；[转引范围](#p-source-15)。

### L1 步骤
同配置重复帧确认持续异常 → 版本化坐标表 → 从未修改的原图提取有效同色邻居 → 只替换表内位置 → 无足够邻居则无效。一遍结束，不把新修复值继续传播。

### L2 机制
固定表把传感器缺陷与真实产品小缺陷分开；中值降低孤立异常幅度影响，但邻域不含真实中心信息，插值不是重新观测。Bayer 跨色替换会造假色。

### L3 工程权衡
先查异常持续率、簇大小、温漂与坐标，再调半径（px）；大簇／整列失效应拒绝计量。表绑定相机、曝光、温度、ROI 与 CFA 相位；边缘真实细线不能用全图异常阈值随意纳表。

### L4 推导
表外 q_i=I_i，表内最小化 Σ_{j∈V_i}|z−I_j|，子梯度平衡给有效邻居中值；局部常值是假设而非真值保证。直接排序 O(|B|k² log k)，B 为坏点集合；少于一半异常仅给秩鲁棒性，不给坏点真实值误差界。

### L5 伪代码与数值测试
```text
q = float_copy(I); repaired = false_map(); valid = original_valid()
for x,y in bad_pixel_table:
    values = original_valid_same_CFA_neighbors(I,x,y)
    if enough(values): q[y,x] = median(values); repaired[y,x] = true
    else: valid[y,x] = false
```
算例：可信邻居 [10,10,12]，坏点255→10，表外255保持255；无邻居必须无效。待测连续坏点、ROI 偏移、CFA 奇偶及原图不变性；稀疏遍历优化不得改变邻居来源。

五层追问答案：L1“输出哪些掩膜？”→修复位置和可信有效性分开；L2“为何不全图中值？”→保护真实细缺陷；L3“整列坏点？”→拒绝计量而非假造观测；L4“中值最小化什么？”→绝对偏差；L5“修复链怎么避免？”→始终从原图取样。易错：修过即真值。

## P24 固定图样 DSNU／PRNU

任务／前提：多个已知相对照度的重复参考 → 像素或列的斜率、截距及校正图。演进：单暗亮参考 → 多照度检查线性响应；代价为采集与拟合，遗留温漂／非线性。未实现；[cite:1](#p-source-1) 为响应与非均匀性背景，拟合为本文明确基线。

### L1 步骤
固定温度曝光，逐照度去掉饱和帧 → 平均随机分量 → 对每像素拟合 a_i L+b_i → 掩膜异常斜率 → 逆映射到参考响应。离线拟合结束，在线每帧一次应用。

### L2 机制
DSNU 描述暗响应空间不一致，PRNU 描述光响应不一致；稳定偏置不会被时间平均消掉。列模型便宜但不能刻画列内差异，任意条纹也不一定是固定图样。

### L3 工程权衡
先检查参考均匀、闪烁、线性残差和工作照度覆盖，再选列级／像素级。L 为照度或固定相对单位，b 为 DN；未知 L 尺度只能估相对响应。相机硬件已开 FFC 时不要无验证再套软件校正。

### L4 推导
I_{i,l}=a_iL_l+b_i+e_{i,l}，设计矩阵 [L,1] 至少两种不同 L 才满列秩。最小二乘拟合后 q_i=(I_i−b_i)a_ref/a_i+b_ref；小 a_i 放大噪声。M 个照度、固定2列拟合 O(NM)，应用 O(N)；非线性与温漂不受此模型保证。

### L5 伪代码与数值测试
```text
X = stack_columns(centered_illumination,ones)
a,b = least_squares_QR_or_SVD(X,reference_means)
ok = finite(a,b) and a > response_floor
q[ok] = (float(I[ok])-b[ok])*a_ref/a[ok]+b_ref
```
居中拟合后须把截距还原到原 L 原点。算例 L=[0,1,2]、I=[10,12,14]→a=2,b=10；I=16、a_ref=1,b_ref=0→3。待测单照度秩亏、温漂、跨照度残差与列频谱；缓存逆增益须保留校正版本。

五层追问答案：L1“拟合几个量？”→斜率与截距；L2“平均仍条纹？”→固定项不抵消；L3“列级够吗？”→看列内残差；L4“为何至少两照度？”→两列设计需满秩；L5“中心化陷阱？”→截距必须还原。易错：宣称校正了全部噪声。

## P25 均值与线性卷积

任务／前提：固定核、锚点、边界、图像 → 浮点滤波图。演进：局部重复信息降低随机噪声 → 核权重设计；代价是结构混合。卡尺有 `filter2D` 高斯剖面调用，**不等于通用均值／卷积接口**；来源为[旧稿官方接口转引](#p-source-15)，高斯特例见 P03。

### L1 步骤
明确数学卷积还是相关 → 固定核和锚点 → 扩边 → 加权求和 → 输出。需保持 DC 时核和归一为1；导数核等零和算子不能强行这样归一。

### L2 机制
独立噪声在平均中部分抵消，信号跨边也一起混合。OpenCV `filter2D` 做相关，非对称核若不翻转，响应方向与数学卷积不同；对称高斯恰好掩盖此差异。

### L3 工程权衡
核宽用 px，先按最小缺陷宽度限上界，再看噪声。矩形均值可用积分图，任意核不能照搬；整型累加防溢出，边界方式必须与全图／ROI 对照一致。

### L4 推导
q_i=Σ_j k_j I_{i−j}，Σk=1 保常量；噪声协方差 Σ_n 给 Var(q)=kᵀΣ_nk。M点均值在独立同方差下为 σ²/M，相关时不成立。直接二维 O(Nk²)，盒式积分图可 O(N)，没有通用边缘位置误差界。

### L5 伪代码与数值测试
```text
kernel_api = flip_both_axes(kernel_math)
anchor_api = reflected_anchor(anchor_math,kernel_shape)
q = correlation(float64(I),kernel_api,anchor_api,border)
```
算例均值 [2,4,6]→4；3点独立单位方差→1/3。非对称核 k_{−1}=1,k_0=2,k_1=3，对 I=[1,2,4] 的中心卷积为11、相关为17。待测脉冲、偶数核锚点、零填充边框与宽类型累加；先保正确性再换积分图。

五层追问答案：L1“先声明什么？”→卷积方向和锚点；L2“为什么模糊边缘？”→不同信号也被平均；L3“大核如何加速？”→矩形积分图，非任意核；L4“方差都除M吗？”→仅独立均匀权重；L5“如何抓翻核错误？”→非对称核算例。易错：相关总等于卷积。

## P26 形态学背景估计

任务／前提：灰度图、目标极性、平坦对称结构元素 B → 背景与白顶帽／黑帽。演进：线性低通混入目标 → 形状与尺度选择；代价为非线性形状偏差。无背景估计实现；[cite:15](#p-source-15)。二值开闭卡只解释集合算子，不能直接代替这里的灰度背景与残差。

### L1 步骤
亮小目标选灰度开运算背景，暗小目标选闭运算 → 固定元素与边界 → 输出背景 → 亮用 I−open(I)，暗用 close(I)−I。一次开／闭组合结束。

### L2 机制
开运算先局部最小再最大，消掉不能容纳 B 的亮结构；闭运算对偶。仅当目标与背景存在尺度分离时背景近似可信，长条方向和大目标会破坏这个条件。

### L3 工程权衡
先判亮暗与形状，再选大于需去除目标、又小于背景变化尺度的 B（px）；不存在合适间隔时换独立空场或采集条件。迭代次数、元素锚点、边框处理影响残差，不能只记元素直径。

### L4 推导
对称 B 下 ε_BI(x)=min_b I(x+b)、δ_BI(x)=max_b I(x+b)；开为 δε，闭为 εδ。合适伴随边界下 open(I)≤I≤close(I)，故对应帽残差非负，但不是无偏背景保证。直接 O(N|B|)，矩形可分离，圆形不能随意改成矩形。

### L5 伪代码与数值测试
```text
background = dilate(erode(I,B,border),B,border) if bright else erode(dilate(I,B,border),B,border)
residual = float(I)-background if bright else background-float(I)
return background,residual,valid_support
```
算例复制边界、长度3元素、I=[10,10,20,10,10]→开背景全10、白顶帽 [0,0,10,0,0]。待测边框目标、反极性、长条和元素超过 ROI；优化后逐点比背景而非只比二值检测数。

五层追问答案：L1“亮目标用什么？”→开估背景；L2“为什么不是线性低通？”→极值与形状筛选；L3“宽目标丢失？”→尺度分离失败；L4“黑帽公式？”→close(I)−I；L5“加速结果不同？”→查元素、锚点、边界。易错：二值开闭实现就是灰度背景管线。

## P27 背景减除

任务／前提：图像和已对齐可信背景 → 有符号加性残差。演进：全局偏置不能表达缓变背景 → 空间背景模型；代价为目标自消除风险。未实现；旧稿 P18 工程模型，背景可接 [P26](#p26)，不包含视频 GMM 等时变前景家族。

### L1 步骤
空场采集或掩膜拟合背景 B → 检查配置和配准 → 浮点 q=I−B → 返回背景版本与有效掩膜；需要显示则加固定偏置，不每帧重新定零点。

### L2 机制
I=S+B+n 才能以减法分离加性项。由同图平滑估 B 会把宽目标也当背景；负瓣和光晕是模型／支持问题，不应先截零掩盖。

### L3 工程权衡
先比较目标幅度是否随背景成比例，再判断减法或 [P28](#p28) 除法。静态缓存仅在曝光、光路和场景稳定时可复用；背景核尺度（px）及失效时间须记录。

### L4 推导
B̂=B+e_B，则 q=S+n−e_B；偏差为−E[e_B]，方差为 Var(n)+Var(e_B)−2Cov(n,e_B)。同图背景与噪声一般相关。若 B̂=LI，则 q=(Id−L)I，是高通而非无偏恢复。应用 O(N)，背景估计成本另算。

### L5 伪代码与数值测试
```text
require aligned(I,B) and matching_capture_config(I,B)
ok = valid(I) and valid(B)
q[ok] = float64(I[ok])-float64(B[ok])
return q,ok,background_version
```
算例 I=[12,18]、B=[10,20]→[2,−2]；I=B 时残差0。待测宽缺陷、背景错位、配置过期和 unsigned 下溢；不要用原地修改破坏原图对照。

五层追问答案：L1“背景哪里来？”→空场或明确估计器；L2“宽目标为何消失？”→进入背景；L3“负值先截吗？”→先诊断；L4“方差相加够吗？”→需协方差；L5“缓存条件？”→配置和场景稳定。易错：减背景就是平场。

## P28 背景除法

任务／前提：去偏置正响应、慢变乘性背景 → 相对响应及有效性。演进：加性减法不统一乘性对比度 → 除背景；代价为暗区噪声放大。未实现；旧稿 P19 与 P02 模型推导，单图估背景不是独立平场标定。

### L1 步骤
先减暗场 → 估计 B>0 → 按参考噪声与饱和建立掩膜 → 固定 m，计算 q=mI/B → 返回背景和比例图。无有效响应则拒绝，不仅加 epsilon。

### L2 机制
I=LR 时除照明可近似得 R；B 混入目标会自消除，物体覆盖全图时 L/R 不可唯一分开。加性偏置未去除时比例失真。

### L3 工程权衡
B 和响应门限用 DN，m 决定输出量纲；先确认模型及背景尺度，再限制增益，最后验暗缺陷。阴影边界可能不是慢变照明，应拒绝局部补偿或转独立参考。

### L4 推导
若 B=L(1+δ)，q/m=R/(1+δ)≈R(1−δ)，近似要求 |δ|≪1；J_I=m/B、J_B=−mI/B²，方差约 JΣJᵀ。B→0 病态且同图估计有相关性，无通用恢复界；应用 O(N)。

### L5 伪代码与数值测试
```text
ok = valid(I,B) and B > noise_based_floor
q = invalid_float_map()
q[ok] = m*float64(I[ok])/B[ok]
return q,ok,B
```
算例 I=[20,40]、B=[10,20]、m=1→[2,2]；B=0 必须无效。待测全暗、目标占比、饱和与错误背景复用；向量化除法只在 ok 上执行。

五层追问答案：L1“第一步？”→去偏置；L2“为何除不减？”→乘性模型；L3“暗区爆亮？”→查分母信噪比；L4“唯一拆 L/R 吗？”→不能；L5“epsilon 足够吗？”→需可信掩膜。易错：任何阴影都等于固定平场。

## P29 局部归一化

任务／前提：图像、有效统计窗、噪声底 → 局部标准化图及置信度。演进：全局拉伸无法适应局部偏置／增益 → 局部二阶统计；代价为光度丢失与光晕。未实现；旧稿 P21 的统计设计，匹配 `_score` 的 ZNCC 不是此图像输出。

### L1 步骤
按统一有效支持计算 μ、v → 检查样本数与方差 → q=(I−μ)/sqrt(v+ε) → 输出 q 与 confidence。一遍统计加映射结束。

### L2 机制
减均值移除局部偏置，除标准差统一幅度；ε 避免平坦区任意放大。窗口跨边缘会把目标本身混进统计，不能保证保边。

### L3 工程权衡
窗用 px，ε 用 DN²；先选目标／背景统计尺度，再以噪声底定 ε。输出无量纲且不受 [-1,1] 限制，不能继续当原反射率或 ZNCC 分数。

### L4 推导
I′=aI+b、a>0 时 μ′=aμ+b、v′=a²v；ε=0、v>0 则 q′=q，ε>0 时需同时 ε′=a²ε 才不变。v=E[I²]−μ² 易消减，盒式累计可 O(N)，无普遍边界偏差界。

### L5 伪代码与数值测试
```text
mu,v,count = centered_local_moments(float64(I),valid,k,border)
require no_significant_negative_variance(v)
ok = count >= minimum_count
q[ok] = (I[ok]-mu[ok])/sqrt(max(v[ok],0)+epsilon)
```
只允许把浮点舍入量级的负 v 截为0，显著负值先报错。算例窗 [1,3] 的 μ=2,v=1、ε=3→输出 [−0.5,0.5]；加常数不变，乘2时 ε 改12才不变。待测常量、缺样、大 DC 小方差和边缘光晕。

五层追问答案：L1“分母是什么？”→正则后的局部标准差；L2“常量区为何危险？”→方差小会放噪；L3“ε 单位？”→强度平方；L4“固定 ε 增益不变吗？”→不严格；L5“负方差怎么办？”→区分舍入与严重消减。易错：输出是相关分数。

## P30 非盲反卷积：Richardson–Lucy 基线

任务／前提：已知非负 PSF、非负泊松观测 → 非负恢复图。演进：线性维纳以平方误差权衡 → 泊松似然乘性更新；代价为迭代及噪声拟合。未实现；[cite:12](#p-source-12) 为外部 RL 接口与参考入口，本文给一般 H/Hᵀ 形式。**只补 RL 基线，P17 维纳并列，不能说非盲家族全部完成。**

### L1 步骤
检查 PSF 与观测模型 → 正值初始化 x → 预测 Hx → 比值 y/(Hx) → 伴随回投影 → 乘性更新 → 到相对变化门限、冻结的早停点或上限停止并报告原因。

### L2 机制
泊松似然匹配计数依赖的噪声，Hᵀ 把误差回分到源。更多迭代会拟合噪声；非负不代表无振铃，强读出噪声或 gamma 图不满足纯泊松前提。

### L3 工程权衡
先查 PSF、黑电平和边界，再选早停轮数。PSF 支持用 px，x/y 用线性计数单位；不能把 API 默认迭代数当质量保证。scikit-image 未声明为依赖，外部 API 不是本地能力。

### L4 推导
负对数似然为 Σ_i[(Hx)_i−y_i log(Hx)_i]。RL 更新 x⁺=x⊙Hᵀ[y/(Hx)]/(Hᵀ1)；分母为观测敏感度，仅通量守恒卷积等条件下为1。精确模型下的似然改进不是物理误差下降保证；每轮直接 O(Nk²) 或 FFT O(N log N)。

### L5 伪代码与数值测试
```text
sensitivity = adjoint_H(ones_observation)
for t in range(max_iterations):
    pred = H(x)
    require not any((pred==0) and (y>0))
    ratio = divide(y,pred,zero_over_zero=0)
    x_next = x*adjoint_H(ratio)/sensitivity on sensitivity>0
    if relative_change_small(x_next,x): return x_next,stop_reason
    x = x_next
return x,iteration_limit
```
未观测敏感度为0的源点需标无效。算例 H=Id、x₀=[1,1]、y=[2,4]→一步 [2,4]；H=0.5Id 时一步 [4,8]，可发现漏除 Hᵀ1。待测伴随内积、边界通量、零预测和早停，FFT 加速须保持伴随。

五层追问答案：L1“何时停？”→预定早停／变化／上限；L2“越锐越好吗？”→可能拟合噪声；L3“高斯读出噪声很强？”→换观测模型；L4“为何除 Hᵀ1？”→补敏感度；L5“首要算子测试？”→内积伴随一致性。易错：RL 代表所有非盲反卷积。

## P31 盲反卷积：受约束交替优化

任务／前提：模糊图、有限 PSF 支持、图像／核先验 → 候选 x、h 与诊断。演进：已知核恢复不够 → 联合估核；代价为非凸与歧义。旧稿 P24 参考设计，未实现，非指定论文复现；本卡固定二次图像梯度与核范数基线，不覆盖稀疏／学习式全部盲恢复。

### L1 步骤
限制核非负且和为1 → 选多组初始核 → 固定 h 解正则图像子问题 → 固定 x 更新核并投影单纯形 → 检查目标下降 → 到停滞或上限停止，输出各候选及判据。

### L2 机制
先验限制无限多图核分解；h=δ,x=y 仍可能是伪解。交替求解减少当前目标不等于找到真实曝光运动；核投影不能用“截负后归一”冒充精确欧氏单纯形投影。

### L3 工程权衡
先用曝光运动限制支持（px），再定正则与多初值；核自由度越多越容易吞掉结构。λ、μ 随强度尺度和目标定义标定；重复纹理、饱和、空间变模糊要分层拒绝或另建模型。

### L4 推导
F=½‖H_hx−y‖²+(λ/2)‖∇x‖²+(μ/2)‖h‖²，约束 h≥0、Σh=1。固定 h 解 (HᵀH+λ∇ᵀ∇)x=Hᵀy；固定 x 的核梯度为 Xᵀ(Xh−y)+μh，其中 Xh=H_hx。投影梯度用回溯保证该子步不增目标。归一只消尺度歧义，联合仍非凸；成本含外轮数、子问题迭代及卷积，无通用真值界。

### L5 伪代码与数值测试
```text
for h0 in approved_initial_kernels:
    h = simplex_projection(h0)
    for t in range(max_outer):
        x = solve_image_normal_system(h,y,lambda,border)
        h = backtracking_projected_gradient(h,kernel_gradient(x,h,y,mu))
        record(objective(x,h),kernel_change)
        if stagnated(): break
    save_candidate(x,h,diagnostics)
```
算例固定 h=[1]、λ=0→x=y；它只验子问题，不能证明盲估核。h=[0.2,0.8]→核和1；反例 h=[1],x=y 的数据残差0不能证明恢复。待测投影 KKT、伴随、单调目标、多初值和独立清晰参考；没有参考不报 PSNR。

五层追问答案：L1“输出只有图？”→图、核、诊断；L2“为何有先验？”→分解多解；L3“核越大越好？”→更易过拟合；L4“分块凸等于联合凸？”→不等于；L5“零残差如何看？”→可能平凡伪解。易错：驻点就是物理真值。

## P32 锐化：反差遮罩

任务／前提：原图、高斯尺度、α≥0 → 浮点锐化图及过冲统计。演进：观感边缘钝 → 增加高通残差；代价为噪声／假边缘。未实现；旧稿 P25 的反差遮罩设计，低通复用 P03，不是反卷积或全部锐化方法。

### L1 步骤
按固定边界求 B=G*I → 提取 I−B → q=I+α(I−B) → 统计裁剪前过冲 → 最后按输出协议量化。一遍结束，α=0 为旁路。

### L2 机制
高频残差增强局部对比，没有估计 PSF；噪声也在高频。先 clip 会掩盖过冲及梯度偏移，因此“更锐”不能作为测量证据。

### L3 工程权衡
σ 用 px，α 无量纲；先查噪声，再选低通尺度，从α=0逐步增益，以假阳性与定位偏差限参数。原图、浮点输出和裁剪掩膜都需保留。

### L4 推导
频响 W=1+α(1−G)，G(0)=1 则 DC 保持；高频 G≈0 时幅值近1+α，噪声谱乘 |W|²。可分离低通 O(Nk)，不提供噪声减少或任意边缘精度保证。

### L5 伪代码与数值测试
```text
B = gaussian(float64(I),sigma,border)
q = float64(I)+alpha*(I-B)
return q,(q<output_min) or (q>output_max)
```
算例 I=10,B=8,α=0.5→11；I=0,B=2→−1，不能无符号回绕。待测阶跃光晕、细线、噪声、饱和区；融合卷积时以裁剪前结果对照。

五层追问答案：L1“怎么锐化？”→加高通残差；L2“等于去模糊？”→没有逆 PSF；L3“伪缺陷变多？”→减增益并查噪声；L4“DC为何不变？”→低通 DC=1；L5“为何保浮点？”→不丢负值过冲。易错：锐利就是准确。

## P33 去马赛克：Bayer 同色线性基线

任务／前提：解包 RAW、明确 RGGB 等 CFA 相位 → RGB 及边界有效性。演进：每像素单色观测 → 邻域补缺色；代价为假色与拉链。无 RAW 管线；[cite:15](#p-source-15) 为旧稿官方接口转引。本卡仅同色线性基线，方向自适应和学习式不算完成。

### L1 步骤
确认位深、黑电平、ROI 奇偶 → 校正坏点 → 保留已观测通道 → 对各缺失通道以该色邻居插值 → 返回通道序与有效边界。一遍完成，邻居不足则无效。

### L2 机制
空间先验补每点缺失的两种颜色；观测本身不含完整 RGB。纹理频率超过 CFA 子格采样能力会产生假色，去马赛克不能恢复未观测光谱。

### L3 工程权衡
先核 CFA 相位与 RAW 解包再选插值。裁一列改变相位，不能沿用旧枚举；OpenCV 的 Bayer 缩写需对照文档，不凭名字猜。尺寸测量应比较 RAW 子格与去马赛克后位置偏差。

### L4 推导
y=M_RR+M_GG+M_BB，每位置一个方程三个未知，欠定。对缺失颜色 q_c(i)=Σ_{j∈V_c}w_jy_j，Σw=1，只在常值等假设下精确；固定支持 O(N)，无任意高频颜色误差界。

### L5 伪代码与数值测试
```text
for pixel in RAW_grid:
    c0 = CFA_color(pixel,roi_origin)
    rgb[pixel,c0] = linear_RAW[pixel]
    for c in missing_colors(c0):
        rgb[pixel,c] = weighted_original_same_color_neighbors(c,pixel)
return rgb,valid_support,CFA_metadata
```
算例内区恒定 RGB=(100,50,20) 的 RGGB 观测必须重建各通道该常数；奇数列裁剪后相位须更新。待测原色块、12位打包、边缘、同色坏点及通道顺序，不以一张好看彩照验收。

五层追问答案：L1“必须知道什么？”→位深和 CFA 相位；L2“为什么假色？”→缺色靠先验；L3“裁一列变色？”→相位错；L4“能唯一恢复？”→一般欠定；L5“如何验 RGB？”→原色及奇偶裁剪。易错：去马赛克基线等于完整 ISP。

## P34 白平衡：中性参考对角增益

任务／前提：线性 RGB 与不饱和中性参考 → 固定通道增益、校正图。演进：通道光源比例不同 → 对角响应补偿；代价为弱通道噪声放大。未实现；旧稿 P27 工程模型，不声称颜色转换 API 提供全自动白平衡。

### L1 步骤
固定曝光光源 → 取中性 ROI 通道均值 μ_c → 选固定 μ_ref → g_c=μ_ref/μ_c → 全图逐通道乘 → 输出裁剪和可信度。参考过暗／饱和则拒绝。

### L2 机制
中性参考约束通道比例；灰世界是假定全图均值中性，单色场景违反假设。对角映射不能修复通道交叉光谱失配，颜色矩阵见 [P35](#p35)。

### L3 工程权衡
增益无量纲，先核中性材质、光源和曝光，再限制最大增益。自动逐帧漂移会破坏固定颜色阈值；混合光源不一定有一个全局合适增益。

### L4 推导
q=D_gI，噪声协方差 Σ_q=D_gΣ_ID_gᵀ；均值被校到 μ_ref，但不推出所有反射光谱都被正确还原。μ_c→0 时增益不可辨识；应用 O(N)，无跨光源统一色差界。

### L5 伪代码与数值测试
```text
mu = mean_valid_neutral_ROI(linear_RGB)
require all(mu>signal_floor) and no_reference_saturation
g = mu_ref/mu
require all(g<=approved_gain_limit)
q = linear_RGB*g
```
算例 μ=(50,100,25)、μ_ref=100→g=(2,1,4)，中性参考输出(100,100,100)。待测 BGR/RGB、暗通道、混合光源、输出过冲；定点增益与浮点基线在量化前比对。

五层追问答案：L1“增益怎么求？”→中性通道均值比；L2“灰世界何时错？”→平均非中性；L3“蓝通道颗粒大？”→查增益和曝光；L4“为何还需矩阵？”→对角模型不混通道；L5“偏红偏蓝？”→先查通道序。易错：白平衡就是完整颜色校准。

## P35 颜色校正矩阵

任务／前提：线性相机色块 X 与同白点目标三刺激值 Y → 3×3 矩阵 C、输出域元数据。演进：白平衡只改对角比例 → 允许通道混合；代价为标定数据与域外失配。未实现；旧稿 P28 最小二乘设计，非厂商标准流程或完整 ICC 管线。

### L1 步骤
固定光源、曝光、黑电平与白平衡 → 提取有效色块均值 → 训练／留出分离 → 拟合 C → 验证留出色块 → 全图 q=CI。矩阵拟合一次结束，条件不符拒绝复用。

### L2 机制
线性通道混合比三个增益更灵活，仍不能消除同色异谱。gamma 编码值直接拟合会失去线性三刺激值解释；矩阵负系数可能合理，不应无说明截成非负。

### L3 工程权衡
先核光源、白点、颜色域与样本秩，再调λ。X、Y 若归一化方式不同，C 的尺度也变；输出负值／超色域应记录，不能裁剪后才统计色差。

### L4 推导
行样本求 min_C ‖XCᵀ−Y‖²+λ‖C‖²。λ=0 要求 rank(X)=3；用增广矩阵 [X;√λI] 对 [Y;0] 作 QR/SVD，不显式求逆。拟合 O(M·3²)、应用 O(9N)，不能保证跨材料／光源精度。增加偏置需独立声明为3×4模型。

### L5 伪代码与数值测试
```text
require matching_whitepoint_and_linear_domains(X,Y)
Ct = least_squares_SVD(stack(X,sqrt(lambda)*identity3),stack(Y,zeros3))
C = transpose(Ct)
q = apply_column_pixel_matrix(C,I)
return q,C,whitepoint,transfer_function
```
算例 X=I₃、Y=diag(2,1,0.5)、λ=0→C=diag(2,1,0.5)；列像素(1,2,4)→(2,2,2)。待测基向量乘序、秩亏、留出色块、负输出及换光源；色差计算精确接[颜色 C01](remaining_domains.md#c01-cielab-与-delta-e-76)，该卡不代做颜色标定。

五层追问答案：L1“拟合数据？”→对应色块响应与三刺激值；L2“与白平衡区别？”→允许通道混合；L3“换光源可复用？”→需重新验证；L4“何时不唯一？”→X 秩不足且无正则；L5“乘反怎么查？”→颜色基向量。易错：小训练色差保证所有材质。

## P36 裁剪与 ROI 坐标交接

任务／前提：整数半开 ROI 与图像 → 子图、有效区域、ROI→整图变换。演进：减少无关像素 → 同时保持几何来源；代价为支持截断。匹配有局部 ROI 协议，无统一预处理对象；来源：[匹配协议](../pose_ncc.md)与旧稿 P30。

### L1 步骤
明确 [x0,x1)×[y0,y1) → 拒绝越界或按声明求交集 → 拒绝空区 → 切片 → 用实际裁剪原点返回平移 T。无插值，一次结束。

### L2 机制
保留像素的值不变，坐标原点却变了。只返回小图会把后续边缘／角点当整图坐标；滤波支持变小会改变 ROI 周围输出。

### L3 工程权衡
坐标用整数 px，先留目标及滤波 halo 再缩范围。NumPy 切片可能共享内存且非连续；明确拷贝和原地写权限，不能默认“裁剪不影响原图”。

### L4 推导
p_full=T(x0,y0)p_roi，K_roi=T(−x0,−y0)K；T 使用交集后的实际原点。纯裁剪无插值误差，但估计支持变化可影响下游结果。视图建立 O(1)，复制 O(N_ROI)。

### L5 伪代码与数值测试
```text
x0,y0,x1,y1 = validated_actual_half_open_ROI(request,image_shape)
require x1>x0 and y1>y0
roi = I[y0:y1,x0:x1].copy() if independent_output else I[y0:y1,x0:x1]
return roi,translation(x0,y0),ownership_policy
```
算例原点(10,20)，ROI点(2,3)→整图(12,23)；主点(320,240)→(310,220)。待测四角回填、空区、负索引拒绝、共享内存与非连续输入。

五层追问答案：L1“除了图还返回？”→实际坐标变换；L2“为何边缘滤波不同？”→支持被裁；L3“ROI 多小？”→含目标和 halo；L4“主点怎么改？”→减实际原点；L5“原图被改？”→切片共享内存。易错：只给目标中心加偏移就完成几何协议。

## P37 缩放与采样坐标

任务／前提：原图、精确目标宽高、采样约定 → 新网格、坐标变换与掩膜。演进：降计算或适配输入 → 改变采样密度；代价为混叠与细节损失。匹配有局部 `resize`，[cite:13](#p-source-13)；不等于所有标签和内参链已实现。

### L1 步骤
定整数目标尺寸 → sx=Wout/Win、sy=Hout/Hin → 缩小时选抗混叠 → 逆采样 → 同步角点、标签、掩膜和 K → 保存实际变换；一次完成。

### L2 机制
放大只是插值，不增加观测；缩小先低通减混叠。非等比缩放改变形状，后续圆度／物理长度不能直接拿新像素度量。

### L3 工程权衡
先按最小目标采样宽度定倍率，再选 P18–P21 插值。半像素是明确约定而非所有 API 通用规则；legacy nearest 与 warp 要单独核对。多级金字塔用每层真实尺寸，不机械用2的幂回填。

### L4 推导
半像素逆映射 x_src=(x_dst+½)/sx−½，对应 A 的第一行为 [sx,0,(sx−1)/2]，y 类同，K′=AK。连续坐标变换可逆不意味采样信息可逆；缩小 s 倍理想源频率需低于1/(2s)，盒式面积并非理想砖墙。固定支持 O(N_out)，抗混叠成本另算。

### L5 伪代码与数值测试
```text
sx,sy = Wout/Win,Hout/Hin
A = half_pixel_forward_matrix(sx,sy)
q = resample_with_declared_antialias(I,inverse(A),target_shape)
return q,A,A@K,valid_support
```
算例宽5→3，sx=0.6、前向 x′=0.6x−0.2；源中心x=2→1，目标x′=0→源1/3。待测奇数尺寸、坐标斜坡、细周期纹理、标签集合；P21 面积只承接滤波，不替代本卡几何元数据。

五层追问答案：L1“倍率怎么求？”→真实宽高比；L2“放大等于超分？”→仅插值；L3“缩小锯齿？”→先查抗混叠；L4“半像素项来源？”→像素面积中心对齐；L5“多层怎么回填？”→组合每层真实A。易错：只改焦距不改主点。

## P38 旋转与统一几何重采样

任务／前提：前向仿射、中心、目标画布、插值与掩膜 → 重采样图。演进：分步几何操作累积模糊 → 合成映射后采一次；代价为边界支持管理。`pose_ncc._warp` 有模板局部实现，[源码](../../traditional/template_matching/pose_ncc.py)；通用管线未实现。

### L1 步骤
定义角度和中心 → 建前向 H 并选画布 → 每个目标像素用 H⁻¹ 找源供体 → 指定插值 → 返回有效支持。先组合裁剪、缩放、旋转，再尽可能一次采样。

### L2 机制
逆采样填满目标网格，前向散点容易空洞。几何逆矩阵能回坐标，但插值／裁剪不可逆；出界黑色是填充值而非真实观测。

### L3 工程权衡
图像 y 向下，角度 API 的度与数学 rad 分开；先查中心、旋转方向和画布，再调插值。图像可用 P19，类别标签接 P18；不能把匹配的近完整支持阈值用作通用标签语义。

### L4 推导
A=s[[cosθ,sinθ],[−sinθ,cosθ]]，p′=A(p−c)+c+t；q(p′)=I_interp(H⁻¹p′)。H 可逆、供体有支持才有效。固定插值 O(N_out)；透视变换还需齐次除法，非线性畸变不能由单 H 代替。

### L5 伪代码与数值测试
```text
H = compose_forward_transforms_in_order(transforms)
require invertible(H)
for p_out in canvas:
    p_in = dehomogenize(inverse(H)*homogeneous(p_out))
    q[p_out],valid[p_out] = sample_with_support(I,p_in,interpolation)
```
算例 c=(1,1)、s=1、θ=90°、t=0，(2,1)→(1,0)；坐标逆变换须回原点。现有 `_warp` 对 template×mask 与 mask 分别采样、除支持并筛近完整覆盖，只是匹配策略。待测单位／直角／任意角、掩膜边缘及只采一次的图像差异。

五层追问答案：L1“矩阵与采样方向？”→前向定义、逆向取值；L2“为何一次采？”→少损失；L3“转反了？”→查 y 轴和角单位；L4“图像能无损往返？”→不能；L5“黑边为何污染？”→填充值未标无效。易错：匹配 warp 完成全部几何预处理。

## P39 畸变校正重采样

任务／前提：原图、已标定 K/D、模型类型、新 K_new 与可选校正旋转 R → 校正图、map、有效视场。演进：线性 H 不表达镜头非线性 → 射线投影供体；代价为视场裁剪与一次插值。无标定／remap 管线。

### L1 步骤
校正目标像素用 K_new⁻¹ 解射线 → 若 R 把原相机射线转到校正系，则用 R⁻¹ 转回 → 原镜头模型前投影 → 原 K 投到原图供体 → 建图后采样。一图固定参数预计算一次，每帧采一次。

### L2 机制
“去畸变”输出的供体 map 使用原模型的**正向畸变**，不是对源像素简单减位移。无原图覆盖的射线没有真实信息；换 K_new 改变视场与像素尺度。

### L3 工程权衡
先核针孔／鱼眼模型、K 所属尺寸和 ROI，再定 K_new 与插值。只测少量点可直接校正点，避免整图采样。map 缓存绑定 K/D、R、K_new、尺寸及坐标域。

### L4 推导
map(p)=π_old(K,D,R⁻¹K_new⁻¹p)，q(p)=I_interp(map(p))。针孔投影精确承接 [C06](calibration.md#c06-针孔成像)，径向／切向公式与有效逆域接 [C07](calibration.md#c07-径向与切向畸变)，四系数 KB 风格子模型接 [C03](calibration.md#c03-kannalabrandtkb鱼眼模型)。这些卡提供 L1–L5 模型，不提供本卡整图 remap；KB 全文变体仍未覆盖。建图 O(N_out)，每帧固定支持 O(N_out)，无标定视场外精度保证。

### L5 伪代码与数值测试
```text
for p in rectified_grid:
    ray = inverse(R)*solve(K_new,homogeneous(p))
    map[p] = project_original_lens(ray,K,D,model)
    valid[p] = calibrated_FOV(ray) and interpolation_support_in_bounds(map[p])
q = sample_original(I,map,valid)
return q,valid,K_new,zero_distortion,rectified_frame_id
```
算例限**针孔** D=0、R=Id、K_new=K→map(p)=p；KB 的 D=0 为等距模型，不是针孔恒等。待测四周支持、直线残差、模型错用、标签插值及缓存失效。校正输出须使用新 K 和零畸变，不能再次套原 D。

五层追问答案：L1“map指哪？”→目标到原图；L2“去畸变为何前向畸变？”→寻找原观测供体；L3“黑边怎么办？”→标有效视场，不造信息；L4“所有模型零系数恒等？”→KB 与针孔不同；L5“重复校正怎么防？”→版本和坐标域随图传。易错：标定模型卡等于已实现 remap。

## P40 ML 参数选择、质量分类与旁路

任务／前提：质量特征、有限批准动作、独立下游代价 → 配置／旁路／拒绝。演进：固定配置不适配所有成像状态 → 学习条件风险；代价为数据与域外风险。未实现；旧稿 P38 决策设计，现有 HOG/SVM 匹配示例不是预处理策略。

### L1 步骤
离线枚举批准管线并采下游误差／时延 → 按设备、批次、场景留出 → 冻结特征标准化 → 训练每动作代价回归 → 在线查域外与缺失 → 在白名单中选风险最低动作；不可信时旁路或拒绝。

### L2 机制
学习特征到动作后果，不是恢复器本身；没有看到的成像状态无法由分类准确率保障。旁路保留原图，拒绝交给采集或人工流程，两者不能混用。

### L3 工程权衡
先明确漏检、误报、位置偏差和时延代价，再选模型；核宽、增益等输出受物理范围约束。标准化只用训练集，不能每批重估造成训练／部署漂移；禁止同一场景裁块泄漏。

### L4 推导
a*(z)=argmin_{a∈A} E[C(a,Y)|z]；可用线性头 ĉ_a=w_aᵀz+b_a 拟合观测代价，训练平方误差。有限候选最优不是连续参数全局最优，域外条件期望未知。选择 O(d|A|)，图像特征提取另有 O(N) 等成本。

### L5 伪代码与数值测试
```text
z = frozen_scaler(extract_features(I))
if missing_or_OOD(z): return approved_fallback
costs = risk_model(z)
action = approved_actions[argmin(costs)]
require within_parameter_whitelist(action)
return action,policy_version
```
算例批准动作“旁路／弱滤／强滤”的预测代价 [2,1,4]→弱滤；NaN 特征必须回退，不把 argmin 异常结果当动作。待测跨设备、缺失、极暗、白名单越界与最坏时延；没有训练数据不能给准确率。

五层追问答案：L1“输出图吗？”→先输出批准动作；L2“为何需要旁路？”→增强可能损任务；L3“分类率高还漏检？”→损失不对齐风险；L4“优化目标？”→条件期望代价；L5“发布保存什么？”→特征顺序、scaler、白名单和回退。易错：ML 选参免下游验收。

## P41 DL 去模糊：配对残差 CNN 设计

任务／前提：同场景模糊／清晰对训练，模糊图推理 → 恢复候选与域状态。演进：手工逆问题先验不足 → 学习条件先验；代价为数据域与假边缘。**未定义可复现网络、无权重／训练／推理实现**。来源为旧稿 P41；[cite:8](#p-source-8) 仅支撑残差学习概念，DnCNN 去噪权重不支撑去模糊能力。

### L1 步骤
记录真实曝光运动／PSF 分布 → 对齐清晰标签并隔离场景 → 训练 x̂=y+Fθ(y) → 留出早停 → 冻结权重单次推理 → 域外拒绝或返回原图，保留原观测。

### L2 机制
网络先验为衰减频段选解释；频谱零点或空间变模糊仍可能多解。与 P10 的“输入减噪声残差”不同，本设计残差是清晰−模糊，输出用加号。

### L3 工程权衡
先验真实模糊与对齐，再选感受野／模型；像素损失、边缘损失权重无通用数值。曝光路径超训练范围不能只增加锐化；必须比较不处理和已知核恢复基线。

### L4 推导
y=Hx+n，minθ E‖y+Fθ(y)−x‖² 的总体最优为 E[x|y]，不是任意单样本的物理逆；零空间保留歧义。非凸有限样本训练无全局恢复保证。卷积成本 Σ_l H_lW_lk_l²C_in,lC_out,l，分块还要算 halo 重复开销。

### L5 伪代码与数值测试
```text
train_pairs = scene_disjoint_aligned_pairs()
theta = train_until_validation_stop(y+network(y),target=x)
freeze_eval_mode(theta)
q = y+network(y)
return q,original_y,model_and_domain_status
```
接口算例 y=[0.2,0.8]、F=[0.1,−0.1]→[0.3,0.7]，仅验残差符号。待测真实运动方向、饱和、PSF 域外、整图／halo 一致与假缺陷；NCHW、归一化和 BN 状态须固定。此方案不代表全部 DL 去模糊网络已完成。

五层追问答案：L1“标签怎样配？”→同场景清晰且对齐；L2“为何假边缘？”→逆问题多解靠先验；L3“先扩大模型吗？”→先核退化覆盖；L4“MSE 学到什么？”→条件均值；L5“与 DnCNN 符号相同？”→本卡加清晰残差。易错：去噪模型天然支持去模糊。

## P42 DL 超分辨率：固定倍率基线

任务／前提：明确退化与倍率的 LR/HR 配对 → 高密度恢复图及坐标映射。演进：插值无学习先验 → 学习高分辨率残差；代价为虚构纹理与平方级输出内存。未实现、无权重；旧稿 P42 参考路线，[cite:9](#p-source-9) 仅支撑监督条件／多解讨论，不是 SR 网络复现来源。

### L1 步骤
定义 y=DHx+n 的模糊／降采样 → 配准 LR/HR 裁块 → 以固定倍率插值 U_s(y) 为基线，训练 x̂=U_s(y)+Fθ(y) → 留出早停 → 固定倍率推理，返回 LR→HR 映射。

### L2 机制
高频缺失由先验补，不是相机新观测；MSE 对多个解释取均值会模糊，感知／生成损失可更锐却更不真实。回投影一致只说明可观测部分相符。

### L3 工程权衡
先核真实模糊、噪声、压缩、像素中心和倍率，再选模型；测试周期纹理、笔画和最小缺陷。SR 像素不能当更高物理精度真值，最终位置回原图或独立量具验收。

### L4 推导
若 DH z=0，则 x 与 x+z 对应相同无噪 y，不可唯一恢复；平方损失最优仍为 E[x|y]。倍率 s 下输出面积 s²N_LR，输出存储至少 O(s²N_LR)，推理另含各层卷积；无真实细节通用上界。

### L5 伪代码与数值测试
```text
require deployed_scale == trained_scale
base,A = declared_upsampler_and_mapping(y,s)
residual = SR_network(y)
require shape(residual)==shape(base)
q = base+residual
return q,A,original_y
```
尺寸算例 LR为3×5、s=2→HR为6×10，零残差须等于明确 U_s；不能借此声称训练完成。待测 crop 对齐、坐标回填、回投影、微小缺陷与棋盘伪影；pixel shuffle 若采用须另验排列，任意倍率及生成式 SR 尚未展开。

五层追问答案：L1“谁定尺寸？”→训练与部署倍率；L2“新增细节真实？”→可能是先验补全；L3“像素翻倍精度翻倍？”→需独立计量；L4“多解如何证？”→DH 零空间；L5“输出尺寸错？”→倍率／crop／上采样排列。易错：固定倍率基线完成超分全家族。

## P43 DL 低照度：受限增益与残差设计

任务／前提：带曝光元数据的低照度／正常曝光对 → 增强候选、增益与有效性。演进：全局 gamma 不适配空间照明与噪声 → 学习受限增益及残差；代价为观测不足。无网络／权重／实现；旧稿 P43 工程设计，成像推导接 P01/P02，不借 Noise2Noise 名称声称任意曝光对满足其条件。

### L1 步骤
线性域黑电平校正 → 对齐曝光对并掩膜运动／饱和 → 标签按统一曝光目标归一 → 学习正且有上限的增益 g 和残差 r → 留出早停 → q=g(y)y+r(y)，极暗域外拒绝。

### L2 机制
空间增益补亮度，残差用于去噪／修正；没有到达传感器的光子、黑电平裁掉的信息不能被保证恢复。“更亮”的损失会把噪声也奖励为信号。

### L3 工程权衡
先核 RAW/sRGB 域、噪声与曝光，再设增益上限；g 无量纲，阈值按线性 DN 与噪声定。按温度、曝光、暗缺陷分层，不用长曝光运动模糊标签误导短曝光结构。

### L4 推导
y=P(tx)+n_r，E[y/t]=x，独立零均值读出噪声时 Var(y/t)=x/t+σ_r²/t²；短曝光放大方差。g(y)y+r(y) 的分解非唯一，约束增益只控制部分表达，不保证真实恢复。网络成本按层求和，无暗区真值界。

### L5 伪代码与数值测试
```text
require within_calibrated_exposure_domain(metadata)
g = g_min+(g_max-g_min)*sigmoid(gain_head(y))
q = g*y+residual_head(y)
return q,g,original_y,valid_signal_and_saturation_masks
```
算例 y=0.1,g=4,r=−0.05→0.35；x=4,σ_r²=1，t=1 时曝光归一方差5，t=0.5时12，只验统计公式。待测全黑、热像素、曝光外推、闪烁、暗色缺陷及增益上下限；不以本网络输出作正常曝光标签。

五层追问答案：L1“配对要记录什么？”→曝光、域与对齐；L2“全黑能恢复？”→不能承诺；L3“先调亮度损失？”→先核黑电平／噪声；L4“短曝光为何更噪？”→除t放大计数及读噪；L5“怎样拒绝伪恢复？”→信号掩膜与域外策略。易错：低照度只是 gamma 或所有方法已实现。

## P44 DL 颜色恢复与生成模型边界

任务／前提：定义为色偏恢复或缺色补全的输入与可信颜色参考 → 颜色候选及来源。演进：线性颜色模型不足 → 非线性学习；代价为色彩真实性与多解。无模型／权重／训练；旧稿 P44 与 [cite:8](#p-source-8)、[cite:9](#p-source-9) 仅支撑残差／监督概念，**没有 GAN 或扩散算法的完整推导与实现，不能报生成家族完成**。

### L1 步骤
先分清校色还是着色 → 固定白点、传递函数与配对数据 → 以白平衡／矩阵作基线 → 训练确定性 q=y+Fθ(y) → 留出早停 → 输出原图和候选。若另选条件生成模型，必须额外指定架构、训练目标、采样步数／停止、种子和多候选规则；这些不是本卡已实现步骤。

### L2 机制
确定性网络学习条件颜色映射；生成先验只要求“像真图”的分布，未保证对应当前产品。灰度着色不可恢复丢失色度；残差连接不是真实性约束。

### L3 工程权衡
先验 P34/P35 的物理校准，再考虑非线性；训练按设备、光源、材料隔离。彩色缺陷不能只看灰度 PSNR，需同白点色差、错误颜色及假缺陷；生成图不可作为唯一放行证据。

### L4 推导
确定性 min E‖fθ(y)−x‖² 得条件均值。若观测 A 为灰度投影，存在 Az=0 的非零色度 z，故颜色不可辨识；另加 λD(p_generated,p_reference) 只约束分布，不推出逐样本 f(y)=x。D 的选择／生成训练未指定，不能推导其收敛；若采样 T 步，成本至少包含 T 次相应网络调用。

### L5 伪代码与数值测试
```text
require matching_color_domain_and_whitepoint(y,model)
q = y+deterministic_color_residual(y)
return q,original_y,weight_hash,color_metadata,domain_status
```
接口算例 y=(0.2,0.3,0.4)、残差=(0.1,0,−0.1)→(0.3,0.3,0.3)，不是颜色恢复实验。待测原色／中性、特殊材质、混光、量化前后与独立色卡。未来生成分支还需记录权重、数据、随机种子、采样器及多次输出差异，不能把“固定种子”说成准确性保证。

五层追问答案：L1“先定义什么任务？”→校色还是多解着色；L2“逼真等于真实？”→不等于个体对应；L3“先上网络？”→先物理基线；L4“分布匹配保证色差？”→不能；L5“如何追溯生成结果？”→权重、域、种子、采样器和候选。易错：颜色残差基线代表全部 GAN／扩散恢复。

## 颜色空间补充（承接 P22）

旧稿 P29 同时提到灰度、HSV、Lab。现有 P22 完整正文只处理灰度；本节补充 HSV 代表变换及 Lab 的精确跨卡入口，**不计新增整卡，也不宣称覆盖所有颜色空间**。本地只发现 `_prep` 的 BGR2GRAY，无 HSV／Lab 通用颜色管理实现；来源为 [cite:15](#p-source-15) 的官方接口转引。

### L1 步骤
声明 RGB/BGR、编码、dtype 与范围 → 选择明确空间：灰度接 P22；HSV 先按指定编码域求极值及色相；Lab 先校准线性 RGB→同白点 XYZ，再接 [C01 CIELAB 与 Delta E 76](remaining_domains.md#c01-cielab-与-delta-e-76) 的 L1–L5。转换一次后连同颜色域元数据返回。

### L2 机制
HSV 将明暗幅度与色相表达分开，低饱和时色相不可辨；Lab 的白点归一与分段立方根是感知近似，不是自动相机标定。灰度投影丢色后无法逆回真实 RGB。

### L3 工程权衡
先按颜色缺陷需求选择空间，再定阈值单位。普通 OpenCV 8位 HSV 的 H 常用0–179，FULL 模式不同；浮点 HSV 色相用度，不能直接复制整数阈值。Lab 8位编码偏移／缩放不能当物理 L*a*b*；域变更必须重新验证阈值。

### L4 推导
对 [0,1] RGB 编码值，M=max(R,G,B)、m=min、Δ=M−m，V=M，S=0（M=0）否则Δ/M。Δ>0 时，若 M=R 则 H=60·((G−B)/Δ mod 6)，M=G 则 H=60·((B−R)/Δ+2)，M=B 则 H=60·((R−G)/Δ+4)；Δ=0 的 H 是约定值且无色相意义。Lab 的 f(t)、白点与 ΔE76 公式只由所链 C01 承接；XYZ 前置校准由 P35 承接，二者都不是全部色差标准。固定通道转换 O(N)，Δ→0 的色相敏感度发散。

### L5 伪代码与数值测试
```text
rgb = validate_order_encoding_and_range(I,metadata)
hsv = explicit_HSV_formula(rgb)
hue_valid = hsv.saturation > application_saturation_floor
return hsv,hue_valid,declared_HSV_units
```
算例 RGB=(1,0,0)→H=0°,S=1,V=1，纯绿→120°，中性(0.5,0.5,0.5)→S=0且 H 不可信。待测原色、低饱和、普通/FULL、浮点/整数范围；Lab 复用 C01 的同白点与分段连续测试，不把无色卡输入称已校准。

五层追问答案：L1“转换前查什么？”→通道、编码、范围；L2“灰区色相跳？”→Δ小不可辨；L3“H门限为何错倍数？”→整数与度混用；L4“Lab推导在哪里？”→所链 C01，需同白点XYZ；L5“类型转换就是颜色转换？”→不是，必须更新域协议。易错：灰度卡完成旧稿全部颜色范围。

## Q01 PSNR 全参考指标

任务／前提：同几何、同颜色／曝光域的可信参考 x、候选 y、冻结有效区域与动态范围 L>0 → MSE及PSNR（dB）。定位：像素误差的对数表达，**不是预处理算法**。无专用评测接入，[tests/metrics.py](../../tests/metrics.py) 的 RMSE／定位指标不等于 PSNR 实现；来源：[cite:16](#p-source-16)。

### L1 步骤
核对参考来源与配准 → 固定 ROI、通道、边缘裁剪和 L → 转 float64 → 同一有效区域累计平方误差及样本数 → 求 MSE → MSE=0 返回 +∞，否则取对数；无有效样本拒绝。没有可信参考则不报全参考 PSNR。

### L2 机制
同 L 下 PSNR 与 MSE 单调反向，放大误差差别的可读性但不增加结构判断能力。参考含噪时衡量的是对该参考的差，不是对潜在干净图的误差；原始有噪图不能自动作去噪真值。

### L3 工程权衡
L 是协议规定的最大最小可能值之差：8位常用255、归一化常用1，不能逐图取 max−min。彩色平均前固定通道单位，SR 先固定评测坐标和裁边；不能为提高指标额外自适应配准／曝光拟合而不披露。逐图 dB 平均与池化 MSE 后换 dB 不同，需写明聚合方法及∞策略。

### L4 推导
MSE=(1/n)Σ(x_i−y_i)²，PSNR=10log10(L²/MSE)=20log10(L/RMSE)。同时 x,y,L 乘 a>0 指标不变；只把 L 从1错设255会虚增20log10(255)≈48.1308 dB。相同 MSE 可对应完全不同的局部缺陷；O(n)，没有位置误差或最小缺陷召回保证。

### L5 参考实现与数值测试
函数仅处理传入的共同有效 ROI；掩膜需在调用前按冻结协议抽取，不自动删除异常值，也不静默 clip 输出。

```python
import math
import numpy as np

def psnr_reference(x, y, data_range):
    x, y = np.asarray(x, dtype=np.float64), np.asarray(y, dtype=np.float64)
    if x.shape != y.shape or x.size == 0:
        raise ValueError('shape mismatch or empty support')
    if not np.isfinite(data_range) or data_range <= 0:
        raise ValueError('invalid data_range')
    if not np.isfinite(x).all() or not np.isfinite(y).all():
        raise ValueError('nonfinite input')
    mse = np.mean((x-y)**2, dtype=np.float64)
    if not np.isfinite(mse):
        raise ValueError('overflow in squared error')
    return (math.inf if mse == 0 else 20*math.log10(data_range)-10*math.log10(mse)), mse

assert psnr_reference([0.,1.], [0.,1.], 1)[0] == math.inf
score, mse = psnr_reference([0.,1.], [0.,0.], 1)
np.testing.assert_allclose([score,mse], [3.010299956639812,0.5])
```
这是文内参考函数，未写入模块、未在本次 Python 环境执行；待测空掩膜、NaN、尺寸错、uint16 差分、缩放不变、错误 L 和批次聚合。分块累计须累加平方和与样本数，不能先平均各块 PSNR。

五层追问答案：L1“没有干净图怎么办？”→不报对干净真值的全参考分数；L2“PSNR高必然缺陷更清楚？”→不保证；L3“浮点 L 如何定？”→按冻结强度协议，不按dtype猜；L4“零误差多少？”→数学定义+∞；L5“批次如何合并？”→明确按图dB还是池化MSE。易错：PSNR就是相机物理 SNR，或高分等于工业合格。

## Q02 SSIM 单尺度结构相似度

任务／前提：同网格、同强度域的可信参考与候选灰度图、固定局部窗与动态范围 L → SSIM图及均值。演进：MSE 不区分结构 → 局部亮度／对比／结构统计；代价为窗口和尺度依赖。无本地评测接入；[cite:17](#p-source-17) 原作者入口、[cite:16](#p-source-16) 外部 API。本文仅单尺度灰度，不覆盖 MS-SSIM、彩色感知或无参考指标家族。

### L1 步骤
冻结参考、配准、ROI与范围 → 用归一化11×11高斯窗σ=1.5计算均值、方差、协方差 → 用 C1/C2 求局部分数 → 只平均完整有效窗口中心 → 返回均值和图；图小于窗或无完整有效窗拒绝。

### L2 机制
亮度项比较均值，对比／结构项比较方差与协方差；常数稳定项避免近零分母。平均分数可能稀释微小缺陷，负相关可产生负值，不能强行裁成[0,1]。结构相似不提供物理边缘真值保证。

### L3 工程权衡
窗口用 px、σ用 px、C1/C2用强度平方；先固定尺度、边界、通道和协方差分母，再比方法。本文用总体加权矩（不乘 n/(n−1)），K1=0.01、K2=0.03，不额外下采样；作者推荐的预下采样版与此单尺度核不是同一个协议。彩色若逐通道算需各自正确范围，不能给 Lab 三通道共用L后当同一指标。

### L4 推导
局部 μ_x=Σw_ix_i、v_x=Σw_i(x_i−μ_x)²、c_xy=Σw_i(x_i−μ_x)(y_i−μ_y)，Σw=1。取亮度、对比、结构指数均为1且 C3=C2/2，可合并为 SSIM=((2μ_xμ_y+C1)(2c_xy+C2))/((μ_x²+μ_y²+C1)(v_x+v_y+C2))，C1=(K1L)²、C2=(K2L)²。x=y 时为1；常数 a,b 时只剩亮度比。精确一致统计下 |SSIM|≤1，但不是距离度量。直接 O(Nk²)，可分离统计 O(Nk)，全图均值不能推出局部误差界。

### L5 参考实现与数值测试
下列保守参考实现逐窗计算中心化矩，避免大偏置下的二阶矩消减；输入限定二维有限灰度，不自动配准或归一化。边界采用 valid 窗，输出比输入每轴少10；掩膜评测须额外只选择所有11×11邻居均有效的中心，不以无效像素填零骗分。

```python
import numpy as np

def ssim_reference(x, y, data_range):
    x, y = np.asarray(x, dtype=np.float64), np.asarray(y, dtype=np.float64)
    if x.shape != y.shape or x.ndim != 2 or min(x.shape) < 11:
        raise ValueError('expected equal 2D images at least 11 by 11')
    if not np.isfinite(data_range) or data_range <= 0:
        raise ValueError('invalid data_range')
    if not np.isfinite(x).all() or not np.isfinite(y).all():
        raise ValueError('nonfinite input')
    axis = np.arange(-5,6,dtype=np.float64)
    g = np.exp(-axis**2/(2*1.5**2)); g /= g.sum()
    w = np.outer(g,g)
    c1, c2 = (0.01*data_range)**2, (0.03*data_range)**2
    result = np.empty((x.shape[0]-10,x.shape[1]-10),dtype=np.float64)
    for row,col in np.ndindex(result.shape):
        a,b = x[row:row+11,col:col+11],y[row:row+11,col:col+11]
        ma,mb = np.sum(w*a),np.sum(w*b)
        da,db = a-ma,b-mb
        va,vb,cov = np.sum(w*da*da),np.sum(w*db*db),np.sum(w*da*db)
        result[row,col] = ((2*ma*mb+c1)*(2*cov+c2))/((ma*ma+mb*mb+c1)*(va+vb+c2))
    if not np.isfinite(result).all():
        raise ValueError('nonfinite moment or score')
    return float(result.mean()),result

zero = np.zeros((11,11),dtype=np.float64)
np.testing.assert_allclose(ssim_reference(zero,zero,1)[0],1)
np.testing.assert_allclose(ssim_reference(zero,zero+1,1)[0],0.0001/1.0001)
np.testing.assert_allclose(ssim_reference(zero+0.5,zero+0.5,1)[0],1)
```

五层追问答案：L1“先算哪些量？”→局部均值、方差、协方差；L2“有负值是错吗？”→负相关可为负；L3“不同库为何不一致？”→窗、范围、协方差、裁边、通道和尺度；L4“同图为何1？”→分子分母相同且稳定项为正；L5“掩膜怎么做？”→只统计完整有效支持，不能无效填零。易错：SSIM高代表缺陷没丢，或单尺度实现完成全部SSIM变体。
