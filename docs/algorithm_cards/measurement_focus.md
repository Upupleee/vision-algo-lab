**领域双线。**测量持续优化成像模型、亚像素可辨识性、异常点与标定不确定度：微分产生候选，Canny（1986）增加细化/连接，Devernay（1995，IPOL 实现为 2017）增加连续定位；Zernike（1993 的正交矩论文分支）不是 Canny 的必然后继；Harris（1988）解决二维角点可定位性；学习网络用数据先验换取标注与域迁移成本。工程顺序是成像/ROI → 候选 → 连续坐标 → 拟合 → 标定误差传播，不可跳过最后一步。[cite:1](#source-1)[cite:2](#source-2)[cite:4](#source-4)

对焦持续优化评分的纹理/噪声鲁棒性、曲线采样与运动耗时：差分/相关统计便宜，但受内容与噪声影响；变换域增加选频能力，也增加块支持和实现成本；搜索减少评价次数，依赖峰形；学习回归减少扫描的愿望不能消除方向不可辨识。评分、曲线模型和搜索是可组合分支，不按年代声称全面替代。未核验各评分原始提出年份，不填猜测年份；本机库版本也不是方法提出日期。

## M01 卡尺 Caliper

**任务/来源/状态：**灰度图及矩形布局 → `points(N,2)`、强度、可选直线/RMS。[Caliper.measure](../../traditional/caliper_measurement/caliper.py#L30-L141) 已实现；源代码单一事实来源 `[SINGLE-SOURCE]`，未核验与商业卡尺等价。前提为剖面内目标边缘可分辨。

**L1 步骤：**构造长轴 a 与法向 n，沿长轴排探针，沿法向双线性采样，横向平滑，求带符号梯度；按极性翻转、取峰并拒绝弱峰，优先 erf、异常时抛物线回退；回填图像坐标，有效点至少两个且跨度大于 5 px 才 PCA。

**L2 机制：**ROI 将二维搜索约束为一维；平滑降噪、拟合汇聚几何证据。实际每探针只有一条采样线，**没有切向厚度投影平均**。`polarity=0` 用全部梯度均值统一翻转，不是每行自动选择任意极性；混合边缘会误选。

**L3 工程权衡：**length/width/sigma 单位 px，强度阈值随灰度尺度变。先检查 ROI 和法向，再平滑、极性和强度阈值，最后增加探针数；更多相关探针不消除系统偏差。偶数 width 实际生成 width+1 个采样。先看有效率、剖面与残差，再看尺寸，不能只看 RMS。

**L4 推导：**令 \(a=(\cos\theta,\sin\theta),n=(-\sin\theta,\cos\theta)\)，探针点
\(p_i(s)=c+a[t_i-(L-1)/2]+ns\)。双线性权重为横纵小数权重乘积，四项和为 1，故能精确再现平面灰度。若仅 s 的方差为 \(\sigma_s^2\)，点协方差为 \(nn^T\sigma_s^2\)，不是各向同性。扫描偏离真实法向角 \(\phi\) 时过渡宽约为 \(\sigma/|\cos\phi|\)，切向扫描退化。固定核采样 O(PW)，erf 另乘迭代成本。

**L5 实现：**数组索引 `[y,x]`，返回 `(x,y)`；`points` 实为图像像素而非注释中的世界坐标，`positions` 仅 x 列。`_sample_points` 在用 `ok` 屏蔽前已访问四邻点，可能先越界或负索引绕回；erf 成功返回也未检查中心/RMS。下列质量门是参考方案，不是已有保护。

```text
for t in probe_positions:
    p = center + axis*(t-(length-1)/2) + normal*offsets
    if any_four_neighbor_invalid(p): mark_invalid; continue
    profile = bilinear(gray,p)
    gradient = signed_gradient(smooth(profile))
    if peak_strength < threshold: mark_invalid; continue
    s = fit_erf_or_parabola(profile,gradient)
    if not quality_ok(s): mark_invalid; continue
    point = center + axis*(t-(length-1)/2) + normal*(s-half_width)
fit_PCA(valid_points)
```

**数值例：**c=(10,20)、theta=90°、居中探针法向偏移 s=2，a=(0,1)、n=(-1,0)，回填为 (8,20)，不是 (12,20)。若四邻灰度为 0、10、20、30，横/纵小数均 0.5，采样为 15。

**测试与验收：**已有 `test_caliper` 仅一类近竖直边。新增设计：四边越界须拒绝而非崩溃，偶宽应核对实际长度，混合极性不得误称独立选边，整体平移检查回填；记录有效率、真值误差和 RMS 三个量。缓存采样坐标前后须同边界规则逐点对照。

**追问链与答案：**L1「下标如何变二维？」答：基点加法向位移；L2「降噪来自投影吗？」答：当前没有厚度平均；L3「反边漏检先降阈值？」答：先查法向/极性；L4「点误差为何各向异性？」答：单剖面只估法向位移；L5「有 ok 为何越界？」答：检查发生在索引之后。易错答案：把像素坐标称毫米坐标。证据入口为本卡源码及上述映射。

## M02 三点抛物线梯度峰

**任务/来源/状态：**单边缘剖面 → 连续峰位和整数峰强度；[parabolic_gradient_subpixel](../../traditional/subpixel/edge_subpixel.py#L23-L32)、[_parabolic_peak](../../traditional/caliper_measurement/caliper.py#L123-L130) 已实现。原理为局部插值；不是完整统计边缘模型。

**L1 步骤：**浮点差分取绝对值，找 k，读取相邻三点，计算顶点偏移；边界/近零分母回退整数，偏移裁到 ±0.5。卡尺内部对已统一极性的梯度操作。

**L2 机制：**阶跃灰度没有极大值，梯度才形成峰；三个等距样点确定一个二次函数。裁剪避免大幅外推，但不证明峰来自真实边缘，更不证明无偏。

**L3 工程权衡：**采样间距 h、平滑宽度均影响曲率。平峰先查低对比或过平滑，不能只减小分母阈值；源码 `1e-12` 是绝对尺度阈值。双边缘和平台应单独拒绝。

**L4 推导：**设 \(q(t)=At^2+Bt+C\)，在 -h、0、h 解得 \(A=(f_--2f_0+f_+)/(2h^2), B=(f_+-f_-)/(2h)\)，于是
\(t_*=-B/(2A)=h(f_--f_+)/[2(f_--2f_0+f_+)]\)。峰需 A<0；A=0 不可辨识。误差一阶传播 \(\operatorname{Var}t_*\approx J\Sigma_fJ^T\)，差分噪声可能相关；平峰分母趋零使方差大。取峰 O(W)，插值 O(1)。

**L5 实现：**返回强度是 f[k] 而非插值顶点值；需对空/单点/非有限输入另加保护（尚未实现）。批量优化保持 `argmax` 首次并列峰语义。

```text
k = argmax(abs(gradient(float(profile))))
if k is boundary: return k, integer_strength
D = f[k-1]-2*f[k]+f[k+1]
delta = 0 if abs(D)<epsilon else clip((f[k-1]-f[k+1])/(2*D),-0.5,0.5)
return k+delta, f[k]
```

**数值例：**f=(6,9,8)、h=1，D=-4，A=-2，B=1，delta=0.25；k=10 时输出 10.25。拟合顶点高 9.125，但函数返回强度 9。

**测试与验收：**上述三点应恢复 0.25；平坦分母回退、边界峰不访问越界、反极性绝对梯度不变。`test_subpixel_profile` 有一个无噪 erf 剖面，不覆盖双峰和相位遍历。

**追问链与答案：**L1「三个点够全局找峰？」答：不，先扫剖面；L2「为何不拟合灰度峰？」答：阶跃无峰；L3「平峰怎么办？」答：检查成像/曲率，必要时回退；L4「偏移哪来？」答：解 A、B 后求 -B/2A；L5「返回的是新峰强度？」答：仍为 f[k]。易错：把半像素裁剪当精度界。来源状态：源码已读、公式按三点定义核算。

## M03 erf 积分高斯剖面拟合

**任务/来源/状态：**灰度剖面 → c、残差 RMS、sigma；[gaussian_fit_subpixel](../../traditional/subpixel/edge_subpixel.py#L35-L54) 的四参数无约束最小二乘已实现。与 F10 的高斯峰不同。

**L1 步骤：**抛物线/指定 x0 初值、半极差幅值、均值背景、sigma=1 → `curve_fit` → 返回 c、RMS、abs(sigma)，最多 5000 次函数评估。

**L2 机制：**以多个灰度点同时估计模糊和位置，不只依赖三点导数。先验正确才有优势；背景斜坡、饱和、非对称 PSF 和双边缘会产生模型偏差，RMS 小不等于物理边缘准。

**L3 工程权衡：**c/sigma 为 px，a/b 为灰度；窗需同时覆盖过渡与平台。无平台时幅值/中心/宽度耦合，增加迭代不能解决不可辨识。下降边缘需负幅值，先看残差形状和条件数，再改窗/约束。

**L4 推导：**理想边 \(b_0+\Delta H(x-c)\) 卷积高斯后为 \(b_0+\Delta[1+\operatorname{erf}((x-c)/(\sqrt2\sigma))]/2\)，故 a=Delta/2、b=b0+Delta/2。同方差独立高斯噪声时最小二乘为最大似然。中心导数
\(\partial m/\partial c=-a\sqrt{2/\pi}\exp[-(x-c)^2/(2\sigma^2)]/\sigma\)。局部满秩时协方差近似 \((J^T\Sigma^{-1}J)^{-1}\)，不是误差上界；点采样也不等于像素面积积分。每次迭代 O(W)。

**L5 实现：**sigma 可跨零，a/sigma 同时翻转等价，事后 abs 无法修复求解退化。参考方案用正宽度参数化、中心 bounds、有限性/残差/条件数验收；当前未接入。生成器同用 erf，已有无噪测试存在模型同源优势。

```text
xs = arange(length(profile))
c0 = supplied_center_or_parabolic(profile)
theta0 = (half_range,c0,1,mean(profile))
theta = least_squares(model(theta,xs)-profile,theta0)
return theta.center, rms(model(theta,xs)-profile), abs(theta.sigma)
```

**数值例：**b0=40、Delta=160，则 a=80、b=120；x=c 时 erf(0)=0，灰度 120；左右远端趋于 40/200。sigma=1 时中心导数约 -63.8308 灰度/px（对 c 求导）。

**测试与验收：**正反极性、无噪参数恢复、短窗病态、常量图、多边缘、饱和均需覆盖；解析雅可比对有限差分，报告拟合失败率而非只统计成功点误差。

**追问链与答案：**L1「估几个参数？」答：四个；L2「erf 来源？」答：阶跃卷积高斯积分；L3「低 RMS 不稳定？」答：平台不足/参数耦合；L4「协方差何时成立？」答：模型、噪声及局部满秩条件成立；L5「abs(sigma) 足够？」答：不，需在优化中约束。易错：把协方差近似称确定性界。来源状态：本地模型与最小二乘推导，未宣称原始论文性能复现。

## M04 Devernay 二维边缘精化

**任务/来源/状态：**图像 → 无序 Nx2 像素坐标；[devernay_edges](../../traditional/subpixel/edge_subpixel.py#L57-L105) 已实现简化版。IPOL 2017 方法有边链，不能与当前实现等同。[cite:1](#source-1)

**L1 步骤：**高斯平滑、Sobel、幅值/方向、high 单阈值、八邻近似方向 NMS；沿单位梯度正负 1 px 双线性采样幅值，三点插值，裁偏移到半像素后回填。

**L2 机制：**梯度近似边缘法向，沿法向精化有峰，沿切向通常不具位置约束。当前没有 Canny 的双阈值滞后或边链；保留弱边的能力不等同完整 Canny/Devernay。

**L3 工程权衡：**sigma_grad 为 px，high 是 Sobel 幅值，随核增益/灰度范围变。先看噪声与法向，再阈值；交叉、窄条、曲边、多边缘破坏孤立局部峰。旋转周期误差应查 NMS/插值，不只降阈值。

**L4 推导：**令 \(g=\|\nabla I_s\|,n=\nabla I_s/g\)，对 \(g(p+tn)\) 二次展开，由 M02 得
\(\delta=[g(p-n)-g(p+n)]/[2(g(p-n)-2g(p)+g(p+n))]\)，\(\hat p=p+\delta n\)。需要非零梯度及负曲率；方向误差也传播到点位置。固定核 O(HW)，候选 O(N)，内存 O(HW)。

**L5 实现：**`abs(ux*sx+uy*sy)>0.5` 未归一化邻居长度，不是统一 ±45°判定；连续采样用 `[y,x]`，输出 `[x,y]`。`np.where` 两分支先求值仍可能除零；掩膜除法是改进方案，不是现有行为。

```text
gx,gy = sobel(gaussian(gray))
mag,n = magnitude_and_unit_direction(gx,gy)
pixels = approximate_direction_NMS(mag,threshold)
gm,g0,gp = sample(mag,pixels-n),mag[pixels],sample(mag,pixels+n)
delta = clip(parabolic_offset(gm,g0,gp),-0.5,0.5)
return pixels_xy + delta*n
```

**数值例：**p=(10,20)、n=(0.6,0.8)、(gm,g0,gp)=(6,9,8)，delta=0.25，结果 (10.15,20.20)。位移长度 0.25 而非两个坐标各 0.25。

## M05 Zernike 矩边缘

**任务/来源/状态：**圆邻域 → 法向与连续边位置；本仓库**无可调用函数**，仅[旧笔记](../research_notes.md#1-zernike-矩亚像素边缘todo)及源码头。书目核验指向 Ghosal–Mehrotra，*Orthogonal moment operators for subpixel edge detection*，Pattern Recognition 26(2), 1993；旧笔记题名/期刊与此不一致。A31 模糊补偿的原文归属尚未充分核验。[cite:4](#source-4)

**L1 步骤：**教学方案：候选窗映射单位圆，积分 A11/A20，复矩相位给法向，矩比给归一化距离 l，乘窗口半径 R 回填；弱矩、越域或模型残差大则拒绝。模糊联合估计另建模型，不冒充已有函数。

**L2 机制：**正交矩压缩局部结构，特定模型下用比值消去对比度。复矩相位随旋转变化，只有相应幅值不变；丢相位就不能得方向。大窗降低部分随机扰动，却混入曲率与其他边缘。

**L3 工程权衡：**R 为 px，l 为无量纲；先固定基函数、面积权与归一化，再比误差。A11 近零时方向退化；点采样的无模糊阶跃在亚像素移动时可能完全不变，不能从没有变化的观测恢复连续位置。

**L4 推导：**采用 \(A_{nm}=(n+1)\pi^{-1}\int_D I V_{nm}^*dA\)，\(V_{11}=x+iy,V_{20}=2(x^2+y^2)-1\)。旋至法向 +x、\(I=b+\Delta H(x-l),\Delta>0\) 时背景项积分为零，且
\(\int_l^1 2x\sqrt{1-x^2}dx=\tfrac23(1-l^2)^{3/2}\)，因此
\(A'_{11}=4\Delta(1-l^2)^{3/2}/(3\pi)\)，\(A_{20}=2\Delta l(1-l^2)^{3/2}/\pi\)，从而 \(l=2A_{20}/(3A'_{11})\)，\(\theta=-\arg A_{11}\)。标准归一化下不能直接用 A20/abs(A11)。对模糊模型 \(I=b+\Delta\Phi((n^Tp-l)/s)\)，可加 \(V_{31}=(3r^2-2)(x+iy)\) 的预测矩联合最小二乘；关于 l、s 的雅可比满秩才局部可辨识。这是参考数值方案，不是已核验原论文闭式补偿。固定矩数、每窗 O(R²)。

**L5 实现：**预计算复核、圆掩膜与面积权；检验常量泄漏、旋转相位、极性和矩归一化；离散圆并不严格保持连续正交性。A31 具体补偿实现、像素积分与真实误差验证均未完成。

```text
map patch coordinates to unit_disk
A11,A20 = weighted_complex_moments(patch)
if abs(A11)<threshold: reject
theta = -arg(A11)
l = 2*A20/(3*real(rotated_A11))
if abs(l)>=1: reject
return center + radius*l*(cos(theta),sin(theta))
```

**数值例：**指定模型 Delta=1、l=0.5，\((1-l²)^{3/2}=3\sqrt3/8\)，A11'=\(\sqrt3/(2\pi)\)，A20=\(3\sqrt3/(8\pi)\)；原始矩比为 0.75，乘 2/3 才回到 0.5。R=4 时法向像素偏移 2。

**测试与验收：**数值圆域积分应逼近解析矩，常量非零阶矩应随积分精度趋零；测试旋转相位、反极性、半径变化、模糊/位置联合参数奇异值。仅给设计，未有仓库 Zernike 回归或实测精度。

**追问链与答案：**L1「从矩到点？」答：相位+归一化距离+R；L2「全部旋转不变？」答：复相位不变性说法错误；L3「大窗必优？」答：曲率/多边干扰增加；L4「2/3 哪来？」答：不同阶 (n+1)/pi 常数；L5「能调用吗？」答：没有函数。易错：把理想阶跃公式和 A31 研究方向称已完成模糊补偿。来源状态：书目为二手检索 `[SINGLE-SOURCE]`，理想模型按本文定义推导，模糊原文 `[INSUFFICIENT DATA]`。

## M06 Canny

**任务/来源/状态：**灰度图 → 二值薄边缘；完整流程未在本仓库实现。依据官方 API 与 IPOL 页面，不将 M04 当其别名。[cite:1](#source-1)[cite:2](#source-2)

**L1 步骤：**按噪声设计平滑，求梯度，法向 NMS，高/低双阈值，保留低阈值图中与强边可达的弱边，输出像素边图；队列耗尽停止。

**L2 机制：**NMS 消除厚响应；滞后连接让弱而连续的边保留，孤立弱噪声丢弃。一个低阈值不能代替连通性，也不能从二值输出直接得亚像素中心。

**L3 工程权衡：**阈值随导数核/输入动态范围变化；OpenCV 默认 L1 幅值，与 L2 幅值不同。先查噪声/平滑，再看断裂/虚连，最后调双阈值；交叉边可造成错误连通。显式高斯尺度不能假定由 `Canny` 自动提供。

**L4 推导：**\(\nabla(G*I)=(\nabla G)*I\)。NMS 是法向局部极大近似；令 W={g≥Tl}、S={g≥Th}，输出为 W 的连通图内可从 S 到达的顶点集。固定八邻域 BFS O(HW)。这里只推导图可达机制，未复现 Canny 原论文变分最优滤波完整推导；原最优性有阶跃/噪声条件，不是任意图最佳。

**L5 实现：**接入方案需明确 uint8 图像入口、浮点梯度保留、边界与 NMS 平台规则。入队即标记，避免重复遍历。不能把外部 API 可用称本仓库已接入。

```text
g,n = gradient(smoothed_image)
t = nonmaximum_suppression(g,n)
allowed = t>=low
queue = pixels(t>=high)
while queue not empty:
    p = pop(queue)
    visit_unseen_allowed_neighbors(p,queue)
return visited_mask
```

**数值例：**NMS 后图上，强点幅值 10 连到 6 再连到 5，另一孤立点 6；Tl=5、Th=9，则前三点保留，孤立 6 删除。阈值相等的边界使用 ≥。

**测试与验收：**该连接例、无强种子、长链、斜边和交叉；分别测细化宽度、连接完整性及孤立弱边拒绝。尚未有本仓库 Canny 端到端回归。

**追问链与答案：**L1「双阈值后？」答：可达性搜索；L2「只有 NMS？」答：不解决弱边连接；L3「换 L2 沿用阈值？」答：重标定；L4「滞后数学本质？」答：受限图遍历；L5「二值边可直接拟合 erf？」答：须回原灰度/梯度。易错：称完整原始最优性已推完。来源状态：官方正文已读，原始变分推导仍部分。

## M07 Sobel

**任务/来源/状态：**图像 → 带符号 gx/gy；M04、F02 中 `cv2.Sobel(...,CV_64F,ksize=3)` 已使用。是算子，不是检测器。

**L1 步骤：**确定灰度与边界，在两方向应用核，保留正负浮点导数，再由任务计算幅值/方向；有限次卷积，无迭代。

**L2 机制：**[-1,0,1] 做中心差分，正交方向 [1,2,1] 平滑；常量内部为零，单独输出没有目标边缘判定。过早取绝对值会损失极性。

**L3 工程权衡：**ksize 是 px，scale 决定增益；改变核而不重标定阈值会误判。uint8 输出会丢负值，边界扩展也可制造导数。先核对类型/核，再调幅值门。

**L4 推导：**\(I(x+h)-I(x-h)=2hI_x+O(h³)\)；\(K_x=[1,2,1]^T[-1,0,1],K_y=K_x^T\)。单位斜坡响应为 2×4=8；白噪声输出方差为 \(\sigma_n²\sum K_x²=12\sigma_n²\)（内部独立样点）。可分离卷积从每像素 O(k²) 变为 O(k)。

**L5 实现：**边界须和库一致，测试时区分内部与整图；浮点幅值与显示用 8 位绝对值不是同一数据。替换可分离实现先逐像素等价比较。

```text
gx = correlate(gray,outer([1,2,1],[-1,0,1]),border)
gy = correlate(gray,transpose(Kx),border)
return gx,gy
```

**数值例：**3×3 邻域三行均为 (0,1,2)，中心 gx=8、gy=0；若斜坡增益变 2，gx=16，能量增四倍。

**测试与验收：**常量内部零，x/y 斜坡增益、转置交换、负增益反向；边界单独检查。算术测试不等于真实边缘精度评测。

**追问链与答案：**L1「输出边？」答：导数；L2「平滑方向？」答：与微分正交；L3「16 位阈值？」答：按有效幅值重定；L4「为何八倍？」答：差分 2 乘平滑 4；L5「方向倒了？」答：查相关/卷积、x/y 和符号。来源状态：库调用已核对，核增益直接数值核验。

## M08 Harris 角点检测

**任务/来源/状态：**图像 → 角点响应及候选；[demo 与测试](../../traditional/subpixel/corner_subpixel.py#L60-L80) 调用 `cornerHarris` 后**按真值附近挑点**，不是部署检测器。[cite:2](#source-2)

**L1 步骤：**梯度、窗内外积和 M、响应 R、阈值、NMS/距离去重、可选精化。通用 NMS 是接入方案，当前示例用真值筛候选。

**L2 机制：**角点两个方向位移都会改变图像，直边沿切向几乎不变。梯度幅值只看强弱，张量特征值才能区分直边与角点。

**L3 工程权衡：**导数窗与累积窗不同；源码 block=3、ksize=5、k=0.04。R 随对比度四次方变，不能跨曝光搬阈值；无正响应时阈值 max 的比例不构成有效检测。先看特征值，再查相邻角合并/重复。

**L4 推导：**小位移 u 下 \(I(p+u)-I(p)\approx g_p^Tu\)，SSD \(E(u)\approx u^T(\sum w_p g_pg_p^T)u=u^TMu\)。\(R=\det M-k(\operatorname{tr}M)^2=\lambda_1\lambda_2-k(\lambda_1+\lambda_2)^2\)。增益 a 给 M'=a²M、R'=a⁴R。旋转时连续 M 正交相似，但离散核非严格旋转不变；固定窗 O(HW)。

**L5 实现：**评估检测能力要去除真值辅助并定义空候选、NMS 和一对一匹配；当前误差只支持给定近真值初值的精化表现。M 三个独立分量可盒滤累计，改变窗权重则非等价。

```text
M = window_sum(gradient_outer_products(gray))
R = det(M)-k*trace(M)^2
if max(R)<=0: return empty
candidates = spatial_NMS(R,threshold,min_distance)
return candidates
```

**数值例：**M=diag(9,4)、k=.04，R=36-.04×169=29.24；直边 M=diag(9,0)，R=-3.24；平坦 M=0，R=0。

**测试与验收：**平坦/直边/角点响应排序、增益四次关系、无目标和密集角点；检测召回/重复率与精化误差分开。上述 NMS 方案尚未实现。

**追问链与答案：**L1「响应图如何成点？」答：阈值与 NMS；L2「强直边为什么不行？」答：小特征值；L3「曝光影响？」答：四次缩放；L4「M 哪来？」答：SSD 泰勒；L5「现有测试证明召回？」答：真值参与挑点，不能。易错：将 Harris 说成尺度不变。来源状态：官方机制+源码核对，部署验证缺失。

## M09 手写梯度正交角点精化

**任务/来源/状态：**图像+近似角点 → Nx2 连续坐标；[refine_corners_gradient](../../traditional/subpixel/corner_subpixel.py#L26-L57) 已实现固定窗单次解。

**L1 步骤：**全图 `np.gradient`，初值整数截断取窗，越界保持原点，筛选梯度幅值平方大于最大值的 1e-3，构建 A/b，cond(AᵀA)<1e8 则解，否则保留初值。

**L2 机制：**理想局部边经过角点 c，梯度为法向，满足 gᵀ(c-p)=0；两个独立方向约束交点。纯直边存在孔径问题，无法约束切向。代码没有迭代移动窗口。

**L3 工程权衡：**win 为半窗 px；窗小信息少，过大会混邻角。条件数好也可能信号极弱，须同时看最小特征值、位移和残差。先验证初值属于目标角，再改窗；没有位移限幅。

**L4 推导：**A 每行 gᵀ，b 每项 gᵀp。\(\min_c\|Ac-b\|²\) 求导得到 \(A^TAc=A^Tb\)。唯一解需 rank(A)=2，\(\kappa(A^TA)=\kappa(A)^2\)。固定全图梯度后，K 个窗成本 O(Kw²)；非直边会引入模型误差，残差不等同几何真值偏差。

**L5 实现：**用 `solve` 而非逆矩阵；QR/SVD 可降低正规方程数值损失但不恢复缺失方向。参考方案需有限性、空集合和位移验收。棋盘真值为 cell*n-0.5，不能自行补半像素掩盖错误。

```text
for c0 in corners:
    A,b = gradient_constraints(integer_window(c0))
    if valid_window and cond(A.T*A)<1e8:
        c = solve(A.T*A,A.T*b)
    else: c = c0
return corners_refined
```

**数值例：**两条约束分别 g=(1,0)、p=(2,0)，g=(0,1)、p=(0,3)，A=I、b=(2,3)，解 c=(2,3)；去掉第二条后 y 任意，不能唯一精化。

**测试与验收：**直边退化应保持初值、角点两约束应恢复、靠边窗口不越界、坐标转置一致；记录未移动/拒绝率。现有角点冒烟仅真值辅助初值。

**追问链与答案：**L1「迭代次数？」答：一次；L2「直边为何不行？」答：秩不足；L3「cond 正常可靠？」答：还需绝对信号量；L4「正规方程？」答：对残差求导；L5「半像素差？」答：先查真值坐标约定。来源状态：本地实现已读，方法命名不等于注释所称相机标定。

## M10 OpenCV cornerSubPix 精化

**任务/来源/状态：**同 M09，但[refine_corners_opencv](../../traditional/subpixel/corner_subpixel.py#L8-L23) 是迭代库封装，非手写版同义词。[cite:2](#source-2)

**L5 实现：**封装无独立输入域验收。公平比较手写版应统一初值、窗支持、灰度量化与半像素真值。保留浮点输入是拟议修改，当前未做；不宣称 1e-6 px 精度。

```text
pts = reshape_float32(corners,N,1,2)
image = cast_uint8(gray)
pts = cornerSubPix(image,pts,half_window,zero_zone,100,1e-6)
return reshape(pts,N,2)
```

**数值例：**某轮得到 G=diag(2,4)、b=(4.5,14)，新点 (2.25,3.5)；若旧点 (2.2,3.5)，位移 0.05，未达到 1e-6。只说明一轮局部解，不代表 OpenCV 对任意图都产生此 G。

**测试与验收：**同初值比较两实现，检查 0–1 浮点图量化、直边退化、边界、初值距离；现有冒烟不覆盖这些输入域。

**追问链与答案：**L1「win 是全窗？」答：半窗；L2「与单次解差异？」答：移窗再建约束；L3「阈值更小更准？」答：不突破图像信息；L4「何时收敛？」答：局部映射性质，不是无条件；L5「浮点归一化图出错？」答：uint8 强转。来源状态：官方 API 已读，未逐行审计库内部插值实现。

## M11 EdgeNet 边缘与偏移网络

**任务/来源/状态：**B1HW → B3HW（一个热图 logit、两个偏移）；[EdgeNet/loss_fn](../../dl/subpixel_edge_net.py#L22-L60) 为本地自定义网络/损失骨架，无完整标签管线、训练循环或验证权重。不等于外部同名模型。

**L2 机制：**热图负责有无，offset 负责连续坐标；只在边缘监督偏移，避免背景无唯一归属。数据先验不自动保证真实亚像素精度；相加跳接不是原始 U-Net 拼接。

**L3 工程权衡：**base=16 控制通道，w_off=10 是配置不是最优常数。偏移单位必须 px，H/W 被 4 整除可避免常见跳接尺寸不匹配。先核标签/布局再调损失权重，跨设备需独立场景验证。

**L4 推导：**单位法向边 nᵀp=d，垂足 q=p-(nᵀp-d)n，标签 o=q-p。BCE 为 Bernoulli 负对数似然 \(\operatorname{softplus}(z)-yz\)；建议 offset 项 \(\sum m\|\hat o-o\|_1/(2\sum m)\)。L1 最优对应条件中位数，不自动无偏；非凸训练无全局保证。卷积成本为各层 O(HW k² Cin Cout) 之和。

**L5 实现：**实际 out=3 与类注释 2 冲突。`pred[:,1:]` 为 B2HW，`m=heat>0.5` 为 BHW，直接 `pred[:,1:][m]` 布尔索引不匹配。下列为修正损失方案，未更改源码；还需空掩膜有限梯度与奇数尺寸策略。

```text
pred = model(frame)
heat_loss = BCEWithLogits(pred[:,0],heat)
mask = expand_channel(heat>0.5)
offset_loss = sum(abs(pred[:,1:]-offset)*mask)/max(2*sum(mask),1)
loss = w_heat*heat_loss + w_off*offset_loss
backward(loss)
```

**数值例：**n=(1,0)、d=10.25、p=(10,5)，offset=(0.25,0)；预测 (0.10,0.20)，两坐标平均 L1=(0.15+0.20)/2=0.175。若 logit=0、y=1，则 BCE=ln2≈0.693147，按默认权重总损失≈2.443147（单有效点）。

**测试与验收：**前向应 B3HW、空/满/稀疏掩膜、两坐标均有梯度、奇数尺寸、归一化/缩放回填；需要场景隔离训练及真实法向定位误差。当前环境未装 torch，未执行前向/反向或训练，不以算术例称网络通过。

**追问链与答案：**L1「几个通道？」答：三个；L2「为何掩膜？」答：背景偏移无定义；L3「误差翻倍查什么？」答：缩放/单位/标签；L4「偏移如何推？」答：垂足减像素中心；L5「索引报错原因？」答：BHW 不能直接索引 B2HW。来源状态：源码静态维度证据，训练效果无证据。易错：引用同名论文精度。

## M12 PCA 二维正交直线拟合

**任务/来源/状态：**有限二维点集 → (vx,vy,x0,y0)、正交 RMS；[_fit_line](../../traditional/caliper_measurement/caliper.py#L133-L141) 已实现。不是圆拟合，也不是鲁棒拟合。

**L1 步骤：**质心 c、中心化 Q、薄 SVD、取第一右奇异向量 v；求 Q-Qvvᵀ 的正交残差，平方均值开根。

**L2 机制：**对 x/y 对称，支持竖直线，不像 y=ax+b 的纵向回归。平方残差会放大离群点；strengths 没有进入权重。v 与 -v 表示同一直线。

**L3 工程权衡：**RMS 单位 px，点数/跨度/特征值间隙决定稳定性。两点残差可为零但不可靠；整体偏移亦不增加 RMS。先查空间分布、离群点和谱，再看残差。

**L4 推导：**\(E(v)=\sum\|(I-vv^T)(p_i-c)\|²=\operatorname{tr}(Q^TQ)-v^TQ^TQv\)，约束 ||v||=1，最大 Rayleigh 商得主方向。奇异值 s1≥s2 时 RMS=s2/sqrt(N)；s1=s2 时方向不唯一。固定二维 O(N)，各向同性坐标噪声才有直接正交似然解释。

**L5 实现：**调用者过滤 NaN 并检查跨度>5，函数本身无点数/有限性保护。散布矩阵累积可省内存，须验证大坐标相消；不由低 RMS 推断毫米精度。

```text
c = mean(points,axis=0)
Q = points-c
U,s,Vt = svd(Q)
v = Vt[0]
residual = Q-outer(Q@v,v)
return v,c,sqrt(mean(row_sum(residual^2)))
```

**数值例：**四点 (-2,-1)、(-2,1)、(2,-1)、(2,1)，QᵀQ=diag(16,4)，v=(1,0)，s2=2，RMS=2/sqrt4=1；全部加 (10,20)，RMS 仍 1。

**测试与验收：**竖/横线、整体平移、方向符号、重合点、圆形散布及离群点；比较投影矩阵 vvᵀ，不比较 v 的正负。已有卡尺测试只间接覆盖拟合。

**追问链与答案：**L1「为何 vt[0]？」答：最大散布切向；L2「抗异常吗？」答：不；L3「零 RMS 可靠？」答：两点/统一偏移也零；L4「特征值为何出现？」答：总能量减投影能量；L5「方向翻转失败？」答：同一无向直线。来源状态：源码与目标推导核验，鲁棒/物理精度未覆盖。

## M13 Laplacian 二阶算子

**任务/来源/状态：**图像 → 二阶响应；[laplacian_energy](../../traditional/autofocus/focus_measures.py#L60-L64) 中已调用，零交叉边缘检测尚未实现；评分另见 F05。

**L1 步骤：**选择核/浮点深度和可选平滑，计算 Ixx+Iyy；测量方案可按幅值门找零交叉，现有评分则平方均值。两者不是同一任务。

**L2 机制：**一维对称孤立过渡中，一阶峰对应二阶零点；二阶导对高频噪声更敏感，任意零点不是目标边。核求和零保证常量内部无响应。

**L3 工程权衡：**ksize=1 与 3 核不同，尺度与噪声/相邻边分离权衡。先检查核增益和边界，再调平滑；不能跨核直接比较绝对能量。

**L4 推导：**Taylor 相加得到 \(I(x+h)-2I(x)+I(x-h)=h²I_{xx}+O(h⁴)\)。ksize=1 的四邻核中心 -4、轴邻 +1；当前 ksize=3 为 \([[2,0,2],[0,-8,0],[2,0,2]]\)。连续频域乘 -||omega||²，能量再平方则为四次频率权。固定核 O(HW)；零交叉定位只在对称局部模型下成立。

**L5 实现：**保留 CV_64F 正负响应，勿先变显示图。若添零交叉连接需单独回归，不计入现有测试。分块须留 halo，边界与整图对照。

```text
lap = second_derivative_x(gray)+second_derivative_y(gray)
return lap
```

**数值例：**中心为 1、其余为 0 的 3×3 邻域：ksize=1 中心响应 -4，ksize=3 为 -8；对 I=x²+y² 内部，分别响应 4 与 16。不能把两核当数值等价。

**测试与验收：**常量/斜坡内部零，二次面常量响应，脉冲核检验，边界单列。零交叉端到端尚未测试。

**追问链与答案：**L1「现有最终输出？」答：F05 的标量；L2「零点为何可能是边？」答：一阶峰在二阶零处且须对称条件；L3「响应大一定清晰？」答：噪声也大；L4「四次频权？」答：二阶乘子再平方；L5「手写核不一致？」答：核尺寸/边界/scale。来源状态：本地调用及离散核算式核验，无普遍精度界。

## F01 Brenner

**任务/来源/状态：**图像 → 横向跨 2 px 差平方均值；[brenner](../../traditional/autofocus/focus_measures.py#L30-L34) 已实现，无纵向项。

**L1 步骤：**灰度浮点，取 `I[:,2:]-I[:,:-2]`，平方求有效支持均值。

**L2 机制：**固定偏置被抵消，模糊通常削弱短距变化；这是跨距一阶差，不是二阶导。仅沿 x 的评分对只随 y 变化的纹理失明。

**L3 工程权衡：**宽至少 3，步距是像素而非固定物理距离。先看方向与噪声，再 ROI/峰形；增益 a 令分数变 a²。无纹理时不要继续搜索并声称对焦成功。

**L4 推导：**\(F=\sum[I(x+2)-I(x)]²/[H(W-2)]\)。频率权 \(|e^{2i\omega_x}-1|²=4\sin²\omega_x\)，DC 和 Nyquist 都为零；白噪声方差 sigma_n² 时差分能量底为 2sigma_n²，相关噪声需减 2Cov。时间 O(HW)。

**L5 实现：**浮点差避免 uint8 下溢；窄图当前可空均值得 NaN。流式累计必须保留有效差分计数，不能分块漏跨界差。

```text
I = prep(image)
d = I[:,2:]-I[:,:-2]
return mean(d*d)
```

**数值例：**每行 (0,1,2,3)，两个差均 2，评分 4；交替 (0,1,0,1) 的二距差均 0，虽有高频仍得 0。

**测试与验收：**斜坡 4、交替纹理 0、转置盲区、增益平方、窄图拒绝设计；已有焦栈冒烟只覆盖一种底图。

**追问链与答案：**L1「相隔多远？」答：2 px；L2「二阶导？」答：没有 -2 中心项；L3「横条纹失效？」答：随 y 变而仅测 x；L4「所有高频都大？」答：Nyquist 也为零；L5「NaN？」答：检查空支持。来源状态：源码/公式已核验，原始论文版本未独立核验。

## F02 Tenengrad

**任务/来源/状态：**[tenengrad](../../traditional/autofocus/focus_measures.py#L37-L42) 已实现双向 Sobel 平方均值，当前无梯度阈值。

**L1 步骤：**prep → gx/gy → 平方和 → 全图均值。

**L2 机制：**比单方向差分减少方向盲区；平方突出强纹理，也放大噪声/锐化。Sobel 正交平滑不意味着导数完全抗噪。

**L3 工程权衡：**默认 ksize=3，改变核增益必须重标定。先固定灰度/ROI，再重复采集比较峰差与噪声；引入阈值是新变体，不是等价优化。

**L4 推导：**\(F=E[(K_x*I)²+(K_y*I)²]\)，Parseval 给非负频权 \(|\hat K_x|²+|\hat K_y|²\)。固定信号高斯模糊时各频点乘衰减，支持条件成立才可推随 sigma 不增。3×3 内部白噪声底为 (12+12)sigma_n²=24sigma_n²；边界另计。时间 O(HW)。

**L5 实现：**共享预处理/梯度可减少七函数重复成本；若改 dtype 或降采样，需核验排序和数值，不能默认无损。边界默认反射影响整图均值。

```text
gx,gy = sobel(prep(image),ksize)
return mean(gx*gx+gy*gy)
```

**数值例：**3×3 每行 (0,1,2)，默认反射边界下 gx 每行为 (0,8,0)，gy=0，整图评分 64/3≈21.333333；只取中心有效区则为 64，两种支持不能混报。

**测试与验收：**该边界例、转置、偏置、增益平方、不同核、重复噪声；焦栈峰偏断言不等于每条曲线单峰已证明。

**追问链与答案：**L1「低梯度剔除？」答：当前没有；L2「双方向为何？」答：覆盖更多方向；L3「大核涨分？」答：先查增益；L4「模糊下降条件？」答：固定信号及非负能量频权模型；L5「彩色先转什么？」答：灰度再 float64。来源状态：本地定义已核验，不冒充所有 Tenengrad 变体。

## F03 SMD

**任务/来源/状态：**[smd](../../traditional/autofocus/focus_measures.py#L45-L50) 已实现横/纵邻差绝对值各自均值之和，不是乘积版本或 modified Laplacian。

**L1 步骤：**prep，横邻差绝对值均值、纵邻差绝对值均值，相加。

**L2 机制：**绝对值防正负相消，比平方少强调大响应；仍有噪声底，不可把文件注释中的抗噪排序当普遍结论。

**L3 工程权衡：**至少两行两列，ROI/曝光固定。增益 a 乘 |a|；横纵支持计数不同，尺寸变化时要看两项各自统计。

**L4 推导：**\(F=\sum|\Delta_x I|/[H(W-1)]+\sum|\Delta_y I|/[(H-1)W]\)，是分别平均的离散总变差型统计。纯独立高斯噪声邻差为 N(0,2sigma_n²)，绝对均值 2sigma_n/sqrt(pi)，两项和 4sigma_n/sqrt(pi)。有信号时不可直接减此常数得到无偏绝对差。时间 O(HW)。

**L5 实现：**分块优化需跨块边及独立分母；无效小图返回状态是方案，当前无尺寸检查。

```text
I = prep(image)
return mean(abs(I[:,1:]-I[:,:-1])) + mean(abs(I[1:,:]-I[:-1,:]))
```

**数值例：**I=[[0,1],[2,3]]，横差均值 1、纵差均值 2，结果 3；若把四差统一平均会得到 1.5，非同一定义。

**测试与验收：**该例、常量、负增益、转置、分块等价、小图拒绝；当前只有焦栈集合测试。

**追问链与答案：**L1「怎么平均？」答：各向分别；L2「绝对值干什么？」答：防相消；L3「跨曝光可比？」答：非增益不变；L4「噪声底？」答：高斯差分绝对期望；L5「分块偏小？」答：漏跨界差或分母错。来源状态：源码变体已核验，普遍抗噪排名未核验。

## F04 归一化方差 variance

**任务/来源/状态：**[variance](../../traditional/autofocus/focus_measures.py#L53-L57) 计算方差/均值，不是方差/均值²。

**L1 步骤：**prep，求 mu，偏差平方均值，除 mu；前提均值正且远离零。

**L2 机制：**灰度散布可反映对比度，但忽略空间排列；大块亮暗也能高分，不一定有精细清晰结构。归一化不意味着光照不变。

**L3 工程权衡：**先查暗场均值、饱和比例、ROI 内容，再调对焦范围；反光和构图改变可能比焦差更强。任意 epsilon 只掩盖除零，不能增加可辨识信息。

**L4 推导：**\(F=\operatorname{Var}(I)/\mu\)；若 I'=aI+b，则 \(F'=a²\operatorname{Var}(I)/(a\mu+b)\)。b=0 时仍乘 a；重排像素 F 不变，是其不包含空间锐度的反例。两遍统计 O(N)，均值近零敏感性发散。

**L5 实现：**黑图直接 0/0 可 NaN，含负值图还可负分；需要定义输入域/最小可信均值和拒绝状态（未实现）。勿逐帧归一化后声称原指标不变。

```text
I = prep(image)
mu = mean(I)
return mean((I-mu)^2)/mu
```

**数值例：**I=(1,3)，mu=2、var=1，F=.5；加 2 得 (3,5)，var 仍 1、mu=4，F=.25；乘 2 得 F=1。

**测试与验收：**上述偏置/增益、像素重排、非黑常量应零、黑图当前非有限需被调用方发现。没有“加 epsilon 后可靠”测试结论。

**追问链与答案：**L1「分母？」答：mu；L2「内容为何影响？」答：只看直方图；L3「黑图异常先调搜索？」答：先评分有效性；L4「增益不变？」答：公式反证；L5「epsilon 足够？」答：不，需拒绝域。来源状态：源码公式已核验，无普遍对焦保证。

## F05 Laplacian energy

```text
lap = Laplacian(prep(image),ksize=3)
```

## F06 Vollath F4 自相关差

**任务/来源/状态：**[vollath_f4](../../traditional/autofocus/focus_measures.py#L67-L72) 已实现横向滞后 1、2 的乘积各自均值之差；不宣称与所有文献求和版相同。

**L1 步骤：**prep，a=mean(I[:,:-1]*I[:,1:])，b=mean(I[:,:-2]*I[:,2:])，返回 a-b。

**L2 机制：**较短/较长距离相关差体现结构；独立零均值噪声的非零滞后相关期望为零，但有限帧仍有方差，相关条纹噪声也不会消失。

**L3 工程权衡：**宽至少 3，周期纹理/方向/ROI 边界影响强，可负分。先看 a、b 与差值，再看焦栈，不可把负分送 F10 后依赖截断“修好”。

**L4 推导：**平稳信号加独立白噪声时 \(E[F]\approx R_S(1)-R_S(2)\)，噪声非零滞后期望抵消；有限不同支持使加性亮度交叉项未必严格抵消。频率权 cos(omega)-cos(2omega) 可负，不能套非负频权的单峰证明。无偏置增益 a 则乘 a²。O(HW)。

**L5 实现：**必须保持两个分母不同，统一求和/支持是指标修订，不是等价优化；浮点乘积和稳定累计防溢出/相消。

```text
I = prep(image)
a = mean(I[:,:-1]*I[:,1:])
b = mean(I[:,:-2]*I[:,2:])
return a-b
```

**数值例：**一行 (1,2,3)，a=(2+6)/2=4，b=3，F=1；一行 (1,0,1)，a=0、b=1，F=-1，负值本身不证明实现错误。

**测试与验收：**该正/负例、常量零、乘法增益、边界偏置、转置与相关噪声；既有焦栈一次通过不代表任意噪声最优。

**追问链与答案：**L1「两个量？」答：距离 1/2 相关均值；L2「抗噪条件？」答：独立零均值非零滞后相关零；L3「负分怎么办？」答：分析结构并拒绝直接 log；L4「单峰能证明？」答：权重可负，无通用保证；L5「改 sum 等价？」答：支持数不同，不等价。来源状态：源码变体已核验，原始公式版本及排名未独立核验。

## F07 dct_sharpness 当前评分

**任务/来源/状态：**[dct_sharpness](../../traditional/autofocus/focus_measures.py#L75-L84) 已实现的是**系数绝对值 top-k 和的块均值**，不是注释所称高频能量。[cite:3](#source-3)

**L1 步骤：**裁下/右余边成整块，reshape/transpose 为块，逐块 DCT，系数绝对值排序，选最大 `max(1,int(block²*ratio))` 项求和，再跨块平均。默认 8×8、ratio=.5，DC 不排除。

**L2 机制：**大系数是强成分，不代表高频；排序丢失频率位置。常量亮块 DC 大也可高分，“大图背景稀释”不是该实现问题的唯一解释。

**L3 工程权衡：**block 为 px，ratio 是保留系数数量比例，不是频率截止；小图无完整块可能失败。先澄清指标语义/输入范围，再选块和 ROI，最后优化。

**L4 推导：**每块排序绝对值 s1≤…≤s(b²)，\(F=M^{-1}\sum_j\sum_{r=b²-k+1}^{b²}s_{jr}\)。常量 c 的正交 DCT 只有 DC=bc，故分数 b|c|；真正去 DC 的高频平方能量应为零。排序成本 O(Mb²log(b²))，Python 每块调用也有常数开销。

**L5 实现：**top-k 分区可替代排序但需验证累加误差；去 DC/频率掩膜/平方/高分位块聚合均是新定义，不能称现有高频法等价加速。输入 block/ratio 合法性当前未统一检查。

```text
blocks = split_complete_blocks(prep(image),block)
values = []
for B in blocks:
    s = sort(abs(flatten(DCT(B))))
    values.append(sum(last_k(s)))
return mean(values)
```

**数值例：**8×8 全为 10 的块，DC=80、其余零，当前评分 80；全为 20 则 160，没有任何边缘也能涨分。

**测试与验收：**常量 80、单频系数定位、亮度漂移、裁边目标、块数为零；历史 RTImg 失败只能限定为当前指标/配置，不泛指所有 DCT 评分。

## F08 DCT-II 变换

**任务/来源/状态：**实数块 → 同形状频率系数；F07 调用 `cv2.dct`，本卡不是第八个评分。[cite:3](#source-3)

**L1 步骤：**指定正交归一化，沿块内两轴分别变换；可逆变换还原。评分需另指定频率集合和聚合。

**L2 机制：**有限信号的余弦基分解，频率由下标而非系数幅值决定。正交变换保能，不自动去噪，也不自动选择有用细节。

**L3 工程权衡：**块大频率分辨率高但空间局部性弱，块小相反；边界/裁余边会变支持。跨库先查 type=2、norm='ortho' 和轴，再比较数值。

**L4 推导：**\(Q_{ux}=\alpha_u\cos[\pi(2x+1)u/(2b)]\)，\(\alpha_0=1/\sqrt b,\alpha_{u>0}=\sqrt{2/b}\)。余弦离散正交和给 QQᵀ=I，C=QIQᵀ，逆为 QᵀCQ，故 ||C||F²=||I||F²。舍弃系数的平方和等于重建平方误差；不是清晰度保证。直接可分离矩阵算 O(b³)，快速算法可到 O(b²log b)，具体库实现未审计。

**L5 实现：**块布局转为 (块行,块列,块内行,块内列) 后，只变换最后两轴；测试逆变换、Parseval 和单频位置，防止把块索引轴当空间轴。

```text
Q = orthonormal_cosine_basis(block)
C = Q@I@transpose(Q)
I_reconstructed = transpose(Q)@C@Q
return C
```

**数值例：**2×2 全 3，C00=6，其余 0；像素平方和 4×9=36，系数平方和也 36。该保能恒等式不表示高频存在。

**测试与验收：**常量例、单频余弦、逆误差、跨库同归一化对照；变换通过不等于 F07 定义正确。

**追问链与答案：**L1「二维怎么做？」答：两空间轴；L2「最大系数最高频？」答：不是；L3「跨库差先查？」答：类型/归一化/轴；L4「保能哪来？」答：正交矩阵；L5「布局怎么测？」答：单频位置和逆变换。来源状态：SciPy 正文已读，本仓库执行 OpenCV，默认参数不可混用。

## F09 单峰性比例

**任务/来源/状态：**有序得分 → 严格增减比例；[monotonic_ratio](../../traditional/autofocus/focus_measures.py#L103-L110) 与 [unimodality](../../tests/metrics.py#L30-L36) 两份同逻辑。不是图像评分或连续单峰证明。

**L1 步骤：**先按 z 排序，首次最大 k，峰前正差计数、峰后负差计数，除 max(N-1,1)。空数组会报错，单点返回 0。

**L2 机制：**描述采样曲线的先升后降；平台不计通过，端点单调曲线也可得 1，因此不能证明范围包住焦点或峰位正确。

**L3 工程权衡：**没有容忍 epsilon，不均匀 z 间隔仍各计一票；先检查排序、重复帧、内部峰与重复噪声。若平滑后计算，须另报原曲线，不能隐改指标。

**L4 推导：**\(U=[\sum_{i<k}1(s_{i+1}>s_i)+\sum_{i\ge k}1(s_{i+1}<s_i)]/\max(N-1,1)\)。0≤U≤1 为计数界；U=1 仅保证这些采样比较，采样间函数可另有窄峰。严格递增分数映射保序，U 不变。O(N)。

**L5 实现：**两函数应同输入对照；最近邻数据源会制造平台，不能据高 U 直接允许连续黄金搜索。新增拒绝空/NaN 和内部峰标志是方案。

```text
k = first_argmax(scores)
good = count(diff(scores[:k+1])>0) + count(diff(scores[k:])<0)
return good/max(length(scores)-1,1)
```

**数值例：**(1,3,2,2,1) 的首次峰 k=1，四个差中三次符合方向，U=.75；(1,2,3) 得 1 但峰在右端；常量长度>1 得 0。

**测试与验收：**上述三例、空/单点、双峰、重复帧、严格单调分数变换；不以 U=1 当对焦正确率。

**追问链与答案：**L1「并列峰？」答：首个；L2「U=1 即准确？」答：端点反例；L3「波动先平滑？」答：先查采样与噪声；L4「连续保证？」答：没有；L5「离线平台？」答：不同请求命中同帧。来源状态：仓库自定义诊断，未借外部名称包装为理论检验。

## F10 三点高斯峰位

**任务/来源/状态：**已有位置/分数数组 → 连续峰估计；[gaussian_fit](../../traditional/autofocus/focus_search.py#L13-L29) 已实现等距简式。不是只用三次曝光完成全局搜索。

**L1 步骤：**全数组找最大 k，端点返回，取相邻 k-1/k/k+1，分数下限 1e-12 后 log，算二次顶点，索引偏移裁 ±1，乘左右间距均值。

**L2 机制：**无基线高斯评分 log 后二次，连续顶点减少格点误差。未知常量底噪会破坏二次性；截断负分只避免 log 非法，不修复模型。

**L3 工程权衡：**位置互异、评分正、局部负曲率，简式要求等距。RTImg mm 非等距，且镜头对焦距离不等于电机位置；先查这些条件，再拟合。平滑的模糊模型不保证拟合无偏。

**L4 推导：**\(s=Ae^{-(z-z_*)²/(2\tau²)}\) 给 \(\ell=az²+bz+c,a<0,z_*=-b/(2a)\)。等距 h：\(z_*=z_0+h(\ell_--\ell_+)/[2(\ell_--2\ell_0+\ell_+)]\)。不等距应以实际 z 解三元二次系数，先中心化/尺度归一化避免病态，再检查曲率与顶点范围。log 噪声一阶约为 delta_s/s，低分更敏感。O(N) 取峰+O(1) 局部解。

**L5 实现：**代码用平均间距不等于一般不等距二次拟合；demo 图用 `polyfit`，可与返回值不一致。当前成本图的“3”只是局部点数，未包含发现峰的采图成本。

```text
k = argmax(scores)
if k is boundary: return positions[k]
ell = log(maximum(scores[k-1:k+2],1e-12))
denom = ell[0]-2*ell[1]+ell[2]
if abs(denom) < 1e-12: return positions[k]
delta = clip((ell[0]-ell[2])/(2*denom),-1,1)
return positions[k]+delta*(positions[k+1]-positions[k-1])/2
```

**数值例：**令 log s=-(z-1)²，等距 z=(0,1,2) 恢复 1；非等距 z=(0,1,3)，log=(-1,0,-4)，当前 delta=-.3，返回 .55，而按真实坐标二次求解是 1。这是可复核反例，不是精度统计。

**测试与验收：**等距恢复、非等距反例、端点、非正分、平顶、重复位置；生产方案应不等距正确求解或明确拒绝，而非保留误导注释。

**追问链与答案：**L1「全局前三？」答：峰的相邻三点；L2「为何 log？」答：高斯转二次；L3「平均 h 能修？」答：反例不行；L4「顶点？」答：2az+b=0；L5「图和数不同？」答：polyfit 与简式模型不同。来源状态：源码/反例已核验，未宣称原函数支持一般非均匀采样。

## F11 粗扫加缩步爬山

**任务/来源/状态：**score_fn、lo/hi → 请求位置/调用次数；[hill_climb](../../traditional/autofocus/focus_search.py#L32-L58) 已实现，无硬件闭环。

**L2 机制：**粗扫降低落错峰盆概率，缩步降低局部采样量；保证记录的最好分数不下降，但窄峰可能从一开始漏掉，多峰不保证全局。

**L4 推导：**\(h_0=(hi-lo)/(C-1),h_j=h_0/2^j\)，调用数 C+2T。best_v 更新条件保证非减，但没有维护真峰包围区间，所以不能推最终位置误差≤最终步长。O(C+T) 次评分，实际成本另加移动/等待。

**L5 实现：**Python 元组 `(best-step,best+step)` 预先求值，两侧围绕旧 best。应验证 C≥2、lo<hi、有限分数并加硬限位/去重（尚未实现）；限幅后实际调用统计也需更新。

```text
best = best_of_uniform_scan(lo,hi,C)
h = (hi-lo)/(C-1)
repeat T times:
    h = h/2
    candidates = (best-h,best+h)
    for p in candidates:
        if score(p)>best_score: update_best(p)
return best,C+2*T
```

**数值例：**score=-(z-3)²，lo=0、hi=8、C=5、T=1。粗点 0/2/4/6/8，2 与 4 并列，先取 2；h=1，探 1/3，返回 3，调用 7 次。

**测试与验收：**该调用例、边界最高记录越界请求、多峰/窄峰、噪声与重复帧；报告请求数和独立图像数，不能混用。

## F12 黄金分割

**任务/来源/状态：**单峰 score_fn、区间/tol → 中点/次数；[golden_section](../../traditional/autofocus/focus_search.py#L61-L86) 已实现最大化版，绝对区间宽停止。

**L1 步骤：**两个黄金内点，比较丢一侧，复用一点和得分，算一个新点；宽≤tol 后返回中点。

**L2 机制：**只有单峰且比较可信，才可断定被丢部分不含最优；比例让保留点成为新区间合适内点。多峰/噪声逆序/非最大平台可能误丢真峰。

**L3 工程权衡：**tol 单位同 z，不能小于帧/执行器分辨率还声称物理更准；需有效 lo/hi/tol、最大次数和浮点停滞门（当前未有）。端点最优也须明确验收。

**L4 推导：**复用点的相似几何要求 r²=1-r，\(r=(\sqrt5-1)/2\)。n 次后 \(L_n=r^nL_0\)，\(n\ge\lceil\log(tol/L_0)/\log r\rceil\)，调用 2+n。若最优始终保留，中点误差≤Ln/2，这是条件确定性区间界；不保证对查表/噪声函数成立。

**L5 实现：**相等走左保留分支，宽平台可错误删掉右边峰；最近邻帧映射不是连续严格单峰。新增帧 ID 去重、无缩进度停止与安全上限属于方案。

```text
r = (sqrt(5)-1)/2
x1,x2 = b-r*(b-a),a+r*(b-a)
f1,f2 = score(x1),score(x2)
while b-a>tol:
    discard_side_by_comparison_and_reuse_one_point()
    evaluate_one_new_point()
return (a+b)/2
```

**数值例：**L0=10、tol=1，n=5，L5≈.901699，正常调用 7 次；若真峰始终保留，中点误差上界 .450850。该界是区间条件，不是相机测量误差。

**测试与验收：**严格单峰检验包围不变量与次数、平台/多峰暴露失败、非法 tol 拒绝方案、最小可分辨步长；切勿在当前无保护循环上测试 tol=0 到无穷。

**追问链与答案：**L1「每轮几次新评分？」答：一次；L2「为何可丢区间？」答：单峰和正确比较；L3「tol 越小越准？」答：受数据分辨率限；L4「比例哪里来？」答：r²=1-r；L5「查表可直接保证？」答：平台破坏比较推论。来源状态：源码与区间推导核验，无噪声通用界。

**数值例：**候选对焦距离 (1000,1004,1060) mm，目标距离 1040 mm，距离差 (40,36,20)，代理真值帧为 1060；若请求 z=1030，则最近邻加载 1004。请求位置、实际帧位置、目标距离是三个量，不能混写。

**测试与验收：**文件解析/排序、上述代理标签、最近邻并列、非法 ROI、重复位置、全部无效分数、缓存命中；真实验证需独立光学真值与时间戳。当前未重跑 RTImg 全量。

**追问链与答案：**L1「输出连续最优？」答：采样最优；L2「多峰还能用？」答：离散穷举可以；L3「主要成本？」答：须分项计时；L4「总是半步长界？」答：要额外对称条件；L5「load_at 是移动电机？」答：只是最近帧查表。来源状态：数据源和评估源码完整已读，代理真值不当物理焦点真值。

## F14 FocusNet 有符号离焦回归

**任务/来源/状态：**B1HW → B 个标量 d=z-z_focus；[FocusNet/train_loop](../../dl/autofocus_cnn.py#L23-L50) 有网络/Adam-MSE 循环，缺完整数据集、权重/验证与闭环。自定义类名，不是同名论文复现。

**L1 步骤：**参考训练：按场景分焦栈、规范标签/预处理；三层 stride=2 卷积 ReLU、全局均值池化、64→32→1 回归；MSE 更新。推理只给 d；运动更新和闭环停止未实现。

**L2 机制：**从纹理学习模糊关联，池化减少尺寸依赖；但对称 PSF 下同一物体正负离焦图像相同，单帧没有方向信息。学习不能恢复观测中不存在的信息。

**L3 工程权衡：**标签需统一单位，数据按整个场景分割防邻帧泄漏；噪声种子/采集顺序可能泄漏方向。先确认单侧先验或可观测性，再调整学习率/网络；“1–2 帧收敛”无仓库证据。

**L4 推导：**\(R(f)=E[(f(I)-d)^2]\)，固定 I 求导 \(2(f-E[d|I])=0\)，故最优预测为条件均值。若同图等概率对应 ±a，则 f*=0，不能输出正确运动方向。生成器 \(\sigma(z)=\sqrt{\sigma_0²+k²(z-z_*)²}\) 正负对称，正是退化条件。需要第二帧受控位移/当前位置先验/单侧范围才可能破除歧义；是改问题条件，不是现有能力。CNN 非凸优化无通用收敛/帧数界。

**L5 实现：**输出 B，标签 B1 会广播成 B×B 错配损失；训练循环缺显式 train/device、空 loader 检查、种子、验证、保存/恢复。epoch 打印末批损失不是均值。当前 torch 缺失，未训练验证；本卡只静态核验。

```text
for frame,defocus in loader:
    pred = model(frame)
    require shape(defocus)==shape(pred)==(batch,)
    loss = mean((pred-defocus)^2)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

**数值例：**相同观测对应 d=-2、+2，各概率 .5，则平均风险 \(((f+2)²+(f-2)²)/2=f²+4\)，f=0 最小但两例都错 2 单位。96×96 输入三次 stride=2 依次 48/24/12，池化后每例 64 维。

**测试与验收：**标签 B/B1 形状、空 loader、正负对称样本、场景隔离、权重恢复和设备一致性；部署需绝对离焦误差、方向准确率、闭环失败率，不能只报训练 MSE。

**追问链与答案：**L1「输出分数还是 d？」答：有符号 d；L2「单帧方向能学出？」答：对称不可辨识；L3「训练低实机错？」答：先查泄漏/单位/域；L4「同图±2 学什么？」答：条件均值 0；L5「B1 标签行吗？」答：必须匹配 B。来源状态：网络/生成器已读，条件风险按定义推导，训练与闭环未验证。
