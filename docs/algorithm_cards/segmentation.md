## 演进维度与双线导航

持续优化的六个维度是：**区域表示、区分依据、空间约束、多尺度上下文、监督方式、边界与实例处理**。历史代表节点不等于整个方法族的首次发明时间，工程组合也不等于年代上的替代。

| 分支与代表年代 | 前序瓶颈 → 改变的维度与机制 | 新增成本 → 遗留问题 |
|---|---|---|
| 固定／局部阈值、Otsu 1979 | 手调标量 → 区分依据变为局部统计或直方图目标 | 窗口／统计假设 → 不理解类别及实例 |
| 形态学、连通域、填孔、生长 | 单点判别碎裂 → 尺度约束、拓扑与种子可达性 | 核／邻接／seed 协议 → 可误删小缺陷、合并对象 |
| Vincent–Soille 1991 与标记控制分支 | 泛洪组织与噪声盆地 → 分层队列及受控区域起点 | 地形和种子设计 → 仍有过拆、漏拆 |
| 图割、GrabCut 2004、随机游走 2006 | 局部外观不一致 → 联合空间能量或扩散概率 | 图存储、求解与交互 → 同色、弱边界及错误种子 |
| FCN 2015（预印本 2014）、U-Net 2015 | 滑窗重复与定位／上下文冲突 → 共享稠密特征、跨尺度融合 | 像素标注、训练和显存 → 域偏移、小目标 |
| Mask R-CNN／RoIAlign 2017 | 类别图没有个体身份 → 检测候选、连续对齐、实例掩膜 | 实例标注、候选成本 → 检测漏召回与掩膜分辨率 |
| 原始 SAM 2023 | 新任务反复训练 → 预训练与提示条件掩膜 | 大模型、提示／候选筛选 → 不自带业务类别 |

年代与外部来源状态沿用总览的出版记录，不重新宣称论文全文已核验。FCN 与 U-Net 是同年不同侧重点；分水岭与 Otsu 可组成同一管线；SAM 与 GrabCut 可服务同一标注任务。[cite:2](#seg-source-2)[cite:3](#seg-source-3)

工程线：成像与标签协议 → 阈值或学习得分 → 形态学／拓扑 → 种子与实例 → 坐标恢复 → 重叠、边界、实例和物理量验收。分类器和损失移到配套篇，不把 IoU 当作区域生成算法。

## 阈值分支

### S01 固定阈值

任务／前提／状态：标定强度图 → 二值掩膜；要求前背景在所选通道可分。演进：逐像素区分依据的基线，成本低但不具照明适应性。实现：未接入分割管线；覆盖五元状态见阅读协议；来源：[cite:3](#seg-source-3)，本地已读、外部转引未重访。

- **L1 步骤**：选 ROI、强度尺度、t 和亮／暗极性；逐点比较；全图扫描结束返回 mask。OpenCV BINARY 用 `I>t`，反向用 `I<=t`。TRUNC、TOZERO 是灰度映射，不都产生二值区域。
- **L2 机制**：把强度当类别证据；同强度前景和背景不可区分。省去极性约定会整体翻转，增加形态学不能修复这种类别错误。
- **L3 工程**：t 单位为 DN 或归一化强度。先查曝光／位深／饱和，再看分组验证集直方图和误报漏报代价，最后选阈值；耗时 O(N)，不要用更低阈值掩盖成像漂移。
- **L4 推导**：误报代价 C_FP、漏报 C_FN 下，预测前景应使 `C_FP P(0|I)<C_FN P(1|I)`。仅当后验比随 I 单调时可化为单阈值；这不是任意双峰数据的最优分类保证。等号需固定归属。
- **L5 实现**：参考 `used_t,mask=cv2.threshold(...)`，不要把返回元组当图。负浮点不能直接转 uint8。测试等号、常量、空 ROI、反极性；向量化与库比较需同 dtype、比较符和边界协议。

**分层面试答案**：L1 问“何时结束？”答：一次扫描；L2 问“同灰度能否分开？”答：不能，需其他特征；L3 问“换位深先做什么？”答：标定单位；L4 问“单阈值最优条件？”答：代价固定且似然比单调；L5 问“边界差一圈？”答：核查 `>`／`>=`。易错：把所有 threshold 模式称二值分割。证据入口为本卡来源。

### S02 自适应均值阈值

任务／前提／状态：慢变背景图 → 局部阈值图与 mask；目标尺度须与背景变化尺度可分。演进：区分依据由全局值变为局部均值，新增窗口成本与目标自污染风险。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，本地已读／转引未重访。

- **L1 步骤**：选奇数窗口 k；计算均值 m；形成 `t(x)=m(x)-C`；按极性比较，边界处理后完成一遍滤波与决策。
- **L2 机制**：局部均值估计背景，缓解加性慢变照明；大均匀目标充满窗口时 m 被目标主导，输出由 C 主导，可能出现边带而非完整目标。
- **L3 工程**：k 为 px，C 为强度。先按最细目标及光照变化长度选 k，再调 C 和极性；保存阈值图定位光晕。积分图／滑动和可 O(N)，朴素 O(Nk²)。
- **L4 推导**：`I=S+b`，归一化平均 A 满足 A1=1，故 `I-AI=S-AS+b-Ab`；b 局部常量则抵消。若 b 为 Lipschitz，则背景残差受常数乘邻域距离约束，但不包含噪声和类别重叠误差；乘性照明不自动消失。
- **L5 实现**：`adaptiveThreshold` 均值模式要求 uint8 单通道、k>1 且奇数。积分图用宽累加类型；与库对照需相同边界、舍入。测试常量、宽目标、渐变背景、触边；缓存 m 便于排障。

**分层面试答案**：L1 问“t 是一个数吗？”答：逐像素图；L2 问“大物体为何只剩边？”答：均值被目标主导；L3 问“先改 k 还是 C？”答：先尺度；L4 问“消除什么照明？”答：局部近常量加性项；L5 问“积分图负数？”答：查溢出和 dtype。易错：把 C 当像素尺寸。证据入口为本卡来源。

### S03 自适应高斯阈值

任务／前提／状态：图像 → 中心加权局部阈值与 mask；仍要求局部背景可估计。演进：改变局部统计权重，减少远邻突变影响，增加中心目标自污染；不是 Otsu。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，本地已读／转引未重访。

- **L1 步骤**：构造归一化高斯 G，算 `m=G*I`，逐点比较 `I>m-C` 或反向；完成卷积和比较即停。
- **L2 机制**：中心权重大、远处权重小；若不归一化，常量背景都不能保持。中心权重大也可能让目标更强地进入背景估计，并非必优于均值。
- **L3 工程**：窗口、σ 是 px，C 是强度。先核对 API 是否开放 σ，再选窗口和 C；OpenCV adaptiveThreshold 不单独开放 σ。可分离卷积 O(Nk)，更多平滑可能吃掉小缺陷。
- **L4 推导**：`ΣG=1` 保持直流；独立同方差噪声经 G 后方差为 `σn²ΣG²`。原噪声与平滑噪声相关，残差方差为 `σn²(1+ΣG²-2G0)`，不能直接相加两个方差。
- **L5 实现**：参考高斯自适应模式。显式 GaussianBlur 再比较时须核对中间量化及边界才能声称等价。测试冲激、平坦、梯度与宽目标；优化用分离滤波但保留数值精度。

**分层面试答案**：L1 问“与均值版改哪步？”答：邻域权重；L2 问“为何归一化？”答：保持常量；L3 问“σ 越大越好？”答：会跨结构混合；L4 问“残差方差为何有负项？”答：协方差；L5 问“差一个灰度？”答：先查舍入。易错：混淆窗口宽度和可独立设置的 σ。证据入口为本卡来源。

### S04 Otsu 自动全局阈值

任务／前提／状态：ROI 灰度直方图 → 阈值及 mask；灰度分区应对应业务前背景。演进：1979 代表工作，改变阈值选择目标，不引入空间语义。未接入；覆盖同阅读协议；来源：[cite:2](#seg-source-2)[cite:3](#seg-source-3)，原始 DOI 转引未重访。

- **L1 步骤**：统计归一化直方图；对每个 t 划分 `[0,t]` 和 `[t+1,L-1]`；排除空类，计算类间方差；取最大值并固定并列规则；最后按极性生成 mask。
- **L2 机制**：类均值距离与两类权重共同决定分数；只看均值距离会偏爱极少极端值。极小缺陷可能不如背景内部差异影响目标函数。
- **L3 工程**：t 是输出，不是手动调参。先查 ROI、目标占比和直方图，再查预平滑尺度，最后考虑局部法；平滑单位 px，可能删缺陷。总复杂度 O(N+L)。
- **L4 推导**：写 `I-μ=(I-μk)+(μk-μ)`，条件均值令交叉项为零，得 `σT²=ω0σ0²+ω1σ1²+ω0ω1(μ0-μ1)²`。固定直方图时总方差固定，故最小类内等价最大类间；不保证最小分类错误。常量图、空类退化。
- **L5 实现**：参考 OTSU 与 BINARY 标志组合；核对库支持的输入类型。自写用 float64 前缀权重／矩，跳过零分母；测试常量、并列平台、极小前景。比较掩膜分区而非只比较 t。

**分层面试答案**：L1 问“先输出什么？”答：最优 t 再应用极性；L2 问“为何要 ω0ω1？”答：反映两类质量；L3 问“小缺陷没了怎么办？”答：查 ROI 与占比，不能假定自动等于正确；L4 问“两准则为何等价？”答：全方差分解；L5 问“同分如何处理？”答：固定 tie-break。易错：声称必须严格双峰才能运行。证据入口为本卡来源。

## 形态学与拓扑

以下集合公式采用一致的反射／锚点和边界约定，B 包含原点；灰度版使用对应 min／max。有限图像上不一致的 padding 会破坏朴素的不变量判断。

### S05 腐蚀 Erosion

任务／前提／状态：mask → 收缩区域；以结构可容纳性过滤前景。演进：增加尺度与形状先验，代价是窄目标也被删。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，本地已读／转引未重访。

- **L1 步骤**：平移 B；只有全部支撑位于前景才保留锚点；灰度图取局部最小。一次扫描或指定次数后终止。
- **L2 机制**：AND 规则使放不下核的窄桥消失；平均滤波不表达“全部满足”。前景腐蚀会扩张背景孔洞，不能声称只删外边界。
- **L3 工程**：核宽、迭代半径为 px，先按物理最细结构换算，再选形状、anchor 和次数。诊断同时看面积与断桥，触边异常先看 padding。
- **L4 推导**：`A⊖B={x:x+B⊆A}=∩b∈B(A-b)`；0∈B 推出 `A⊖B⊆A`。朴素 O(N|B|)，反扩张不保证拓扑保持。
- **L5 实现**：参考 `cv2.erode`；明确 uint8／bool、核锚点和边界值。测单点、窄桥、触边及包含关系；矩形核可拆行列 min，加速前验证 footprint 和边界等价。

**分层面试答案**：L1 问“何时保留？”答：全核满足；L2 问“为何断桥？”答：桥容不下核；L3 问“先调什么？”答：最细结构对应尺度；L4 问“反扩张前提？”答：含原点、一致定义；L5 问“偶数核错位？”答：anchor 不对称。易错：腐蚀必能保留小缺陷。证据入口为本卡来源。

### S06 膨胀 Dilation

任务／前提／状态：mask → 扩张区域；允许指定尺度邻近点连接。演进：空间约束补裂缝，但可合并实例。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，本地已读／转引未重访。

- **L1 步骤**：以每个前景点平移 B 后取并集；灰度版取局部最大；执行固定遍数结束。
- **L2 机制**：OR 规则扩展支撑，填窄隙；不能找回腐蚀已经删除的结构身份，膨胀不是腐蚀的逆函数。
- **L3 工程**：核为 px，先查看最小实例间隙，再选形状／半径／遍数。标签数下降及面积突增是误合并证据；速度和核大小有关。
- **L4 推导**：`A⊕B={a+b}=∪b∈B(A+b)`，含原点时 `A⊆A⊕B`；两次等于以 `B⊕B` 膨胀。该 Minkowski 和不等于任意离散核的简单“半径翻倍”；朴素 O(N|B|)。
- **L5 实现**：参考 `cv2.dilate`；非对称核须核查反射，别只用圆核测试。测包含、两近物体和边缘；分解核优化须保留连接关系。

**分层面试答案**：L1 问“并还是交？”答：并；L2 问“可逆吗？”答：不可恢复已丢信息；L3 问“物体数少了？”答：核跨过间隙；L4 问“多次等价什么？”答：核的 Minkowski 和；L5 问“方向偏了？”答：反射和 anchor。易错：以为扩张后总能按原实例分开。证据入口为本卡来源。

### S07 开运算 Opening

任务／前提／状态：mask → 去除不能容纳 B 的前景；细节是否可删须先定义。演进：组合腐蚀筛选与膨胀恢复，增加形状选择性，不等价面积过滤。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，本地已读／转引未重访。

- **L1 步骤**：同核先腐蚀再膨胀；一对操作完成返回，不以视觉观感作为停止条件。
- **L2 机制**：腐蚀删除细结构，膨胀恢复幸存主体的范围；细长对象和同面积圆块可能一删一留，不能把开运算解释成面积阈值。
- **L3 工程**：先确定最细有价值结构宽度，再调核和形状；看目标存活率、面积偏差而不只看噪点数。较大核不适合保护细裂纹。
- **L4 推导**：`A∘B=(A⊖B)⊕B` 是所有能置于 A 内的 B 平移之并，故反扩张且幂等；复杂度两次 O(N|B|)。性质要求完整算子和一致边界。
- **L5 实现**：参考 MORPH_OPEN；`iterations=n` 是腐蚀 n 次再膨胀 n 次，不是完整开运算重复 n 次。测幂等、窄长结构、触边；分离核须同有效形状。

**分层面试答案**：L1 问“先后？”答：先腐蚀；L2 问“为何不是面积筛？”答：可容纳性取决形状；L3 问“裂纹消失？”答：核过宽；L4 问“为何幂等？”答：输出已是可容纳核平移的并；L5 问“次数有何坑？”答：底层多次与完整幂等算子不同。易错：把膨胀称无损恢复。证据入口为本卡来源。

### S08 闭运算 Closing

任务／前提／状态：mask → 封小间隙；真实孔洞需先决定保留。演进：先扩后收的尺度补全，代价是错误连接；非拓扑填孔。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，本地已读／转引未重访。

- **L1 步骤**：同核先膨胀再腐蚀，一对操作后输出；不保证每个封闭洞都被填。
- **L2 机制**：膨胀跨小缝，腐蚀收回外部；已形成的连接可能保留。大洞可不变，开放小缝却能闭合，与是否连外界不同。
- **L3 工程**：先定义孔洞业务语义，再按缝宽选核；观察合并数、周长和面积。增大核提高补缝能力，也提高合并风险。
- **L4 推导**：`A•B=(A⊕B)⊖B`，一致伴随定义给 `A⊆A•B` 和幂等；补集与反射核开运算对偶。朴素 O(N|B|)，不是原始轮廓恢复保证。
- **L5 实现**：参考 MORPH_CLOSE；检验有限域 padding 对扩张性的影响。测小隙、大洞、触边、幂等；不能把闭运算与 flood 填孔当等价优化。

**分层面试答案**：L1 问“先后？”答：先膨胀；L2 问“可替代填孔？”答：否，尺度与可达性不同；L3 问“两件粘连？”答：缩核并查最小间隙；L4 问“扩张性依赖什么？”答：一致定义和边界；L5 问“边界反而缩小？”答：查腐蚀 padding。易错：所有洞必填。证据入口为本卡来源。

### S09 孔洞填充

任务／前提／状态：二值 mask → 填充封闭背景；需明确数字拓扑及 ROI 外界。演进：用可达性代替核尺度，能填大洞，也可能填掉业务孔。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，SciPy 依据转引未重访。

- **L1 步骤**：取补集 C；从所有边界背景点泛洪得到 R；将未访问背景 `C\R` 并入前景；队列空结束。
- **L2 机制**：孔洞是与外界不连通的背景，不是“较暗且较小”。仅从左上角出发可能漏其他外部背景，过大 footprint 可跨薄壁侵入洞。
- **L3 工程**：先设前背景互补连通性、触边和 ROI 协议，再决定是否只填小面积孔（px²）；业务孔消失先查规则而非调滤波。
- **L4 推导**：`H=C\R`，输出 `A∪H=Ω\R`；填后没有内部背景孔，因此幂等。BFS 为 O(N+E)，保证的是定义中的拓扑，而非真实材料恢复。
- **L5 实现**：参考 `scipy.ndimage.binary_fill_holes`，或 pad 一圈背景再 flood 并裁回。测闭环、破环、嵌套岛、角连通和触边；队列与位图可 O(N) 空间。

**分层面试答案**：L1 问“洞如何识别？”答：补集里外界不可达部分；L2 问“闭运算相同吗？”答：不；L3 问“细壁洞没填？”答：查邻接和 footprint；L4 问“为何幂等？”答：填后内部背景已消除；L5 问“一个角够吗？”答：全边界或外圈 padding。易错：前背景都用同邻接而不检查拓扑。证据入口为本卡来源。

### S10 连通域 Connected Components

任务／前提／状态：二值或逐类 mask → 标签、面积、框和质心；需定义 4／8 邻接。演进：区域表示由布尔变可达等价类，成本近线性，但编号不是类别／实例真值。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，本地已读／转引未重访。

- **L1 步骤**：扫描未标前景，BFS 或两遍并查集赋标签；累积统计；全部访问后按规则筛域并返回背景协议。
- **L2 机制**：同标签表示路径可达；对角像素在 8 邻接可合并。接触的两件物体常同域，面积过滤只能删域而不能分离它们。
- **L3 工程**：先连通性再面积／形状阈值；面积单位 px²，物理面积乘 sx·sy。缩放后线性尺度变 r 时面积门限乘 r²；查看被删域，不只看最终图。
- **L4 推导**：无向邻接可达性自反、对称、传递，分区唯一到标签置换；BFS O(N+E)。`A=Σ1[label=k]`，`cx=Σx/A`，空域不定义质心。
- **L5 实现**：参考 `connectedComponentsWithStats`，返回总数含背景，CV_32S 标签、质心 xy。测全空、对角、超多小域；并行实现编号可不同，验证分区同构而非数组逐值一致。

**分层面试答案**：L1 问“数量减一吗？”答：排除背景才减；L2 问“域等于实例？”答：不；L3 问“分辨率变了？”答：重算面积门限；L4 问“唯一什么？”答：分区而非编号；L5 问“编号变就错？”答：先比等价关系。易错：直接把多类图所有非零像素一起合并。证据入口为本卡来源。

## 种子与地形

### S11 区域生长 Region Growing

任务／前提／状态：图像＋种子＋相似规则 → 连通区域；种子必须可靠。演进：在特征判别外加可达约束，动态统计可适应外观但引入顺序依赖。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，动态规则推导为本篇明确模型。

- **L1 步骤**：初始化 seed、队列、区域统计；取候选，与固定 seed 或当前区域均值比较；接纳后扩邻居并更新统计；队列空或资源上限停止，后者返回截断标识。
- **L2 机制**：连通约束阻止远处同色区直接并入；动态均值又会随接纳结果漂移，拒绝点是否重试可改变最终区域。
- **L3 工程**：容差为强度／特征距离，邻接为 px。先验证 seed 和参考模型，再调阈值；保存均值轨迹和泄漏路径。动态多次重试耗时不能按单次 BFS 估计。
- **L4 推导**：固定 `Q={p:|I(p)-I(s)|≤τ}` 时结果是 s 在 Q 中的连通分量，O(N+E)；动态 `μ'=(nμ+I(p))/(n+1)` 改变 Q，唯一性与顺序无关结论不再成立。
- **L5 实现**：参考 deque、独立访问图和不可变原图；动态版定义重试与多 seed 冲突规则。测错误 seed、斜坡、队列反序和截断；只在固定可行集合下安全改为并行连通域。

**分层面试答案**：L1 问“停止条件？”答：队列空或带标志的上限；L2 问“均值为何漂移？”答：接纳改变模型；L3 问“先减容差？”答：先查 seed／参考规则；L4 问“何时顺序无关？”答：固定可行集合；L5 问“拒绝能永不重试？”答：动态规则未必。易错：把方法族当唯一算法。证据入口为本卡来源。

### S12 洪水填充 Flood Fill

任务／前提／状态：图像＋seed＋容差与阻挡 mask → 可达填充；区分固定和浮动范围。演进：具体化生长的可达规则，浮动范围增加渐变适应也增加泄漏。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，API 本次未运行。

- **L1 步骤**：固定版把候选与 seed 原值比，浮动版与已接纳邻点原值比；在 4／8 邻接及 mask 约束下扩张；没有可达新点后停止。
- **L2 机制**：浮动范围每步变化小就能走过长斜坡，终点可远离 seed；固定范围不累计漂移。非对称 lo／up 会形成有向可达关系。
- **L3 工程**：先选 fixed／floating，再按通道强度尺度选 loDiff、upDiff；看泄漏路径强度而不是仅最终面积。边缘阻挡一处破口就可泄漏。
- **L4 推导**：固定版条件 `Is-lo≤Ip≤Is+up`；浮动边 q→p 条件 `Iq-lo≤Ip≤Iq+up`。有限图访问一次可 O(N+E) 完成，结果不等于最小类内方差集合。
- **L5 实现**：`cv2.floodFill` 的 uint8 mask 为 `(H+2,W+2)`，图 xy 对应 mask 的偏移一格；mask 非零是阻挡。MASK_ONLY 避免覆盖原图；测梯度、非对称范围、触边和阻挡，保留原始强度比较。

**分层面试答案**：L1 问“mask 非零？”答：禁止通过；L2 问“为何越走越远？”答：浮动比较邻点；L3 问“同容差不同结果？”答：查范围模式；L4 问“非对称是什么图？”答：有向；L5 问“偏一个像素？”答：查扩展 mask 坐标。易错：把填充值用于后续相似性比较。证据入口为本卡来源。

### S13 距离变换 Distance Transform

任务／前提／状态：前景 mask → 最近背景距离；需定义度量、背景及间距。演进：区域表示增加内部厚度／中心证据，代价是形状假设，不直接产生实例。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，EDT 官方出处转引未重访。

- **L1 步骤**：零像素为背景，选择 L1／L2／棋盘度量与 spacing；计算每点最近零点距离；遍历算法结束输出浮点图。无背景时拒绝或显式 pad，不依赖库偶然值。
- **L2 机制**：内部中心距离大，可作为种子；长条、凹形可能多峰，一个峰不等于一个真实对象。3／5 掩模近似距离会改变峰位置。
- **L3 工程**：距离为 px 或物理单位；先核对极性、各向异性和边界，再选精确度，最后定峰筛选。精确 EDT 仅对给定栅格精确。
- **L4 推导**：`D(p)=minq∈背景 ||S(p-q)||`。L1 是绝对值和，L∞ 是最大分量，L2 是平方和开方；平方欧氏距离可分离为各轴抛物线下包络，固定维度 O(N)，而非 O(N²) 全对枚举。
- **L5 实现**：参考 OpenCV DIST_L2＋DIST_MASK_PRECISE，或 SciPy EDT 的 `sampling=(sy,sx)`；测空／满前景、单背景、各向异性和背景为零。到背景像素中心的距离不等于连续边界距离；取负前保持 float。

**分层面试答案**：L1 问“距什么？”答：最近零背景；L2 问“峰数等于件数？”答：只是形状假设；L3 问“矩形像素？”答：轴向 spacing；L4 问“为何能线性？”答：可分离下包络；L5 问“负距离异常？”答：查 uint 回绕。易错：把精确栅格距离当物理真值。证据入口为本卡来源。

### S14 Vincent–Soille（VS）浸水分水岭

任务／前提／状态：标量地形 → 盆地与分界；需固定平台、邻接和分水线定义。演进：1991 代表数字浸水高效实现，以排序／队列组织泛洪；不是全部分水岭思想的首创。未实现；覆盖同阅读协议；来源：[cite:2](#seg-source-2)[cite:3](#seg-source-3)，原论文转引未重访。

- **L1 步骤**：按高程排序或分桶；逐层入水，以同层 FIFO 传播已有盆地并处理距离层；不同标签冲突处记分界；剩余极小平台建立新盆地；最高层处理完停止。
- **L2 机制**：同高程平台需专门组织，不能仅按扫描先后抢占；每个极小值都可出生盆地，噪声过分割来自模型机制而不只是程序错误。
- **L3 工程**：先选灰度／梯度地形和邻接，再观察平滑后极小值数；高程量化改变平台。排序 O(N log N)，整数分桶还要计值域成本。
- **L4 推导**：子水平集 `Ωh={p:f(p)≤h}` 随 h 单调扩张；新成分对应盆地出生，已有成分相遇产生分界。有限高程层保证终止，不保证语义／实例正确；平台距离规则决定离散结果。
- **L5 实现**：复现需区分未访问、当前层 mask、盆地、分水线及队列哨兵，保留层内距离；不能只调用 `cv2.watershed` 就声称复现 VS。测试平坦图、鞍点、大片平台和对角邻接；队列替代反复扫描须保留传播顺序语义。

**分层面试答案**：L1 问“新盆地何时出现？”答：剩余极小平台；L2 问“为什么过分割？”答：噪声增极小值；L3 问“量化会影响吗？”答：改变平台；L4 问“保证什么？”答：指定规则下有限泛洪，不保真值；L5 问“OpenCV 等于 VS？”答：不能混同实现。易错：以 1991 当所有分水岭发明年。证据入口为本卡来源。

### S15 标记控制分水岭

任务／前提／状态：地形＋可靠前景／背景 markers → 受控分区；每个待分对象需合适 seed。演进：空间监督限制自发生盆地，代价是种子生成与校验；不是单纯重命名 VS。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，外部库约定转引未重访。

- **L1 步骤**：建立独立目标标记和背景标记；从 seed 按地形优先扩张；冲突按规定形成线或归属；可达域分配完停止，无种子的分量单独报错／处理。
- **L2 机制**：不允许任意噪声极小值生新盆地，减少过分割；种子多仍过拆，种子少仍漏拆，强梯度无法补出缺失实例。
- **L3 工程**：先看 seed 覆盖与重复，再查地形、平滑和邻接；记录种子数、未知区和拆分／合并率。标记数无物理单位，平滑尺度为 px。
- **L4 推导**：一种标量图模型定义 `ds(p)=minπ:s→p maxq∈π f(q)`；优先队列用 `d(v)=min(d(v),max(d(u),f(v)))`。这是最小瓶颈而非最短路求和，堆实现 O((N+E)log N)，并列需规则，不是 OpenCV 逐位等价证明。
- **L5 实现**：标量地形参考 `skimage.segmentation.watershed(f,markers,mask=ROI)`，该库未声明依赖。OpenCV 接收 uint8 三通道图与 int32 markers，正数为已知、0 为未知、输出 -1 为界，原地修改；无同义 mask 参数。测背景标签、相邻 seeds、无 seed 岛、边界。

**分层面试答案**：L1 问“0 是背景？”答：OpenCV 中是未知；L2 问“为什么仍过拆？”答：seed 过多；L3 问“先调梯度？”答：先查 seed；L4 问“路径代价是什么？”答：这里是 max；L5 问“浮点地形转 BGR 就等价？”答：接口与代价不同。易错：把标记法视为无条件消除过分割。证据入口为本卡来源。

### S16 负距离标记分水岭

任务／前提／状态：前景 mask → 粘连实例；要求中心与颈部结构能代表对象。演进：区分依据从颜色边界变形状距离，可组合 Otsu、EDT、标记法；代价是中心假设。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，本地已读／转引未重访。

- **L1 步骤**：计算内部 D，提峰、合并平台并为峰编号；构造 -D；只在前景 mask 内执行标记分水岭；空前景直接返回空标签。
- **L2 机制**：中心峰取负成为低盆地，颈部成为相对高岭；原颜色没有接触线时仍可拆分。不取负会改变起洪地形。
- **L3 工程**：先修前景拓扑，再看峰和每个分量 seed，最后调峰间距、显著性 h；距离和 h 同单位。全局 `αDmax` 容易漏小件，空间间距与高度显著性不可互换。
- **L4 推导**：负号把 D 的局部最大转为地形极小，再按 S15 的受限瓶颈分配；形状多峰不能推出真实实例唯一。EDT＋堆泛洪约 O(N log N)，误差包含前景和种子错误。
- **L5 实现**：参考 `watershed(-D,markers,mask=M)`；D 保持浮点，不把 uint8 取负。测大小悬殊粘连、长条单件、洞、无种子域；分块时 basin 可跨块，不能简单拼标签。

**分层面试答案**：L1 问“为何负号？”答：中心成低盆地；L2 问“与梯度法差什么？”答：形状而非颜色边界；L3 问“小件无 seed？”答：查全局峰门限；L4 问“可恢复遮挡真实线？”答：无此保证；L5 问“OpenCV 同参调用？”答：不能，需匹配接口。易错：一个物体必一个距离峰。证据入口为本卡来源。

## 图模型

### S17 二值图割 Graph Cut

任务／前提／状态：数据项＋邻接项 → 二值标签；需满足可图表示条件。演进：由局部决策变联合能量优化，增加空间一致性和图求解成本。未接入图割库；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，原始能量可表示性记录转引未重访。

- **L1 步骤**：算每像素前背景 unary；建源汇 t-link 和邻点 n-link；求最大流／最小割；按源侧约定解码；求解结束核对原能量。
- **L2 机制**：数据项支持外观，边项抑制不连续；无边项退化独立分类，过强边项吞掉小目标。并不是任何目标都能直接最小割。
- **L3 工程**：先统一能量及颜色归一化尺度，再调 λ；检查数据／边界能量、seed 违例和小目标召回。图内存 O(N+E)，时间依最大流算法，不能宣称通用线性。
- **L4 推导**：`E(l)=ΣDp(lp)+Σwpq[lp≠lq]`，w≥0 满足二元次模条件 `V00+V11≤V01+V10`。源側定义 label=1 时，源→p 容量 Dp(0)、p→汇容量 Dp(1)，割边之和即 unary；邻边表示 Potts。可表示二值问题可全局最优，多类近似不能继承任意全局保证。
- **L5 实现**：外部 maxflow 仅参考，未声明依赖；先减去与标签无关的 unary 常数确保容量可用。硬 seed 容量须超过竞争有限能量上界；用小图穷举验证方向、重复边、非负容量和 cut 能量，稀疏化不能无声删项。

**分层面试答案**：L1 问“返回什么？”答：源汇划分的标签；L2 问“小物体为何消失？”答：边界成本超过数据收益；L3 问“强度换尺度？”答：同步颜色差和相对 λ；L4 问“何时全局最优？”答：可图表示二值次模问题；L5 问“前背景反了？”答：查 t-link 方向。易错：任意多类都可一次精确最小割。证据入口为本卡来源。

### S18 GrabCut

任务／前提／状态：颜色图＋框／四状态提示 → 前景 mask；至少有有效前背景样本。演进：2004，交替外观模型与图割降低交互负担；代价是非凸迭代和颜色可分假设。未接入；覆盖同阅读协议；来源：[cite:2](#seg-source-2)[cite:3](#seg-source-3)，原始记录转引未重访。

- **L1 步骤**：初始化确定／可能前背景；拟合两类 GMM，分配成分、更新模型、图割更新区域；到迭代上限或能量／标签稳定停；用户可追加硬 seed。
- **L2 机制**：多模态 GMM 表达颜色，边权在颜色突变处减弱平滑；框外硬背景不能靠多迭代自动恢复。二值 mask 不等于 border matting 的连续 alpha。
- **L3 工程**：先查框覆盖和 seed，再查颜色样本、最后迭代数；同色前背景不因迭代多而必改善。迭代数无量纲，协方差随颜色尺度变化。
- **L4 推导**：单成分 unary 来自负对数高斯密度：`-logπ+0.5log|Σ|+0.5(z-μ)ᵀΣ⁻¹(z-μ)`，加上颜色差调制 Potts。固定模型二值子问题可精确割，联合模型／标签交替为非凸，不能推全局最优；空成分、奇异协方差需处理。
- **L5 实现**：参考 `cv2.grabCut`，uint8 三通道图，四值 mask 和两个 `(1,65)` float64 模型缓冲；输出取确定前景 OR 可能前景，`mask>0` 会错收可能背景。测恒色、框越界、硬 seed、重复迭代与模型复用；本次未运行。

**分层面试答案**：L1 问“四态如何二值化？”答：合并两种前景；L2 问“为何重估 GMM？”答：标签反过来改善外观估计；L3 问“框漏目标？”答：修改提示而非盲增迭代；L4 问“图割最优为何整体不保证？”答：交替非凸；L5 问“mask>0 对吗？”答：不。易错：把 alpha matting 与二值分割混同。证据入口为本卡来源。

### S19 随机游走 Random Walker

任务／前提／状态：图像＋各类 seeds → 首次命中概率与标签；每个未知连通分量须连接已知 seed。演进：2006 代表图扩散方法，以多路径概率替代单路径地形竞争，代价是稀疏求解。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，Grady 书目转引未重访。

- **L1 步骤**：构造非负对称权图；固定种子为 Dirichlet 条件；逐类求未知点调和解；argmax 得标签；残差达阈值或达到迭代上限停，未收敛须报告。
- **L2 机制**：高相似邻点导通强，跨边缘导通弱；概率聚合所有可行路径，通常直接求方程，不必蒙特卡洛随机采样。
- **L3 工程**：先查无 seed 孤岛，再核对强度归一化及 β，最后容差／预条件；β 与强度平方尺度相反，过大会下溢和病态。保存残差及概率和作为证据。
- **L4 推导**：`w=exp(-β||Ip-Iq||²)`，`L=D-W`；最小 Dirichlet 能量对未知求导给 `L_UU u_U=-L_US u_S`。各未知分量连种子时 L_UU 正定，唯一解满足最大值原理；每步稀疏乘法 O(E)，总步数依条件数，不作固定线性承诺。
- **L5 实现**：参考 skimage random_walker，未安装；正标签 seed、0 未知、负数排除的接口语义应核版本。CSR 存图，测 seed 边界、孤岛、概率和及残差；大 β 错误不能靠裁剪概率掩盖。

**分层面试答案**：L1 问“必须真走随机路径？”答：可解线性系统；L2 问“与分水岭差异？”答：扩散多路径与地形竞争不同；L3 问“不收敛先查？”答：孤岛和权重病态；L4 问“何时唯一？”答：未知分量均接固定边界；L5 问“概率和不为一？”答：查构图、残差与排除区。易错：无 seed 也会自然生成新类别。证据入口为本卡来源。

## 学习式分割与对齐

### S20 FCN

任务／前提／状态：图像 → 每像素类别；需要标签协议和代表性训练数据。演进：CVPR 2015，预印本 2014；共享稠密卷积与跨层得分融合减少滑窗重算，代价是监督和显存。未实现；覆盖同阅读协议；来源：[cite:2](#seg-source-2)[cite:3](#seg-source-3)，论文记录转引未重访。

- **L1 步骤**：训练将分类网络卷积化，形成粗得分、上采样，与像素标签计算 CE 更新；32s／16s／8s 逐步融合更细层得分。推理前向、恢复尺寸、argmax；训练按验证早停或 epoch 上限结束。
- **L2 机制**：整图共享特征，深层供语义、浅层供位置；仅放大粗图无法恢复已丢细节。有效 stride 不是类别数。
- **L3 工程**：先查标签／忽略值、归一化和输入采样，再看 stride、融合与分块；更小 stride 增成本。看小目标召回和边界，而非大背景主导的准确率。
- **L4 推导**：固定特征块展平后的 `Wh+b` 可将 W 重排为空间卷积核，滑动得稠密输出；softmax 分类负对数似然给 CE。共享核有局部平移等变，但 stride／padding 不保证任意像素精确等变；训练非凸无全局保证。
- **L5 实现**：外部 torchvision FCN-ResNet 不是原论文 VGG FCN-8s 逐层复现。输入 BCHW、logits BKHW，标签 BHW；标签最近邻缩放，先插值 logits 后决策的协议需固定。测奇数图、忽略区、tile 接缝；未运行网络。

**分层面试答案**：L1 问“32s 和 8s？”答：步幅和融合层级；L2 问“上采样能找回细节？”答：不能凭空恢复；L3 问“小件漏？”答：先看采样与 stride；L4 问“FC 如何卷积化？”答：重排同一线性权重；L5 问“标签可双线性吗？”答：不可制造中间类别。易错：有 FCN API 即原论文复现。证据入口为本卡来源。

### S21 U-Net 与 EdgeNet 边界

任务／前提／状态：图像 → 稠密区域类别；需要区域标签。演进：2015，编码器—解码器拼接保留局部信息，代价是高分辨率激活内存；与 FCN 并行发展。原始 U-Net 未复现，仅有边缘风格骨架；覆盖同阅读协议；来源：[cite:3](#seg-source-3)[cite:4](#seg-source-4)，源码本地已读。

- **L1 步骤**：原型用双卷积／池化编码，上卷积、裁剪并拼接同尺度特征、双卷积解码、1×1 类别投影；训练区域 CE 等，推理恢复坐标后决策。原论文 valid 卷积与现代 same-padding 变体需分开。
- **L2 机制**：跳连保留定位细节；拼接后自由选择两路权重，相加把通道逐点混合，不等价。边缘 heat 和偏移不能直接解释为物体内部类别。
- **L3 工程**：先定二值／多类区域监督，再按最小目标宽度定深度和 tile，最后通道数和损失；检查边界与 tile 拼缝。增加通道不能修数据泄漏，少量训练图成功不代表无需代表性数据。
- **L4 推导**：拼接卷积为 `Wa*a+Wb*b`，先相加再卷积限制为 `W*(a+b)`。原边界加权 `w=wc+w0 exp(-(d1+d2)²/(2σ²))` 依赖最近及次近实例边界，不能凭普通无实例语义标签无条件构造。非凸目标无通用误差界。
- **L5 实现**：本地两次池化＋两次转置卷积，skip 相加，`out` 明确 3 通道。当前尺寸应能被 4 整除才能直接相加；偏移 B2HW 与 BHW mask 的索引问题见配套 L1 损失卡。测试非方形、奇数、空／非空边缘及通道契约；本次仅静态核对，不修源码。

**分层面试答案**：L1 问“本地就是 U-Net？”答：浅层相加边缘变体；L2 问“拼接可任意换相加？”答：表达约束不同；L3 问“奇数图为何错？”答：池化取整与 skip 对齐；L4 问“边界权重需何标签？”答：可区分实例边界；L5 问“heat 能算区域 Dice？”答：先有区域定义，边缘 Dice 不等于区域 Dice。易错：照旧注释认为输出两通道。证据入口为本卡来源。

### S22 RoIAlign

任务／前提／状态：特征图＋连续候选框 → 固定形状 RoI 特征；坐标链必须一致。演进：2017，去掉 RoIPool 框／bin 量化改善空间对齐，增加连续采样成本；自身不是区域分割模型。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)，论文与 torchvision 约定转引未重访。

- **L1 步骤**：原图 xyxy 框乘 spatial_scale 到特征空间；按约定移位、分 bin，在连续位置双线性采样并聚合；所有 RoI 完成后返回 KCHW。torchvision 路径按平均聚合。
- **L2 机制**：不把框和 bin 边界取整，保留亚像素对应；插值不能补偿错误框或 backbone 丢失的信息，更不保证亚像素物理测量精度。
- **L3 工程**：框是原图 px，scale 是比例；先查 resize／padding／aligned，再调输出 bin 与采样数。半像素系统偏差提示坐标约定不匹配；更多采样仅增加成本。
- **L4 推导**：以 `F[y,x]` 记数组，点 `(x+u,y+v)` 的值是 `(1-u)(1-v)F[y,x]+u(1-v)F[y,x+1]+(1-u)vF[y+1,x]+uvF[y+1,x+1]`；两次线性插值相乘，权重和为 1。成本 O(KC HoWo r²)，分段可微不是连续场精确重建。
- **L5 实现**：参考 `torchvision.ops.roi_align`，K×5 框首列为 batch 或逐图 K×4；`aligned=True` 使用 -0.5 坐标移位，须匹配版本。测常量、仿射特征、亚像素平移、越界／空框；比较数值而非仅尺寸。

**分层面试答案**：L1 问“框取整吗？”答：不做 RoIPool 式量化；L2 问“为何利于 mask？”答：保留空间对应；L3 问“总偏半像素？”答：查 aligned 与中心约定；L4 问“常量保持为何？”答：插值权重和一；L5 问“亚像素输出等于精度？”答：不。易错：混淆 xy 与行列。证据入口为本卡来源。

### S23 Mask R-CNN

任务／前提／状态：图像 → 每实例类别、框、分数与 mask；需要实例标签。演进：2017，检测框架并行增加 mask 与 RoIAlign，解决身份而非仅类别；代价是候选成本和检测漏召回。未实现；覆盖同阅读协议；来源：[cite:2](#seg-source-2)[cite:3](#seg-source-3)，外部转引未重访。

- **L1 步骤**：backbone（可带 FPN）、RPN 提候选，RoIAlign 后分类／框回归与 mask 并行；训练匹配正负 RoI，推理筛框和 NMS、选择预测类 mask、贴回原图；处理完候选终止。
- **L2 机制**：候选提供实例身份，同类目标可独立出 mask；RPN 漏检无法由 mask 头挽回。mask 各类独立 sigmoid，类别由分类头判断，不做 mask 跨类 softmax 竞争。
- **L3 工程**：先 proposal recall，再类别／框，最后 mask 分辨率和阈值；框尺度 px、IoU 阈值无量纲。拥挤时 NMS 会删邻件，增候选增加耗时与内存。
- **L4 推导**：损失含 RPN 与 RoI 分类／回归及 mask；正 RoI 真实类 k 上 `Lmask=-Σ[y logσ(zk)+(1-y)log(1-σ(zk))]/m²`，其他 mask 类通道不计该 RoI 损失。可微采样不消除离散候选筛选及整体非凸性。
- **L5 实现**：外部 torchvision 接口使用逐图输入和 boxes／labels／masks targets；锁定 weights、类别头及 resize 规则。测空实例、同类重叠、贴回偏移、分类通道选择和实例 AP；无本地权重与实例验收。

**分层面试答案**：L1 问“mask 与分类串行？”答：RoI 后并行，推理按类选；L2 问“为何不是 mask softmax？”答：类别与形状解耦；L3 问“漏件先降 mask 阈值？”答：先查候选存在否；L4 问“所有类 mask 都反传？”答：只真实类；L5 问“AP 好就尺寸准？”答：需物理边界验收。易错：语义类别图等于实例图。证据入口为本卡来源。

### S24 原始 SAM

任务／前提／状态：图像＋点／框／mask 提示 → 候选掩膜及质量预测；提示语义和域适用性须验证。演进：2023，以预训练和提示条件化减少逐任务建模，代价是编码、交互和候选筛选；不是业务分类器。未接入、无权重；覆盖同阅读协议；来源：[cite:2](#seg-source-2)[cite:3](#seg-source-3)，论文和 predictor 源码仅转引、未重访。

- **L1 步骤**：图像编码并缓存；编码正负点、框或低分辨率 mask；解码一个／多个候选及质量，恢复原尺寸再选。自动生成器内部铺网格、裁剪提示并过滤去重；训练与实际提示协议另行固定。
- **L2 机制**：提示限定目标，多 mask 表达整体／部件歧义；缓存减少重复编码。预测 IoU 是质量回归，不是现场有真值计算的 IoU，掩膜也不自带缺陷类别。
- **L3 工程**：先查提示坐标、RGB／预处理及权重，再调候选质量／稳定性筛选，最后网格密度与裁剪；增加提示提高成本且有重复候选。小缺陷、透明物和跨域需分层验收。
- **L4 推导**：提示条件输出记 `pθ(M|I,P)`；缩放点积注意力 `softmax(QKᵀ/√d)V` 在独立单位方差分量假设下稳定点积方差。原始 SAM 训练使用 focal＋Dice 掩膜目标和质量回归，多候选处理歧义；条件风险最小不推出跨域最优。全局注意力 token 成本平方级，窗口模块另计。
- **L5 实现**：外部高层 predictor 约定 `set_image` HWC uint8，点用原图 XY，由内部变换；不能预缩放后再由同接口重复缩放。换图需刷新 embedding，低分辨率 logits 可用于下一轮提示。测缓存失效、正负点、框、坐标还原和候选去重；不宣称下载／推理通过。

**分层面试答案**：L1 问“自动生成不用提示？”答：内部生成提示；L2 问“为何多个 mask？”答：粒度歧义；L3 问“最高质量必可验收？”答：是模型预测，仍需真值；L4 问“为何除 √d？”答：特定独立分量方差尺度；L5 问“提示整体错位？”答：查 XY、缩放、padding 和双重变换。易错：把原始 SAM 当后续视频／语义版本。证据入口为本卡来源。

## 补齐卡片：颜色、形态学、轮廓与形状先验

本节按承接索引扩展原有工程链，而非新增一条替代 S01–S24 的年代线。形态学公式沿用 S05–S08 的含原点结构元素、反射／锚点和一致边界约定；残差为强度图，种子为标记图，二者不能直接混作最终实例标签。

<a id="seg-card-25"></a>
### S25 颜色／多通道范围阈值

任务／前提／状态：H×W×C 特征图 → 二值 mask，要求通道顺序、颜色空间与照明标定一致。演进：由 S01 单强度比较扩为多通道联合区间，改善部分同灰度异色混淆，新增颜色标定和区间维护成本。族级：手工范围阈值变体，不等于概率分类或完整颜色识别。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)[cite:5](#seg-source-5)，旧 S02 本地已读、外部转引未重访。

- **L1 步骤**：按约定将 BGR 转为 HSV 等特征；逐通道判上下界，同一区间内 AND、不同区间间 OR，再与 ROI 相交；遍历所有像素后输出 0／255 mask。跨周期端点的色相范围拆成两段，不写成下界大于上界的一段。
- **L2 机制**：多维约束排除仅在某一通道相似的背景；HSV 可分开部分亮度与色彩影响，但低饱和时 H 不可靠。单区间是轴对齐长方体，不能表达一般通道相关性；去掉 S／V 可靠性约束可能收进灰色与反光。
- **L3 工程**：先查曝光、白平衡、颜色顺序和目标／背景通道分布，再定 S／V 可靠区，最后定 H 和多区间规则。标准 uint8 OpenCV HSV 的 H 为 0–179，HSV_FULL 及浮点尺度不同；阈值按实际转换约定，不照搬数值。C 通道、r 个范围成本 O(rNC)，扩大区间增加相似背景误报。
- **L4 推导**：单范围 `M(p)=∏c 1[lc≤fc(p)≤uc]`，多范围是该集合的并。若特征服从协方差正定的相关高斯，等密度面满足 `(f-μ)ᵀΣ⁻¹(f-μ)=k`，一般为旋转椭球，不能被一个长方体精确表示；Σ 奇异时这一逆矩阵表达也失效。颜色空间变换不提供光照不变或最优分类保证。
- **L5 实现**：参考 `cv2.cvtColor`、`cv2.inRange` 和掩膜按位或；inRange 两端含等号，输出单通道 uint8。测上下界等号、周期接缝、低饱和、BGR／RGB 混用和空 ROI；保留颜色图及各区间 mask 定位误报。固定图像与转换参数才可缓存颜色变换，不能跨帧复用旧特征。

**分层面试答案**：L1 问“多范围怎么组合？”答：范围内逐通道 AND、范围间 OR；L2 问“红色为何分两段？”答：色相周期接缝，不是两种红色类别；L3 问“反光误检先扩大 H？”答：先查 S／V 可靠性和成像；L4 问“能表达旋转椭球吗？”答：单轴对齐区间不能，需改变模型；L5 问“上下界像素该留下吗？”答：inRange 含等号，须与手写规则一致。易错：把增加颜色通道当作照明不变保证。证据入口为本卡来源。

### S26 形态学梯度

任务／前提／状态：灰度或二值图 → 局部范围响应／带状边界，需冻结核尺度与边界延拓。演进：组合 S05／S06 的局部极值形成边界证据，新增噪点扩散与边带厚度问题。族级：形态学复合算子，不是线性导数、闭合区域或完整分水岭。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)[cite:5](#seg-source-5)，旧 S10 本地已读、外部转引未重访。

- **L1 步骤**：对同一输入、同一 B 分别膨胀和腐蚀，计算 `g=δB(I)-εB(I)`；两次形态学与一次差分完成后返回。二值集合对应 `(A⊕B)\(A⊖B)`；进入 S15 前仍需独立 markers 与 ROI 协议。
- **L2 机制**：局部最大减最小刻画支撑范围内的强度起伏，常量内区无响应；极端噪点可影响整片支撑。缩小核减少边带，但也改变检测尺度；它不携带前景极性或实例身份。
- **L3 工程**：核宽为 px，响应为强度，二者不能混用。先查噪声／饱和，再按所需边界尺度选核，最后检查地形极小值与种子数。朴素 O(N|B|)，大核增加算量与边带；边带宽不是实际定位误差。
- **L4 推导**：同一支撑中 max≥min，所以 `g≥0`；保持常量的延拓下，`δ(I+b)=δ(I)+b`、`ε(I+b)=ε(I)+b`，相减得加性常量不变。a>0 时 max／min 均按 a 缩放，故 `g(aI)=a g(I)`。空间变化照明不能按常数抵消，非负响应亦不保证闭合或类别正确。
- **L5 实现**：参考 `cv2.morphologyEx(I,cv2.MORPH_GRADIENT,B)`；显式差分用足够精度并保持相同 anchor、iterations、borderType。测常量、单亮点、阶跃、触边与非负性；只有相同输入、核和边界时才能复用膨胀／腐蚀中间量。送标量地形分水岭与直接调用三通道 `cv2.watershed` 不是同义接线。

**分层面试答案**：L1 问“减法顺序？”答：膨胀减腐蚀；L2 问“噪点为什么变一片？”答：极值传播到覆盖它的邻域；L3 问“边太厚先改什么？”答：核尺度并复核噪声，不把阈值当厚度唯一控制；L4 问“整体加常数呢？”答：一致且保持常量的边界下两项相消；L5 问“常量图边缘不为零？”答：核查延拓，不能只检查内区公式。易错：把边带直接当实例 mask。证据入口为本卡来源。

<a id="seg-card-27"></a>
### S27 顶帽 Top-hat

任务／前提／状态：强度图 → 小亮结构残差，目标宽度应与缓变背景尺度可分。演进：在 S07 开运算背景估计上做相减，以形状尺度替代单一全局背景值，新增核选择和背景伪响应。族级：白顶帽残差算子，不是二值分割或缺陷概率。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)[cite:5](#seg-source-5)[cite:6](#seg-source-6)，旧 S11 本地已读、外部转引未重访。

- **L1 步骤**：计算 `Io=I∘B`，输出 `T=I-Io`；一对开运算加差分即完成。需要区域时再以 S01／S04 阈值化、限制 ROI，不能直接统计所有非零浮点残差作为缺陷面积。
- **L2 机制**：开运算去掉容不下 B 的亮结构，减去该背景后它们留在残差；宽目标若可容纳 B，其主体仍在背景中，响应可能只在细节处。普通减均值没有相同的形状筛选性。
- **L3 工程**：核尺度为 px，残差阈值为强度。先量目标宽度和背景变化长度，选择能去掉目标而不跨显著背景变化的核，再诊断噪声／饱和，最后选阈值；若两种尺度重叠则假设失败。朴素 O(N|B|)，盲增核增加背景伪边缘和成本。
- **L4 推导**：一致定义下开运算反扩张，`I∘B≤I`，所以 `T≥0`。对平坦结构元素和兼容边界，`(I+b)∘B=(I∘B)+b`，故 T 对加性常量不变；开运算不满足一般叠加性，不能由此推成线性高通或乘性光照校正。
- **L5 实现**：参考 `MORPH_TOPHAT`，显式 `I-Io` 先转有符号或浮点以暴露异常负值，避免无符号回绕；数值裁剪不能掩盖边界不一致。测常量、窄／宽亮条、缓变背景、触边和饱和；缓存 Io 必须绑定输入、核和边界，同核换图不能复用旧背景。

**分层面试答案**：L1 问“原图减什么？”答：开运算结果；L2 问“宽目标为何不亮？”答：被开运算当背景保留；L3 问“核越大越好吗？”答：会跨背景尺度，需看目标与背景能否分离；L4 问“非负从哪来？”答：开运算反扩张，依赖一致定义；L5 问“负数变亮斑？”答：检查无符号减法和边界，不直接归咎目标。易错：把残差强度称为缺陷概率。证据入口为本卡来源。

<a id="seg-card-28"></a>
### S28 黑帽 Black-hat

任务／前提／状态：强度图 → 小暗结构残差，需先定义真实孔洞、阴影与缺陷的业务差别。演进：以 S08 闭运算估计暗谷上方背景，与顶帽形成明暗对偶；新增暗噪声和阴影误报。族级：黑顶帽复合算子，不是 S09 的拓扑填孔。未接入；覆盖同阅读协议；来源：[cite:3](#seg-source-3)[cite:5](#seg-source-5)[cite:6](#seg-source-6)，旧 S12 本地已读、外部转引未重访。

- **L1 步骤**：计算 `Ic=I•B`，取 `K=Ic-I`；闭运算和相减完成后停止，若要区域再独立阈值化与连通域统计。减法方向与顶帽不同。
- **L2 机制**：闭运算填平的窄暗谷进入残差，宽暗区可仍留在背景估计中；真实设计孔或同尺度阴影同样会响应。操作依据是灰度形状尺度，不是成因或背景外界可达性。
- **L3 工程**：按暗结构宽度选核（px），按噪声及对比设残差阈值（强度）。先冻结真实孔语义，再查阴影、饱和与尺度，最后调阈值；漏宽暗带时不只降阈值。大核可能跨背景变化，朴素 O(N|B|)。
- **L4 推导**：闭运算扩张性 `I•B≥I` 给 `K≥0`。定义补图 `J=c-I`，在一致反射核及边界下 `c-(I•B)=J∘B反射`，所以 `K=J-(J∘B反射)`，即补图白顶帽；对称 B 可省反射记号。该对偶不能推出暗缺陷与阴影可分。
- **L5 实现**：参考 `MORPH_BLACKHAT`；残差保持强度单位，显式减法同样注意 dtype、anchor 和边界。测小暗孔、宽暗带、真实业务孔、触边和补图对偶；可共享顶帽的核配置，不能把开运算背景当闭运算背景复用，面积统计须在阈值协议固定后进行。

**分层面试答案**：L1 问“谁减谁？”答：闭运算减原图；L2 问“为何阴影也响应？”答：只看尺度和极性，不懂成因；L3 问“宽暗带漏掉？”答：先看核能否填平该宽度及背景尺度；L4 问“与顶帽如何对应？”答：补图对偶，核反射与边界必须一致；L5 问“残差能直接算区域面积？”答：不能，先阈值并明确孔洞协议。易错：把黑帽解释为填掉所有孔洞。证据入口为本卡来源。

<a id="seg-card-29"></a>
### S29 轮廓提取、孔洞层级与区域统计

任务／前提／状态：二值 mask → 有序轮廓、嵌套树及面积／周长／矩，要求区域闭合、拓扑与测量定义固定。演进：在 S10 可达标签之外增加边界次序和孔洞身份，支持几何测量，新增采样和简化偏差。族级：表示与统计方法族；RETR_TREE 是检索模式，不是新分割模型。未接入专用区域统计；覆盖同阅读协议；来源：[cite:3](#seg-source-3)[cite:5](#seg-source-5)，旧 S14 本地已读、外部转引未重访。

- **L1 步骤**：在 mask 上追踪有序边界，选完整树模式保存轮廓与父子关系；从根遍历求深度，计算每条闭合轮廓面积、周长与矩；按孔洞／岛语义汇总，所有边界与树节点访问后停止。RETR_EXTERNAL 只保留外轮廓，不能据此恢复洞。
- **L2 机制**：点序使几何积分可定义，父子树区分外壳、孔洞和洞中岛；层级深度比轮廓方向更明确。边缘网络未闭合输出不能直接当区域；轮廓像素中心多边形与前景像素并集是不同测量对象。
- **L3 工程**：先定像素计数还是多边形面积、前背景连通性和 ROI 外界，再确定标定与简化。简化容差及周长为 px，面积为 px²；各向异性像素要先把顶点变换到物理坐标再求周长，不能乘单一比例。过度简化删凹点、缩周长，反过来影响 S31 候选。
- **L4 推导**：简单闭合有序多边形的 Green 积分给 `Ai=0.5·|Σj(xj yj+1-xj+1 yj)|`，周长为相邻边长之和；完整嵌套树、外层深度 0 时材料面积为 `Σi(-1)^depth(i) Ai`，洞减、岛加。总边界长度通常逐条相加而非按奇偶抵消。自交曲线有向积分不等于一般填充面积；追踪约 O(N+P)、树遍历和统计 O(P+K)，P 为轮廓点总数、K 为轮廓数。
- **L5 实现**：参考 `findContours(mask,RETR_TREE,CHAIN_APPROX_SIMPLE)`；输入 uint8 单通道，点为 xy，`hierarchy[0,i]` 为 next／previous／first_child／parent，-1 表示不存在，空输出先短路。参考 `contourArea`、`arcLength(...,True)`、`moments`；`m00=0` 不除，回退像素统计或报退化。测单点、环、洞中岛、多根、触边与自交；像素面积作为独立定义对照，不强求相等。缓存原轮廓，优化简化后必须复核拓扑与几何。

**分层面试答案**：L1 问“洞保存在哪里？”答：内轮廓和父子树，不能只取外壳；L2 问“为何与连通域面积不同？”答：中心多边形积分不同于像素计数；L3 问“周长随采样漂移？”答：查尺度、锯齿和简化容差；L4 问“洞中岛面积怎么计？”答：外层加、洞减、岛再加，按树深度奇偶；L5 问“单点质心除零？”答：多边形矩退化，不能硬除 m00。易错：按轮廓列表顺序交替加减，或将读出孔洞等同于填孔。证据入口为本卡来源。

### S30 局部极值、h-maxima／h-minima 与形态学重建

任务／前提／状态：距离或灰度地形 f → 受控重建图、显著极值 mask 与种子标签，需冻结平台连通性、数值尺度和 ROI。演进：补 S13／S16 的峰筛选，以相对显著性抑制噪声峰谷，新增 h 与平台约定。族级：重建是受约束传播，h-extrema 是极值筛选，均非完整实例分割；平顶区域也不是天然多个 seed。未接入，scikit-image 仅参考；覆盖同阅读协议；来源：[cite:3](#seg-source-3)[cite:6](#seg-source-6)，旧 S22 本地已读、外部转引未重访。

- **L1 步骤**：先识别与外邻比较的等值连通平台，规定边界平台是否保留。h>0 时，用 marker `f-h` 在 mask f 下做膨胀重建以压低浅峰；用 `f+h` 在 f 上做腐蚀重建抬高浅谷，均迭代至不动点。再按选定 h-maxima／h-minima 的显著性规则得到极值 mask、对平台编号，送 S15／S16；重建灰度图本身不是 markers。
- **L2 机制**：h 度量峰相对鞍部或谷相对周围的高度／深度，不是绝对 f 值，也不是两个峰的空间间距。重建被原地形逐点约束，不等于均值或高斯平滑。浅峰被抑制不表示保留峰数必等于真实件数，长条和凹形仍可多峰。
- **L3 工程**：距离图的 h 为 px 或物理距离，灰度图的 h 为强度，梯度图则为梯度响应单位。先确认 f、spacing、极性和 ROI，再用噪声起伏与最小有效峰显著性选 h，最后独立设置空间间距。h 增大会删弱种子；先查每个前景分量有无 seed，再调分水岭，不能拿绝对 `αDmax` 代替相对显著性。
- **L4 推导**：`R0=f-h`、`Rt+1=min(δB(Rt),f)`，B 含原点且 R0≤f，故 `Rt≤Rt+1≤f`；对偶 `Q0=f+h`、`Qt+1=max(εB(Qt),f)` 满足 `f≤Qt+1≤Qt`。有限离散值域上序列达到不动点；单调有界本身对任意实数迭代只保证极限，不能凭它承诺固定轮数。理想精确算术下 h-extrema 常用残差 `f-R` 或 `Q-f` 与 h 比较，简单 `>0` 会收进高度不足 h 的残差；全局极值、高度等号、动态范围和浮点修正规则需按选定 API 定义。朴素 K 轮为 O(KN|B|)，队列优化减少无效更新，不承诺任意实现固定线性。
- **L5 实现**：参考 `skimage.morphology.reconstruction(...,method='dilation'/'erosion')`、`h_maxima`、`h_minima` 及 `local_maxima`／`local_minima`；先验 marker 与 mask 大小相同且分别≤／≥，升为足够精度再算 f±h，拒绝 NaN 并定义 ROI 外界。h=0 走明确的局部极值语义，不假定 h-extrema API 接受；返回 mask 后按同邻接合并平台，坐标列表为 row／col。测平顶、边缘峰、两近峰、h 等于显著性、常量、h 超动态范围及补图对偶；浮点容差或队列替代扫描必须与版本参考结果对照，不把残差非零检测冒充完全等价实现。

**分层面试答案**：L1 问“何时停、输出是什么？”答：重建值不变后另取显著极值并编号，灰度重建与 seed 分开；L2 问“h 是峰绝对值吗？”答：相对显著高度／深度；L3 问“两峰太近怎么办？”答：另设空间抑制，h 不能替代距离；L4 问“为何单调有界？”答：含自身的膨胀／腐蚀配合 mask 截断，有限值域才据此说明有限终止；L5 问“平台每点都给标签？”答：会重复种子，先按平台连通分量编号并处理 h=0。易错：混淆 h-dome 残差、h-extrema mask 和完整分水岭。证据入口为本卡来源。

<a id="seg-card-31"></a>
### S31 凹点／形状先验拆分

任务／前提／状态：已粘连的二值区域及轮廓 → 候选切线、分离标签与切割记录，适用于近凸个体接触后产生明显凹陷的假设。演进：补 S16 的中心峰先验，以轮廓接口几何提出拆分，新增配对搜索和真实凹件误拆风险。**族级边界：凹点／形状先验拆分是方法族，不是唯一具名标准算法；以下代价与贪心规则为本文明确的工程示例，不冒充论文复现。** 未实现；覆盖同阅读协议；来源：[cite:3](#seg-source-3)[cite:5](#seg-source-5)，旧 S23 本地已读、API 转引未重访，工程代价未实测。

- **L1 步骤**：用 S29 提取有序外轮廓并保留孔洞树；按固定平滑／凸包缺陷深度筛凹点，枚举点对。只保留线段内部处于原前景、不穿孔洞且栅格切割后恰得两个有效子域的候选；按 L4 代价选择严格改善且得分最小的一条，同分按端点坐标排序，切后用 S10 重标记并在子域重算候选。无合法改善或达到预设切割数上限即停，上限停止须标记截断；不能只连线而不验证分区。
- **L2 机制**：接触颈部可能在轮廓形成相向凹点，切断可拆近凸对象；一个正常凹形零件同样有凹点，完全遮挡或平滑接触又可能没有凹点。去掉前景内线段与连通性检查，最短连线可能穿背景／孔洞或根本没有断开，形状代价改善不代表真实实例正确。
- **L3 工程**：先核对业务类别近凸假设及真实凹件反例，再设轮廓平滑、凹陷深度和切割带宽（px），最后设最小子域面积（px²）与代价权重（无量纲）。长度按 √A 归一化，分辨率变化仍须重定采样／切带规则。保存候选、拒绝原因、删像素数、子域面积及过拆／漏拆；没有合法候选时可保留未拆并报告，不强行造实例。
- **L4 推导**：冻结示例 `Ecut=λl·l/√A+λs·Σj(1-Aj/Ahull,j)`，λl、λs≥0，面积均以相同像素集合约定计算，Ahull,j 为子域栅格凸包面积且>0。`Aj≤Ahull,j` 使形状罚非负；未切基线为 `E0=λs(1-A/Ahull)`，仅接受 Ecut<E0，且满足 L1 硬约束。该轮在枚举候选中选最小，但逐轮贪心不等于全部切线组合的全局最优，更无真实实例唯一性。m 个凹点有 O(m²) 点对，每对还需栅格切割、连通域与凸包面积验证；总成本为各轮 `Σ O(m轮²·(N轮+C几何,轮))`，不能仅报 O(m²)，C几何 包含所用凸包和栅格化代价。
- **L5 实现**：参考 `findContours`、`convexHull(...,returnPoints=False)`、`convexityDefects` 生成候选；缺陷四元组含起点／终点／最远点索引及定点 depth，参考约定以 `depth/256.0` 转像素。退化轮廓、无缺陷或零面积先短路；按选定 4／8 邻接在 mask 副本栅格化切带并重标记，8 邻接的对角桥必须实检。删掉的切带像素单独记录，不把损失面积当真实缝隙；若回分配给实例需另定义标签规则并重验。测试真实凹件、粘连双件、洞、相交候选、单点和对角桥；可缓存轮廓几何，但每次接受切割后使受影响候选失效，不省连通性检查。

**分层面试答案**：L1 问“找到凹点就完成了吗？”答：还需配对、合法切割、子域验证与重标记；L2 问“凹点一定是接触点？”答：可能是本体结构，近凸先验会失败；L3 问“过拆先改哪个阈值？”答：先核对形状假设与反例，再调深度／代价；L4 问“最优指什么？”答：本轮有限候选与本文代价，不是所有切线组合或真实实例最优；L5 问“深度差 256 倍或画线不断？”答：分别查定点单位及切带栅格化／连通性。易错：把 API 候选生成称完整拆分实现，把工程代价当某篇论文结论。证据入口为本卡来源。
