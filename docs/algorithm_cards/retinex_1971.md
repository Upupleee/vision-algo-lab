## RE01 1971 空间比值、顺序乘积与 reset 明度模型

### 任务契约与历史边界

**原文任务：**由场景中各点到达感受器的光信号，为同一光谱敏感系统产生相对明度数；三个系统各自完成空间处理，其明度结果再用于颜色比较。它不是由同一点的原始 R/G、G/B 直接命名颜色，也不是恢复一条可溯源的材料反射光谱。原文 p.1、p.3 与 p.10 区分了独立空间处理和三个系统间的比较，但没有给出完整的现代 RGB／XYZ／Lab 映射或色名决策程序。[cite:1](#source-1)

**本卡参考输入：**单通道正、有限、已说明响应域的 H×W 信号；有效掩膜；显式有向路径列表；显式阈值配置。三通道时逐通道运行；相机 RGB 仅是工程输入选择，不等同于原文的人眼三种感受器。路径中的每次比较必须来自空间邻近点，或预先明确的边界桥接测量，不能拿两块材料中心的非局部亮度比冒充“边界两侧近邻比”。

**参考输出：**各点相对明度、访问计数、有效位及配置记录；中间量包括原始空间比值、阈值后增量、路径状态与 reset 位置。三个通道的明度元组仍不是经标定的颜色坐标；显示映射、增益、白平衡、色差与 OK/NG 判定均为卡外任务。

| 前提／边界 | 原文实际内容与工程解释 |
|---|---|
| 邻近比较 | p.4：同一区域内，两探测器距离缩小时照明差趋小；跨反射边界时比值趋近反射比。要求照明在该小尺度平滑、信号非零；硬阴影边界不满足这一分离 |
| 边界与区域传递 | pp.4–5：把跨各边界的比值相乘，连接远隔区域；不是把亮度中心值直接相除来消除照明 |
| 原型机与一般图像 | p.9：物理机器的边界位置已知；神经模型讨论紧密排列的探测器以免漏边。不能声称原机已有自动边缘检测／任意图像路径生成器 |
| 参考高值 | pp.6–7：起点暂当 100%，遇累计乘积大于 1 才重新立参考。得到路径内相对高值归一化，不保证场景里存在真实 100% 反射物 |
| 多路径 | pp.7–8、p.10：反向两路径例、闭环稳态讨论、同点多路径顺序乘积平均。没有指定必须随机游走、固定四邻域或某个种子 |
| 彩色限制 | p.10：实际是同一感受器波段内光谱积分的比；改变光谱形状可能改变比值。不能从中推出任意混合光源下严格颜色恒常 |

### L1 步骤：一次比较怎样产生路径读数

以下“原文”指 pp.6–10 的可辨文字；为数字实现补充的部分一律标“参考设计”。

1. **选择一个感受器系统，确定空间支持。**同一系统内比较不同位置的信号。参考设计先检查有效掩膜、非正值、饱和和响应域；不对原始三通道在同一点先求色比。[cite:1](#source-1)
2. **明确路径和比较方向。**原文 p.6 规定后一个感受器除以前一个，再依次向前。对路径 \(\pi=(x_0,\ldots,x_m)\)，使用 \(q_i=I(x_i)/I(x_{i-1})\)。图 5／7 为展示顶／底比采用相反方向；不能把那一组倒数直接放进图 8 的前向递推。[cite:1](#source-1)
3. **起点暂立为白参考。**令 \(P_0=1\)，即暂把起点看成 100% 反射；这是算法约定，不是测得真实白。参考程序保留这个起始读数，原文图 8 的两方向例也包含各自起点的 100。[cite:1](#source-1)
4. **去掉小幅变化。**原文 p.6 暂把接近 1 的比值当成 1，p.9 解释密集链上微小系统偏差会积累，提出由突触阈值丢弃。原文这里没有给数值阈值或双侧区间。参考设计选自然对数域死区 \(d_i=\ln q_i\)，\(\tilde d_i=0\) 当 \(|d_i|\le\tau\)，否则保留；这是明确新增的对称阈值定义，不冒称原文公式。[cite:1](#source-1)
5. **先积累，再判断 reset。**乘法域为 \(P_i=\min(1,P_{i-1}\tilde q_i)\)，\(\tilde q_i=e^{\tilde d_i}\)；对数域为 \(s_i=\min(0,s_{i-1}+\tilde d_i)\)，\(s_0=0\)、\(P_i=e^{s_i}\)。原文 pp.6–8 明确只有候选累计量大于上界才 reset，单个 \(q_i>1\) 不足以触发。[cite:1](#source-1)
6. **读出且传递同一个 reset 后状态。**将 \(P_i\) 作为此路径在 \(x_i\) 的读数，并把它传往下一比较。只夹显示值、不夹传播状态会破坏参考更新。reset 不会自动回写此前已读出的所有位置；原文另以闭合路径／反向路径处理历史偏差。[cite:1](#source-1)
7. **同点汇总不同路径读数。**原文 p.10 写顺序乘积的平均，pp.7–8 的具体数字符合算术平均。参考设计采用全部有效访问的等权算术平均，同时记录次数；若一条路径重复经过同点，此“按访问计权”是额外政策，不声称原文已固定了重复访问权重。[cite:1](#source-1)
8. **停止并返回有效位。**参考设计在显式路径列表全部处理后停止；无访问点输出 `NO_SUPPORT`，无效路径严格拒绝，不越过孔洞接到远点。若改成闭环迭代，须另定状态继承、收敛容差、最大圈数与不收敛状态，不能借用原文“足够长达到稳态”当可执行停止条件。

**可走通的输入：**原文图 8 的七区域 \([60,20,40,100,60,80,30]\)，均匀照明且使用区域边界比，可省略区域内部为 1 的比较；前向和反向各遍历一次，得到 L5 中逐项读数。该区域压缩仅对这个已知边界的例子成立，不是一般图像自动分块步骤。

### L2 机制：阈值、reset、路径和比较各自解决什么

**两种比较不要混淆。**第一种是同一波段、不同空间点之间的信号比，继而由路径连接远隔区域；第二种是在每个系统独立产生明度之后比较不同系统的结果以解释颜色。原文 p.10 特别指出，不是直接比较同一点三个未经空间处理的光谱积分。跨路径平均则是同点、同系统的多个空间历史的聚合，是第三个不同操作。[cite:1](#source-1)

| 删除／替换 | 后果与可检验反例 |
|---|---|
| 只保留相邻比，不沿路径传播 | 知道某个边界的相对变化，不知道远隔区域应共用什么参考；局部相同比值可置于不同全局背景 |
| 全部原始相邻比连乘，不设阈值 | 比值望远镜消去，只剩端点亮度比；缓慢照明变化也积回来了，不能凭“每一步很接近1”就忽略总体偏差 |
| 把每个大于1的局部比夹成1 | 20→40 的比为2，本应让已有 1/3 状态上升至2/3；夹局部比会错误地停在1/3 |
| 局部比大于1就把状态重置成1 | 同一个20→40步骤会错误变白；原法候选累计值2/3未超过1，应无 reset |
| 不做 reset | 起点被永远当作参考；经过更亮区域可产生大于1的读数，失去沿途更新高参考的机制 |
| 先找整图最大输入再除 | 仅在阈值不改比值、照明／路径覆盖满足特定条件时与相应极限相关；有限路径读数不同，非均匀照明下最大输入不必是最高反射 |
| 在 log 域直接平均后 exp | 变成几何平均，不是图8例中顺序乘积的算术平均；“乘法改加法”不授权改聚合定义 |
| 多路径共享一个正在更新的状态 | 后一条路径不再独立从1开始；p.10 强调共享感受器不破坏各路径的独立性，串扰是另一个算法 |
| 换成高斯环绕或频域高通 | 不再显式维护路径历史与累计 reset；即使也用乘性成像假设，也不能作为1971机制复现 |

**阈值不是万能的照明识别器。**它按变化大小而不是变化原因分类：弱材料边缘可能被抹掉，强阴影／反光边缘可能被保留。p.9 的动机是去掉大量密集小比值的累计照明漂移，不能简化成“阈值只去噪”。p.4 对失焦边界的视觉论述也不证明任何离散硬阈值程序都能保留模糊边缘；模糊可能把一次大跳变摊成一串低于门限的小变化。[cite:1](#source-1)

**多路径平均降低这个例子的偏差，不等于保证每像素更准确。**原文图8的前向第一点偏高、反向最后一点偏高，平均后仍未恢复全部真实反射。共享边缘误差、漏访高参考、同一阴影造成的误判均可能在多条路径上一致存在。作者后续材料与独立分析对有限空间作用、最大值归一化极限和感知目标侧重不同；不能把某个后续版本的批评或成功无条件转移到本卡。[cite:1](#source-1)[cite:3](#source-3)[cite:4](#source-4)

### L4 数学：从局部比值到有记忆的归一化

#### 成像与邻近比值消照明的条件

对黑白漫反射的标量简化，设 \(I(x)=E(x)R(x)>0\)。在同一区域，\(R(a)=R(b)\)；跨边界则两侧分别取反射值。于是

\[
q(a,b)=\frac{I(b)}{I(a)}
=\frac{R(b)}{R(a)}\frac{E(b)}{E(a)},
\qquad
\ln q=\Delta\ln R+\Delta\ln E.
\]

若局部 \(\ln E\) 是 K-Lipschitz、比较距离为 h，则 \(|\Delta\ln E|\le Kh\)。同反射区域的比值随 h→0 趋近1；跨反射边界、两侧照明连续且为正时，照明比趋近1，留下反射比。这是对原文 p.4 近邻论证的条件化推导，不是任意距离、任意照明分布下的严格消除。[cite:1](#source-1)

在参考硬阈值下，若同区域有 \(Kh\le\tau\)，无噪声时其照明增量被消掉；若真实边界满足 \(|\Delta\ln R|>\tau+Kh\)，可保证其总增量不落入死区。落在这两个条件之间则不能分清。有限噪声还需加入 log 信号误差预算，原文没有给这些工程常数。

#### 顺序乘积、方向与不可辨识性

若每个边界桥接比准确给出 \(q_i=R_i/R_{i-1}\)，不做 reset 时

\[
\prod_{i=1}^{m}q_i
=\frac{R_1}{R_0}\frac{R_2}{R_1}\cdots\frac{R_m}{R_{m-1}}
=\frac{R_m}{R_0}.
\]

因此同起点、同终点的理想路径端点比一致，区域内部理想比1只传递已有状态；不同起点的路径则有不同分母，不能未经归一化就假设结果相同。原文 pp.5–6 正是由这个问题引出高参考和 reset。[cite:1](#source-1)

如果改为把**所有原始像素**比值无阈值连乘，同样的消去却得到

\[
\prod_{i=1}^{m}\frac{I_i}{I_{i-1}}
=\frac{I_m}{I_0}
=\frac{R_m}{R_0}\frac{E_m}{E_0}.
\]

所以“有 log、有相除”本身不能分离照明。即使理想边界比已知，也只约束反射的相对比例：\(R\mapsto aR, E\mapsto E/a\) 不改变 I。把最大值指定为1是选规范，不是测得绝对反射率；若有效区域不连通，各连通分量还可能有独立参考尺度。

#### reset 的逐步推导与前缀最大值

统一采用后点／前点方向，初值 \(P_0=1\)。原文“候选累计乘积大于1则重启为1”可转写为

\[
P_i=\min\{1,P_{i-1}q_i\}.
\]

若 \(q_i=R_i/R_{i-1}\) 精确成立，设 \(M_i=\max_{0\le j\le i}R_j\)。归纳：起点 \(P_0=R_0/M_0=1\)；若 \(P_{i-1}=R_{i-1}/M_{i-1}\)，则

\[
P_i=\min\left(1,\frac{R_i}{M_{i-1}}\right)
=\frac{R_i}{\max(M_{i-1},R_i)}=\frac{R_i}{M_i}.
\]

因此它是**已走过前缀内最高反射归一化**，不是预知整条路径／整张图最高值。首次到达最高参考之前的已输出值不会被这个公式自动修正。阈值不改原始信号比时，同一证明对 I 成立；那是前缀最高**输入信号**，不能偷换成最高反射。

对数状态满足

\[
s_i=\ln P_i=\min(0,s_{i-1}+\tilde d_i),\qquad s_0=0.
\]

令 \(C_0=0,C_i=\sum_{k=1}^{i}\tilde d_k\)，则进一步归纳得

\[
s_i=C_i-\max_{0\le j\le i}C_j.
\]

这里 C 是沿特定路径积分得到的虚拟势。阈值改变边以后，它一般不再是 \(\ln I_i-\ln I_0\)，也未必能定义为全图单值反射势；不可将此式无条件改写成 `I / global_max(I)`。这两个式子是本卡的代数展开，不是伪造原文编号公式。

#### 路径平均与闭环的适用范围

设 \(\mathcal V(x)\) 为到达 x 的有效路径访问集合，本卡参考设计为

\[
L(x)=\frac{1}{|\mathcal V(x)|}\sum_{v\in\mathcal V(x)}e^{s_v(x)}.
\]

原文图8例及 p.10 支持平均顺序乘积，但重复访问的权重来自本卡设计。若在 log 域稳定汇总，应算 \(\ln L=\operatorname{logsumexp}(s_v)-\ln|\mathcal V|\)，而不是 \(\operatorname{mean}(s_v)\)；后者对应几何平均。[cite:1](#source-1)

在**精确反射比、静态、单条有限闭合路径持续传递状态**的理想情形，经过该环最高反射后再走完整圈，各点可以读到相对该环最高值的比例。不是相对所有未访问点的最高值，也不是“任意随机路径一圈必收敛”。当阈值或噪声使环路 \(\sum\tilde d_i\ne0\) 时，路径场不再保守：例如一圈总和为负，持续积累可不断变暗；正和又可能反复 reset。原文 p.7 的稳态直觉不能升级为这些离散实现的通用收敛定理。[cite:1](#source-1)

独立的1986分析中，附录 A 讨论的是包括后续并行比较程序在内的 reset 路线；其 p.1658 明说收敛结论以“如果收敛”为条件，未证明收敛。本卡不把那套迭代方程或其极限模拟结果当作1971有限路径算法的精确实现／性能结果。[cite:4](#source-4)

#### 彩色积分、复杂度和误差边界

原文 p.10 对彩色材料改用

\[
I_c(x)=\int S_c(\lambda)E(x,\lambda)R(x,\lambda)\,d\lambda,
\qquad q_{c,i}=I_c(x_i)/I_c(x_{i-1}).
\]

积分的比通常不是一个照明无关的反射积分比。若该系统所有位置信号共同乘正数 \(a_c\)，空间比完全不变，因此固定路径、固定 log 阈值下输出不变；但改变照明光谱形状时，材料光谱与感受器重叠会改变积分比。原文也承认这种变化可带来明度尺度小移，不能省略后只讲严格颜色恒常。[cite:1](#source-1)

设 N 为像素数、C 为通道数、V 为全部路径访问数，参考递推约为 \(O(C(N+V))\)，图像与累加／计数存储 \(O(CN)\)，若路径全部存储另需 \(O(V)\)。这里没有声明原论文的运行速度或一种固定路径生成器的复杂度。

对固定路径、固定阈值后增量，\(f(z)=\min(0,z)\) 是1-Lipschitz，因此两次递推有

\[
|s_i-s'_i|\le\sum_{k=1}^{i}|\tilde d_k-\tilde d'_k|.
\]

在非正状态域 exp 的导数不大于1，故单次乘积读数误差不超过对应 log 状态误差。此为条件数值传播界，不是相机噪声到感知／反射精度的通用界：硬阈值在 \(\pm\tau\) 处不连续，跨门限会改变增量；低信号的 log 对加性误差很敏感，且路径共享比较导致误差相关。原文没有可移植到任意工业图像的准确率或误差上界。

### L5 实现：参考程序、原文数值与检查范围

#### 数据布局和伪代码

参考图像按 `(channel, row, col)` 或单通道 `(row, col)` 明确存储；行向下、列向右。先转 float64 再做 log 差，避免整数除法、无符号减法和极端比值溢出。路径坐标为显式整数列表；合法性检查包含掩膜、边界与声明的邻接规则，不自动 wrap，也不跨过无效像素拼接路径。区域算例的索引是材料序列位置，不伪装成一般 H×W 邻接。

下面是**未接入仓库的参考设计伪代码**：原文的累计 reset 被保留；对称 log 阈值、按访问计权、无效输入拒绝和有限列表停止由本卡补充。它不是已找到的原作者代码。

```text
RE01_REFERENCE(image, mask, paths, tau):
    require finite tau >= 0
    require nonempty paths and matching image/mask shapes
    require every valid sample finite and strictly positive
    validate all paths against mask, bounds and declared adjacency
    log_image = log(valid image values)
    log_sum = -infinity at every location
    count = 0 at every location
    for each channel c:
        for path in paths:
            state = 0
            record(path[0], state, log_sum[c], count[c])
            for prev, current in consecutive pairs(path):
                delta = log_image[c, current] - log_image[c, prev]
                if abs(delta) <= tau:
                    delta = 0
                candidate = state + delta
                state = min(0, candidate)
                record reset event when candidate > 0
                record(current, state, log_sum[c], count[c])
    valid = count > 0
    log_lightness[valid] = log_sum[valid] - log(count[valid])
    lightness[valid] = exp(log_lightness[valid])
    return lightness, log_lightness, count, valid, configuration

record(location, state, log_sum, count):
    log_sum[location] = logaddexp(log_sum[location], state)
    count[location] += 1
```

`logaddexp` 表示两个指数之和的对数，应使用稳定实现；不可简单 `log(exp(a)+exp(b))` 后宣称不会下溢。输出同时保留 log 明度与有效位，极暗值若 exp 下溢不能被解释为真的零反射；无支持点与低明度点必须区分。计数用足够宽整型，检查总访问数上界。

    state = F(1)
    out = [state]

        candidate = state * values[i] / values[i - 1]
        if candidate > 1:
            resets.append(i)
        state = min(F(1), candidate)
        out.append(state)

        if abs(delta) <= tau:
            delta = 0.0
        state = min(0.0, state + delta)
        out.append(exp(state))
    return out

#### 优化和验证不越界

固定采样与阈值后，可预计算 log 信号、缓存相同边的增量；但反方向符号、阈值政策必须一致。路径之间可以并行，路径内部不能随意打乱；由 \(s_i=C_i-\operatorname{prefixmax}(C)_i\) 可构造前缀算法，但浮点累计顺序和门限附近舍入仍需逐例对比。不能把 reset 移到最终平均之后。流式路径节省路径存储；并行平均须统一计数和 log-sum 合并，速度尚未剖析，不宣称提速。

集成测试应包含合法零灰度的输入政策、饱和、孔洞掩膜、边界不回绕、反向索引回填、重复访问计权、未访问点、路径共享状态错误、模糊／硬阴影、长期闭环漂移、三通道独立缩放和光谱变化。有限算术断言通过不代表这些测试已通过，更不代表1971生理模型已证实。

### 五问五答：贯穿 L1–L5

1. **L1：图8从60走到20、40、100，何时 reset，最后怎样得到一张图？**答：起点状态1，20处1/3，40处2/3，100处候选5/3才 reset 为1；继续传播，收集每条路径在各位置的读数，再同点平均。两方向须先对齐坐标；无访问点无结果。易错：40/20大于1就重启，或把反向数组不倒回就平均。证据：原文 pp.6–8、L5表及断言。[cite:1](#source-1)
2. **L2：近邻比值连乘已经消去中间量，为什么还需要阈值？**答：直接连乘所有原始像素比最终仍含端点照明比；密集的小照明增量会积累。阈值把近1的增量当作区域内缓变而丢弃，但也可能抹掉弱反射边缘，不能识别变化原因。易错：每步小所以总误差小，或说阈值仅去噪。证据：原文 p.9、L2删除反例、L4端点公式。[cite:1](#source-1)
3. **L3：换分辨率后弱污斑消失，应直接套1.003并增加路径数吗？**答：不能；先核像素对应间距、响应域、信噪、边界被模糊后分摊到多少步，以及阈值丢弃比例。1971未提供该数字默认值，后续作者说明有视角前提；增加路径只会重复传播被删掉的边界，未必恢复。易错：把后续生理说明当相机通用阈值。证据：原文 pp.4、9，后续§3.2，L3参数表。[cite:1](#source-1)[cite:3](#source-3)
4. **L4：证明 reset 读数等于相对高值，是否说明可直接除全图最大亮度？**答：精确比下归纳得 \(P_i=R_i/\max_{j\le i}R_j\)，只是已走前缀；有限路径未见全图，阈值后的积分也不等于原输入势，非均匀照明又使最高亮度不等于最高反射。易错：省略精确反射比前提、把局部结论扩大到全图或绝对反射。证据：原文 pp.6–7、L4归纳及条件限制。[cite:1](#source-1)
5. **L5：程序用了 log 和 reset，为何仍与图8不符，怎样优化才安全？**答：逐项核后点／前点方向、初值0、先加再夹到0、传播夹后状态、通道和路径独立、反向回填，以及对 exp 后乘积算术平均；log均值是另一聚合。用图8分数基准先定位，后缓存 log／边增量、并行独立路径或验证前缀等价，不借更短代码声称正确。易错：把全部 log 程序称同态／SSR等价，或把检查器通过当二维原算法复现。证据：原文 pp.8–10、L5算术检查。[cite:1](#source-1)
