## 演进与工程主线

- 缺陷：参考差分先解决可比性，背景统计容纳正常变化，纹理表示容纳局部排列，异常评分容纳“只有正常样本”；代价依次为配准依赖、更新污染、尺度/方向选择、分布建模与阈值。彼此并行可组合，不认为异常网络必替代差分。
- 装配：有无/数量 → 相对几何规则 → 类别与关系联合；核心瓶颈是候选可靠性、关系可观测性和误放行代价。规则解释性高但需明确容差，学习模型需标签和未知类处理。
- 字符与编码：OCR 从切字识别走向序列对齐，减少切分依赖但增加训练/解码成本；条码从图像采样到码字/校验，约束来自码制而非自然语言。两条支线不能合并成一种字符模型。
- 颜色：相机原始通道 → 受控采集/颜色校准 → 感知距离和空间外观；算法无法补回饱和、未知光谱与照明几何。三维：图像对应 → 几何深度 → 点云对齐；重叠/同步/尺度是首要工程前提。
- 跟踪：状态模型（Kalman，1960）与外观滤波（MOSSE，2010）是互补支线：前者传播不确定度却不检测物体，后者在线适应外观却可能漂移；光流提供局部运动，关联维持身份，视觉引导仍需标定和时延稳定性分析。方法年份与参考讲义修订/库版本分开记录。[cite:1](#source-1)[cite:2](#source-2)

## D01 配准后绝对差分

**任务/前提/状态：**参考良品 T 与当前图 I、几何变换 W、有效掩膜 → 残差图与缺陷候选。要求同一对象区域可配准、曝光可比。仅教学管线，无本地实现；已有 ZNCC 只能提供有限几何模型下的前置定位。

**L1 步骤：**配准并重采样，求交集有效域，在可信正常域估亮度 a/b，计算 |I(Wp)-aT(p)-b|，阈值，再按连通域面积/长度/位置判候选；输出候选和未检区域。

**L2 机制：**对齐排除正常几何变化；亮度校正排除全局增益/偏置；掩膜防补零边界成为假缺陷。差分仍混合错位、光照变化与真实缺陷，不能直接当语义缺陷标签。

**L3 工程权衡：**阈值单位灰度、面积为 px²或经标定物理面积；先查对齐残差、反光/饱和，再亮度模型，最后阈值与区域门。形态学会删除细划痕，不能只看去噪效果。不同批次正常差异需单列误报。

**L4 推导：**正常像素最小化 \(\sum[I(Wp)-aT(p)-b]^2\)，设计矩阵 X=[T,1] 满列秩才可解 a/b；常量 T 退化。小位姿误差 delta 有 \(I(Wp+\delta)-I(Wp)\approx\nabla I^T\delta\)，解释强边缘为何出现双边假缺陷。平方误差目标不抗缺陷污染，需独立可信区域或鲁棒估计方案。固定变换后 O(HW)，区域遍历同阶。

**L5 实现方案：**浮点重采样与独立有效掩膜，禁止无符号相减；返回“未检测”而不是把越界区域算 OK。下列伪代码未落地，不把匹配结果低分直接置 NG。

```text
aligned,valid = warp_with_support(image,transform)
a,b = fit_photometric_model(reference,aligned,trusted_normal_mask)
residual = abs(aligned-a*reference-b)
candidates = connected_components((residual>threshold)&valid)
return candidates,valid,residual
```

**数值例：**已校正参考 (10,20,30)，当前 (10,25,30)，阈值 3，用严格 >，仅中间残差 5 过门。若边缘梯度 50 灰度/px、配准误差 .1 px，则仅错位就约有 5 灰度残差。

**测试设计：**纯位移经正确配准应消除大部分残差；曝光线性变化应由 a/b 恢复；细划痕不得被面积门悄悄丢掉；无重叠应 UNKNOWN。真实验收按缺陷尺寸分漏检/误报，未实测。

**追问链与答案：**L1「先差分还是对齐？」答：先对齐；L2「为何有效域？」答：插值外部无观察；L3「边缘成双线先降阈值？」答：先查错位；L4「残差如何随位移变？」答：梯度点乘误差；L5「uint8 直接减？」答：可能下溢，转浮点。来源状态：本地匹配边界已读，本基线为显式数学方案，无专用代码/数据。

## D02 单高斯指数背景模型

**任务/前提/状态：**固定机位序列 → 每像素前景掩膜与背景均值/方差。单峰背景、亮度缓变前提；无本地实现，**不是 MOG2**。

**L1 步骤：**用确认正常帧初始化 mu/v，按旧模型标准化残差判断前景；仅可信背景更新统计，前景暂停更新；帧结束输出掩膜和模型状态。

**L2 机制：**指数遗忘适应缓慢漂移，方差规范化区分正常噪声与异常。若异常也更新，会被吸收；前景门控又可能阻碍适应真实背景突变，需要重初始化策略。

**L3 工程权衡：**alpha 无量纲，记忆长度约 1/alpha 帧；v 单位灰度²，sigma_floor 必须有噪声依据。先查机位/光变与初始化，再调遗忘率；晃叶、屏幕等多模态背景不适合单高斯。

**L4 推导：**将旧分布权重 1-alpha 与新样本权重 alpha 混合，\(\mu'=(1-\alpha)\mu+\alpha I\)，利用均值移动后的二阶矩得
\(v'=(1-\alpha)v+\alpha(1-\alpha)(I-\mu)^2\)。标准化分数 \((I-\mu)^2/(v+\epsilon)\) 只在模型正确时有统计解释；门控改变采样分布，不可无条件套精确卡方阈值。每像素 O(1)，全帧 O(HW)。

**L5 实现方案：**判定必须用更新前 mu/v；保存背景更新掩膜，防顺序依赖；长时间遮挡重置须单独记录，不能把重置当物体消失证明。

```text
r = image-mu
foreground = r*r > threshold_squared*(v+epsilon)
update = trusted & not foreground
mu_new = (1-alpha)*mu+alpha*image
v_new = (1-alpha)*v+alpha*(1-alpha)*r*r
assign_only(update,mu_new,v_new)
```

**数值例：**mu=10、v=4、I=12、alpha=.1，若允许更新，则 mu'=10.2、v'=3.96；若此点被判前景并冻结，仍是 10/4。两种状态不能混用。

**测试设计：**常量噪声、慢亮度漂移、突然光变、静止前景污染、机位抖动；验证 v 非负及先判后更。未提供现场背景模型结果。

**追问链与答案：**L1「判定先后？」答：先用旧模型判；L2「为何不更新前景？」答：防吸收异常；L3「alpha 大？」答：适应快也更易污染；L4「方差式为什么有 1-alpha？」答：混合均值改变带来的二阶矩；L5「这是 MOG2？」答：单高斯不是混合模型。来源状态：本文定义与推导，无外部实现复现声明。

## D03 LBP 纹理直方图基线

**任务/前提/状态：**固定尺度灰度 patch → 基本 8 邻域 LBP 直方图，再与正常参考比较；无实现。此卡不把 GLCM、Gabor、旋转不变/均匀 LBP 变体都算已覆盖。[cite:3](#source-3)

**L1 步骤：**固定邻居顺序和半径，对邻居与中心比较≥，二进制编码为 0–255，统计归一化直方图；计算到正常参考的卡方型距离，阈值判偏离。

**L2 机制：**编码局部强度相对关系，理想严格单调灰度映射保序，减少整体亮度影响。旋转改变位序、噪声翻转近等值位；直方图丢空间布局，不能精定位像素缺陷。

**L3 工程权衡：**半径 px 对应纹理尺度，patch 大降低统计波动但稀释小缺陷；先看纹理尺度/方向和邻差分布，再阈值。固定量化和边界，不能把 basic/uniform 的箱数混用。

**L4 推导：**\(LBP(p)=\sum_{j=0}^{7}1[I(p_j)\ge I(p)]2^j\)。比较 h/q 可用 \(D=\tfrac12\sum_b(h_b-q_b)^2/(h_b+q_b+\epsilon)\)，差为零的共同空箱贡献零。严格单调变换保持符号，但量化/饱和会破坏；任意像素排列不保 LBP，但不同 patch 可有相同直方图。O(8N+256)。

**L5 实现方案：**明确从哪个邻居开始、顺/逆时针、等号和边界是否丢弃；圆周采样插值版本与整数 3×3 版本不同。本卡数值例用整数邻点。

```text
for valid_center in patch:
    bits = neighbors_in_fixed_order >= center_value
    code = sum(bits[j]*2^j for j in 0..7)
    histogram[code] += 1
normalize(histogram)
return chi_square_distance(histogram,normal_reference)
```

**数值例：**按 j=0…7 的比较位 (1,0,1,0,0,0,0,0)，代码为 1+4=5；两箱 h=(1,0)、q=(0,1)，epsilon=0 且非零分母时 D=1。

**测试设计：**位序 5、严格单调灰度变换不变、旋转时位移、等值/量化噪声、不同 patch 尺度；按批次测试误报，不称单箱算对就有纹理异常能力。

**追问链与答案：**L1「输出什么？」答：码图再直方图；L2「为何亮度较稳？」答：比较保序；L3「转动后变了？」答：basic 版不是旋转不变；L4「位权？」答：2^j；L5「两库不一致？」答：邻序/插值/变体/边界。来源状态：官方示例/接口检索已核对，未读取库实现或原论文全文。

## D04 固定特征的收缩 Mahalanobis 异常评分

**任务/前提/状态：**仅正常训练特征 f∈R^d → 偏离分数；具体基线为固定 LBP/颜色等特征加单高斯协方差，**不叫已实现 PaDiM/PatchCore**。无专用实现。[cite:4](#source-4)

**L1 步骤：**按批次划分正常训练/验证，固定特征与归一化，估 mu/S，收缩到正定协方差；用 Cholesky 白化残差求平方范数，验证集设阈值；空间定位需事先定义滑窗/网格。

**L2 机制：**协方差把正常大波动方向降权，小波动方向升权；收缩降低小样本高维逆矩阵不稳。未知缺陷定义为“偏离正常”，不等于某类缺陷语义，也不能检测恰落在正常特征中的异常。

**L3 工程权衡：**lambda∈[0,1] 控制收缩，epsilon 控制最低尺度；先确认训练无缺陷污染/特征足够，再看样本量与条件数，最后阈值。使用全测试集设阈值会泄漏。

**L4 推导：**高斯负对数密度为 \(\tfrac12[(f-\mu)^T\Sigma^{-1}(f-\mu)+\log\det\Sigma+d\log(2\pi)]\)。固定模型后排序只需 D²；取 \(\Sigma=(1-\lambda)S+\lambda\operatorname{tr}(S)I/d+\epsilon I\)。lambda 是预设/验证选值，不冒称已实现 Ledoit–Wolf 最优系数估计。已知真实高斯参数才有相应卡方分布，估参/选择后不能盲套。训练 O(Nd²+d³)，每样本三角求解 O(d²)。

**L5 实现方案：**不要显式求逆，保存特征规范、mu、分解与阈值版本；零方差特征、NaN、跨场景泄漏必须拦截。不同位置独立高斯与全图共享高斯是不同模型。

```text
mu,S = fit_normal_features(training_only)
Sigma = shrink(S,lambda,epsilon)
L = cholesky(Sigma)
u = triangular_solve(L,feature-mu)
score = dot(u,u)
return score, score>threshold
```

**数值例：**mu=(0,0)、Sigma=diag(4,1)、f=(2,1)，D²=4/4+1=2；原始欧氏平方距离为 5，二者权重不同。D²=2 不自动给出缺陷概率。

**测试设计：**对角例、奇异小样本、无变化特征、训练异常污染、分组验证、批次漂移；报告目标误报率下漏检，未有本仓库实测。

**追问链与答案：**L1「学什么？」答：正常均值/协方差；L2「为何白化？」答：规范化正常变动；L3「小样本爆分？」答：检查条件数/收缩/污染；L4「分数哪来？」答：高斯负对数密度；L5「直接 inv？」答：用分解求解。来源状态：官方协方差文档检索+本文显式基线，未复现任何深度异常论文。

## B01 Code 128-B 读码与校验子集

**任务/前提/状态：**已定位、校正、足够分辨率的 Code 128-B 条码 → 码字/字符及校验结果；不含码集切换、FNC 和 GS1 应用标识符解析。无本地解码器，不是完整标准实现。[cite:9](#source-9)

**L1 步骤：**检测静区/起止结构，取多条扫描线，估模块宽，把条空宽度映射合法码字表，限定 Start B，解析数据，验 modulo-103 校验字符与停止结构；不一致则不可读/校验失败。

**L2 机制：**码字结构与校验提供强约束，避免任意宽度序列被解释为字符串；校验发现部分错误，不负责恢复所有错误，也不能代替真实业务码核对。

**L3 工程权衡：**模块宽 px、静区按模块倍数、运动模糊/透视会改变宽度。先查成像/采样再阈值；不能用 OCR 的字符模板识别原理替代条空码字解析。查表必须使用合法规范来源。

**L4 推导：**本子集 Start B 的值为 104，数据码字 ci 的校验为 \(c_{check}=(104+\sum_{i=1}^{n}i c_i)\bmod103\)。这是码制给定同余校验规则，不是最小二乘估计；不同错误可同余碰撞，校验通过不能证明绝对无误。宽度量化/容错的完整标准尚未推导，L4 部分；N 模块、固定码表时解析约 O(N)。

**L5 实现方案：**不在本文伪造码字宽度表；接入时需正式码表、版本和许可确认。输出原码字、校验状态与失败扫描线，定义不支持切换时拒绝，不能把控制码当普通字符。QR/Data Matrix 另走定位图形、网格采样和纠错，不含在本卡。

```text
runs = scan_rectified_barcode(image)
codes = decode_using_verified_code128_table(runs)
require start_is_B and no_switch_or_FNC
expected = (104+sum(i*codes[i] for i in data_positions)) mod 103
require expected==observed_check and valid_stop_and_quiet_zones
return decode_B_data(codes)
```

**数值例：**给定数据码字 33、34（B 集示例 A/B），加权和 104+1×33+2×34=205，校验值 102；若第二码字误为35，校验期望变1，不再为102。这里只验码字级算术，不证明已能从图像读出条码。

**测试设计：**正常码、校验错、静区不足、反向扫描、窄条欠采样、不支持切换、截断停止符；分别记不可读与读错，未做标准一致性认证。

**追问链与答案：**L1「读出字符就结束？」答：验结构/校验；L2「校验能纠所有错？」答：不能且有碰撞；L3「模糊先放宽匹配？」答：先恢复成像可读性；L4「权重是什么？」答：从1递增且含起始值；L5「缺码表能号称实现？」答：不能。来源状态：GS1 官方机构资料仅检索确认 modulo-103，完整 Code128 标准/表未获取，明确子集与获取限制。

## G01 双目 SAD 块匹配与三角测量

**任务/前提/状态：**已标定/校正同步双目、焦距 f 与基线 B → 视差和深度；无本地实现。该卡明确是整数 SAD 基线，不冒称 SGM 或深度立体网络。

**L1 步骤：**沿校正后同一行搜索视差 d，对固定窗口算 SAD，取最小及唯一性门；做左右一致性/遮挡拒绝，正视差才三角化，输出深度与有效掩膜。

**L2 机制：**极线约束把二维对应变一维，窗口聚合减小噪声却模糊深度边；纹理重复/无纹理使匹配不唯一。左右一致性能筛部分错误，不能恢复不可见表面。

**L3 工程权衡：**d/window 以 px，B 以 m 或 mm，f 为 px；先查标定/同步/曝光，再视差范围和窗口，最后唯一性门。大 B 深度灵敏但遮挡更重，远处小视差误差放大。

**L4 推导：**平行校正针孔 \(x_L=fX/Z,x_R=f(X-B)/Z\)，相减得 d=fB/Z，故 Z=fB/d。\(\partial Z/\partial d=-fB/d²\)，一阶 \(\sigma_Z\approx fB\sigma_d/d²\)（仅视差误差）。SAD=\(\sum|I_L(x+u,y+v)-I_R(x+u-d,y+v)|\)，可对应独立 Laplace 光度残差模型；曝光差破坏它。朴素 O(HWDw²)，滑窗聚合可降到 O(HWD)，需同边界。

**L5 实现方案：**视差正负、主点偏置校正、无效值编码、图像/点云坐标明确；d≈0 必须拒绝，不能除零后裁成最大距离。不把像素亚精化自动等同毫米准确。

```text
for pixel in valid_left:
    costs = SAD_over_disparity_range(pixel)
    d = unique_argmin(costs)
    if d<=0 or not left_right_consistent(pixel,d): mark_invalid
    else: depth[pixel] = focal_px*baseline/d
return depth,validity
```

**数值例：**f=800 px、B=.1 m、d=40 px，则 Z=2 m；若 sigma_d=.5 px，线性近似 sigma_Z=80×.5/1600=.025 m。不是总标定误差上界。

**测试设计：**已知平面视差、重复纹理、遮挡、零视差、运动不同步、深度边跨窗；测有效率与深度误差，不仅平均有效点 RMSE。

**追问链与答案：**L1「搜索在哪？」答：校正极线上；L2「大窗一定好？」答：跨深度边混合；L3「远处抖？」答：小视差敏感；L4「Z 怎么来？」答：两投影相减；L5「d=0？」答：无效，不是可靠无穷远。来源状态：显式针孔/SAD 教学模型，未做三维数据验证。

## G02 刚性 point-to-point ICP

**任务/前提/状态：**有足够重叠的两点云+较好初值 → SE(3) 配准变换；无仓库实现。官方教程说明输入粗对齐，不能称无需初值的全局算法。[cite:6](#source-6)

**L1 步骤：**当前变换下找近邻对应，距离门筛对，固定对应解刚性最小二乘，复合更新；位姿/残差变化小或达到预算停止，输出对应数/重叠信息与变换。

**L2 机制：**对应与变换交替，避免一次求所有未知量；好初值使近邻较可能正确。对称形状、低重叠和离群点可落局部错误解；低残差不表示全局配准正确。

**L3 工程权衡：**点间距/门限同物理单位，降采样影响几何细节。先查尺度/坐标/重叠，再初值和门限，最后迭代次数。平面/直线退化与局部对称需查看约束秩，不能只加迭代。

**L4 推导：**固定对应最小化 \(\sum\|Rp_i+t-q_i\|²\)，消 t 得 \(t=\bar q-R\bar p\)。H=\(\sum(p_i-\bar p)(q_i-\bar q)^T=U\Sigma V^T\)，最大化 trace(RH) 给 \(R=V\operatorname{diag}(1,1,\det(VU^T))U^T\)，校正反射后 detR=1。固定对应且精确求解下降；加入门控/变化支持后不能对不同残差集合直接比较单调性。每轮近邻通常 O(NlogM) 加固定维 SVD，最坏依数据结构而变。

**L5 实现方案：**源到目标与反变换不混用，列向量约定 T_new=deltaT*T_old；有限点、最小对应数、奇异谱和反射检查。point-to-plane 另用法向残差，不计入此卡推导。

```text
T = initial_transform
repeat until converged_or_budget:
    pairs = gated_nearest_neighbors(transform(source,T),target)
    require sufficient_non_degenerate_pairs
    deltaR,deltat = rigid_SVD_fit(pairs)
    T = compose(deltaR,deltat,T)
return T,correspondence_diagnostics
```

**数值例：**给定三对非共线点，目标均比源加 (1,2,3)，对应正确时 R=I、t=(1,2,3)，残差 0；如果只给同一条直线，绕线旋转可能不可观测，残差 0 不代表唯一姿态。

**测试设计：**已知刚体变换、反射输入、对称点云、低重叠、单位×1000、离群点；评价姿态误差/覆盖率/错误收敛，不只报配对残差。

**追问链与答案：**L1「先什么？」答：初值下对应；L2「为何局部？」答：对应依赖当前变换；L3「多迭代能救退化？」答：不能；L4「为何修 det？」答：排除镜像；L5「复合方向？」答：按坐标约定左乘增量。来源状态：Open3D 0.11.1 教程正文已读，未安装/运行 Open3D，外部示例结果不移植到本仓库。

## T01 线性 Kalman 常速状态估计

**任务/前提/状态：**时间戳与已关联目标位置观测 → 位置/速度及协方差。基线 s=(x,y,vx,vy)；线性动力学、独立零均值过程/观测噪声，高斯时为对应模型的最小均方误差后验均值。无本地实现；不是目标检测器或控制器。[cite:1](#source-1)

**L1 步骤：**由 delta_t 组 F/Q，预测状态与 P；有观测时算创新、S、门控和 K，更新状态与协方差；缺测仅预测，连续缺测超过预算宣告失锁，不能无限当可信轨迹。

**L2 机制：**预测提供时序先验，创新校正；K 根据相对不确定度自动加权，而非固定平均。错误关联是错误观测，滤波器不会自动知道身份；需要 T04 门控/关联。

**L3 工程权衡：**位置 px、速度 px/s，P/Q 各项单位随状态，R 为位置 px²。先查时间戳/关联和残差偏置，再定 R、运动模型/Q，最后门控。Q 小会滞后且过自信，大则抖；不能只为轨迹好看压 R。丢帧必须更新 delta_t。

**L4 推导：**\(s^-=Fs+Bu,P^-=FPF^T+Q\)，\(z=Hs+v\)。定义创新 r=z-Hs^-、S=HP^-Hᵀ+R。设更新 s+=s^-+Kr，误差协方差
\(P^+=(I-KH)P^-(I-KH)^T+KRK^T\)。对 trace(P+) 求 K 导数，得 \(KS=P^-H^T\)，故 \(K=P^-H^TS^{-1}\)。这是最优线性增益，非高斯时一般不能称全局 MMSE。

对一维常速状态 (x,v)，F=[[1,dt],[0,1]]。若每个区间随机常加速度 a、方差 sigma_a²，则 G=(dt²/2,dt)ᵀ、Q=G sigma_a² Gᵀ；若连续白加速度谱密度 q，则 Q=q[[dt³/3,dt²/2],[dt²/2,dt]]。两种模型单位不同，不得混用。仅位置观测 H=[1,0] 的两步可观测矩阵 [[1,0],[1,dt]] 在 dt≠0 满秩；缺测/错误模型会破坏实际稳定性。通用稠密状态 n、观测 m 下矩阵计算含 O(n³+m³)，固定4维为常数级每目标每帧。

**L5 实现方案：**用求解 KS=P^-Hᵀ 而非显式逆，更新 P 用 Joseph 形式保对称/半正定更稳。计算创新平方 Mahalanobis rᵀS^-1r 做门控；卡方概率解释需正确高斯模型和协方差，阈值不是通用魔数。输出预测/校正状态标志及失锁计数，不能将预测点标成实测点。

```text
F,Q = model_from_elapsed_time(dt)
s = F@s
P = F@P@F.T+Q
if no_measurement: return predicted(s,P)
r = z-H@s
S = H@P@H.T+R
if innovation_gate_fails(r,S): return predicted_or_lost(s,P)
K = solve_right(S,P@H.T)
s = s+K@r
A = identity-K@H
P = A@P@A.T+K@R@K.T
return corrected(s,P)
```

**数值例：**一维位置状态先验 x^-=10、P^-=4，观测 z=12、R=1、H=1，S=5、K=.8，x+=11.6，P+=(.2)²×4+.8²×1=.8。创新平方标准化为 4/5=.8；不是“误差一定≤sqrt(.8)”的确定性保证。

**测试设计：**标量例、Q/R 极限、缺测只预测、非等间隔 dt、半正定/对称性、错误关联门控、常速/加速失配；统计 NEES/NIS 时需独立真值和分布条件。无视频或机器人实测。

**追问链与答案：**L1「缺测如何？」答：只预测并增不确定度/失锁计数；L2「为何非固定平均？」答：K 取决 P/R；L3「拐弯滞后先压 R？」答：先查模型/时间戳/Q；L4「K 从哪来？」答：最小化后验误差迹；L5「P 出负特征值？」答：查求解/对称性/Joseph/噪声模型。易错答案：把高斯协方差称绝对误差界、把 Kalman 当检测器。

**来源状态：**Welch–Bishop TR95-041（读取的版本为2000-06-06）正文预测/校正与增益推导已读，历史方法为1960；未读取 Kalman 1960 原文全文、未作三独立原始来源交叉验证，不引申普遍稳定性。[cite:1](#source-1)

**自适应 Kalman 边界：**根据创新在线估 Q/R、协方差匹配或多模型切换均为另一个族；创新同时受运动失配、异常观测、关联错误影响，不能仅令 R=rrᵀ就声称自适应最优。本文未给具体可辨识估计器、收敛条件或实现，不算第二张已完成 Kalman 卡。

## T02 MOSSE 型自适应相关滤波

**任务/前提/状态：**首帧框+后续局部图像 → 单目标平移位置和可靠性；明确选择 Bolme 等 2010 的 MOSSE 思路。无本地实现；不是 NCC 模板，也不扩称已实现 KCF/CSRT/尺度滤波器。[cite:2](#source-2)

**L1 步骤：**首帧目标窗做 log/归一化/余弦窗，有限扰动形成初始化样本，目标位置生成高斯期望响应；FFT 训练滤波器。下一帧在搜索窗相关，逆 FFT 找峰，解包环绕位移，算 PSR；可靠时更新位置并在新位置取窗，指数更新分子/分母；低可靠度冻结外观并触发失锁处理。

**L2 机制：**不是直接把模板当滤波器，而是学出对训练图产生期望尖峰的滤波器；输出最小二乘降低背景响应。余弦窗减少循环边界伪影但压低边缘目标。在线更新适应外观，错误更新会把背景学成目标。

**L3 工程权衡：**学习率 eta 无量纲，期望峰宽/搜索窗为 px，PSR 无量纲。先查框/中心/位移方向与响应峰，再正则、窗口和学习率；大 eta 适应快也更易漂移。PSR 门随目标/旁瓣定义校准，不能移植论文阈值或帧率为产线指标。单尺度本卡不显式估旋转/尺度。

**L4 推导：**约定 F_i=FFT(f_i)、G_i=FFT(g_i)、滤波频谱 H，相关 \(\hat g=F H^*\)。令 W=H*，各频率独立最小化
\(J(W)=\sum_i|F_iW-G_i|²+\lambda|W|²\)。对 W* 求导得
\((\sum_i|F_i|²+\lambda)W=\sum_iG_iF_i^*\)，故 W=A/(B+lambda)。lambda≥0 是本文明确的岭稳定化版本；原始无正则公式为 lambda=0，不把版本差别藏起来。

指数更新 \(A_t=(1-\eta)A_{t-1}+\eta G_tF_t^*\)，\(B_t=(1-\eta)B_{t-1}+\eta F_tF_t^*\)；必须分别更新统计再做比值，不能平均旧/新滤波器当等价。旧样本权重按 (1-eta)^k 衰减。PSR=(峰值-旁瓣均值)/旁瓣标准差，需排除峰周围区域；旁瓣标准差近零则分数不可信。P 像素窗每帧 FFT/IFFT 主成本 O(PlogP)，内存 O(P)，无通用跟踪误差界。

**L5 实现方案：**明确存 W 还是 H，避免两次共轭；FFT 循环位移超过半宽需减宽，奇偶中心和 `fftshift` 不可混用。锁定训练/推理归一化与余弦窗，方差零窗拒绝。PSR 低时不更新 A/B；重定位器/长期记忆不在本基线内，低 PSR 冻结不保证任意遮挡后找回。

```text
A,B = initialize_spectral_statistics(first_box)
for frame in sequence:
    F = FFT(preprocess(crop(frame,predicted_window)))
    W = A/(B+lambda)
    response = real(IFFT(F*W))
    displacement = unwrap_peak(response)
    confidence = PSR(response,excluded_peak_region)
    if not reliable(confidence): freeze_model; report_lost; continue
    position = position+displacement
    Fnew = FFT(preprocess(crop(frame,position)))
    A = (1-eta)*A+eta*G*conj(Fnew)
    B = (1-eta)*B+eta*Fnew*conj(Fnew)
```

**数值例：**单个频点 F=2、G=1、lambda=1，A=2、B=4，W=.4，响应频点 FW=.8；无正则 W=.5 得1。给旧 A=2/B=4，新 F=1/G=1、eta=.25，则 A'=1.75、B'=3.25，lambda=1 时 W'=1.75/4.25≈.411765。若空间峰10、旁瓣均值2/标准差2，PSR=4；这些单频数值不是完整图像跟踪结果。

**测试设计：**实空间直接循环相关与 FFT 对照、已知正负平移、越半宽解包、零纹理、分子分母更新算例、遮挡不更新、快速运动出窗；报告中心误差、失锁率/重获时长与耗时，不能引用论文帧率替代本机结果。

**追问链与答案：**L1「更新什么？」答：相关统计 A/B；L2「为何不是 NCC？」答：学习期望响应的判别滤波；L3「遮挡后漂移先调 eta？」答：先冻结不可靠更新/查 PSR；L4「闭式解？」答：复变量平方损失逐频点求导；L5「反向位移？」答：查共轭、相关/卷积、FFT 环绕及坐标。易错：平均滤波器等同统计更新、单尺度 MOSSE 等同任意尺度/旋转估计。

**来源状态：**2026-11-04 已获取作者原文可解析内容，核验相关式、预处理与 MOSSE 最小输出误差公式；在线更新/PSR 为论文所述机制，本文伪代码含明确门控与岭版本设计，未逐行复现作者代码，未训练/运行跟踪器。[cite:2](#source-2)

## T03 Lucas–Kanade 局部光流

**任务/前提/状态：**相邻灰度帧、局部特征窗 → 平移 (u,v)；小位移、亮度恒常、局部运动一致前提，无实现。金字塔扩展/稠密光流不作为已完成范围。

**L1 步骤：**计算空间梯度和时间差，在窗口累积正规方程，检查最小特征值/条件数，求位移；可参考迭代重采样直到位移增量小/次数上限，失败返回无效。

**L2 机制：**单像素亮度变化只有一条方程，两维运动欠定；窗口中不同梯度方向补充约束。平坦区无信号，直边只有法向，故角点更合适；遮挡时亮度对应根本不存在。

**L3 工程权衡：**窗半径 px、时间差 s，输出位移是 px/帧而非速度；先查亮度/遮挡/位移是否过大，再窗口。扩大窗口会混合运动，不是必优；金字塔可增捕获范围但需另验尺度回填。

**L4 推导：**\(I(x+u,y+v,t+dt)\approx I+I_xu+I_yv+I_t\)，亮度恒常得 \(I_xu+I_yv=-I_t\)。窗内 \(\min_d\|Ad-b\|²\) 得 AᵀAd=Aᵀb；rank(A)=2 才唯一，最小特征值与噪声放大有关。它与角点精化共享张量，但右端和输出任务不同。K 点单次 O(Kw²)，迭代另乘轮数。

**L5 实现方案：**统一梯度尺度/时间差与 warp 方向；位移加回原图时包含 ROI 和金字塔倍率。保留前后向检查作拒绝证据而非“确保正确”的证明。

```text
A = stack(window_Ix,window_Iy)
b = -window_It
if minimum_eigenvalue(A.T*A)<threshold: return invalid
flow = solve(A.T*A,A.T*b)
return flow,conditioning
```

**数值例：**A=[[1,0],[0,1]]、b=(2,-1)，解 flow=(2,-1) px/帧；dt=.02 s 时速度 (100,-50) px/s。只有第一行则 v 不可辨识。

**测试设计：**小平移、直边孔径、亮度变化、遮挡、快速运动、金字塔回填另立测试；无数据时不虚报光流精度。

**追问链与答案：**L1「输出速度？」答：先位移，除dt才速度；L2「为何窗？」答：提供独立方向；L3「大位移怎么查？」答：线性化失效，考虑金字塔另验；L4「正规方程？」答：亮度恒常泰勒最小二乘；L5「方向相反？」答：warp/时间差符号。来源状态：本文小位移模型推导，原始论文/软件内部未独立读取，L1–L3/L5 为方案部分。

## T04 门控后一对一全局指派

**任务/前提/状态：**预测轨迹、当前检测及协方差 → 匹配/未匹配列表；无本地实现。仅单帧关联优化，不称完整多目标跟踪器。

**L1 步骤：**用 T01 预测，为每对轨迹/检测算创新距离，门外设不可匹配；加入未匹配虚节点代价，解全局最小总成本一对一指派；更新匹配轨迹，未匹配分别丢失/候选新生。

**L2 机制：**全局指派避免逐条贪心抢占，运动门控排不可能跳跃；外观相似/交叉仍可能身份切换。出生/删除/遮挡记忆是轨迹生命周期，不等于指派本身。

**L3 工程权衡：**运动距离无量纲，外观/类别代价组合需校准，未匹配代价决定宁可丢失还是强配。先查检测和时间戳，再门控/代价，最后增加外观特征，勿用强制配满掩盖漏检。

**L4 推导：**对预测 i，r_ij=z_j-Hs_i^-、S_i=HP_i^-Hᵀ+R_j，\(c_{ij}=r_{ij}^TS_i^{-1}r_{ij}\)。若跨轨迹协方差不同，要作高斯负对数似然成本还需 logdetS 项；仅 D² 是明确近似选择。最小化 \(\sum x_{ij}c_{ij}\)，约束每行/列和≤1，x∈{0,1}，再加未匹配成本。匈牙利型稠密实现约 O(n³)，本文只指定优化目标/接入求解器，不冒称已经推导完整匈牙利算法。

**L5 实现方案：**不可匹配用掩膜/安全无穷代价，防任意大有限数导致被选中；空检测/空轨迹、矩形矩阵和 dummy 行列均需覆盖。公开单帧匹配模块没有轨迹 ID/生命周期，不能复用名字就称跟踪已成。

```text
cost,allowed = gated_costs(predicted_tracks,detections)
augmented = add_unmatched_options(cost,allowed)
assignment = solve_min_cost_one_to_one(augmented)
return matched,unmatched_tracks,unmatched_detections
```

**数值例：**成本 [[1,2],[1.1,100]]，按第一轨迹贪心选第一检测后总成本101；全局选交叉配对为2+1.1=3.1。若某交叉对被门控禁止，该解不合法，应重新考虑未匹配，不能忽略门控。

**测试设计：**该贪心反例、空/矩形矩阵、全门外、目标交叉、检测重复、长缺测；报告 ID切换/漏轨/重生，而非只看位置误差。

**追问链与答案：**L1「未匹配怎么办？」答：显式返回生命周期处理；L2「为何不用贪心？」答：3.1 对101反例；L3「总错配？」答：先检查门控与未匹配成本；L4「约束？」答：一对一与可不匹配；L5「无限大代价？」答：仍要核验求解结果合法。来源状态：本文指派问题定义与代数例，完整匈牙利实现/复杂度证明未展开。

## 跟踪组合与视觉引导边界

Kalman 可预测搜索窗，MOSSE/光流可提供位置观测，关联分配身份；这是一项**组合方案**，不等于上述四卡已组成可运行系统。MOSSE PSR 不天然等于观测噪声协方差 R，若需映射必须用独立残差数据校准。一次错误外观更新会污染后续观测，运动滤波无法无条件修复。

视觉引导还需相机-机器人坐标、时间同步、执行器/机械限位、通信超时、延迟与闭环稳定性。运动误差一阶可写位置滞后约 v×delay：100 mm/s、延迟 .05 s 可产生约5 mm位移；这是量纲练习，非实机数据。本文未实现控制律、手眼标定、机器人接口或安全停机，不以算法卡代替现场安全评审。
