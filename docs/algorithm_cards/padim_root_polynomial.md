## G19 PaDiM：逐位置多元高斯异常检测与定位

### 任务、演进与版本

**任务与输入输出。** 用同一产品／场景的正常训练图像拟合模型；推理输入同预处理、同坐标网格的图像，输出 patch Mahalanobis 距离图、映射到图像的异常热图及整图异常分数。需要二值结果时另加冻结的验证阈值。它没有缺陷类别语义头，也不输出“缺陷概率”。正常训练集必须覆盖预期合法外观；预训练 CNN 来自外部有监督数据，不应将“目标域只需正常图”说成完全没有监督或学习。[cite:1](#source-1)

**演进链。** 目标域重建网络需要优化，保留全部正常特征作近邻检索又使推理随训练集增长。PaDiM 固定预训练 CNN，拼接不同语义层并随机抽取特征维，在各位置用均值／完整协方差压缩正常样本。新增代价是逐位置高维统计及其正则化、几何依赖和骨干域差；它既不是 [D04 手工特征收缩评分](remaining_domains.md#d04-固定特征的收缩-mahalanobis-异常评分)，也不是 PatchCore 的共享记忆库／coreset 检索。新方法不全面替代重建和近邻路线。[cite:1](#source-1)

### L1 步骤：先建正常统计，再固定模型评分

1. 按产品、工位、采集批次拆分正常训练／验证及最终测试，保证同一工件不跨集合；冻结输入颜色顺序、缩放／裁剪、骨干预处理和位置索引。
2. 载入 ImageNet 预训练骨干并冻结参数。原文使用 ResNet18、Wide ResNet-50-2，另评估 EfficientNet-B5；ResNet 取前三个特征阶段，不是网络最前面的三个单独卷积算子。[cite:1](#source-1)
3. 将较粗层在空间上对应到最高分辨率特征网格，再沿通道拼接。记拼接结果为 `F[N,D,H,W]`，每个位置同时包含局部细节和大感受野上下文。特征网格不重叠不意味着 CNN 感受野不重叠。
4. 在训练前从 D 个通道选 d 个不同索引 J；该模型所有训练图、空间位置和推理图共享 J，并存入模型。选择的是嵌入维，不是随机丢图片、抽 patch 或为每张图重新抽样。固定一次无放回抽样是本文可复现契约，原文支持训练前随机特征选择。[cite:1](#source-1)
5. 对每个位置 p，仅沿 N 张正常图估计 `mu[p,d]` 和 `Sigma[p,d,d]`。完成所有位置的统计、正定检查及分解后结束拟合；没有目标域 CNN 的梯度迭代或 epoch 停止问题。N 小于 2、数据非有限或分解失败时拒绝出模型。
6. 推理复用全部配置和 J，计算各位置 Mahalanobis 距离 D；§III-C 的整图分数是 `max(D)`。§IV-B 使用双三次插值恢复定位图，并以 σ=4 的高斯滤波平滑。本文保留原始 patch 最大值为基础整图分数，若改取后处理图最大值须另立配置和阈值，不能假定二者相等。[cite:1](#source-1)
7. 若业务需要 OK／NG，用正常验证集或授权的独立验证方案标定阈值，随后冻结。原文的 AUROC／PRO 是评测方式，不会自动产生部署阈值；最终测试集不能用于定阈值。

**原文维度与参数核对。** §V-A／表 II 的 R18 全嵌入 D=448，比较 d=100、200；§V-B 的主对比为 R18-Rd100 与 WR50-Rd550。按常见对应阶段通道数，R18 为 64+128+256=448，WR50 为 256+512+1024=1792；后一个求和是架构布局说明，接入时仍须检查真实 hook 输出。原文默认 ε=0.01；MVTec AD 先缩放至 256×256 再中心裁剪至 224×224，STC 只缩放至 256×256；图像和定位图使用 bicubic，热图 σ=4。原论文比较 10 次随机模型并平均评测，不等于部署时必须集成十个模型。[cite:1](#source-1)

### L2 机制：相关性、位置与降维分别解决什么

| 步骤 | 因果机制 | 删除／替换的后果 |
|---|---|---|
| 固定预训练多层表示 | 复用已有视觉表征；浅层有定位细节，深层有上下文 | 仅用最深层可能使小缺陷被下采样淹没；重训骨干后旧统计不再匹配 |
| 拼接后拟合完整协方差 | 非对角项保留跨通道、跨层相关性 | 每层单独评分后相加相当于另一模型，丢掉跨层相关；对角化也不是原完整高斯 |
| 在每个位置跨图拟合 | 位置先验区分“此处正常”与“别处正常” | 将 N、H、W 混合成一个总体会接受出现在错误位置的正常零件，也改变检测任务 |
| 随机维度选择 | 降低二次存储和三次分解成本；不要求保留最大正常方差方向 | PCA 按正常方差排序，不保证保存异常敏感方向；原文的随机优于 PCA 是特定数据消融，不是普遍定理 |
| εI 与 Mahalanobis | 防止零／极小方差导致不可逆；按正常变化尺度衡量偏离 | ε 过大时趋近缩放欧氏距离，弱化相关性；ε 过小则低方差方向爆分 |

以上核心机制由 §III 与 §V-A 支持。[cite:1](#source-1) 条件反例：若两个正常通道总是同步增大，单看每通道都落在正常范围仍可能掩盖“一个大一个小”的异常；非对角协方差可以放大这种反相关偏离。反之，正常分布若本来有多个分离模式，用一个高斯包住各模式可能把中间未出现过的特征也当正常。

逐位模型有对齐敏感性，但不能简化成“必须绝对配准，否则不能运行”：原文有 Rd-MVTec AD 的旋转／裁剪评估。该评估不是任意旋转平移不变性的证明，生产中应测合法姿态范围；对齐、扩大正常姿态覆盖、按工位拆模型都是需验证的工程方案。[cite:1](#source-1)

### L3 工程权衡：量纲、诊断与调参顺序

| 项目 | 量纲／候选依据 | 代价、症状与诊断 |
|---|---|---|
| d 与骨干 | d 为通道数量，先从原文 R18 的 100／200 对照而非宣称最优 | 存储／评分约按 d² 增长，分解按 d³；比较小缺陷召回、位置误报与峰值内存 |
| ε | 特征坐标下的方差单位，0.01 是原配置，不是跨骨干常数 | 保存最小特征值、条件数及失败位置；变更归一化或骨干后须重新选择 |
| 输入尺寸、裁剪和网格 | 像素；标准 R18 在 224 输入下前三阶段通常为 56、28、14 网格 | 裁剪可直接丢边缘缺陷；原图恢复只能覆盖保留 ROI，未观测区域须标无效 |
| 平滑 σ | 后处理图像像素，原文 σ=4 | 热图视觉更平滑但可抹掉微小峰、改变最大值；保存平滑前后图作对照 |
| 正常样本 N | 图像数，同时看批次／姿态覆盖，不只总数 | N≤d 时无正则样本协方差必秩亏；重复近邻帧多不等于独立有效样本多 |
| 阈值 τ | Mahalanobis 距离无量纲，但随模型变化 | 以目标误报率和独立验证分位定候选；像素阈值与整图阈值分开校准 |

**诊断顺序。** 先查工件 ID 泄漏、污染、RGB/BGR、预处理和 ROI 坐标，再查 J 与 hook 层一致性、协方差条件数，再对照 d／ε／平滑，最后调阈值。若只有正常数据，可以估误报，不可声称已估未知缺陷召回；要验证小缺陷，需真实缺陷、像素标注和尺寸分桶。在线自动吸收被判正常的样本有污染风险，本文不设计默认在线更新。

未提供通用理论检出率或定位误差上界；域差、异常在特征中不可分、正常多峰和图像信息损失都不由矩阵可逆性消除。当前没有本仓库耗时、显存、AUROC、PRO 或现场节拍结果。

### L4 推导：逐位估计、距离与退化

令 p 为固定网格位置，`x[n,p,:]` 为选维后的 d 维向量。假设该位置正常样本来自一个多元高斯，而不是假定不同位置的物理随机过程彼此独立。PaDiM 对各位置分别估参，不拟合位置间联合协方差。[cite:1](#source-1)

\[
\mu_p=\frac1N\sum_{n=1}^N x_{np},\quad
S_p=\frac1{N-1}\sum_n(x_{np}-\mu_p)(x_{np}-\mu_p)^T,\quad
\Sigma_p=S_p+\epsilon I.
\]

从高斯似然对均值求导得样本均值。无约束协方差的极大似然分母是 N；论文采用 N−1 的样本协方差并加 εI，不能称这一整式为无正则高斯 MLE。中心化样本矩阵秩至多 min(d,N−1)，所以 N≤d 时 S 必奇异；ε>0 且 S 为精确半正定时，任意非零 v 都有 \(v^T\Sigma_pv\ge\epsilon\|v\|^2>0\)。这只保证代数正定，不保证统计模型正确或浮点实现安全。

高斯负对数密度为：

\[
-\log f_p(x)=\tfrac12\left[(x-\mu_p)^T\Sigma_p^{-1}(x-\mu_p)+\log\det\Sigma_p+d\log(2\pi)\right].
\]

定义 \(D_p=\sqrt{(x-\mu_p)^T\Sigma_p^{-1}(x-\mu_p)}\)，即论文式 (2)。固定 p、固定模型时，D、D² 与负对数密度有相同排序；**跨位置时 log det 不同，PaDiM 的距离图不是完整负对数似然图**，不能将整图 `max(D)` 解释为联合高斯概率。[cite:1](#source-1)

数值求解令 \(\Sigma_p=L_pL_p^T\)，解 \(L_pu=x-\mu_p\)，则 \(D_p=\|u\|_2\)。这是与显式逆在精确算术下等价的工程实现，不是改变评分。若 \(S=Q\operatorname{diag}(\lambda_i)Q^T\)，则

\[
D^2=\sum_i\frac{[Q^T(x-\mu)]_i^2}{\lambda_i+\epsilon}.
\]

该式说明正则强度如何压低低方差方向的贡献。若输入特征统一乘 a，均值乘 a、样本协方差乘 a²；要维持同一 D，还需 ε 同乘 a²。固定 ε 时不能声称任意特征缩放不变。已知真实高斯参数时才有相应 D² 的卡方解释，有限样本估参、选维和最大值聚合后不能直接把卡方分位当可靠业务阈值。

令 P=H×W，忽略 CNN 成本：批量均值／协方差约 O(NPd²)，分解 O(Pd³)，每图评分 O(Pd²)，模型存储 O(Pd²+Pd+d)。推理不直接依赖 N，但仍随 P、d 和骨干增长。流式估计可避免 O(NPd) 特征缓存；它不能降低逐位完整协方差的 O(Pd²) 基本存储。

### L5 复现设计：数据布局与失败返回

本仓库 Python 源文件检索没有 PaDiM 专用实现；[dl 路线说明](../../dl/README.md)不构成本模型已接入。以下是参考伪代码，未执行。`align_features` 采用固定空间对应映射；最近邻扩展粗层是本文明确的实现选择，不能把原文“图像／定位图 bicubic”误套为每层特征也必须 bicubic。真实复现必须记录各层映射并与参考逐点对照。

```text
FIT(normal_train, cfg):
    require N >= 2 and all_images_finite(normal_train)
    backbone = frozen_pretrained_backbone(cfg.weights, eval_mode=True)
    J = sample_without_replacement(D, cfg.d, cfg.seed)
    count, mean[P,d], M2[P,d,d] = empty_statistics()
    for image in normal_train:
        maps = backbone(preprocess(image, cfg))
        F = concatenate_channels(align_features(maps, cfg.grid_map))
        x[P,d] = select_and_reorder(F, J, p_order="row_major")
        require finite(x) and expected_shape(x)
        update_welford_per_position(count, mean, M2, x)
    S = M2 / (N - 1)
    Sigma = symmetric_part(S) + cfg.epsilon * identity(d)
    L = cholesky_per_position_or_fail(Sigma)
    return model(cfg, J, mean, L, roi_transform)

SCORE(image, model):
    x = extract_with_same_weights_preprocess_grid_and_J(image, model)
    require finite(x) and matching_layout(x, model)
    u = batched_lower_triangular_solve(model.L, x - model.mean)
    D = reshape(norm(u, axis="feature"), H, W)
    image_score = max(D)
    heat = gaussian_filter(bicubic_resize(D, cropped_image_size), model.sigma)
    return image_score, restore_to_observed_roi(heat), validity_mask
```

流式更新必须保持：新增样本前 \(\delta=x-\mu_n\)，更新 \(\mu_{n+1}=\mu_n+\delta/(n+1)\)，再累积 \(M_{2,n+1}=M_{2,n}+\delta(x-\mu_{n+1})^T\)。不能错用新均值计算两个残差，也不能把 batch 维和位置维一起归约。建议统计与分解先用 float64；低精度 CNN 输出转高精度不能恢复其已丢失信息。

模型需序列化权重标识／哈希、库版本、hook 名、RGB 归一化、J 的实际有序索引、输入／网格尺寸、位置顺序、ε、平滑参数、ROI 变换及阈值版本。只存 seed 不足以跨随机库版本重建 J。NaN、形状不符、严重非对称、Cholesky 失败返回模型／输入无效，不能静默把分数置零。增大 ε 的重试若使用，必须有上限并记录新模型配置。

**优化约束。** 先剖析 CNN、统计、分解、评分和后处理；可分块位置、批量三角求解、流式统计和缓存分解。抽小 d、对角协方差、删层、换插值都是模型变更而非严格等价优化；比较应固定权重、J、数据划分，既验分数误差也验排序、阈值附近翻转及峰位置。

## G34 Root-Polynomial：保持曝光缩放的颜色校正

### 任务、演进与版本

**任务。** 输入同一相机／处理链在已知条件下的线性、黑电平已校正、非负且未饱和 RGB 色块，与相同色块的参考 XYZ；拟合从 RGB 到 XYZ 的固定映射，推理时逐像素应用。XYZ 数值尺度、白点、观察者、光源谱和曝光配对须明确。直接将 gamma 编码 JPEG、Lab 或经过任意局部色调映射的数值当原始 RGB，不满足本文曝光证明的物理前提。[cite:4](#source-4)

**版本。** Graham D. Finlayson、Michal Mackiewicz、Anya Hurlbert，Color Correction Using Root-Polynomial Regression，IEEE Transactions on Image Processing 24(5)，2015，1460–1470，DOI 10.1109/TIP.2015.2405336。UEA 作者接受稿题名使用英式 Colour；Newcastle 记录在线 2015-02-24、纸本 2015-05-01、接受 2015-02-02。接受稿正文旧版权模板中的 2013 不作为方法发表年；机构入库／页面更新时间也不作为方法年代。Newcastle 作者元数据次序与稿首不同，本文采用稿首 Finlayson、Mackiewicz、Hurlbert 次序。[cite:4](#source-4)[cite:5](#source-5)

**演进链。** [P35 线性 3×3 校正](preprocessing.md#p35)容易拟合并保留曝光线性缩放，但非 Luther 条件的相机与真实反射谱可产生颜色误差。普通多项式 PCC 提高表达能力，却混有一次、二次、三次项，曝光变化时缩放不同。RPCC 对每个 k 次单项式取 k 次根，使所有保留项一次齐次，仍用线性系数组合拟合。新增代价为更多参数、色度采样需求和近坐标轴的噪声敏感性；它不能恢复同色异谱丢失的信息，也不等于光源估计、白平衡、ICC 或任意光源下颜色恒常性。[cite:4](#source-4)

### L1 步骤：基项扩展、拟合、应用

1. 固定相机、镜头、RAW 处理、黑电平、光源与参考测色条件；去除无效／饱和色块，将 RGB 与参考 XYZ 按色块 ID 一一配对。测试色块／实物与训练选择分开。
2. 选择最高原单项式次数 K。原文列出 K=2、3、4 的去重根基，长度分别为 6、13、22，包含低阶项，不含截距常数。[cite:4](#source-4)
3. 按固定顺序构建设计矩阵 A，行是色块、列是基项。使用同一辐射尺度；不逐像素按自身最大通道归一化而不恢复亮度。
4. 求 RGB 根基到 XYZ 的回归系数 B。最小二乘一次分解即结束；若秩／条件数不合要求，拒绝或采用明确记录的正则化／较低阶模型，而不是增加迭代等待。
5. 用独立留出数据选择 K 和正则强度，再固定 B。对新图先按同一契约校正黑电平、线性化和检查有效域，然后应用相同基项及 B；输出 XYZ 与有效性标记。
6. 若需要显示，再独立执行 XYZ 到显示色空间、色域处理和编码。显示截断会改变齐次性及颜色误差，不能回头把显示图当线性映射的验证对象。

**具体基项。** 令 \(x=(r,g,b)^T\ge0\)。以下按接受稿 §III 顺序记录；二至四阶是“根号内原单项式的最高次数”，不是最终齐次次数。[cite:4](#source-4)

\[
\phi_1(x)=(r,g,b)^T,
\quad\phi_2(x)=(r,g,b,\sqrt{rg},\sqrt{gb},\sqrt{rb})^T.
\]

\[
\phi_3(x)=\left(\phi_2(x)^T,
\sqrt[3]{rg^2},\sqrt[3]{gb^2},\sqrt[3]{rb^2},
\sqrt[3]{gr^2},\sqrt[3]{bg^2},\sqrt[3]{br^2},\sqrt[3]{rgb}\right)^T.
\]

\[
\phi_4(x)=\left(\phi_3(x)^T,
\sqrt[4]{r^3g},\sqrt[4]{r^3b},\sqrt[4]{g^3r},
\sqrt[4]{g^3b},\sqrt[4]{b^3r},\sqrt[4]{b^3g},
\sqrt[4]{r^2gb},\sqrt[4]{g^2rb},\sqrt[4]{b^2rg}\right)^T.
\]

数量为 3、6、13、22。纯幂开根后重复，例如非负域内 \(\sqrt{r^2}=r\)；\(\sqrt[4]{r^2g^2}=\sqrt{rg}\)，均只保留一次。因此不要用普通 PCC 的 9／19／34 列，不要额外添加常数 1 或重复根项。概括集合应写 \(1\le|\alpha|\le K\)，再对 \(\alpha/|\alpha|\) 去重；直接照抄省略下界的集合会把 \(|\alpha|=0\) 引入除零。上式及去重的合法性以非负域为前提。[cite:4](#source-4)

### L2 机制：曝光等变不是亮度不变

普通 PCC 中 \(r\mapsto ar\)，\(rg\mapsto a^2rg\)，固定系数组合因此一般不满足 \(f(ax)=af(x)\)。RPCC 对次数 k 的项取 k 次根，统一缩放为 a 倍；**模型参数不用因为标量曝光而改变，但输出 XYZ 仍应随曝光变化**。更准确的数学词是正一次齐次／曝光缩放等变，而非 \(f(ax)=f(x)\)。只在有效 XYZ 的色度归一化有定义时，其归一化色度才保持不变；黑色处色度未定义。[cite:4](#source-4)

为什么不直接用一次线性模型？RPCC 对输入颜色仍是非线性的，例如 \(\sqrt{rg}\) 改变不同色度之间的曲面形状，因此表达力超过线性 3×3，但仍保留同一色度射线上的线性亮度关系。为什么不加偏置？若 \(f(x)=B^T\phi(x)+c\)，则 \(f(ax)-af(x)=(1-a)c\)，除 c=0 等特殊情形外破坏齐次性。

光源谱变化不是同一标量曝光：不同波长重新加权会改变 RGB 通道比例，原映射没有无条件泛化保证。曝光证明也不适用于饱和、非线性相机响应、黑电平偏置未减、自动白平衡随曝光变化或强局部色调映射。对非负 RGB 定义映射不代表输出 XYZ 必非负，拟合系数可含负数；无约束回归不会自动保证物理可实现色域。[cite:4](#source-4)

### L3 工程权衡：采样、正则和负值边界

| 项目 | 参数尺度／选择依据 | 失效表现与排查 |
|---|---|---|
| K／m | K=1／2／3／4，对应 m=3／6／13／22；由留出色块决定 | 更高阶训练残差下降不等于泛化提高；比较同一曝光／跨曝光和高饱和色块尾部误差 |
| 训练色度覆盖 | 至少 m 个样本仅是满列秩的必要条件之一 | 只改变同一色块曝光仍只有同一特征方向，无法提供全部色度约束；检查奇异值与覆盖 |
| 岭系数 λ | 若目标为平方残差和＋λ范数，λ 与 AᵀA 同尺度 | 改 RGB 单位或样本权重后 λ 不应盲搬；先定预处理／尺度，再选正则 |
| 黑电平／噪声 | 输入辐射单位、传感器 DN 或约定归一尺度 | 暗部负值、偏置和低信噪比可能让根项不可定义或放大噪声，先看暗帧与色块分布 |
| 目标误差 | XYZ 残差与感知色差不同；白点、亮度归一必须说明 | 不能把 XYZ 最小二乘说成直接最小化 ΔE；只报训练平均误差会隐藏最差色块 |
| 有效曝光范围 | 线性、非饱和、相同光源谱的采集区间 | 一旦饱和／自动处理改变，不靠扩大 K 或降低 λ 恢复丢失信息 |

**负值边界必须显式选择。** 原接受稿 §III-A 用传感器值 0 到 1 作理论说明，§III 的实根基没有为任意负 RGB 规定完整延拓。黑电平扣除后带噪值可以为负，这不应被默认为论文已覆盖的输入域。[cite:4](#source-4)

- 本卡默认严格域：任一 RGB<0 即标无效／排除训练色块，记录负值数量及位置；不以最终输出全是有限数作为有效性标准。
- 对偶数根，负被开方数没有实值，例如 r<0、g>0 时 \(\sqrt{rg}\) 无实数解；两个负数乘积虽正，也不能使整个负 RGB 向量自动满足原域。对奇数根可取实立方根，但编程语言通用 `pow(negative, 1/3)` 未必给实值，而且这解决不了二阶／四阶项。
- 简单裁到零 `max(x,0)` 是工程改造，会改变观测与噪声偏差。它对 a≥0 本身仍满足 `clip_lower(ax)=a*clip_lower(x)`，所以不能笼统说“所有裁剪都破坏齐次性”；但传感器上限裁剪、固定正数 floor、加 δ 后开根通常不满足。数学缩放成立也不等于校正准确。
- Colour v0.4.6 的实现使用 \(\operatorname{spow}(z,p)=\operatorname{sign}(z)|z|^p\)（启用时），这是现代库的有符号延拓，不是偶数实根。其符号策略可以保留正标量齐次性，却不证明负相机响应的颜色学有效性。采用时必须作为独立变体标名、重新拟合及验证，不能称原稿明确支持。[cite:6](#source-6)
- 0 是函数值的合法边界，根项可为 0；但并非处处光滑。\(\partial\sqrt{rg}/\partial r=\tfrac12\sqrt{g/r}\) 在 r→0⁺、g>0 时发散，不能因没有除法就声称暗部稳定。

原文讨论的“负幂不稳定”是另一件事：如 \(r^2g^{-1}\) 同样一次齐次，但 g→0 时会爆炸；它不是对“负 RGB 已获支持”的证明。[cite:4](#source-4) 调参顺序应为采集／线性化与参考配对 → 非负／饱和有效域 → 训练色度覆盖／矩阵条件数 → K／λ → 独立曝光及相机验证。

### L4 推导：齐次、回归、可辨识性与敏感性

对非负整数多重指标 \(\alpha=(\alpha_r,\alpha_g,\alpha_b)\)，令 \(k=|\alpha|\ge1\)，定义：

\[
\psi_\alpha(x)=(r^{\alpha_r}g^{\alpha_g}b^{\alpha_b})^{1/k}.
\]

对 a>0、x≥0，有

\[
\psi_\alpha(ax)=(a^k x^\alpha)^{1/k}=a\psi_\alpha(x),
\quad \phi_K(ax)=a\phi_K(x),
\quad f(ax)=B^T\phi_K(ax)=af(x).
\]

a=0 时由连续定义得 \(\phi_K(0)=0\)，同样成立；a<0 没有物理曝光意义，也不在原非负定义域保证内。若参考真值也随曝光乘 a，则 XYZ 误差向量也乘 a，不能由此声称绝对 XYZ 误差数值不变；归一化后的色度／感知评测还依赖所选白点和亮度约定。以上是对原文缩放解释的条件化推导。[cite:4](#source-4)

令 A∈R^(N×m)，第 i 行为 \(\phi_K(x_i)^T\)；Y∈R^(N×3) 为 XYZ，B∈R^(m×3)，预测 \(\hat Y=AB\)。最小二乘目标及驻点为：

\[
\min_B\|AB-Y\|_F^2,\qquad
\nabla_B=2A^T(AB-Y)=0,\qquad B=A^+Y.
\]

只有 A 满列秩时才可用 \((A^TA)^{-1}A^TY\) 的闭式表达；实际优先 QR／SVD，避免正规方程平方条件数。原文以列样本和 M 表示 3×m 矩阵，本文 \(M=B^T\)，两者布局不同但映射一致。原文 §II 给 Moore–Penrose 拟合并讨论正则，本文显式岭形式是复现选择，不声称作者实验采用本文某个固定 λ。[cite:4](#source-4)

\[
\min_B\|W^{1/2}(AB-Y)\|_F^2+\lambda\|B\|_F^2,
\qquad (A^TWA+\lambda I)B=A^TWY.
\]

W 为固定非负样本权重，λ≥0；λ>0 时左侧正定。可通过增广系统 \([W^{1/2}A;\sqrt\lambda I]B\approx[W^{1/2}Y;0]\) 做 QR／SVD。正则限制系数但不新增常数项，固定 B 下的曝光齐次性仍成立；“用整体放大后的数据重新拟合且保持同一个 λ”则不是必然得到同样的 B，不能混淆推理性质与估计过程的尺度性质。

**函数基独立不等于有限样本满秩。** 对去重后的分数指数，取根次数公倍数 L，代换 r=u^L、g=v^L、b=w^L，所有基函数成为不同的整数指数单项式；在正开域上这些单项式线性独立，支持原文的函数基论证。可是若样本都在同一颜色射线 \(x_i=a_i x_0\)，则 \(A_i=a_i\phi(x_0)^T\)，rank(A)≤1。即使样本很多、函数基理论上独立，也无法辨识 m 个系数。K≥2 时仅用灰阶也有同类退化。[cite:4](#source-4)

**敏感性。** 正内域有 \(\partial\psi_\alpha/\partial x_j=(\alpha_j/k)\psi_\alpha/x_j\)（α_j=0 时该偏导为零）；小扰动局部满足 \(\delta f\approx B^TJ_\phi\delta x\)。因此噪声放大同时受系数范数、颜色所处位置及设计矩阵条件数影响。在坐标轴边界 Jacobian 可能不存在或无界，没有覆盖黑色、强噪声、饱和和任意光谱变化的统一色差上界。

计算成本：给定基项每样本约 O(m) 扩展，密集 QR／SVD 拟合在 N≥m 下约 O(Nm²+m³)，单像素映射 O(3m)，模型 O(3m)。K 增大并非免费；向量化或按像素分块可保持同一模型，降阶、截断输入或 LUT 近似则必须重新验证。

### L5 复现设计：固定基项顺序和严格输入域

当前没有本仓库 RPCC 专用函数、校准数据或运行记录；P35 是线性方法卡，不是本方法源码。以下为未执行的参考伪代码。实际依赖、相机解码与参考颜色转换需接入时另核；不因查阅 Colour 源码而宣称仓库安装了该库。

```text
EXPAND_STRICT(rgb[...,3], K):
    require K in {1,2,3,4}
    require finite(rgb) and all(rgb >= 0)
    t = max(rgb, axis="channel", keepdims=True)
    u = divide_where_t_positive(rgb, t, zero_else=True)
    basis = ordered_unique_exponents_from_document(K)
    phi = stack(product_of_nonzero_exponent_powers(u, alpha / sum(alpha))
                for alpha in basis)
    return t * phi

FIT(rgb[N,3], xyz[N,3], K, lambda, weights):
    require paired_ids and fixed_units_and_preprocessing
    require nonnegative_finite(lambda, weights) and finite(xyz)
    A = EXPAND_STRICT(rgb, K)
    require weights.shape == (N,) and any(weights > 0)
    A_weighted = sqrt(weights)[:, None] * A
    rank, singular_values = inspect_svd(A_weighted)
    if lambda == 0 and rank < number_of_columns(A): return UNIDENTIFIABLE
    A_aug, Y_aug = weighted_ridge_augmented_system(A, xyz, lambda, weights)
    B = least_squares_by_qr_or_svd(A_aug, Y_aug)
    return model(B, K, basis_order, units, black_level, domain_policy, metadata)

APPLY(rgb, model):
    valid = finite_nonnegative_unsaturated_mask(rgb, model)
    xyz[valid] = EXPAND_STRICT(rgb[valid], model.K) @ model.B
    xyz[not valid] = INVALID
    return xyz, valid
```

秩与条件数应检查加权有效设计矩阵，而非加权前的 A。全部零权重必须拒绝；正则项令增广系统有唯一解不等于数据本身可辨识，需在模型元数据中分别记录有效秩和正则强度。例如一阶单位 RGB 三样本配权重 [1,0,0] 时，A 满秩但加权后秩为 1，无正则不得报告三通道校准已确定。

这里每像素先取 t=max(r,g,b)，在 u=x/t 上计算根基，再乘回 t，是避免先算高次乘积溢出／下溢的代数等价实现；**不是丢掉 t 的色度归一化模型**。t=0 分支直接返回全零，幂指数为零的通道不参与乘积，不让 0⁰ 的库约定决定结果。正内域还可用对数求乘积，但零值需单独处理；极小通道下的数值损失仍须测。

应保存基项顺序、输入 RGB 顺序及尺度、K、B、λ、权重策略、求解器精度／秩阈值、黑电平、饱和上限、负值策略、参考 XYZ 尺度／白点／观察者／光源和验证划分。B 的转置错误可不触发形状异常而产生错误颜色，至少核对单色块向量和整图通道次序。

输出 XYZ 可为负或超出显示色域，应标记并单独报告；不能静默截断后再声称拟合残差或曝光测试通过。若采用 signed-power、低端裁零或特殊暗部模型，应在模型 ID 中区分，并对训练与推理采用完全相同策略。优化前后要固定同一 B、输入和有效域，比较各基项、XYZ、曝光残差及边界样本；仅图像视觉近似不足以证明等价。
