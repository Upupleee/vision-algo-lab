# 研究笔记

## 1. Zernike 矩亚像素边缘（TODO）

Ghosal & Mehrotra, "Detection of Edges via Zernike Moments", IEEE Trans. IP, 1993。

已验证的问题（本仓库试验记录）：
- 纯理想阶跃（σ=0）在整数采样网格上，7×7 窗口内容只随边缘位置离散变化，
  A20/|A11| 无法给出连续亚像素估计；
- 对模糊边缘（σ≥0.5px），A20/|A11| 同时依赖边缘位置 l 和模糊宽度 σ，
  不做模糊补偿时误差可达 ~0.5px。论文用 A31 矩联合估计 (l, σ)，
  实现时需要精确推导归一化常数。
- 结论：在完成 A31 补偿推导前，二维亚像素边缘使用 Devernay 法
  （`traditional/subpixel/edge_subpixel.devernay_edges`）。

## 2. 各种亚像素方法精度参考（合成数据，σ=1.2，无噪声）

| 方法 | 误差 |
|------|------|
| 梯度抛物线插值（1D） | ~0.02 px |
| erf 剖面拟合（1D） | ~0.001 px |
| Devernay 梯度抛物面（2D） | ~0.05 px |

注意：噪声增大时 erf 拟合仍最稳；抛物线法对噪声更敏感，适合高速场景。

## 3. 半像素约定陷阱（已踩坑）

cv2.cornerSubPix 在完美棋盘上会把 Harris 角点精确移到 (-0.5, -0.5) 偏移处——
这不是 bug：4 个方块交界位于像素角上（连续坐标 = 格边长·n - 0.5），
而直觉真值常写成格边长·n（像素中心约定）。构造合成数据的角点真值时
必须用 `c·cell - 0.5`，否则会误判亚像素角点算法有 ~0.7px 系统偏差。

## 4. 双三次插值过冲会偏置梯度类亚像素方法（已踩坑）

棋盘格经 `warpPerspective(INTER_CUBIC)` 重采样后，白块边缘产生 >255 的
过冲并被 uint8 截断，梯度场不对称 → cornerSubPix 出现 ~0.9px 系统偏差。
合成数据应使用 INTER_LINEAR，或在 float 域保留过冲不做截断。

## 5. 对焦曲线模型（已踩坑）

用 `sigma(z) = σ₀ + k|z - z_focus|` 生成对焦序列时，真值处存在尖点（导数
不连续），三点高斯/抛物线拟合会产生 ~0.5px 的系统性偏差。应使用几何
离焦模型 `sigma(z) = sqrt(σ₀² + k²(z-z_focus)²)`（模糊圆直径 ∝ |Δz|，
MTF 平滑过渡），评分曲线处处光滑，拟合才无偏。注意 σ₀ 过小会使近焦区
曲线过平（评分差被噪声淹没），σ₀/k 取值需保证峰邻域评分变化 > 10%。
