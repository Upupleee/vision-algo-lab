## 旋转／尺度 ZNCC（2026-10-30）

复现：`python -B -W error -m tests.benchmark_pose_ncc`，输出 JSON。

环境：Windows 10 build 19045、Python 3.12.14、NumPy 2.5.4、SciPy 1.18.1、OpenCV 5.0.0。未使用 GPU。耗时为本机观测，不是设备节拍承诺。

数据为明确构造的合成测试，不是产线采样：图像 145×181，模板 33×41，种子 731/732/733。通过独立逆向仿射采样生成目标，不调用匹配器的模板变换函数。每个种子预热一次、重复三次；表中时间取九次调用的中位数，包含模板变换与搜索。

标准搜索：角度 [-30°,30°]、步长 15°；尺度 [0.8,1.2]、步长 0.2，共 15 个姿态；3 层空间金字塔，默认全分辨率复核。得分阈值 0.8，单目标分差阈值 0.03，多目标关闭分差拒识。匹配成功判定要求中心欧氏误差 ≤2 px、角误差 ≤7.5°、尺度绝对误差 ≤0.1，并以一对一分配统计目标。

细步长场景：角度 [5°,20°]、步长 2°，尺度 [1.05,1.2]、步长 0.025，共 63 个姿态，真值仍不在采样点上。它是已知搜索范围内的调参对照，不是自动粗到细姿态优化，也不是独立泛化验证。

全部 30 个场景中，应检目标 27 个，返回正确目标 24 个，漏检 3 个（11.1%），误检 0 个；歧义场景按“应拒识”任务统计，不将其两个实体计入应检目标。漏检均来自故意设置过粗采样的场景，已保留失败结果而非通过降低阈值掩盖问题。样本量很小，不能据此声称产线零误检。

回归验证：`python -B -W error -m unittest tests.test_pose_ncc`，37/37 通过；原冒烟测试 8/8 通过。包括有限性、极端亮度、常量邻窗、近距离目标、掩膜、边界、非法参数和高频纹理金字塔漏检复现。耗时不是单元测试断言。

结论：已形成可复现的姿态匹配与拒识基线，但离散采样存在精度／耗时权衡。默认全图复核保证不因粗层候选截断丢失单姿态最佳位置，但不是连续姿态或所有可能多目标的全局最优保证。快速模式不具备同等搜索完整性。尚缺真实产线图片、设备节拍验证、自动姿态精化和跨算法对比。
