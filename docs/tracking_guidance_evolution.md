# 跟踪、运动与视觉引导：方法演进与工程实践双线总览

[文档导航](README.md) · [编写与学习规范](algorithm_learning_standard.md) · [跟踪卡片索引](algorithm_cards/README.md#其余领域) · [标定坐标](calibration_coordinates.md) · [三维重建测量总览](3d_evolution.md)

## 1. 范围、结论与状态口径

本域的持续优化对象是**状态与观测模型、数据关联、时序估计、遮挡重定位、坐标同步、延迟和闭环稳定性**。本文用方法演进线解释九个代表节点的瓶颈、机制和代价，用工程实践线说明选型、诊断、验收与安全边界；不把“单帧定位 → 深度跟踪 → 机器人控制”误写成自动成立的升级链。

跟踪估计回答“目标现在或未来在哪里”，关联回答“这个观测属于谁”，控制回答“设备应施加什么动作”。Kalman 的估计模型、Kuhn 的指派问题和视觉伺服的控制律分别处理这些任务，SORT 等系统把前两者组合，并不因此获得控制稳定性。[cite:1](#source-1)[cite:2](#source-2)[cite:5](#source-5)[cite:9](#source-9)

**核对日期：2026-11-04；仓库基准：HEAD `918a03e` 加当日工作树。** T01–T04 有教学正文但均未实现；没有视频跟踪器、完整 MOT 生命周期、机器人控制接口或闭环安全测试。现有二维 ZNCC 只是潜在观测／重定位前置，不是轨迹；公开模型和论文实机结果不是本仓库实测。本文不宣称通用帧率、跟踪精度、稳定收敛或安全等级。

**必要回链本地同步：2026-11-06。** G45／G46由[SO01](algorithm_cards/sort.md#so01)／[SI01](algorithm_cards/siamfc.md#si01)、G47／G48由[DS01](algorithm_cards/deep_sort.md#ds01)／[BT01](algorithm_cards/bytetrack.md#bt01)承接，原五层、P2及未实现边界不变。本轮[G44](algorithm_cards/ftp_hybrid_servo.md#g44)原守卫／初值／变增益辨识已有，机制缺卡转已有；本域九节点为已有9、部分0、缺卡0、非算法0。**G44证明一致性与采样安全仍独立P0、不降级**；训练／权重、依赖／视频缺口不清除，原来源和历史验证不冒称本轮实测。

深度方法不是全部替代：SiamFC 改变外观相似性表示，Deep SORT 加入学习外观距离，ByteTrack 重点改变低分检测的关联使用方式；它们与运动模型、几何门控、时间同步和安全监控可组合。单目标框、身份轨迹、相机运动和机器人动作是不同输出。[cite:6](#source-6)[cite:7](#source-7)[cite:8](#source-8)

## 2. 核心维度与分支地图

### 2.1 跟踪引导领域核心维度

| 核心维度 | 必须回答的问题 | 应记录的证据 |
|---|---|---|
| 状态与观测模型 | 估计像素位置／框／姿态／速度中的哪些量？观测如何生成？ | 状态量纲、测量时间、动力学／噪声假设、预测与校正标志 |
| 数据关联 | 是首帧指定对象、特征点身份还是多目标 ID？允许不匹配吗？ | 运动门、外观距离、代价矩阵、拒配／出生／删除原因 |
| 时序估计 | dt 是否真实？滤波与未来预测是否分开？ | 创新、协方差、丢帧／乱序、观测年龄、预测时间跨度 |
| 遮挡重定位 | 何时冻结更新、宣布丢失、重新检测和确认身份？ | 响应峰、更新掩膜、失锁次数、重获时长与错误重获 |
| 坐标同步 | 像素、相机、工具、基座与编码器时间如何对应？ | 标定版本、变换方向、单位、时钟偏移／漂移与同步记录 |
| 延迟与闭环稳定性 | 感知到执行的延迟、抖动、限幅与执行器动态如何影响反馈？ | 端到端时序、误差／命令／反馈、超时、饱和、停机与恢复记录 |

维度来自[领域规范](algorithm_learning_standard.md#一领域层先建立演进核心主线)。轨迹更平滑可能只是滤波滞后增加，ID 指标更高也不等于机械动作更安全；验收必须逐层对应任务。

### 2.2 三类任务与工程接口

| 分支 | 输入 → 处理 → 输出 | 不包含的能力 |
|---|---|---|
| 跟踪 A：状态估计 | 已关联位置观测＋时间戳 → Kalman 预测／校正 → 状态与协方差 | 不负责从像素检测目标，不自动识别错误身份，不产生控制律 |
| 跟踪 B：局部图像运动 | 相邻图像＋特征窗 → LK → 局部位移与有效性 | 光流不是目标语义，不保证长期身份，也不等于刚体三维速度 |
| 跟踪 C：单目标外观 | 首帧框＋连续图像 → MOSSE／SiamFC → 位置／框与响应 | 不自动处理多目标出生删除，不等于长期重识别或机器人跟随 |
| 关联 D：指派与 MOT | 检测集合＋轨迹预测 → 门控／一对一指派／生命周期 → ID 轨迹 | Kuhn 是求解器；SORT／Deep SORT／ByteTrack 是组合系统，检测器不是可省略输入 |
| 控制 E：视觉伺服 | 目标误差＋状态／标定＋执行器反馈 → 控制律与约束 → 速度等命令 | 不等于跟踪器；IBVS、PBVS 与混合方案有各自模型、可观测性和稳定性条件 |

可组合链为“成像与时间戳 → 观测 → 预测门控 → 身份关联 → 校正／失锁 → 同步坐标转换 → 控制器 → 独立安全检查 → 执行与反馈”。单目标场景未必需要 MOT；仅做轨迹统计可以止于感知层。控制链是架构方案，当前没有落地实现。[cite:2](#source-2)[cite:5](#source-5)[cite:8](#source-8)[cite:10](#source-10)

### 3.1 E01：Kuhn 指派，优化给定代价不等于识别真实身份

**瓶颈 → 改进机制：**逐条轨迹贪心选最近检测，可能抢占另一条轨迹唯一合理候选。Kuhn 1955 年论文处理给定数值收益的全局指派；用于视觉关联时，把收益／代价矩阵与一对一约束分开建立。该论文不是目标检测器，也不是完整 MOT 系统。[cite:1](#source-1)

**代价与遗留问题：**需构造两两代价、处理矩形集合与未匹配；错误代价的全局最优仍可能身份全错。现代稠密指派常讨论三次复杂度，不能不区分实现就归为 1955 原文定理。运动门控、虚节点与生命周期是系统层设计，不冒称原始人—任务分配论文已有视觉失锁机制。

**工程连接：**多目标相邻、易贪心抢配时，优先查代价、可匹配掩膜和未匹配惩罚，再换求解器；禁止强制配满。[T04](algorithm_cards/remaining_domains.md#t04-门控后一对一全局指派)只有目标定义、例题和接入方案，尚无本地指派或 MOT 实现。

### 3.2 E02：Kalman，把逐帧观测变成带不确定度的递归估计

**瓶颈 → 改进机制：**观测有噪声与缺测，重复处理全部历史不利于递推。Kalman 1960 年论文从状态转移和误差协方差出发求线性估计；指定线性模型下递归预测、创新校正使历史信息压缩为状态与协方差。原文接收／报告于 1959，不应替代 1960 期刊年份。[cite:2](#source-2)

**代价与遗留问题：**须设置动力学、dt、Q/R 及初始不确定度；常速模型无法凭空预测机动，错误关联会污染状态。线性高斯模型可解释为对应后验均值；非高斯时一般只保证相应条件下的最优线性估计，不是任意系统最优。P 是模型条件下统计量，不是确定性误差上界。

**工程连接：**已有关联位置、需稳定估计速度和短期预测时使用；先查时间戳、量纲和创新偏置，再校准观测噪声与运动噪声，缺测必须增加不确定性并有限期失锁。[T01](algorithm_cards/remaining_domains.md#t01-线性-kalman-常速状态估计)是常速线性基线，不包含 EKF／UKF、自适应 Q/R 或控制器，未实现。

### 3.3 E03：LK，小位移图像观测而非长期目标身份

**瓶颈 → 改进机制：**局部图像配准穷举成本较大。Lucas、Kanade 的 IJCAI 1981 论文使用空间梯度和迭代更新求匹配；T03 选局部亮度恒常、小位移、窗口共同平移作为教学基线。同年 DARPA Workshop 扩展稿和 IJCAI 引用页码需分开。[cite:3](#source-3)

**代价与遗留问题：**依赖可观测梯度、亮度模型和近初值；平坦区、单直边孔径问题、运动边界和遮挡都会失败。增大窗口混合运动；金字塔是另需验证的扩展，不能把现代稠密光流、逆组合或任意大位移能力全放入 1981 基线。

**工程连接：**受控连续帧特征点可评估 LK，先查最小特征值／条件数、前后向不一致、残差与帧间位移。位移除真实 dt 才是速度，像素速度不是工具坐标速度。[T03](algorithm_cards/remaining_domains.md#t03-lucaskanade-局部光流)未实现，现有亚像素角点或 ZNCC 峰拟合均不是 LK 跟踪。

### 3.4 E04：混合视觉伺服，控制目标之间的协调

**瓶颈 → 改进机制：**仅关注图像误差或位姿误差会忽略另一空间的约束，导致特征出视野或可达域问题。Gans、Hutchinson 的 T-RO 2007 论文组合 image-based 与 position-based 控制，通过特定状态依赖切换方案讨论稳定性。这是控制分支，不是从轨迹输出直接乘一个增益。[cite:9](#source-9)

**代价与遗留问题：**要获取图像特征／位姿、构造切换状态与判据，处理奇异、视野、可达性及执行器约束。初建总览只读摘要／作者说明的记录保留；后续[G44作者PDF页图记录](algorithm_cards/ftp_hybrid_servo.md#source-5)已定位pp.531–535与式(21)–(32)，不再称缺符号。邻域记号与增益证明疑点仍未闭合，式(32)不是已验证端到端时延界，也不保证未知时延、碰撞或饱和下安全。

**工程连接：**需要协调视野与空间运动约束时才研究混合方案；基础IBVS／PBVS的误差、交互矩阵与坐标先学清。2006／2007教学综述不是两者发明年份，也不额外增节点。[cite:10](#source-10) 当前[G44](algorithm_cards/ftp_hybrid_servo.md#g44)已承接机制，[视觉引导边界](algorithm_cards/remaining_domains.md#跟踪组合与视觉引导边界)与[手眼卡](algorithm_cards/calibration.md#c02-tsailenz-手眼标定)仅为相关基础；证明一致性／采样安全[独立P0](evolution_coverage.md#g44-independent-p0)保留，无控制仿真、硬件在环、实机接口或稳定性实测。

### 3.5 E05：MOSSE，学习响应而非直接保存模板

**瓶颈 → 改进机制：**原始模板易有背景响应，外观又随时间变化。Bolme 等 CVPR 2010 的 MOSSE 最小化滤波输出与期望峰的平方误差，在频域求滤波器，并以在线更新适应外观；PSR 用于识别不可靠响应。所读作者扩展稿明确包含会议删减内容。[cite:4](#source-4)

**代价与遗留问题：**FFT 需要处理循环边界和共轭方向，在线更新可能把遮挡物学成目标。冻结更新不保证任意遮挡后找回；PSR 也不是概率或 Kalman R。T02 是灰度平移教学版本，岭稳定化与门控为明确方案，不能据原文鲁棒性摘要声称显式输出旋转、尺度或六自由度。

**工程连接：**CPU 预算受限、短期单目标局部跟踪可作为候选；先查窗中心、位移回绕、响应峰和冻结逻辑，再调学习率。[T02](algorithm_cards/remaining_domains.md#t02-mosse-型自适应相关滤波)未实现；不能把已有 FFT-ZNCC 改名 MOSSE，更不能搬用论文帧率。

### 3.6 E06：SORT，检测质量与简单时序组件的组合

**瓶颈 → 改进机制：**在线 MOT 需要在检测集合中维持轨迹。SORT（ICIP 2016；arXiv v1 2016-02-02，页面 v2 修订为 2017-07-07）把 Kalman 预测、框重叠代价与 Hungarian 指派组成简单在线系统，突出检测质量对跟踪的影响。[cite:5](#source-5)[cite:8](#source-8)

**代价与遗留问题：**必须有检测器与轨迹出生／删除策略；相机运动、长遮挡、交叉和非线性机动可使仅运动／位置关联失效。检测网络换了不能把所有提升归给跟踪算法；T01 的四维点状态不等于 SORT 的框状态。

**工程连接：**短遮挡、检测稳定的多目标场景可先做可解释基线，固定检测输出再比较关联；未匹配和重复检测要保留诊断。[SO01](algorithm_cards/sort.md#so01)已承接框状态／IoU／生命周期，门控分支、NaN／Inf索引和视频身份验收保留P2；[T01](algorithm_cards/remaining_domains.md#t01-线性-kalman-常速状态估计)加[T04](algorithm_cards/remaining_domains.md#t04-门控后一对一全局指派)仍只是组件路径，没有可运行SORT系统。

### 3.7 E07：SiamFC，离线相似性学习与在线相关互补

**瓶颈 → 改进机制：**单视频在线样本有限，在线深层训练成本较高。SiamFC（ECCV **Workshops** 2016）离线训练孪生全卷积嵌入，在线把首帧 exemplar 与搜索图特征交叉相关。正式正文所述简单跟踪器固定首帧特征，并搜索有限尺度；不是 MOSSE 式逐帧最小二乘更新。[cite:6](#source-6)

**代价与遗留问题：**需要视频训练数据、权重、推理环境与裁剪／缩放回填；相似干扰、出搜索区和大外观变化仍困难。网络响应不是身份认证或安全置信度，单目标模型也不包含完整 MOT 生命周期。arXiv v3 修订于 2021，不代表方法首次发表于 2021。

**工程连接：**有模型部署预算、外观变化较大时与 MOSSE 等在同一完整视频上比较；分别检查首帧初始化、搜索范围、尺度与重定位协议。[SI01](algorithm_cards/siamfc.md#si01)已承接共享训练、固定模板、相关与尺度回填，仍未实现；通道／BN、训练尺寸／插值及视频验收保留P2；[族级边界](algorithm_cards/remaining_domains.md#泛称各列的族级边界)只是学习单目标路线说明。

### 3.8 E08：Deep SORT，给关联增加外观证据

**瓶颈 → 改进机制：**SORT 的运动／框重叠在遮挡和交叉后可能不足以维持身份。Wojke 等 2017 年 Deep SORT 离线学习外观度量，在线联合运动与外观进行检测—轨迹关联；它扩展 SORT，而不是抛弃全部经典估计组件。[cite:7](#source-7)[cite:8](#source-8)

**代价与遗留问题：**额外外观网络推理、特征存储、阈值和训练域依赖；原论文使用行人重识别训练，不能无验证推广到同外观工业零件。外观近似不证明同一物体，外观被严重遮挡时也可能误导。

**工程连接：**身份连续性很重要且外观有可区分性时评估；先看漏检和时间同步，再检查运动门与外观距离分布，分别统计交叉／长遮挡 ID 切换。[DS01](algorithm_cards/deep_sort.md#ds01)已承接具体机制，但无模型／训练或完整视频实现；2017方法与后续训练／跟踪快照分开，权重血缘、空特征／gallery、IoU绕门污染和截顶后拒配保留P2；[T04](algorithm_cards/remaining_domains.md#t04-门控后一对一全局指派)不含其训练器、级联关联或完整生命周期。

### 3.9 E09：BYTE／ByteTrack，低分候选的条件使用

**瓶颈 → 改进机制：**遮挡目标的检测分下降，直接丢掉所有低分框会断轨。BYTE 先关联高分框，再用剩余轨迹与低分框做第二次关联，并丢弃未关联低分候选；ByteTrack 是结合检测器的具体系统。ECCV 2022 正文及 2021 起始预印本必须分开记录。[cite:8](#source-8)

**代价与遗留问题：**增加候选与关联步骤，也增加低分背景误接风险；需要高低分划分、运动／相似性门和失踪轨迹管理。不是“任意低分都接收”，更不是无条件删掉 Re-ID；原文不同数据集配置并不完全相同，不能将一种设置泛化到所有工况。

**工程连接：**确有低分真检测导致断轨时，固定检测结果、分层统计第二次关联恢复和误接，再判断是否有价值。低分框用于维持轨迹不意味着可直接驱动设备。[BT01](algorithm_cards/bytetrack.md#bt01)已承接BYTE策略与ByteTrack系统，仍未实现；依赖／tie-break、inclusive IoU、Removed残留／去重、坐标及空帧时钟保留P2，不把固定路径推广为全部数据集配置；[T04](algorithm_cards/remaining_domains.md#t04-门控后一对一全局指派)不因此升级成完整 MOT。

## 5. 坐标同步、延迟与闭环安全

### 5.1 坐标与时间是控制输入契约

采用列向量与 \(T_{a\leftarrow b}\) 表示 b 系到 a 系。眼在手上时，曝光时刻 t 的目标点满足 \(p_b(t)=T_{b\leftarrow e}(t)T_{e\leftarrow c}p_c(t)\)。相机观测和机器人位姿必须对应同一时刻；不能直接把曝光时刻的点与收包时刻的末端姿态相乘。固定相机则用对应固定相机到基座链，不混用两种安装结构。标定步骤见[Tsai–Lenz 卡](algorithm_cards/calibration.md#c02-tsailenz-手眼标定)。

必须明确曝光时间定义、相机与控制器时钟偏移／漂移、数据到达顺序、设备反馈采样和变换版本。速度／角速度变换还需对应的旋量约定与伴随映射，不能把三维点平移规则直接套到速度。二维匹配中心坐标也不能不经相机模型就解释为工具目标点。

对近似恒速目标，未补偿延迟 tau 的位置滞后一阶约为 \(\delta p\approx v\tau\)；这只是局部运动近似，不是闭环稳定性定理或碰撞距离上界。预测到执行时刻需估计执行时间并传播不确定度，预测有效期超限时拒绝命令，不能无限外推。总延迟应覆盖曝光／读出、传输、排队、感知、控制计算、通信与执行响应，不只算推理耗时。

### 5.2 视觉伺服的理论边界

IBVS 以图像特征误差构造反馈，PBVS 以估计位姿误差构造反馈；混合控制试图协调两者的困难。作者教程说明交互矩阵、稳定性分析和速度控制的适用范围；高速任务、非完整约束及欠驱动系统还需动力学建模。[cite:9](#source-9)[cite:10](#source-10)

作为现代局部模型说明，若 \(e=s-s^*\)、\(\dot s=L_s v_c\)，常见速度反馈形式为 \(v_c=-\lambda\widehat L_s^+e\)。此时 \(\dot e=-\lambda L_s\widehat L_s^+e\)，不能未经秩、估计误差和可达误差子空间检查就写成 \(\dot e=-\lambda e\)。这不是本文已逐式核验的 2007 切换律，也不是可直接下发设备的实现。

连续时间局部分析还不覆盖采样、时延／抖动、丢包、饱和、视野丢失、机械限位及碰撞。两个控制器各自在某条件下稳定，也不推出任意切换稳定。论文方法名称含“Stable”不代表本仓库或现场闭环已有保证。

### 5.3 必须独立设计的安全闭环

以下是系统设计要求，不是已实现安全功能或认证结论；具体停止方式、限值与审批需由设备规范、风险评估及具资质人员确定。

- **运行状态：**显式区分未初始化、跟踪可信、仅预测、失锁、重获确认与故障。仅预测和重获候选不能默认拥有与已校正观测相同的动作权限。
- **动作门控：**检查目标身份、观测年龄、坐标／标定版本、预测不确定度、可达域、速度／加速度限值和设备互锁；网络高分不旁路这些检查。
- **失败处理：**失锁、NaN、超时、通信异常或坐标链错误时撤销普通视觉命令，经设备安全机制进入风险评估规定的安全状态；“发送零速度”或“保持上一命令”均不是通用安全方案。
- **独立保护：**安全急停、看门狗、限位与防碰撞不能只依赖非安全级视觉进程；程序崩溃、旧帧重放或网络阻塞也应被覆盖。
- **恢复条件：**重新获取目标后重新确认身份／姿态／工作区和设备状态，禁止仅因分数恢复就无条件自动续动；保留人工审批或系统规定的复位流程。
- **验证顺序：**离线回放与故障注入 → 仿真 → 受控硬件在环 → 审批后的低速限域实机 → 工况验收。仿真和安全门存在都不自动构成现场认证。

### 5.4 分层验收，禁止用感知指标替代安全

| 层级 | 建议指标与数据 | 必须分开记录 |
|---|---|---|
| 单目标／局部运动 | 中心误差、框 IoU 成功曲线、失锁率、重获耗时、遮挡分层 | 初始化、是否允许真值重置、拒绝帧；只测成功片段会有偏差 |
| 状态估计 | 位置／速度误差、创新分布、有真值时的统计一致性检查 | 预测与校正、真实 dt、Q/R 模型；协方差不能当绝对保证 |
| 多目标关联 | ID 切换、碎轨、漏轨、IDF1／HOTA 等指定协议指标 | 检测器、外观模型、关联器与生命周期版本；计数指标不等于控制风险 |
| 控制效果 | 跟随误差、超调、稳态误差、收敛域实验、命令／反馈饱和 | 图像误差与物理误差、目标运动、负载、时延／抖动和模型条件 |
| 实时与安全 | 端到端尾延迟、截止时间违约、失锁至安全状态的响应、故障覆盖 | 日志与独立设备反馈、危险工况；观察到未碰撞不证明所有工况安全 |

MOT 指标用法可追溯到 ByteTrack 的评测说明，但本仓库尚无这些指标的专用实现。[cite:8](#source-8) 完整视频按对象／场景／批次隔离训练与验收；保留出画、交叉、漏检、乱序、重获错误和失败原因。所有阈值、时限与容差都应由任务要求和独立数据确定，本文不编造万能值。
