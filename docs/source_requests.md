## 交付与合法访问要求

- **身份先行**：附题名页／文章首页及必要版权或版本说明，逐项核对作者拼写、完整题名、年份、期刊卷期或书籍版次、DOI／ISBN。以下标识只转录已有证据；未获标识不猜填，不由DOI数字推年份，不自行展开作者姓名缩写。
- **页码双记**：分别记录印刷页码、文件中从1起计的PDF页序、稿内页码及其对应关系；无印刷页号如实标注。目录推定的章节范围不是已读方法页，整篇请求范围不是精确方法引文；禁止直接把印刷p.311写为`#page=311`。
- **保留上下文**：提供完整可辨识页面，含页眉／页脚、公式号、图题、定义和跨页续文；按正文回指补所需页。扫描符号须看页图，OCR只作定位；曲线裁图、摘要、目录或空OCR命中不能代替定义。
- **合法渠道**：优先作者／机构授权公开稿、正式机构仓储、已有合法订阅及图书馆文献传递；收费、借阅、联系作者等操作须由用户确认后办理。本轮未发送索稿、未提交馆际互借、未登录或付费，未确认任何机构必能供件。
- **可接受作者稿**：须有可追溯作者／机构来源或版本声明，能指向目标DOI／卷页／版次，并逐项对照方法、公式、图和实施段。记录预印本、接受稿或出版版身份与差异；未确认同版只能作对照材料，不能仅凭同作者、相似题名或近年认定等价。书籍节选也须能核第一版身份及完整上下文。
- **停止与留存**：遇验证码、403、登录或试读限制即停止自动获取，不伪装身份、关闭证书校验、改参数扩展试读或使用非授权下载站。记录合法来源URL／馆藏申请标识、取得日期、版本、页数与文件哈希；有阅读权限不等于有再分发权，扫描副本不默认提交仓库。
