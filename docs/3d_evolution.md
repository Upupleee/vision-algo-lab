[文档导航](README.md) · [编写与学习规范](algorithm_learning_standard.md) · [三维卡片索引](algorithm_cards/README.md#其余领域) · [标定坐标](calibration_coordinates.md) · [跟踪与视觉引导总览](tracking_guidance_evolution.md)

## 1. 范围、结论与状态口径

三维系统持续解决的不是单一的“匹配精度”，而是：深度从何而来、对应是否可信、几何是否可观测、多视数据如何对齐与融合、尺度如何追溯、缺失与误差如何交付。本文保留**方法演进线**和**工程实践线**，选取九个代表节点，不构成完整三维算法史，也不以发表时间排序工程优劣。

深度获取、对应、配准是不同任务：ToF 可直接提供距离观测，双目和结构光需要对应与三角化，ICP 消费已有几何而不从普通照片直接产生深度。融合又以已对齐的深度为前提。该任务分解可由 ToF、SGM、ICP 与体积融合原始资料交叉核对。[cite:2](#source-2)[cite:3](#source-3)[cite:4](#source-4)[cite:5](#source-5)

**原始核对日期：2026-11-04；仓库基准：HEAD `918a03e` 加当日工作树；覆盖描述本地同步：2026-11-06。** 本域无专用深度图、点云、三维配准或物理尺寸验收实现。下文“未实现”限定本仓库，不表示第三方没有软件；“有教学卡”“原文已读”“本地实现”“测试通过”“现场验证”分别记录。G37–G40由CL01／SM01／FP01／PM01承接具体机制，G41／G42由[MD01](algorithm_cards/monodepth2.md#md01)／[FG01](algorithm_cards/fcgf.md#fg01)承接；本域九节点为已有7、部分0、缺卡1、非算法1。两张新纳入卡仍核／核／部／核（各自限定）／部、P2且未实现；FP01两子算法各五层、共享答5仍一卡，2009方法原文未取得保留P2。此次不升级读卡、来源或实现状态；既有二维 ZNCC 和学习匹配接口也不能使本域状态升级。

深度学习改变了对应表示、正则化或训练监督，不会自动替代主动传感、标定、刚体几何与验收。PSMNet、Monodepth2、FCGF 分别对应双目匹配、单图深度推断和点云特征，不能合称一种端到端三维测量器。[cite:7](#source-7)[cite:8](#source-8)[cite:9](#source-9) 工程建议均为机制分析，本文没有统一算法实验、排行榜或毫米级性能承诺。

2026-11-06本轮仅补G36来源回链：[FTP对照卡](algorithm_cards/ftp_hybrid_servo.md#g36)已记1983篇幅3977–3982及2005 pp.378–380后续转换文本，但1983频带／相位／高度几何／标定原页仍未取得，不猜方法页或式号，G36保持缺卡／P0、全部分、未实现。与其同文件的G44机制已有仅影响跟踪域，证明／采样安全仍独立P0，不改变本域7／0／1／1计数。

## 2. 核心维度与分支地图

### 2.1 三维领域核心维度

| 核心维度 | 必须回答的问题 | 工程证据与交付物 |
|---|---|---|
| 深度获取模型 | 被动双目、投影编码、ToF，还是学习先验？输出是光轴深度还是射线距离？ | 原始左右图／编码图／相位与幅值、传感模式、曝光、同步、无效掩膜 |
| 对应关系 | 匹配的是像素、投影码、局部点云特征，还是当前变换下近邻？ | 代价曲线、唯一性、左右一致性、对应空间覆盖及外点比例 |
| 几何约束 | 内外参、极线、刚性、尺度和静态场景假设是否成立？ | 标定版本、重投影残差分布、三角化夹角、变换方向、退化诊断 |
| 重建优化 | 局部窗口、路径聚合、学习代价体、位姿优化、体积融合各优化什么？ | 初值敏感性、目标函数、停止理由、计算预算、原始与融合结果对照 |
| 遮挡与完整性 | 没测到、被拒绝、被插值和真正观测到的表面能否区分？ | 可见性、有效率、孔洞、补全标签、跨视覆盖；不只统计成功点 |
| 尺度与误差 | 米／毫米、视差像素、网格间距及不确定度如何传递？ | 可追溯真值、系统偏差、重复性、距离／材质分组误差、拒绝率 |

上述维度遵循[领域规范](algorithm_learning_standard.md#一领域层先建立演进核心主线)。增大基线、增大窗口、强化平滑和加深网络都可能改善一项指标而损害另一项；不能只比较可视化的平整度。

### 2.2 方法演进线的并行关系

| 分支 | 输入 → 核心处理 → 输出 | 与其他分支的连接及排除项 |
|---|---|---|
| 获取 A：被动几何 | 同步双目／多视图 → 像素对应＋标定几何 → 深度 | G01、SGM、PSMNet 可作对应前端；SfM 的位姿／稀疏结构和 MVS 的稠密恢复要分开，本文不另计其历史节点 |
| 获取 B：主动投影 | 已知投影图案＋相机图 → 编码／相位对应 → 三角化或标定相位到高度映射 | FTP 是一个代表；Gray code、时间相移为并行族，不是本文已展开的独立算法卡 |
| 获取 C：ToF | 调制光或脉冲回波 → 相位／时间测距 → 距离图 | 本文选调制式固态 ToF 论文；不把所有 ToF 都称为三角测量，不将相位式与脉冲式混为一版 |
| 对应 D：点云表示 | 已有点云 → FPFH／FCGF 描述与候选点对 → 鲁棒初始对齐 | 描述子不是 SE(3) 变换；还需几何估计、退化检查和拒识 |
| 配准 E：局部几何 | 已有点云＋初值 → ICP 交替对应／刚体拟合 → 变换与残差 | 不能修复单位错误、无重叠或任意错误初值；不会自动生成不可见表面 |
| 融合 F：重建后端 | 已对齐深度＋权重 → 有符号距离融合 → 表面 | 位于获取和配准之后；补洞是推断，不是新增测量真值 |
| 学习 G：单图先验 | 训练时多视监督；推理时单图 → Monodepth2 → 预测深度 | 推理输入与训练监督分开；纯单目训练的尺度歧义不能靠输出单位文字消除 |

连接是组合而不是逐代替换：例如“标定双目 → SGM → 深度 → FPFH 初始对齐 → ICP → 融合”可评估，但当前没有这条可运行流水线。另一个合法系统可能直接消费 ToF 距离图，根本不需要双目视差。结构光和单目学习也不能按同一输入预算直接比较。[cite:1](#source-1)[cite:4](#source-4)[cite:5](#source-5)[cite:6](#source-6)[cite:8](#source-8)

### 3.1 E01：FTP，把纹理不足转成投影编码问题

**瓶颈 → 改进机制：**自然表面未必有可匹配纹理。Takeda、Mutoh 的 1983 年工作采用投影光栅及频域处理建立形貌信息；现代 FTP 解释为分离载频、恢复包裹相位，再经解包裹和标定恢复几何。原始年份与题名由 PubMed 书目核实；频带分离、解包裹和相机—投影仪对应机制由已读的后续独立研究正文支持，不伪称已经读到 1983 全文。[cite:1](#source-1)[cite:10](#source-10)

**代价与遗留问题：**新增投影硬件、几何标定及有效相位判据；频谱混叠、阴影、反射、条纹欠采样和表面不连续会破坏恢复。单次编码减少多帧之间的错位机会，但曝光期间运动仍可模糊，不能称“对运动免疫”。时间相移／Gray code 可提供不同的解码约束，同时增加投影序列同步成本，不能当作 FTP 原版功能。

**工程连接：**弱纹理漫反射工件可优先评估主动光；先查条纹调制度、饱和、频谱分离及相位跳变，再调解包裹。已有[G36教学卡](algorithm_cards/ftp_hybrid_servo.md#g36)与[族级边界](algorithm_cards/remaining_domains.md#泛称各列的族级边界)，1983原机制仍缺证、P0缺卡保留；无 FTP 解码、投影控制或硬件验收实现。

### 3.2 E02：ICP，解决已有几何的局部对齐

**瓶颈 → 改进机制：**两份几何的对应和位姿都未知。1992 年 ICP 以当前变换找最近点，再求使距离下降的刚体变换，迭代细化。论文摘要明确讨论局部极小值；不能删掉初始化条件，把“迭代收敛”改写为“任意初值全局正确”。[cite:2](#source-2)

**代价与遗留问题：**重复近邻搜索和拟合；依赖重叠、合理初值与几何区分度。错误对应、部分重叠和对称表面可产生低残差错误解；门控改变支持集后，不能无条件沿用原始目标单调性。点到点、点到面和非刚性是不同目标，本文 G02 只覆盖刚性 point-to-point。

**工程连接：**夹具给出初值或粗配准成功后可评估 ICP；先核对米／毫米、源到目标方向、重叠和可观测自由度，再调距离门、降采样和停止条件。[G02](algorithm_cards/remaining_domains.md#g02-刚性-point-to-point-icp)有步骤和代数，L5 为部分，仓库无实现或三维回归。

### 3.3 E03：体积融合，整合多视观测而非替代配准

**瓶颈 → 改进机制：**单次扫描不完整，多片表面有冗余和噪声。Curless、Levoy 的 SIGGRAPH 1996 方法将已对齐距离图转为带权有符号距离函数，增量累积并提取等值面；其表面最小二乘解释有明确假设。[cite:3](#source-3)

**代价与遗留问题：**体素分辨率、空间存储、权重与截断范围形成取舍。位姿错误会产生双层或厚表面，细结构可能被平滑；补洞构造的合理曲面不等于观测证据。不能把该节点直接叫作已完成 KinectFusion 或 SLAM，实时位姿跟踪和回环另有任务。

**工程连接：**用于已可靠对齐的多角度扫描整合；保留原始深度、每体素支持和未观测标记，先查重叠区配准再调体素。[CL01](algorithm_cards/curless_levoy.md#cl01)已承接视线距离、权重累积、可见性与提取；L4仍部分，一般三维证明、量化及补洞验收保留P2，未实现；[G02](algorithm_cards/remaining_domains.md#g02-刚性-point-to-point-icp)不包含体积后端。

### 3.4 E04：固态 ToF，改变深度观测物理机制

**瓶颈 → 改进机制：**密集距离获取不一定要扫描机械或求自然纹理对应。Lange、Seitz 2001 年论文使用调制可见／近红外光与二维锁相像素，每像素测幅值、偏置和相位。它是此处选取的固态调制式 ToF 代表，不是所有 ToF 技术的起源。[cite:4](#source-4)

**代价与遗留问题：**需要主动照明与解调硬件；距离噪声受回波幅值和背景光影响。工程上还需单独验证多径、混合像素、温漂、相位距离歧义与多机互扰；这些是待验风险清单，不声称本次已逐项复核原文实验。距离是沿射线还是光轴深度必须看设备协议，不能直接套双目视差公式。

**工程连接：**可评估低纹理场景的空间感知；先看原始幅值、无效值、环境光和温度，再做滤波。论文实验指标不搬作仓库性能。无独立 ToF 卡、驱动或测试；现状见[三维族级边界](algorithm_cards/remaining_domains.md#泛称各列的族级边界)。

### 3.5 E05：SGM，在局部窗口与二维全局优化之间取舍

**瓶颈 → 改进机制：**固定大窗口跨越深度边，小窗口又易歧义；逐行动态规划存在方向条纹，二维优化成本较大。2005 年会议论文提出像素代价与多方向一维路径累积，近似二维平滑约束；2008 年 TPAMI 版扩充讨论与评估，正文注明在线发表为 2007-05-02。[cite:5](#source-5)

**代价与遗留问题：**路径数、图像大小、视差范围影响成本；平滑惩罚 P1/P2 必须与代价量纲一致。仍需极线几何、遮挡检查、无效点处理；近似多路径不是二维全局最优证明。不能把任意库的 SGBM 默认代价、路径数和后处理等同原始 MI-SGM。

**工程连接：**标定同步双目、可控资源下的基线候选；先查极线纵向残差、视差范围和输入辐射差，再调平滑／一致性门。[SM01](algorithm_cards/sgm.md#sm01)已承接HMI代价、归一路径聚合与左右检查，L4核限代数，完整MI图像链与整数／后处理验收保留P2；[G01](algorithm_cards/remaining_domains.md#g01-双目-sad-块匹配与三角测量)仅整数 SAD 教学，本仓库没有两者的深度输出。

### 3.6 E06：FPFH 与 SAC-IA，为局部配准寻找初值

**瓶颈 → 改进机制：**ICP 所需粗初值未知，局部几何描述又有计算成本。Rusu 等 ICRA 2009 论文简化 PFH 描述计算并提出 FPFH；同时给出 SAC-IA，把候选对齐送入局部优化的收敛区域。特征、特征对应、初始对齐和 ICP 应分层理解。[cite:6](#source-6)

**代价与遗留问题：**需估计法向、选邻域尺度、构造对应并检验几何；密度差、噪声和重复几何使特征不唯一。原文“初始对齐”不意味着任意低重叠都能恢复正确姿态；描述距离也不是物理配准误差。

**工程连接：**无可靠位姿初值且有足够几何结构时可评估手工特征粗配准，再接局部精化。先查法向一致性、邻域相对点间距和候选分布；[FP01](algorithm_cards/fpfh_sacia.md#范围版本与覆盖状态)分别展开[FPFH](algorithm_cards/fpfh_sacia.md#fp01-fpfh)与[SAC-IA](algorithm_cards/fpfh_sacia.md#fp01-sacia)，两子算法各五层、共享答5仍一卡，均部／核／部／部／部并保留源码限定。2009方法原文未得，权重／Huber原式与固定PCL变体差异、状态污染及退化拒识仍列P2；与[G02 后续局部基线](algorithm_cards/remaining_domains.md#g02-刚性-point-to-point-icp)均未实现。

### 3.7 E07：PSMNet，学习双目对应与代价聚合

**瓶颈 → 改进机制：**局部匹配特征缺乏上下文，困难区域对应不稳定。PSMNet（CVPR 2018；arXiv v1 2018-03-23）以空间金字塔池化汇集上下文，并用 3D CNN 规则化代价体。这里的“3D 卷积”处理含视差维度的代价体，不等于直接获得完整三维物体模型。[cite:7](#source-7)

**代价与遗留问题：**训练监督、权重、显存及输入分辨率／视差范围契约；工件纹理、相机和照明域偏移需重验。它仍消费双目数据，不能替代基线尺度、标定和同步；网络平滑结果可能掩盖薄片和边界失效。

**工程连接：**传统对应在目标域难以满足要求且资源允许时评估；在同一双目真值与有效掩膜协议下比较，不借 KITTI 当时排名承诺工业效果。[PM01](algorithm_cards/psmnet.md#pm01)已承接SPP、拼接体、hourglass与视差监督，L4核限模型；GT／padding／插值与旧框架分支风险保留P2。[G01](algorithm_cards/remaining_domains.md#g01-双目-sad-块匹配与三角测量)仅提供几何基础，仍无 PSMNet 训练或推理实现。

### 3.8 E08：Monodepth2，训练监督变化不等于尺度问题消失

**瓶颈 → 改进机制：**大量逐像素深度真值难获取。Monodepth2 的 ICCV 2019 版采用最小重投影损失、全分辨率多尺度采样及自动掩膜，处理训练中的遮挡和相对运动假设违背。预印本始于 2018-06-04，所读提交历史最新为 v4（2019-08-17）；不能把最终机制全部反推给 v1。[cite:8](#source-8)

**代价与遗留问题：**仍需训练数据、相机内参及图像生成假设；训练可选单目视频、双目或联合，推理单图不说明训练无几何信息。纯单目视频重投影中，深度与平移同乘正尺度不改变投影，因此缺少度量锚点时绝对尺度不可辨识。双目训练可提供尺度信息，但需正确基线、内参与域条件，不能推出任意单图毫米精度。

**工程连接：**可评估相对空间先验或辅助补充；若用于尺寸验收，应有独立尺度约束、物理真值和域外拒绝测试。禁止用测试真值逐帧尺度对齐后宣称在线测量能力。[MD01](algorithm_cards/monodepth2.md#md01)已承接训练／推理、重投影／掩膜、多尺度及尺度协议；仍未实现，内参／采样边界与域外验收保留P2；[族级边界](algorithm_cards/remaining_domains.md#泛称各列的族级边界)不升级为模型复现。

### 3.9 E09：FCGF，学习点云特征而非取消刚体估计

**瓶颈 → 改进机制：**逐点局部描述的上下文及重复计算受限。Choy 等 ICCV 2019 的 FCGF 通过三维全卷积网络计算几何特征并使用度量学习损失；输出角色仍是对应前端。[cite:9](#source-9)

**代价与遗留问题：**需要训练权重、三维网络运行环境及一致的输入采样约定；点密度、噪声、尺度和训练场景变化需要验证。本文只核验原论文页摘要，不展开未读正文的具体稀疏算子或损失推导。高特征匹配率不能替代 SE(3) 验证、重叠检查或刚体模型选择。

**工程连接：**可作为 FPFH 的学习前端对照，后接鲁棒对齐与 ICP，而不是把三个阶段一起删掉。[FG01](algorithm_cards/fcgf.md#fg01)已有稀疏网络、量化索引与hardest负排除说明，仍未实现；坐标映射／采样／零范数和真实配准保留P2。本文原始来源深度不变，后续卡片证据另记；[二维学习匹配骨架](../dl/learned_matching.py)直接抛出 `NotImplementedError`，且不是点云网络。

## 4. 工程实践线：选型、误差与排障

### 4.1 从任务约束选型

| 场景／约束 | 优先评估路线 | 必须提供的证据 | 不可默认成立 |
|---|---|---|---|
| 有纹理、双目可同步、需要度量深度 | SAD 教学基线 → SGM；不足再对照 PSMNet | 标定与基线、左右图、有效视差／深度真值 | 输出稠密就没有遮挡，亚像素就毫米准确 |
| 弱纹理漫反射工件，可受控投影 | 结构光 FTP 或另立相移／Gray code 方案 | 条纹对比、相位可靠性、投影时序、相机—投影仪标定 | 镜面／透明表面也服从同一成像模型 |
| 缺自然纹理且需要距离观测 | 调制式 ToF 等主动测距候选 | 幅值、环境光、温度、距离定义与无效码 | 滤波能消除多径偏差，距离分辨率就是总准确度 |
| 两点云有较好初值和重叠 | 刚性 ICP | 坐标单位、初值扰动测试、残差和几何覆盖 | 残差小就是姿态唯一 |
| 两点云无可靠初值 | FPFH／FCGF 对应＋鲁棒粗配准＋ICP | 点密度、法向或网络输入、内点分布、姿态真值 | 描述子直接产生正确变换 |
| 多视扫描表面整合 | 已验证配准＋有符号距离融合 | 每视位姿、融合权重、体素尺度、原始支持 | 补洞区域可当实测表面用于验收 |
| 只有单图，需要相对空间提示 | 单目学习先验 | 训练域、尺度锚点、未知输入拒识、独立真值 | 用一张无尺度图即可追溯尺寸 |

这些是待实施的选型路径，不是已测试产品组合。若目标是机器人抓取，还需[跟踪引导的坐标同步与安全闭环](tracking_guidance_evolution.md#5-坐标同步延迟与闭环安全)，三维位姿通过验收并不直接授权设备动作。

### 4.2 误差传播与可观测性

在已校正、主点偏移已处理的平行针孔双目中，视差 d、像素焦距 f、物理基线 B 满足 \(Z=fB/d\)。小扰动一阶近似为 \(\delta Z=(B/d)\delta f+(f/d)\delta B-(fB/d^2)\delta d\)。独立误差假设下可平方加权合成方差；存在共同标定误差则要用完整协方差 \(J\Sigma J^T\)，不能删除交叉项。这是[G01 的显式几何模型](algorithm_cards/remaining_domains.md#g01-双目-sad-块匹配与三角测量)的敏感性说明，不是整个三维系统误差上界。

小视差、近乎平行的三角化射线、错误相机模型及不同步都会削弱深度可信度。点云配准还需区分目标函数的退化：固定正确对应的非共线平面点可确定 point-to-point 刚体变换；无纹理大平面的近邻对应会滑移，point-to-plane 则对某些切向运动缺约束，不能笼统写“所有平面点 ICP 都不可解”。[G02](algorithm_cards/remaining_domains.md#g02-刚性-point-to-point-icp)的 SVD 反射修正也不能消除错误对应。

### 4.3 按症状组织排障

| 症状 | 先查证据／假设 | 调整顺序与动作 | 拒绝的捷径 |
|---|---|---|---|
| 深度整体成比例偏差 | B 单位、缩图后 f、视差缩放、设备 distance/Z 定义 | 先修单位和几何，再估随机误差 | 直接乘经验系数覆盖全部距离 |
| 远距离深度抖动 | d 分布、匹配曲线、曝光、标定残差 | 先查小视差敏感性与采样，再评估基线／分辨率 | 只加平滑并宣称精度提升 |
| 物体边缘肥厚、飞点 | 遮挡、左右一致性、窗口跨深度边、ToF 混合像素 | 单独标记边界与无效点，再比较聚合策略 | 把删除困难点后的 RMSE 当全域性能 |
| 结构光条纹断层 | 饱和、阴影、相位展开、序列错位 | 查原始条纹／频谱／时序，失败区域保留掩膜 | 不看原图只改相位阈值 |
| ToF 特定材料／角落偏深 | 回波幅值、背景光、多径、距离与温度分组 | 在受控条件下隔离因素，再选补偿或换传感路线 | 用重复性小证明绝对距离正确 |
| ICP 残差低但姿态错误 | 重叠、对称、初值、对应覆盖与变换方向 | 查姿态真值和多个初值，再粗配准／物理约束 | 无限制加迭代、只看 fitness |
| 融合出现双层表面 | 单帧深度与位姿是否一致，时序／动态物体 | 先排配准和同步，再调权重／体素 | 用更粗网格隐藏几何错位 |
| 网络换相机或材质失效 | 输入尺寸、颜色／归一化、训练域、权重版本 | 固定协议做分组评测，必要时回退几何基线 | 网络高置信即测量有效 |
| 单目结果外形合理、尺度漂移 | 训练监督类型、度量锚点、是否用真值缩放 | 分开相对与绝对指标，缺尺度时不放行测量 | 将逐图对齐结果当绝对测量 |

排障行是后续接入方案，不代表本次收集了三维运行时证据。相机与机器人变换还应核对[标定卡 C02](algorithm_cards/calibration.md#c02-tsailenz-手眼标定)；二维坐标约定可参考[ZNCC 坐标专题](pose_ncc.md#第一章坐标与变换)，不能代替内外参。

### 4.4 最小验收协议

- **数据与真值：**覆盖距离、角度、材质、光照、遮挡、温度与批次；物理标准件／参考仪器及不确定度可追溯。训练、调参和验收按对象／场景隔离，不把邻近视图当独立泛化样本。
- **获取／对应：**视差错误率与深度误差分开；记录有效率、边界、遮挡和完整性。固定评价区域，不用增加拒绝点偷偷降低误差。
- **配准／融合：**报告旋转、平移误差及失败率，给出初值范围和重叠分层；融合后误差不能只测被平滑过的区域，补全区单列且不当实测。
- **资源与复现：**固定算法／库／权重、硬件、图像／点数／体素规模、预热和输入管线；分开采集、传输、推理／优化的耗时，记录尾延迟和超时拒绝。
- **交付：**输出几何值、单位、坐标系、时间戳、有效掩膜、质量证据和失败原因。没有尺度、低重叠、不收敛或传感异常时返回不可测，而不是填零后判合格。

此处为验收设计，未执行三维数据、网络训练、硬件或机器人试验；无可移植的统一阈值、速度和测量误差保证。
