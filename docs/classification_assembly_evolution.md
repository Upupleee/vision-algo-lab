## 1. 范围与领域演进核心主线

本领域持续优化的是 **“对象是什么、对象之间应当怎样、当前观测能否支撑合格决策”**，而不是把分类准确率不断提高就称为装配系统。类别是对象属性；装配还涉及实例数量、对应槽位、相对位置／朝向、连接与接触、可见性，以及需要时的过程状态。两个零件都识别正确，仍可能互换位置、反装或未插到底；一段“拧紧”动作被识别，也不能证明扭矩合格。

**方法演进线**沿对象表示、类别决策、未知类拒识、实例定位、关系表达与时序证据并行发展；**工程实践线**沿规格／BOM → 可观测性 → 候选与身份 → 产品坐标 → 关系／过程核对 → OK／NG／UNKNOWN → 按失效代价验收。经典计划图、深度分类器、目标检测器与关系网络解决不同层次问题，不构成单一淘汰链。原始装配计划图、场景关系图和装配活动数据三种独立研究分别说明了结构、关系与时间的必要角色，但不共同构成一套已验证产线方案。[cite:2](#source-2)[cite:7](#source-7)[cite:8](#source-8)

核验日期 **2026-11-04**。本文选取八个代表节点，其中 IKEA ASM 是数据／评测节点，AND/OR 图是装配计划表示节点；不将它们误计为八种图像分类算法。年份表示选定原文版本，不宣称首创或最新。全文为领域总览，不新增网络、训练、检测器、装配执行接口或 L5 完成状态。

| 核心维度 | 分类一侧 | 装配一侧 |
|---|---|---|
| 对象表示 | 颜色／纹理／形状特征或学习嵌入 | 必须保留实例 ID、位置、朝向及可见性 |
| 类别与关系 | 闭集类别、开放集拒识、属性 | 数量、槽位绑定、部件关系、接触／连接与状态 |
| 监督数据 | 类标签及可信负例；预训练来源单列 | 框／掩膜／关键点、关系标签或工程规则、过程标签 |
| 未知处理 | 未见类、域外输入、分类歧义 | 遮挡、未观察状态、关系不可判，不自动等同缺件 |
| 决策与代价 | 错分类别的成本可能不对称 | 漏放、误拒与复检分别计价，安全关键项不能被平均分抵消 |
| 泛化 | 新批次／材质／拍摄条件 | 新产品拓扑、工艺顺序、对称件和跨工位坐标 |

## 2. 任务分支与工程依赖

| 并行任务 | 输入 → 输出 | 需要什么证据 | 不能推出什么 |
|---|---|---|---|
| 零件分类 | 单件 ROI → 类别／属性／未知 | 类标签、尺度一致性、困难混淆与开放集样本 | 不能回答全图有几件、是否装在正确槽位 |
| 零件检测／分割 | 图像 → 实例框／掩膜与类别 | 实例标注、候选召回、去重及遮挡协议 | 框重叠不证明机械接触，框中心不等于装配基准点 |
| 位姿与几何测量 | 实例图像／特征 → 位姿和测量 | 标定、坐标链、可辨识结构与不确定度 | 小数坐标不等于毫米准确；二维重合不等于三维插接 |
| 静态装配规则 | 实例集＋产品规格 → 数量／关系三态 | BOM、槽位、相对距离／朝向、有效观测 | 检测失败不自动等于漏装；不可见不算合格 |
| 学习式关系识别 | 对象与上下文 → 主体—关系—客体 | 关系词表、关系标注、对象对应与方向性 | 自然场景“在上方”不等于工业“锁紧到位” |
| 工序／状态理解 | 多帧／多视图 → 动作段、状态、顺序证据 | 时间标签、同步、合法顺序和返工记录 | 动作识别不证明结果合格；看到终态不证明过程全部合规 |
| 装配计划／机器人执行 | 产品结构与约束 → 可行计划／控制动作 | 可行性、碰撞、夹具、力控、安全接口 | 计划存在不等于视觉确认执行成功 |

例如“检测零件 → 分类确认型号 → 关键点估朝向 → 产品系一对一槽位绑定 → A01 几何规则 → 复检不可见项”是可评估的组合；端到端分类整件 OK/NG 是另一条监督路线，但仍要证明它覆盖具体失效和新产品变化。关系模型可辅助消歧，不得用上下文先验补出本来没观察到的零件。[cite:5](#source-5)[cite:7](#source-7)

## 3. 方法演进线：有据代表节点

| 节点 | 时间／版本 | 改变的维度与任务 | 原始证据 |
|---|---|---|---|
| E01 Haralick 纹理分类 | IEEE TSMC 1973 | 手工统计表示＋有标签类别决策 | [cite:1](#source-1) |
| E02 AND/OR 装配计划图 | 本章采用 AAAI 1986 原文 | 子装配与替代操作的结构表达；非视觉分类 | [cite:2](#source-2) |
| E03 HOG＋SVM 检测范式 | CVPR 2005 | 局部形状表示与窗口判别分离 | [cite:3](#source-3) |
| E04 ResNet | 2015-12-10 v1／CVPR 2016 | 残差学习缓解深网络优化退化 | [cite:4](#source-4) |
| E05 Faster R-CNN | 2015-06-04 v1／2016-01-06 v3 扩展稿 | 候选产生与检测共享卷积特征 | [cite:5](#source-5) |
| E06 OpenMax | 本章采用 CVPR 2016 | 闭集分类增加未知类拒识机制 | [cite:6](#source-6) |
| E07 迭代消息传递场景图 | CVPR 2017 | 对象节点与关系边联合推断 | [cite:7](#source-7) |

节点按任务连接组织，E04 与 E05 不按发表先后暗示继承：Faster R-CNN 并不要求 ResNet 才能成立，原文有 ZF／VGG 等骨干。表中仅列本次真正核验的版本，不将更晚 arXiv 修订说成方法首次出现。

### 3.1 E01：手工表示与类别决策形成可解释基线

**先前瓶颈 → 改变维度 → 机制：**平均颜色／亮度不能充分区分纹理。Haralick 等从空间灰度共现提取统计量，再使用有标签训练／测试及决策规则完成类别识别；原文任务包括岩石与遥感类别，不是装配合格性。[cite:1](#source-1)

**新增代价与遗留问题：**量化、方向、窗口和特征选择依赖场景；全局统计可能相同而局部位置完全不同。迁移到材质／表面型号分类需实际标签与受控采集，不能迁移原文准确率。规则几何和纹理分类从一开始就是可组合的不同证据：材质对了，不代表件数和位置正确。仓库 GLCM 未实现；分类器基础另见 [学习组件](algorithm_cards/learning_components.md)。

### 3.2 E02：AND/OR 图把装配表示为子结构和可选过程

**先前瓶颈 → 改变维度 → 机制：**单一操作列表不能表达同一产品的多种合法装配序列，一份简单优先关系图也未必覆盖全部选择。Homem de Mello 与 Sanderson 的 1986 原文用 AND/OR 图表示装配／子装配及可行分解，AND 表示需共同满足的子问题，OR 表示替代路径，支持离线选计划和在线机会调度。[cite:2](#source-2)

**新增代价与遗留问题：**必须给出产品结构、操作可行性及成本；状态和分解组合随复杂度增长。它不从像素识别零件，没有图像类别标签训练，知识来自模型和工程约束；逆向分解还要求对应可行装配操作，不能把物理可拆等同任意可装。此节点用于说明“装配关系与过程”早于深度分类器且独立存在，不宣称 A01 规则卡是该论文复现。本章未实现计划生成、碰撞检查或机器人执行。

### 3.3 E03：HOG＋SVM 改进对象外观证据，不提供关系证据

**先前瓶颈 → 改变维度 → 机制：**直接像素模板难容纳局部姿态和光变。Dalal／Triggs 在密集 cell 内累计梯度方向，在重叠 block 内归一化，用线性 SVM 进行人／非人窗口判别，并在训练负图上挖困难负例；滑窗多尺度和去重再得到实例。这里是 2005 行人检测原文，不是工业零件论文。[cite:3](#source-3)

**新增代价与遗留问题：**cell／block 尺寸、窗口比例及困难负例决定表现；多尺度搜索耗时，局部容忍不等于任意旋转不变。迁移到零件需要重新定义类别和训练集，换分类器也不能补救候选漏检。现有 [hog_svm_matching.py](../ml/hog_svm_matching.py#L57-L80) 是 StandardScaler＋RBF SVC，调用时生成教学样本并训练，返回带分数的候选排序；没有阈值剔除、开放集拒识或装配关系。它不是原论文线性 SVM 检测流水线。

### 3.4 E04：ResNet 扩大学习表示能力，但闭集任务边界仍在

**先前瓶颈 → 改变维度 → 机制：**简单堆深网络可能出现训练误差反而更高的退化，不仅是测试过拟合。ResNet 把映射写为残差 F(x)＋x（尺寸变化可投影），改善优化路径；所选论文的图像分类实验使用有标签数据，迁移骨干也继承预训练数据假设。[cite:4](#source-4)

**新增代价与遗留问题：**增加训练数据、权重、算力和输入规范维护；残差结构不保证全局优化、概率校准或跨材质泛化。对可裁出单件且类别足够标注的情况可评估迁移分类，但分类头仍回答“是什么”，不能给出配合关系。方向是业务语义时，不能用任意旋转增强把正装／反装混成同类。已有 [跳跃连接组件卡](algorithm_cards/learning_components.md#c13-跳跃连接相加与拼接) 不等于仓库有原版 ResNet 零件分类器。

### 3.5 E05：Faster R-CNN 把候选瓶颈纳入学习式检测

**先前瓶颈 → 改变维度 → 机制：**快速 ROI 分类后，外部区域建议仍可能成为检测瓶颈。Faster R-CNN 的 RPN 与检测器共享整图卷积特征，用参考框产生 objectness 与框回归，再分类、回归候选。训练要求对象框与类别，objectness 监督由框匹配派生；它不是只用整图类别就能学出精确零件框的无监督方法。[cite:5](#source-5)

**新增代价与遗留问题：**框标注、尺度／比例覆盖、候选预算、去重和特征分辨率都要管理；小螺钉、密排件、遮挡可能在分类前就漏掉。框齐全之后还需要实例身份、槽位关联、姿态与关系验证；相邻框重叠不证明连接。本文读取的 2016 v3 为扩展技术稿，不把其中新增联合训练说明无条件倒写成 2015 所有实现均有。仓库无此检测器。

### 3.6 E06：OpenMax 将未知输入从闭集置信中分离

**先前瓶颈 → 改变维度 → 机制：**Softmax 必须把质量分配给已知类别，未知件仍可能得到高置信类别。OpenMax 用已正确分类的有标签训练样本建立每类平均激活向量，对距离尾部分布作极值建模，再重新分配部分激活以估计未知类别。它是有监督识别之上的开放集机制，不是仅正常训练的异常检测。[cite:6](#source-6)

**新增代价与遗留问题：**引入尾部样本量、激活层、距离模型和拒识阈值；类内多模态、数据漂移与近似未知件仍可能失效。原文的 open-space risk 讨论有模型条件，不是所有未知件拒识保证。仅拒掉未知零件也不够：已知零件错位仍是装配 NG，已知零件被手遮挡则可能 UNKNOWN。仓库 SVC 概率输出没有该机制，也未做现场概率校准。

### 3.7 E07：关系边成为独立预测对象

**先前瓶颈 → 改变维度 → 机制：**逐件检测即使全对，也不能区分相同对象集合上的不同关系。Xu 等把对象框／类别作为节点、成对有向谓词作为边，用对象与关系之间的迭代消息传递利用上下文。原文涉及 Visual Genome 的人工关系标注和 NYU Depth V2 支撑关系；不仅需要类标签，也要关系监督。[cite:7](#source-7)

**新增代价与遗留问题：**有 n 个候选时全有向对象对可达 n(n−1)，关系预算与迭代次数增加计算；关系长尾、标注缺失、对象错检会传播。自然图像“在上面／支撑”与工业“插接、锁止、间隙超限”不同，迁移必须重定义谓词与物理可观测证据。上下文模型能提高关系预测，不保证硬规格必满足；安全关键项应保留显式约束和未知状态。仓库无该场景图网络，A01 是工程规则而非学习消息传递。

### 3.8 E08：IKEA ASM 把时间、对象与多视角放到装配活动评测中

**先前瓶颈 → 改变维度 → 机制：**短视频动作分类难覆盖长装配流程；相似零件、遮挡与相近动作需要上下文。IKEA ASM 提供多视角家具装配视频及深度、原子动作、对象分割、人体姿态等数据，建立动作识别、对象分割／跟踪和姿态等基线。正式论文为 **WACV 2021，不是 CVPR 2021**；2020 是预印本，2023 是 arXiv 修订。[cite:8](#source-8)

**新增代价与遗留问题：**采集同步、跨视角对应和时序标注增加成本；动作、姿态、对象分割的标注粒度不同，不能默认每帧每项都有完整真值。家具装配活动基准不是工业不良品／扭矩质量认证。看到“旋入”不证明已到底，长时序模型也可能把常见顺序当成执行事实；必须另外接终态几何或工艺传感证据。当前只有教学跟踪卡，未实现完整视频理解或流程核验。

## 4. 工程实践线：从对象证据到装配决策

### 4.1 任务契约与静态三态基线

先把规格写成可检查字段：产品／BOM 版本、每种部件的数量和槽位、允许位置／角度、必须可见的方向标志、哪些接触／锁止需要额外传感器。输入不只是图像，也包括产品型号与工位状态；若业务不给产品型号，型号识别和未知产品拒识必须先验收。不能把所有合法装配序列强行收束为唯一动作顺序。

候选确定后，按 [A01](algorithm_cards/remaining_domains.md#a01-数量与相对几何装配规则) 先去重、一对一绑定实例与槽位，再把测点变换到产品系。采用列向量约定时 \(p_{product}=T_{image\leftarrow product}^{-1}p_{image}\)；框中心、孔心、连接点要区分，ROI 偏移、畸变和毫米尺度另由 [标定坐标](calibration_coordinates.md) 管理。此处是二维规则骨架，不冒充三维配合验证。

关系残差可写为 \(r=(p_j-p_i)-d_{ij}^{nominal}\)。若两个测点误差有关，\(\Sigma_r=\Sigma_i+\Sigma_j-\Sigma_{ij}-\Sigma_{ji}\)，不能默认共享配准误差独立。角度使用周期差，但对称件的真实朝向可能本来不可辨识；应增加非对称标志／视角或返回 UNKNOWN，而非把一个高分角度当真值。公式来自既有卡的模型推导，不是给定工业误差保证。

**三态汇总：**存在可信硬规则违例时报告 NG 并列出证据；无已证实违例但有不可评估必检项时为 UNKNOWN；所有必检项均可靠通过才为 OK。被遮挡区域没有候选，不足以证明漏装；有效可见且检测能力经验证的应有槽位确实为空，才可按规格判 NG。具体 NG 优先级、复检和停线策略由业务安全评审确定。

### 4.2 工程选型矩阵

| 场景／约束 | 优先评估路线 | 为改进支付的代价 | 不可跳过的验证 |
|---|---|---|---|
| 少型号、稳定工位、明显几何差别 | 模板／测量前置＋A01 规则 | 每 SKU 容差与参考维护 | 缺／多／错／反装、可见性与坐标 |
| 单件已可靠裁出、类别主要差在纹理／轮廓 | 手工特征＋SVM／RF 与学习分类器对照 | 真标签、困难负例、概率校准 | 逐类混淆与未知件拒识，不只总体准确率 |
| 型号多且外观变化大 | 迁移 CNN 分类，未知类处理另设 | 预训练域、微调、推理与版本成本 | 批次隔离、裁剪／归一化、方向语义 |
| 一图多件、位置变化大 | 检测／分割＋槽位关联＋规则 | 实例标注、候选召回和去重成本 | 小件／密排／遮挡的召回，整件漏放 |
| 零件都在但关系复杂 | 几何规则优先，必要时学习关系辅助 | 关系标注、成对计算、上下文偏差 | 错位／交叉连接反例、硬规格一致性 |
| 过程顺序与中间状态重要 | 时序识别＋合法状态／偏序约束 | 视频标注、同步与在线延迟 | 跳步、重复、返工、遮挡恢复和报警时刻 |
| 插接深度、隐藏锁止、拧紧力矩 | 额外视角／深度／工艺传感器 | 硬件、标定、同步和质量溯源 | 直接物理真值；不以 RGB 类分数替代 |

推荐不是论文性能排名。分阶段系统可提供逐条证据，但误差会传递；端到端模型可减少人工规则，却可能学背景捷径并难以解释罕见失效。对安全关键装配，判为“未知需复检”是合法设计，不应只追求低复检率而提高误放行。

### 4.3 按症状排障

| 症状 | 优先检查的证据 | 调整顺序 | 不应采用的捷径 |
|---|---|---|---|
| 类别准确率高，漏装仍漏放 | 应有槽位、候选召回、规则输入与整件结果 | 可见性／召回 → 关联 → 数量规则 | 只换更强分类器 |
| 重复框导致多装报警 | 原候选、NMS、槽位一对一分配 | 先去重与实例绑定，再规则 | 框数直接等于零件数 |
| 密排小件少检 | 下采样、参考框／候选预算、NMS 压制 | 原分辨率／切片 → 召回 → 去重 | 仅降低分类阈值 |
| 产品转动后关系全错 | 产品姿态、变换方向、ROI 与角度单位 | 坐标链 → 测点定义 → 容差 | 在图像系硬调位置阈值 |
| 正反装混淆 | 对称性、关键标志、旋转增强与标签 | 可观测性 → 采集 → 标签／模型 | 让方向不变特征自动恢复朝向 |
| 新型号被高置信判老型号 | logits／激活、标签表、域差 | 型号管理 → 开放集校准 → 模型适配 | Softmax 最大值当存在证明 |
| 关系网络把缺件“补齐” | 原始候选与关系先验、未观测节点 | 分离观测与推断 → 硬约束 → UNKNOWN | 关系高分等于实际看见 |
| 动作识别正确但装配不良 | 动作段与终态几何／工艺记录 | 同步 → 状态转移 → 物理验证 | “拧紧”动作类等于扭矩达标 |
| 离线准确、在线报警晚 | 是否用未来帧、缓存、跨相机时间戳 | 因果推理协议 → 延迟预算 → 状态回退 | 离线全视频指标冒充在线指标 |
| 换批下降或离线异常优秀 | 同件裁片泄漏、背景捷径、类别先验 | 实物分组 → 背景对照 → 重新校准 | 测试集反复调参后仍称独立验收 |

这些是接入后的排查方案，不表示本次采集过对应算法的运行时证据。

### 4.4 决策代价、指标与数据组织

分类器的训练损失不等于装配决策代价。若可获得适用域内校准后验，允许动作 a 的条件风险可写为 \(R(a\mid x)=\sum_y C(a,y)p(y\mid x)\)，其中 a 可含复检；这只是指定成本和概率条件下的决策模型。未校准分数不能直接代入充当可靠风险，物理不可观测项也不能因期望成本低就推断通过。

| 验收层 | 必报内容 | 必须固定的协议 |
|---|---|---|
| 类别／未知 | 逐类混淆、召回／精确率、未知错接收和已知误拒 | 类别词表、先验、开放集类别隔离与阈值 |
| 检测／定位 | AP 或召回及小件／遮挡分层、测点／朝向误差 | 真值框／点、匹配规则、NMS、坐标与单位 |
| 关系／装配 | 缺、多、错、反、不到位分别统计；整件漏放／误拒／UNKNOWN | 规则版本、可见性、关系方向及未检项处理 |
| 过程 | 动作／状态识别、段边界、跳步与返工漏报、报警延迟 | 是否允许未来帧、多视角同步、合法偏序 |
| 部署 | 端到端与分阶段尾延迟、资源峰值、超时／复检比例 | 输入分辨率、候选数、权重、软件／硬件与预热 |

漏放率应说明分母是实际不合格整件数，误拒率分母是实际合格整件数；UNKNOWN 独立统计，不能从分母悄悄剔除。训练／调参／验收按实物、批次、产品版本分组，视频按完整序列或人员／场景分组，跨视角同一次装配不能分到不同集合。新产品拓扑与新外观是两种泛化，必须分开评价。本文未执行这些测试，也没有通用精度／漏放率或机器人安全保证。
