# 算法演进与 L1–L5 学习规范

[返回知识库总目录](README.md)

本规范适用于知识库全部领域。目标是同时服务系统学习、面试追问与现场排障；它是后续编写和既有章节补齐的标准，不表示现有算法已经完成全部层级。

## 一、领域层：先建立演进核心主线

每个领域保留“历史演进线＋工程实践线”，并在时间线之前解释该领域持续优化的核心问题。不得把匹配领域的维度机械套用到所有领域。以下是编写用分析框架，不是唯一的学术分类或已经核验完毕的算法史。

| 领域 | 建议分析的核心维度 |
|---|---|
| 预处理增强 | 退化与噪声模型、先验、保真目标、恢复求解、下游任务影响、计算成本 |
| 标定坐标 | 成像模型、可观测性与采样设计、参数估计、鲁棒性、误差传播、坐标链一致性 |
| 分割区域 | 区域表示、区分依据、空间约束、多尺度上下文、监督方式、边界与实例处理 |
| 定位匹配配准 | 表示空间、相似度量、几何模型与约束、搜索求解与加速、验证拒识 |
| 边缘几何测量 | 成像与边缘模型、亚像素估计、几何拟合、异常点处理、标定与不确定度 |
| 缺陷异常 | 正常与异常定义、特征表示、监督和样本组织、评分定位、小缺陷处理、阈值与跨域泛化 |
| 分类装配 | 对象表示、类别与关系建模、监督数据、未知类处理、决策与代价、泛化 |
| 字符编码 | 成像与定位、字符切分或序列建模、识别与解码约束、拒识、质量与追溯；OCR 与条码分支区分 |
| 颜色外观 | 光源与相机响应、颜色表示、校准与感知度量、空间纹理、参考标准、批次稳定性 |
| 三维重建测量 | 深度获取模型、对应关系、几何约束、重建优化、遮挡完整性、尺度与误差 |
| 对焦成像质量 | 清晰度评价、纹理与噪声鲁棒性、焦点曲线模型、采样搜索、运动闭环、耗时 |
| 跟踪运动视觉引导 | 状态与观测模型、数据关联、时序估计、遮挡重定位、坐标同步、延迟和闭环稳定性 |

每个历史节点说明：先前瓶颈 → 本方法改变的维度 → 改进机制 → 新增代价 → 遗留问题。并行、组合、继承关系分开表达；新方法不等于全面替代旧方法。方法年代、软件版本和仓库实现日期分开记录，引用原始资料并注明获取限制。

## 二、算法层：按 L1–L5 展开

在 L1 前先交代任务、输入输出、适用前提、所属演进分支和当前实现状态。

| 层级 | 核心问题 | 必备内容 | 可检验的学习目标 |
|---|---|---|---|
| L1 步骤 | 流程是什么？ | 输入输出、步骤、依赖关系、停止条件、流程或伪代码 | 不只背名称，能用一个具体输入走完整个过程 |
| L2 机制 | 为什么有这一步？ | 每步解决的困难、因果机制、不变量、删除或替换后的后果 | 能解释必要性，并给出反例或替代方案 |
| L3 工程权衡 | 参数如何定、何时失效？ | 参数单位与尺度、初值范围的依据、精度与耗时权衡、失效症状、诊断证据、调参顺序 | 能根据约束选型、调参和排障，而非背固定参数 |
| L4 数学推导 | 公式从哪来、成立条件是什么？ | 建模假设、目标函数、关键推导、可辨识性、退化条件、复杂度、适用的误差或收敛分析 | 能推导关键关系，明确保证的前提和不保证的部分 |
| L5 实现 | 如何正确复现与优化？ | 源码对应、数据布局、坐标、精度、边界、数值稳定性、测试、剖析、优化前后等价性 | 能实现、验证和优化；不以“从零写完所有依赖”为要求 |

层级是讲解深度，不是不可逆的学习顺序。实际可先复现最小实现，再回到机制和推导。不是每个算法都需要完整独立训练工程，但未完成的层级必须标明。

## 三、数学与实现的诚实边界

- 误差界并非每个方法都有。区分确定性上界、统计方差或置信区间、渐近结果、数值误差、离散化误差与实测误差，不能互相替代。
- 例如 Cramér–Rao 下界依赖统计模型与正则条件，通常针对符合条件的估计器；它不是具体程序误差的上界，也不能无条件用于有偏估计。
- 优化收敛不代表达到全局最优；输出亚像素坐标不代表达到相同物理测量精度。
- 没有可证通用界时，写明“未提供通用理论界”，改述敏感性、成立条件和可验证指标；不得编造常数或论文结论。
- ML/DL 区分训练目标、推理流程与数据假设；论文结果、公开实现结果与本仓库实测分开标注。
- L5 可先提供明确标注的参考实现或伪代码分析，但“有伪代码”“读过外部源码”“本仓库已实现”“测试通过”“现场验证”是不同状态。
- 包装第三方函数不代表理解内部机制；自己重写也不自动优于经过验证的库。优化前先验证正确性，再按实际瓶颈选择向量化、缓存、剪枝、并行或硬件加速。

## 四、每个算法的面试追问与答题要点

每个算法至少设置一条贯穿 L1–L5 的追问链，并记录参考答案要点、成立条件、易错答案和证据入口。题目是知识库自测设计，不冒充某家公司真实题库或必考题。

| 层级 | 通用问法 | 答题应包含 |
|---|---|---|
| L1 | 给定输入，完整流程与输出是什么？ | 步骤顺序、输入约束、停止条件、异常输出 |
| L2 | 去掉这一步会怎样？为什么不用另一种方法？ | 因果解释、成立条件、具体反例 |
| L3 | 场景发生变化，先改哪个参数？ | 诊断证据、参数量纲、对照实验、代价与回退策略 |
| L4 | 从假设推导关键公式，什么情况下失效？ | 中间步骤、退化条件、界或保证的适用范围 |
| L5 | 数学没错但代码出错，可能在哪？怎样优化？ | 数据类型、坐标、边界、数值问题、测试与剖析证据 |

### ZNCC 示例追问链

1. L1：如何由图像和模板生成位置？要点：有效支持、去均值归一化评分、取峰、候选抑制、拒识与可选精化。
2. L2：为什么去均值？要点：消除固定支持下的加性常数偏置；不消除局部反光、饱和、遮挡或几何错位。
3. L3：旋转目标低分，是否直接降低阈值？要点：先核对姿态范围与步长、成像、纹理和掩膜，再用独立正负样本标定；降阈值可能增加误报。
4. L4：若 I=aT+b，得分是多少？要点：模板非恒定且 a>0 时为 1，a<0 时为 -1，a=0 时退化；要求几何对齐、同一支持且没有破坏关系的量化或饱和。
5. L5：为何局部方差可能算成负数？要点：Q−S²/n 的大数相消；解释幅值处理、可靠性判断、直接评分兜底和常量窗口处理，不能仅加一个极小分母掩盖问题。

对应依据：[ZNCC 理论与实际实现边界](pose_ncc.md)、[匹配演进样章](matching_evolution.md)。这些问题不表示其他算法已经完成五层内容。

## 五、覆盖检查与补齐顺序

每个算法维护以下独立字段：演进定位；L1、L2、L3、L4、L5 的覆盖状态；面试追问链；来源；实现状态；验证范围。各层使用“未写／部分／已核验／不适用并说明原因”，不按篇幅或算法名称出现次数认定完整。

算法卡片填写模板：

| 项目 | 要填写的内容 |
|---|---|
| 演进定位 | 年份版本、分支、前序瓶颈、核心改进维度、代价 |
| L1–L5 | 分层正文或对应章节链接、当前覆盖状态、遗留问题 |
| 面试自测 | 逐层问题、答题要点、反例、推导题或实现题 |
| 来源与实现 | 原始资料、公式来源、源码路径、版本、是否本地实现 |
| 验证 | 测试数据、指标、结果来源与适用范围；无实测则明确填写 |

先以已有实现的 ZNCC 补齐标准算法卡片，再覆盖各领域的代表性基础方法。保持广度目录与深度卡片分离：领域已建总览不代表每个算法已达 L5，面试准备也不能替代现场安全与验收要求。
