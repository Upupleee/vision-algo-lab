## 2. 基础评分、形状与局部优化

### 01. 匹配滤波与噪声白化

**任务／演进／状态：R。** 已知非零有限能量信号和噪声模型 → 线性检测响应；North 1943 报告、1963 重印是重要早期来源，不是全部图像匹配的唯一源头。改进是按信号形状汇聚能量，代价是噪声模型与模板依赖。仓库无独立检测器或白化链；ZNCC 分子相关不等于完整匹配滤波。[cite:1](#source-1)

**L1 步骤。** 固定观测支持和模板 → 从无信号背景估计协方差 → 白化或求解权重 → 滑动内积 → 根据虚警要求取阈值 → 返回峰位置、响应和拒绝结果。候选穷尽即停止，信号零能量或协方差不可用应报告失败。

**L2 机制。** 线性权重让与模板一致的信号同向累加；有色噪声中高噪声方向须降权。删掉白化，在强条纹背景上普通相关可能主要响应条纹。ZNCC 的窗口分母依赖观测，不是固定线性滤波器，不能继承同一个最优性证明。

**L3 工程。** 先检查背景平稳性与协方差特征值，再选估计支持与正则强度，最后标定阈值。协方差样本不足时全矩阵估计不稳定，可用结构化模型；正则化改变原始最优解，不是免费修复。先收窄物理位移范围，别把背景峰当检测概率。

**L4 推导。** \(x=s+n,E[n]=0,E[nn^H]=C\succ0\)，令 \(a=C^{1/2}w,b=C^{-1/2}s\)。由 Cauchy–Schwarz，
\[
\operatorname{SNR}(w)=\frac{|w^Hs|^2}{w^HCw}=\frac{|a^Hb|^2}{a^Ha}\le s^HC^{-1}s,
\]
等号条件 \(w\propto C^{-1}s\)。白噪声 \(C=\sigma^2I\) 时 \(w\propto s\)，卷积核为共轭反转模板。证明只需二阶矩，不需高斯；给定虚警率的检测最优性另需分布与假设。一般协方差分解约 \(O(n^3)\)，空间匹配 \(O(Pn)\)。

**L5 复现设计。** 用 Cholesky 解线性系统而非显式求逆；复数必须共轭，输出索引要扣除核延迟。以单位协方差检查退化成普通相关，以有色背景检查白化收益，以病态矩阵检查拒绝／正则协议。此设计未在仓库运行，外部推导不是 North 全文逐项复现。

**五层面试答案。** L1 问“输出是什么？”答：响应与假设检验结果，不自动是姿态。L2 问“为何白化？”答：抑制高方差方向。L3 问“先调阈值吗？”答：先确认噪声模型与背景样本。L4 问“必须高斯吗？”答：SNR 推导不必，概率最优性另论。L5 问“怎样避免求逆失稳？”答：分解求解、条件数与零能量测试。易错答案是“相关对任意背景最优”；证据为本节推导和来源 1。

### 02. SAD、SSD 与原始互相关

**任务／演进／状态：R。** 同尺寸、对齐支持上的块比较 → 标量或评分图；它们是基本目标函数而非本仓库可切换模式。由全像素误差转为相关展开可以复用快速卷积，但不能任意删去窗口能量项。[cite:3](#source-3)[cite:4](#source-4)

**L1 步骤。** 统一类型和支持 → 对每个合法平移求绝对差、平方差或内积 → 分别取最小、最小、最大 → 阈值及候选抑制。无合法窗口应异常，不以全零评分代替。

**L2 机制。** SAD 对大残差线性惩罚，SSD 二次惩罚；原始相关强调同向能量，但亮斑可能压过真正目标。删除归一化前应判断照明是否稳定；SAD 对异常值影响较小不等于具有任意遮挡鲁棒性。

**L3 工程。** SAD 单位是灰度、SSD 是灰度平方，求和还随 n 增长；跨模板比较需说明是否除 n。调参顺序为曝光／位深 → 支持大小 → 噪声模型 → 阈值。整数先相减再转换会发生无符号回绕，必须先转有符号宽类型或浮点。

**L4 推导。** \(E_1=\sum|I_i-T_i|\)，\(E_2=\sum(I_i-T_i)^2=\sum I_i^2+\sum T_i^2-2c\)，\(c=\sum I_iT_i\)。固定模板且候选图像能量恒定才可用最大 c 等价最小 SSD。独立同尺度 Laplace 残差的负对数似然对应 SAD；独立同方差高斯对应 SSD，异方差须加权。直接全图 \(O(Pn)\)。

**L5 复现设计。** 构建非向量化宽精度参考，再对卷积展开与逐项 SSD 作等价检查，特别验证高亮低纹理、反相、不同支持和溢出。OpenCV 六种模板模式包含 SSD／相关及归一化版本，但没有 SAD 模式；本地两个 NCC 接口均不是 `matchTemplate` 包装。

**五层面试答案。** L1 问“最优方向？”答：差异最小、相关最大。L2 问“相关为什么可能找亮斑？”答：未控制能量。L3 问“换位深阈值呢？”答：按残差量纲重新标定。L4 问“SSD 等价相关的条件？”答：候选能量不变。L5 问“uint8 相减安全吗？”答：先提升类型。易错是“SSD 展开后只有相关项”；证据为来源 3、4 与展开式。

### 03. SSDA：统计式逐次相似性检测

**任务／演进／状态：R。** Barnea／Silverman 1972：对大量差候选减少访问项数，新增早停参数与漏峰风险。仓库未实现 SSDA；后处理 NMS、候选截断、整行早停均不算候选内部逐次比较。[cite:2](#source-2)[cite:3](#source-3)

**L1 步骤。** 为候选指定随机访问次序 → 逐批累积部分相关 → 估计是否可能接近最佳值 → 不看好则结束该候选，否则继续到完整支持 → 进入下一候选。最终最优是已评估流程的最优，不必是完整相关面的最优。

**L2 机制。** 容易排除的位置无需相同算力；但少数强证据可能很晚出现，部分样本不足时会误判窄峰。Lewis 讨论的是 Monte Carlo 式部分相关；不能把该解释称为 1972 全文所有变体的共同定义或精确保证。

**L3 工程。** 参数为批大小（像素数）、早停阈值（评分单位）、访问次序及种子。先固定完整目标作基准，再记录平均／最大访问比例与漏掉全局峰的频率，最后减少预算。重复纹理与窄峰必须独立验收；困难样本仍可能全算。

**L4 推导。** 均匀抽样时 \(\hat c_k=(n/k)\sum_{i\in S_k}T_iI_i\) 可估计完整和，条件是抽样独立于被估贡献或使用正确权重；无放回抽样还改变方差。估计小不推出真实 c 小；连续查看并早停也不能直接套一次性置信区间。最坏复杂度仍 \(O(Pn)\)，无通用固定加速倍数。

**L5 复现设计。** 记录每个候选的访问顺序、停止位置、估计值与完整分数；保留完整搜索模式做逐候选反证。不能用局部样本均值代替完整 ZNCC 均值后仍声称同目标。1972 全文未取得，L5 仅为 Lewis 所述统计变体的设计。

**五层面试答案。** L1 问“哪里退出？”答：单候选内部。L2 问“为何能快？”答：差候选少算。L3 问“如何量化代价？”答：像素访问、尾延迟和漏峰一起看。L4 问“无偏估计是否不漏？”答：不是。L5 问“如何证伪？”答：逐候选对照完整评分。易错是把任何 `break` 称为 SSDA；证据为来源 2、3。

### 04. 严格界剪枝与启发式早停

**任务／演进／状态：M。** 将“估计差”改成“证明不能更优”可保留完整搜索最优性，但须合法界；仓库没有 SAD／SSD 部分和或 ZNCC 上界剪枝，仅形状模块有整行后启发式早停。以下界由代数推出，不冒充 SSDA 原文算法。[cite:3](#source-3)

**L1 步骤。** 先完整算一个候选建立最好值 B → 累积下一候选并更新合法界 → 界证明不可能优于 B 时退出 → 否则算完更新 B。形状当前流程则是整行评分后，最佳分数达到 `max(min_score,0.98)` 就跳过后续行。

**L2 机制。** 固定非负误差的部分和单调不减，所以可排除；相关乘积有正负，不满足同一单调性。形状分数虽理论不超过 1，得到 0.98 仍可能后面有 1，故不能宣称保留最优位置。

**L3 工程。** 排列大残差可能早暴露的像素有利，但次序不能改变目标。保留所有并列最优时用严格比较；浮点界需保守舍入裕量，不能用未经量纲分析的固定 epsilon 随意排除。先比较与完整遍历结果，再比较节省计算量。

**L4 推导。** \(E_k=\sum_{i=1}^ke_i\le E_n\) 要求 \(e_i\ge0\)、支持与权重固定；\(E_k>B\) 可剪，允许丢弃并列解才用 \(\ge\)。对完整去均值向量 t、i，剩余集合 R 满足
\[
c\le c_k+\|t_R\|\|i_R\|,
\]
分母 \(\|t\|\|i\|>0\) 已知时可得 ZNCC 上界。若均值／分母随部分样本改变，界失效；预先计算全统计也有成本。

**L5 源码／设计。** [形状源码][code-shape] 60–73 行是行级启发式，`min_score` 不过滤最终结果。严格剪枝需新增实现，本章不改它；应以包含并列峰、反号贡献、溢出和遍历次序变化的测试验证，不能只测随机容易样本。

**五层面试答案。** L1 问“何时更新 B？”答：完整候选或可信完整值。L2 问“部分相关低能剪吗？”答：还需剩余上界。L3 问“相等能剪吗？”答：看是否保留并列。L4 问“ZNCC 上界从哪来？”答：剩余向量 Cauchy–Schwarz。L5 问“0.98 早停精确吗？”答：不是。易错是把统计／启发式／严格界混称无损；证据为本节推导及源码。

### 05. NCC 与 ZNCC 的共同数学契约

**任务／演进／状态：M。** 固定支持灰度向量 → 无量纲相似度；能量归一化抑制增益，去均值再抑制常数偏置，代价是局部统计和常量退化。本仓库两套名为 NCC 的实现实际均为 ZNCC，未提供未去均值 NCC 切换。[cite:3](#source-3)[cite:4](#source-4)

**L1 步骤。** 取相同支持 → 算范数（NCC）或均值与中心化范数（ZNCC）→ 非退化时内积除范数 → 生成评分图 → 取峰与拒识。常量 ZNCC 窗口没有定义，不能直接赋满分。

**L2 机制。** 均值投影去掉常数方向，但也丢弃绝对亮度线索；两个不同灰度但同纹理对象可都高分。正负极性仍保留，取绝对值是另一个目标函数；局部反光与饱和破坏线性光度关系。

**L3 工程。** 分数范围理论 \([-1,1]\) 不是概率，候选数增加会改变无目标最大值分布。先检查纹理有效性、支持和姿态，再以独立正负样本选阈值；不要将 NCC、PSR、SVM 概率共用 0.8。

**L4 推导。** \(J=I_n-\mathbf1\mathbf1^T/n\) 是常数子空间的正交补投影，
\[
r_N=\frac{T^TI}{\|T\|\|I\|},\qquad r_Z=\frac{(JT)^T(JI)}{\|JT\|\|JI\|}.
\]
由范数不等式得范围；若 \(I=aT+b\mathbf1\)，则 \(JI=aJT\)，非恒定模板且 \(a\ne0\) 时 \(r_Z=\operatorname{sign}(a)\)，\(a=0\) 退化。直接每窗 \(O(n)\)，快速统计不改变数学目标。

**L5 源码契约。** [旧源码][code-ncc] 的 `local_std` 是 \(\sqrt{\sum(I-\mu)^2}\)，不是除 n 的统计标准差；模块开头用“标准差”容易误读。单元参考应按两个中心化范数计算，不能丢掉 \(\sqrt n\) 因子。两实现数值差异分别见 06、07；它们不是逐位等价。

**五层面试答案。** L1 问“先算什么？”答：同支持统计。L2 问“为何去均值？”答：去掉加性常数。L3 问“高分说明存在吗？”答：还需竞争峰及负样本。L4 问“反相得几分？”答：理想 -1，常量无定义。L5 问“标准差能直接替换范数吗？”答：需补 \(\sqrt n\)。易错是“ZNCC 对任何光照不变”；证据为来源 3、4。

### 06. 平移 ZNCC：FFT 分子＋矩形积分图实现

**任务／演进／状态：K。** 二维图像、非恒定矩形模板 → 平移评分图／候选列表；对应 Lewis 快速归一化路线。仓库已实现，不含掩膜、姿态网格或新拒识协议。[cite:3](#source-3)

**L1 步骤。** 转 `float64` → 检查二维及模板不大于图像 → 模板中心化与能量 → FFT 相关分子 → 两张积分图求 S、Q → 方差下限处理 → 相除；`find_best_matches` 再阈值、排序、NMS、可选抛物线。

**L2 机制。** 模板和为零使图像局部均值项在分子抵消；矩形积分图四角查询避免逐窗重算。删去平方和分母会退回亮度敏感相关；对任意旋转掩膜仍用矩形查询则错误加入无效像素。

**L3 工程。** 旧入口默认 `min_score=0.9,nms_radius=8,max_count=10`。先固定支持与灰度量纲，再检查最大分数、常量背景和阈值；大偏置弱纹理可能导致积分图相消。参数检查较弱，不应承诺非法 max_count／负半径和 NaN 都得到新接口式 `ValueError`。

**L4 推导。** \(t=T-\mu_T\)，\(\sum t=0\)，所以 \(\sum(I-\mu_I)t=\sum It\)；\(V=Q-S^2/n\)，\(r=\operatorname{corr}(I,t)/(\sqrt V\|t\|)\)。构表 \(O(HW)\)，FFT \(O(F\log F)\)，结果 \(P\) 个；候选全排序另付 \(O(C\log C)\)。

**L5 源码／验证。** [match_template_ncc][code-ncc] 16–51 行将所有 `var<1e-12` 置 `1e-12`，没有幅值归一化、可靠性判断、直接兜底或输出裁剪；返回范围只是理想目标，不是所有浮点输入保证。空数组与非有限数未全面检查。37 项回归中的 `test_legacy_ncc_interfaces` 和冒烟匹配已运行通过，但不证明极端数值与新实现相同；改进方案是先直接评分验证，不是强裁剪掩盖错误。

**五层面试答案。** L1 问“两张积分图做什么？”答：局部和与平方和。L2 问“分子为何不减局部均值？”答：模板零和。L3 问“偏置大时先调阈值？”答：先查方差相消。L4 问“复杂度？”答：FFT 加线性构表。L5 问“旧版有 -inf 常量协议吗？”答：没有新接口那套可靠性协议。易错是把新数值保护写给旧入口；证据为源码和来源 3。

### 07. 姿态 ZNCC：掩膜 FFT 统计实现

**任务／演进／状态：K。** 二维有限数组、二值支持和有限相似变换网格 → 带坐标矩阵的匹配／拒识字典。它把矩形统计扩为掩膜统计，代价是三次卷积及姿态枚举，不是 Lewis 论文逐项复现。[cite:3](#source-3)[cite:5](#source-5)

**L1 步骤。** 输入及配置检查 → 模板自评分检查 → 图像金字塔 → 每姿态变换模板和支持 → `_search_pose` → 有限邻域平移精化 → 构造模板到图像矩阵 → 跨姿态中心 NMS → 分数／分差拒识。没有合法姿态、无有效峰和歧义有不同原因。

**L2 机制。** 掩膜卷积让分子与局部统计用同一支持，避免旋转补零形成伪纹理；直接兜底避免常量附近的数值误差制造高峰。模板有效区域只保留可见像素，并不赋予出画目标或任意遮挡不变性。

**L3 工程。** 默认 `0.8/0.03/8 px/1目标/3层/8候选`，默认角度 0、尺度 1、全分辨率复核开启。先校验坐标与范围 → 网格 → 支持纹理 → 候选容量与半径 → 阈值。角度／尺度离散，关闭复核可漏次优而错误放行唯一性。

**L4 推导。** 对二值 M，\(n=\sum M\)，\(t_i=M_i(T_i-\mu_T)\)，\(S=I\star M,Q=I^2\star M,N=I\star t\)，\(r=N/\sqrt{(Q-S^2/n)\sum t_i^2}\)。三种相关必须同一核原点和 `valid` 支持。忽略兜底时 G 个姿态约 \(O(GF\log F)\)，实际 F 随画布变化；兜底最坏增加 \(O(GPn)\)。

**L5 源码／验证。** [pose_ncc.py][code-pose] `_score` 要求至少 4 有效像素、模板非恒定；原始模板非法抛异常，变换后退化姿态跳过。内部无效窗口 `-inf`，顶层缺失分数 `None`；输入不修改。现有 37 项测试通过，含掩膜、姿态、极值、常量、奇数相位等；不含现场精度认证、所有姿态歧义或全面 ML/DL 验证。

**五层面试答案。** L1 问“输出 x 是画布左上角吗？”答：不是，是原模板原点映射。L2 问“掩膜为何也卷积？”答：局部统计必须同支持。L3 问“金字塔默认更快吗？”答：保留每姿态原图完整复核，不能这么推断。L4 问“为何三次卷积？”答：分子、和、平方和。L5 问“常量图像与无姿态区别？”答：前者可已搜索但无峰，后者无合法评分姿态。易错是把 FFT 当旋转不变；证据为源码及 26–37 项。

### 08. 相位相关

**任务／演进／状态：R。** 同运动且充分重叠的两图 → 平移；Kuglin／Hines 1975 为代表文献。相位谱消去幅值，将全局平移化为峰，代价是周期歧义与弱频率噪声敏感。仓库无相位归一化／`phaseCorrelate`。[cite:6](#source-6)

**L1 步骤。** 确定参考图与移动图 → 去不连续边界或加窗 → FFT → 归一化互功率谱 → IFFT → 峰与回绕位移 → 可选局部上采样 DFT → 检查重叠与可信度。不足频谱能量或多个运动应拒绝。

**L2 机制。** 平移只改变相位，但把很小频谱幅值也归一到单位会抬高噪声。窗函数抑制边界，却破坏严格纯平移关系；掩膜注册是额外算法，不能认为传 mask 后仍走完全同一相位公式。

**L3 工程。** 位移为像素，DFT 上采样因子决定离散估计分辨率，不等于物理准确度。先检查方向和回绕，再检查窗、重叠及频谱噪声；高噪声时可比较未归一化相关。旋转／尺度须单独引入对数极坐标扩展，不由一次基础相位相关获得。

**L4 推导。** 固定 DFT 负指数约定，若 \(B(x)=A(x-d)\)，则 \(F_B=F_Ae^{-i\omega d}\)。取 \(R=F_B\overline{F_A}/|F_B\overline{F_A}|\)，非零频率上 R 为位移相位，逆变换峰位是 d；若交换乘积次序则是 -d。零频率集合被剔除后不再是理想全带冲激。复杂度 \(O(F\log F)\)，输出按图尺寸取模。

**L5 复现设计。** 使用带方向的单轴已知位移测试，并区分“移动图需施加的校正量 -d”与“目标位移 d”；scikit-image 返回按数组轴排序的校正量。近零谱先建可靠掩膜再除法；局部 DFT 与三点抛物线分开验收。本仓库尚未运行这一链路。

**五层面试答案。** L1 问“峰后还做什么？”答：回绕与方向转换。L2 问“为何不总抗噪？”答：弱频率被等权放大。L3 问“有旋转怎么办？”答：换模型／独立扩展。L4 问“符号由什么决定？”答：乘积顺序与 DFT 约定。L5 问“坐标顺序？”答：确认 API 的 yx／xy 和校正方向。易错是“FFT-NCC 就是相位相关”；证据为来源 3、6。

### 09. Chamfer 与距离变换

**任务／演进／状态：R。** 模板轮廓点、图像边缘及变换族 → 最小距离姿态；Barrow 等 IJCAI 1977 将严格边缘重合改为最近边缘距离，代价是边缘提取、杂边歧义及搜索。仓库形状模块没有距离场，不是 Chamfer。[cite:7](#source-7)

**L1 步骤。** 提取图像边缘 → 边缘置零、其余初始化无穷 → 距离传播 → 每个姿态变换模板点 → 查询距离并聚合 → 取最小及阈值检查。空边集、点越界和无有效支持要显式失败。

**L2 机制。** 距离场使稍偏离的轮廓也能获得连续接近信息；单个图像边缘可能吸引多条模板边，杂边密集时低距离未必正确。加入方向或双向距离可提高约束，但不再等同基础单向目标。

**L3 工程。** 精确欧氏距离单位为像素；原始离散 chamfer 的轴向 2、对角 3 是相对距离近似，不能直接当 px。先控制边缘密度／极性，再确定截断距离与几何范围。截断能降低遮挡影响也可能让错误姿态更难区分；报告覆盖率而非仅均距。

**L4 推导。** \(D_E(x)=\min_{q\in E}\|x-q\|\)，\(C(p)=n^{-1}\sum_i D_E(W(p_i;p))\)。由交换“每姿态最近邻搜索”为预计算 D 得到每姿态 \(O(n)\) 查询，固定维度精确 EDT 可线性于图像像素，但原论文两遍离散近似不应称精确 EDT。截断形式 \(\sum\min(D,\tau)/n\) 是鲁棒扩展，无全局几何最优保证。

**L5 复现设计。** 保证 EDT 的零集合是边缘而不是背景；双线性查询的坐标为 xy，数组为 yx。以直线已知距离检验单位，以空边缘、平行线、多边指向一边和遮挡测试退化。原文含参数化投影／逐参数搜索，本地没有相应求解器。

**五层面试答案。** L1 问“距离场算几次？”答：固定图像边集一次。L2 问“为何杂边高风险？”答：最近距离可能靠错边。L3 问“2/3 权重是欧氏像素吗？”答：是近似相对代价。L4 问“加速何来？”答：最近邻搜索变查表。L5 问“如何发现前景反了？”答：直线距离与零集合测试。易错是把方向内积当距离；证据为来源 7。

### 10. 稀疏梯度方向形状匹配

**任务／演进／状态：K。** 灰度模板与图像 → 整数平移 `(x,y,score)`；本地教学基线使用梯度而非灰度幅值，代价是丢弃纹理幅值和 Python 全扫描。源码提到商业 shape-based 路线不构成 Steger／HALCON 等价复现，确切算法以本地函数为原始实现证据。

**L1 步骤。** Sobel → 选 `mag>20` 且前 `top_k=200` 点 → 单位方向及幅值归一权重 → 图像 Sobel → 遍历合法特征支持平移 → 全部点加权正内积 → 行级早停 → 返回目前最好位置。无特征抛 `ValueError`。

**L2 机制。** 正增益与常数偏置不改变非零梯度方向；负增益把极性翻转而被 `max(0,dot)` 排除。模板权重仍依幅值，固定阈值也使提点不对任意增益不变；零梯度图像点贡献零而非随机方向。

**L3 工程。** `min_mag` 是 3×3 Sobel 响应量纲，归一图像不能照搬 20；top_k 过小漏结构，过大会拖慢并引入噪点。先看选点空间分布与极性，再调阈值／数量。`min_score` 只影响 `max(min_score,0.98)` 早停，不是最终拒识阈值。

**L4 推导。** \(w_i=m_i/\sum m_i\)，\(S(u)=\sum_iw_i\max(0,d_i^Tg(u+p_i)/\|g(u+p_i)\|)\)，非零方向单位化且权重非负时 \(0\le S\le1\)。零图像梯度定义贡献 0。图像梯度 \(O(HW)\)，评分 \(O(PK)\)，模板排序 \(O(wh\log(wh))\)；无距离变换、旋转或尺度搜索。

**L5 源码／验证。** [shape_based.py][code-shape] 限制的是选中点支持而非完整模板画布；`u_min,v_min>=1`，上界由最大特征坐标决定，不能宣称覆盖左上角零位置的完整矩形搜索。冒烟形状测试通过；top_k 非法、NaN、边界和行早停偏差没有新接口同等测试覆盖。优化先批量平移评分，再与关闭早停的完整结果比较。

**五层面试答案。** L1 问“输出亚像素吗？”答：整数平移。L2 问“反相还高分吗？”答：非负方向点积保留极性，通常下降。L3 问“0.7 会拒绝低分吗？”答：当前不会。L4 问“为何上界 1？”答：单位点积与凸权重。L5 问“合法区域按谁算？”答：稀疏特征坐标。易错是“完整商业形状匹配／Chamfer”；证据为本地源码。

### 11. Lucas–Kanade：前向加法与逆组合边界

**任务／演进／状态：R。** 两图、初始变换、稳定支持 → 局部配准；Lucas／Kanade 1981 用梯度迭代替代枚举，代价是捕获范围和可观测性限制。逆组合属后续扩展，不全部归给 1981。仓库没有匹配／跟踪 LK。[cite:8](#source-8)[cite:9](#source-9)

**L1 步骤。** 给初值 → 在模板坐标采样移动图 → 残差及梯度 → Jacobian → 解参数增量 → 更新 → 增量／目标变化足够小或预算耗尽停止；奇异、越界或残差恶化需失败协议。金字塔可从粗层传播，但不是全局搜索保证。

**L2 机制。** 一阶线性化把非线性配准局部化为小系统。单边缘沿切向运动不可观测，平坦区两方向都不可观测；增加迭代次数不能增加信息。逆组合交换增量作用方向，固定模板梯度以复用 Hessian，但要求变换族可组合可逆及支持假设成立。

**L3 工程。** 窗大小 px、最大层数、迭代预算、停止阈值分别影响信息量和运动范围。先查初值与最小特征值，再查亮度／遮挡和窗口，最后改迭代。窗口跨多个运动会产生折中解；跟踪应检查前后向误差并在失锁时重定位。

**L4 推导。** \(E(p)=\frac12\sum_x[I(W(x;p))-T(x)]^2\)。令 \(r=I(W)-T,J=\nabla I(W)\partial W/\partial p\)，展开 \(r(p+\delta)\approx r+J\delta\)，得 \(J^TJ\delta=-J^Tr\)。满列秩才局部可辨识；线性模型同方差噪声下协方差约 \(\sigma^2(J^TJ)^{-1}\)，不是非线性实际误差上界。每步约 \(O(nd^2+d^3)\)。

**L5 复现设计。** 用 QR／SVD 解病态系统，有限差分核验 Jacobian 符号；前向加法 `p+=delta` 不可直接用于逆组合，后者 \(W_p\leftarrow W_p\circ W_\delta^{-1}\)。图像插值与梯度保持一致，以平坦、单边缘、小平移、远初值检查拒绝与收敛；三点评分峰拟合不是 LK。

**五层面试答案。** L1 问“停止是否成功？”答：预算耗尽不等于收敛。L2 问“单边缘为何漂？”答：Jacobian 缺秩。L3 问“先加层还是加迭代？”答：先证据判断位移／纹理。L4 问“正规方程从何来？”答：最小化线性化平方残差。L5 问“IC 怎么更新？”答：逆增量组合而非参数盲加。易错是“LK 无初值可全局定位”；证据为来源 8、9。

### 12. ECC：相关系数连续参数配准

**任务／演进／状态：R。** 初始变换、参考／移动图和固定目标支持 → 局部最大相关参数；Evangelidis／Psarakis 2008，用相关目标改善原始 SSD 的光度敏感性，代价是归一化 Jacobian 和局部收敛。仓库没有 ECC 更新或 `findTransformECC`。[cite:10](#source-10)[cite:9](#source-9)

**L1 步骤。** 初值与变换族 → warp → 两图中心化 → Jacobian 及投影量 → 解 ECC 局部近似增量 → 检查支持、相关提升与停止条件。出现退化或非收敛要拒识，而不是无条件输出最后矩阵。

**L2 机制。** 比较中心化单位向量方向，消除统一正增益和偏置；与 ZNCC 评分相连，但求解是连续参数迭代，不是网格加抛物线。负增益不是同一个正相关最优点；空间阴影、反光与遮挡仍会破坏模型。

**L3 工程。** 先用粗匹配取得合理初值，再选择最小可解释自由度；仿射／单应过自由可能把缺陷配准掉。记录每步相关、有效支持、矩阵条件、终止原因。OpenCV 终止 epsilon 是相关变化，不是毫米或参数统一范数。

**L4 推导。** \(t\) 为中心化参考，\(i(p)\) 为中心化采样，\(\rho=t^Ti/(\|t\|\|i\|)\)，故单位向量平方差为 \(2-2\rho\)。在 \(i+J\delta\) 近似下，令 \(H=J^TJ,g_i=J^Ti,g_t=J^Tt\)，当 H 可逆且下面分母为正时，局部 ECC 驻点更新为
\[
\lambda=\frac{i^Ti-g_i^TH^{-1}g_i}{t^Ti-g_t^TH^{-1}g_i},\qquad
\delta=H^{-1}(\lambda g_t-g_i).
\]
这是前向近似的一种记号；J 须与去均值操作一致，分母非正／接近零不适用这一分支。局部解析步不保证原非线性目标全局最优，每步成本与 LK 同量级。

**L5 复现设计。** 对采样方向构建独立已知变换测试，使用 OpenCV 时明确 `WARP_INVERSE_MAP` 对齐用途；不要误把逆采样当输出矩阵方向已反转。正增益偏置、低纹理、初值远、掩膜变动、近奇异 H 都需测试；本章未接入，公式不等于完成外部 API 验收。

**五层面试答案。** L1 问“输入必须有初值吗？”答：至少隐含单位初值，远运动需粗定位。L2 问“为何比原始 SSD 抗亮度？”答：中心化及单位范数。L3 问“高相关就安全？”答：还看支持、矩阵与模型。L4 问“解析更新无条件吗？”答：满秩与正分母等局部条件。L5 问“最易错何处？”答：warp 方向、均值 Jacobian 和失败处理。易错是“ECC 等于三点亚像素”；证据为来源 9、10。

### 13. RANSAC 鲁棒几何估计

**任务／演进／状态：R。** 含外点的对应集、模型与残差阈值 → 模型及内点集合；Fischler／Bolles 1981 用小样本共识替代全部点最小二乘，新增随机预算与退化样本成本。本地仅学习骨架文字提及，没有运行中的 RANSAC。[cite:11](#source-11)

**L1 步骤。** 选模型及最小样本数 → 无重复抽样 → 退化检查 → 拟合 → 全部对应求残差 → 更新最好共识与预算 → 达预算／置信条件停止 → 内点重拟合并重新验证。不足点数、无有效模型要返回失败。

**L2 机制。** 偶尔抽到全内点子集即可避免大外点拖偏；但全内点也可能共线、聚集或来自错误重复图案。高内点率不自动证明目标语义或物理模型正确；NMS 抑制峰不是共识拟合。

**L3 工程。** 重投影阈值单位是坐标所在图像的像素，缩图后必须换算。先选物理模型 → 检查点分布 → 标定残差噪声 → 调预算和置信度。阈值太宽会接受错误模型，太窄降低内点率并增时；种子只控制采样可复现性。

**L4 推导。** 独立试验、每次全内点概率近似 \(w^s\)，N 次全失败为 \((1-w^s)^N\)，要求不超过 \(1-p\) 得 \(N\ge\lceil\log(1-p)/\log(1-w^s)\rceil\)。有限集合无放回单次概率应为 \(\binom Is/\binom Ms\)；还需扣除退化概率。w=0 无有限保证，w=1 且样本非退化可一次。评分成本约 \(O(NM)\)。

**L5 复现设计。** 数值计算使用 `log1p` 处理近零概率，预算设上限；分别检查最小样本退化、重拟合后残差及投影角点。`min_inliers=30` 在 [学习骨架][code-dl] 中没有执行，不是有效拒识。验证应含共线、重复点、错误一致图案、不同坐标尺度。

**五层面试答案。** L1 问“什么时候重拟合？”答：选出共识后。L2 问“全内点就行吗？”答：仍须非退化。L3 问“阈值怎么定？”答：按重投影噪声与图像尺度。L4 问“次数公式保证什么？”答：理想采样至少一次全内点，不保证正确语义。L5 问“库成功返回就接受？”答：再查空间覆盖及物理合理性。易错是“RANSAC 自动产生特征”；证据为来源 11。

### 14. SIFT 尺度空间特征

**任务／演进／状态：R。** 灰度图 → 带尺度／主方向的关键点及描述子；Lowe 1999 会议、2004 期刊系统版。解决整块模板大尺度和旋转失配，代价是多尺度计算及浮点描述子；仓库未接入。[cite:12](#source-12)

**L1 步骤。** 高斯尺度空间 → DoG 三维极值 → 亚像素／尺度二次定位 → 去低对比及边缘响应 → 主方向分配 → 归一局部梯度直方图 → 最近邻过滤 → 可选几何验证。尺度层扫描完成停止，描述支持越界／不稳定点丢弃。

**L2 机制。** 尺度极值选择特征自身尺度，主方向消去平面旋转，空间／方向分箱允许小变形；去边缘点防止只有一方向精确定位。没有纹理的区域无法凭尺度归一化创造信息；不能称完全仿射或透视不变。

**L3 工程。** octave、每 octave 层数、对比度阈值、边缘阈值和点数预算分别影响覆盖与成本；先看尺度覆盖和空间分布，再看 ratio 过滤与几何内点。Lowe 的 4×4×8=128 维是标准描述布局；库版本的阈值尺度不能盲搬论文。

**L4 推导。** \(L=G_\sigma*I,D=L(k\sigma)-L(\sigma)\approx(k-1)\sigma^2\nabla^2L\)，利用高斯尺度导数关系。局部 \(D(z+\delta)\approx D+g^T\delta+\frac12\delta^TH\delta\)，驻点 \(\delta=-H^{-1}g\)。二维空间 Hessian 满足 \(\det H>0\) 时，曲率比约束可写 \((\operatorname{tr}H)^2/\det H<(r+1)^2/r\)。极值响应不等于几何误差界。

**L5 复现设计。** 3×3×3 中比较其余 26 邻点；尺度梯度用对应高斯层。描述子裁剪／重新归一化前防零范数，典型论文裁剪 0.2 是幅值限制非匹配阈值。输出 xy、尺度和方向，距离选 L2；测试旋转、尺度间点、单边缘、常量及边界。未运行本地 SIFT。

**五层面试答案。** L1 问“四阶段？”答：极值、定位、方向、描述。L2 问“为何去边缘响应？”答：沿边定位不稳定。L3 问“点多但 H 错？”答：查分布及重复纹理。L4 问“DoG 为何近 LoG？”答：尺度 Taylor 展开。L5 问“128 维用 Hamming 吗？”答：标准浮点 SIFT 用 L2。易错是“完全透视不变”；证据为来源 12。

### 15. FAST 圆周连续段检测

**任务／演进／状态：R。** 图像 → 角点候选；Rosten／Drummond 2006 代表版本通过像素比较和学习决策树加速，不输出描述子或自动尺度／方向。仓库未实现 FAST。[cite:13](#source-13)

**L1 步骤。** 对非边界像素读取半径 3 的 16 点圆周 → 相对中心按阈值分亮／暗／近似 → 找连续 n 个同亮或同暗 → 对通过点计算强度并 NMS → 返回位置。全文扫描停止，无候选返回空集。

**L2 机制。** 连续段比单个梯度更接近角形局部结构；快速四点测试可提前排掉多数非角点，学习树调整访问顺序。FAST-12 的四点至少三同类规则不能原封不动用于 n<12；2006 学习树在有限训练覆盖下不必与完整段测试完全等价。

**L3 工程。** t 是原灰度差，n 是连续点数，不是任意圆周点数；阈值过低噪点多，过高弱角丢失。先查灰度量纲和模糊，再调整 t 与 NMS，最后增加尺度层。不同 FAST 变体与打分定义应固定版本。

**L4 推导。** 设 \(b_j=[I_{p_j}>I_p+t],d_j=[I_{p_j}<I_p-t]\)，存在起点 k 使 \(\prod_{j=0}^{n-1}b_{(k+j)\bmod16}=1\) 或暗段乘积为 1 即通过。连续 12 段必覆盖四个正交检查点中的至少三个，故构成必要条件；对 FAST-9 不成立。固定 16 点使全图最坏 \(O(HW)\)，常数由比较次序决定。

**L5 复现设计。** 用圆周索引复制前 n−1 项解决首尾连接，避免漏跨零段；阈值等号要按选定实现约定固定，原文三态端点与口头严格比较需区分。用所有旋转的亮暗段、纯边缘及边界测试；检测器输出空描述子是正常，不应调用未存在的匹配属性。

**五层面试答案。** L1 问“检测完能匹配吗？”答：还需描述。L2 问“四点快速判定充分吗？”答：必要条件后仍需完整段。L3 问“归一到 0–1 后 t 不变？”答：必须换量纲。L4 问“为什么三点规则？”答：12 连段与圆周四分点覆盖。L5 问“跨首尾连续怎么测？”答：循环索引。易错是“任意 n 个亮点即可”；证据为来源 13。

### 16. BRIEF 二值描述子

**任务／演进／状态：R。** 检测器给出的点及局部图像 → 固定位数描述；Calonder 等 ECCV 2010 用平滑后强度比较直接产生二进制串，减少浮点描述开销，代价是旋转敏感。仓库未接入。[cite:14](#source-14)

**L1 步骤。** 取得关键点 → 平滑局部支持 → 按同一固定测试点对采样 → 逐对比较产生 bit → 打包 → Hamming 最近邻。支持越界的点丢弃并同步更新点与描述子行号；没有检测步骤属于正常职责边界。

**L2 机制。** 平滑降低噪声翻转，固定点对保证跨图同一 bit 有同一含义；每张图重抽点对会破坏可比性。正单调灰度变换在理想对应采样下保持比较顺序，但饱和／量化导致并列；无方向补偿时大旋转改变采样结构。

**L3 工程。** 位数单位 bit，OpenCV 参数通常是 byte；256 bit 为 32 byte。点对支持半径、平滑核和位数要联合控制抗噪与区分能力。先看旋转差与模糊，再调描述参数，最后 ratio；BRIEF 不是 SIFT 浮点向量的哈希后处理。

**L4 推导。** \(b_k=[\tilde I(p+a_k)<\tilde I(p+b_k')]\)，距离 \(d_H=\sum_k[b_k^{(A)}\ne b_k^{(B)}]\)。若像素差噪声幅度超过真实差就可能翻 bit，所以接近零差的测试不稳定。独立且均衡 bit 的理想随机不匹配距离可用二项模型解释，但真实 bit 相关，不能据此无条件给错配概率。生成 \(O(KB)\)，匹配 \(O(MNB/\text{字长})\)。

**L5 复现设计。** 固定测试模式、bit 顺序及平滑边界；用 XOR＋popcount，不能对打包 byte 做普通 L2。库可能删除边缘点，必须使用返回的新关键点列表。OpenCV BRIEF 属 contrib 路径，当前依赖 `opencv-python` 不保证有它，未新增依赖或测试。

**五层面试答案。** L1 问“点从哪来？”答：外部检测器。L2 问“每图随机模式可以吗？”答：不可以。L3 问“32 是维度还是字节？”答：核对接口，常为字节。L4 问“为什么 Hamming？”答：统计测试结果不一致数。L5 问“描述子行数少了？”答：可能边界点被过滤。易错是“BRIEF 自带旋转不变”；证据为来源 14。

### 17. ORB：定向 FAST 与 rBRIEF

**任务／演进／状态：R。** 图像 → 多尺度定向关键点及二值描述；Rublee 等 ICCV 2011 将 FAST、质心方向和学习测试选择组合，降低开销，仍有视角／模糊限制。仓库未实现 ORB。[cite:15](#source-15)

**L1 步骤。** 金字塔 → FAST 候选 → Harris 或 FAST 响应排序预算 → 强度质心方向 → 转动并选择 BRIEF 测试 → 二值描述 → Hamming 类匹配 → 几何验证。层数和特征预算穷尽停止。

**L2 机制。** 方向补偿使测试跟随目标旋转；rBRIEF 选择均衡且低相关测试，避免定向后大量 bit 冗余。强度矩方向在对称／低对比 patch 可不稳定，金字塔只提供有限尺度覆盖，不是任意尺度不变。

**L3 工程。** 先查各层点数与覆盖，再调 `nfeatures`、`scaleFactor`、层数和边界；增点可能只增重复结构。OpenCV `WTA_K=2` 用 Hamming，3／4 用 Hamming2；匹配阈值不可与 SIFT L2 混用。论文速度不是本仓库节拍。

**L4 推导。** 局部矩 \(m_{pq}=\sum x^py^qI(x,y)\)，方向 \(\theta=\operatorname{atan2}(m_{01},m_{10})\)；以旋转矩阵作用测试点对。若两个一阶矩同时接近零则方向不可辨。二值均值 p 的方差 \(p(1-p)\) 在 p=1/2 最大，解释均衡测试偏好，但不保证全部 bit 独立。检测为各层像素线性级，暴力匹配仍二次于点数。

**L5 复现设计。** 坐标从 octave 回到原图，方向单位和图像 y 向下约定必须一致；OpenCV KeyPoint 的角度为图像坐标顺时针，不能直接等同 `pose_ncc` 视觉逆时针参数。测试对称 patch、90°旋转、边缘支持及 WTA 距离类型。rBRIEF 训练模式复用，不在推理时随机重选。

**五层面试答案。** L1 问“只是 FAST+BRIEF？”答：还有金字塔、选点、方向和测试选择。L2 问“为何学测试？”答：保持区分度并减少相关。L3 问“WTA_K 改后？”答：同步距离类型。L4 问“质心方向何时退化？”答：一阶矩近零。L5 问“角度能直接塞姿态接口？”答：先转换约定。易错是“ORB 全场景比 SIFT 准”；证据为来源 15、26。

### 18. SURF：盒滤波 Hessian 与 Haar 描述

**任务／演进／状态：R。** 图像 → 尺度、方向关键点与浮点描述；Bay／Tuytelaars／Van Gool 2006 会议版，含 Ess 的期刊扩展版为后续版本。用积分图盒滤波近似高斯二阶导降低成本，代价是近似与方向离散性。仓库未实现 SURF。[cite:16](#source-16)

**L1 步骤。** 积分图 → 多尺寸盒滤波近似 Hessian → 空间尺度极值与插值 → Haar 响应主方向 → 定向区域分 4×4 子区 → 每区累积 dx、dy 及绝对值 → 64 维归一描述 → L2 匹配。U-SURF 跳过方向，只适用于方向受限场景。

**L2 机制。** 盒滤波查询与核面积无关，尺度通过增大滤波器而非只缩图获得；Hessian 行列式偏好双方向变化的 blob。Haar 聚合降低细节噪声，但无法自动应对显著透视、遮挡或完全无纹理。

**L3 工程。** 阈值单位依响应归一化，octave、层数和描述维数影响速度与覆盖。先检查小结构是否被最小核滤掉，再调响应阈值。使用 upright 省方向计算但丢旋转适应；是否可商用及库是否编译 nonfree 是独立核验项，不能从可导入 cv2 推断。

**L4 推导。** \(\det H_{approx}=D_{xx}D_{yy}-(wD_{xy})^2\)，原方法以核 Frobenius 范数补偿得到 \(w\approx0.9\)，它不是普适常数，取决于盒核设计。每子区 \(v=(\sum d_x,\sum d_y,\sum|d_x|,\sum|d_y|)\)，16 区共 64 维；归一化消除理想正增益。滤波每尺度 \(O(HW)\)，并非整套算法与尺度数无关。

**L5 复现设计。** 显式核布局、面积归一与积分图端点，用直接盒核卷积验证；descriptor 和 keypoint 的尺度单位必须一致。检查 0.9 系数平方位置、Hessian 正负、零范数、Laplacian 极性过滤。本轮读取大学镜像文件名 `Bay06.pdf` 实际是四作者扩展稿，不能将文件名当版本证据；未运行 SURF。

**五层面试答案。** L1 问“描述维数怎么算？”答：16 子区乘 4 聚合量。L2 问“为何快？”答：积分图查询盒响应。L3 问“upright 的代价？”答：牺牲旋转适应。L4 问“0.9 从何来？”答：近似核能量补偿。L5 问“装 opencv-python 就有 SURF？”答：不保证。易错是“精确高斯 Hessian”；证据为来源 16。

### 19. 最近邻、互近邻与 ratio test

**任务／演进／状态：R。** 两组描述子 → 候选对应；Lowe 的相对距离过滤及互近邻规则比单个最近邻增加歧义检查，代价是减少召回。学习骨架提及这些策略但没有执行。[cite:12](#source-12)[cite:18](#source-18)

**L1 步骤。** 检查描述子维数／类型 → 求每点两个最近邻 → ratio 阈值 → 可选反向最近邻互检 → 几何验证。另一图不足两点时 ratio 不可算，按协议拒绝而不是补零距离。

**L2 机制。** 最近邻即使全是错误也会返回一个；ratio 检查第一名相对第二名是否独特，互检限制多点争一个点。重复纹理可能两个距离都小而被正确拒配，几何一致的错误重复图案仍可能通过二者。

**L3 工程。** ratio 无量纲，绝对距离阈值与描述子尺度相关；先选 L2／Hamming，再检查最近邻质量，最后调 ratio。更严格互检会丢遮挡／检测偏移下的真匹配。近似索引提高速度却可能错过第二近邻，让 ratio 过于乐观；先对照精确搜索。

**L4 推导。** \(d_1/d_2<\tau\)，若使用平方 L2 距离则应 \(d_1^2<\tau^2d_2^2\)，而非仍使用 \(\tau\)。单位描述子有 \(\|a-b\|^2=2-2a^Tb\)，故 L2 与余弦排序等价；非单位时不成立。暴力搜索 \(O(MND)\)，分块可保持精确结果而减少峰值内存。

**L5 复现设计。** 0/0、并列距离、空集、描述子被边界过滤和索引映射要明确；不要将 NumPy `-1` 拒配索引当最后一行有效点。KD-tree／FLANN 等近似索引并未接入；要记录搜索参数和召回损失，不称无损加速。

**五层面试答案。** L1 问“为什么要两个邻居？”答：度量相对歧义。L2 问“互检够几何正确吗？”答：不够。L3 问“ANN 能直接替换吗？”答：需验最近及次近邻召回。L4 问“平方距离阈值？”答：平方 ratio 阈值。L5 问“零距离并列？”答：显式拒配或定义并列规则。易错是“最近邻一定是有效对应”；证据为来源 12、18。

### 20. 几何模型、DLT／最小二乘与重投影验证

**任务／演进／状态：M。** 对应点 → 平移／相似／仿射／单应矩阵；几何估计把局部对应约束成统一运动，增加模型失配风险。姿态 ZNCC 仅构造相似矩阵，未实现点对 DLT／仿射估计；学习骨架的单应输出也未实现。[cite:25](#source-25)[cite:26](#source-26)

**L1 步骤。** 明确模板到图像方向 → 按物理选择自由度 → 点归一化 → 解参数 → 反归一化 → 计算重投影／覆盖 → 超界拒绝。单应不能把三维视差无条件解释成平面运动。

**L2 机制。** 多余自由度可降低训练点残差却增加外推漂移；几何验证须看点分布而不只看数量。平移 2、相似 4、仿射 6、单应 8 自由度；一个 3×3 矩阵不自动等于已估计单应。

**L3 工程。** 先最小物理模型，再看重投影残差空间模式；系统方向偏差可能说明模型不够而非阈值太小。归一化以去质心及平均距离调到 \(\sqrt2\) 改善条件；点聚集会使四角外推不可靠，阈值要按缩放后的坐标量纲。

**L4 推导。** 单应 \(\tilde q\sim H\tilde p\)，叉积消去比例得到 \(\tilde q\times H\tilde p=0\)，每对提供两独立约束，叠成 \(Ah=0\)，约束 \(\|h\|=1\) 取最小奇异向量。至少四对且构型非退化；仿射至少三对非共线，相似至少两对不同点且限制正尺度／定向，平移一对。代数残差与像素重投影误差不同；随后非线性重拟合是额外优化。

**L5 源码／设计。** [pose_ncc.py][code-pose] 返回底行为 `[0,0,1]` 的相似矩阵；不能因此标注“透视已实现”。DLT 应用 SVD，分母接近零、H 近奇异、翻折、投影面积及视场范围独立检查。参考书官网只取得目录／书目信息，本节 DLT 是显式代数推导，不宣称本轮取得相应书章全文。

**五层面试答案。** L1 问“先选 H 吗？”答：先选物理变换族。L2 问“自由度多总好？”答：容易拟合噪声／缺陷。L3 问“点多还不稳？”答：检查覆盖及条件数。L4 问“四对总可求 H？”答：要非退化。L5 问“矩阵有限就能放行？”答：还检查投影分母与物理约束。易错是“3×3 输出证明透视匹配”；证据为来源 25、26 与源码。

### 21. SuperPoint 检测与描述

**任务／演进／状态：R。** 图像 → 兴趣点、分数、描述子；2018 CVPR Workshops、2017 预印本，学习共享表示解决手工前端局限，代价是训练域与权重依赖。本地只有路线骨架，无网络或权重加载。[cite:17](#source-17)

**L1 步骤。** 训练：合成形状训练 MagicPoint → 多单应 Homographic Adaptation 生成真实图伪标签 → 检测与描述联合训练。推理：共享编码器 → 检测头 softmax／重排 → 阈值、NMS、边界筛选 → 描述图插值及 L2 归一 → 返回点与描述，不直接返回 H。

**L2 机制。** 多视图伪标注改善可重复检测，几何对应监督让描述子接近真实匹配。每个 8×8 cell 的 65 通道含 64 位置加 dustbin；去掉 dustbin 前做 softmax。热图 softmax 本身不等于亚像素坐标估计；描述子插值也不自动细化关键点位置。

**L3 工程。** 输入尺寸／归一化、检测阈值、NMS 半径、最大点数必须与权重契约一致。先查工况域偏差及点覆盖，再调点数与阈值。大量反光边缘不等于可重复兴趣点；没有检测到的点不能靠稀疏匹配器补出。

**L4 推导。** 检测损失 \(L_p=-\sum_c\log\operatorname{softmax}(z_c)_{y_c}/N_c\)，联合 \(L=L_p+L'_p+\lambda L_d\)。描述损失由单应产生正负对应，用正对吸引、负对间隔排斥；伪标签质量限定学习目标。Homographic Adaptation 可解释为把各变换检测热图拉回原图并按有效次数平均，不是所有图像都精确单应的保证。卷积成本随像素，描述对应训练可随 cell 对数二次增长。

**L5 复现设计。** 张量从 `B×65×Hc×Wc` 正确重排到像素，不把 xy 与行列互换；点在缩放／补边后须映回原图。原论文描述插值为 bicubic，公开实现可能采用其他采样策略，必须固定版本。校验空点、非 8 倍数尺寸、边界和 descriptor 零范数。骨架“softmax + NMS 得亚像素配准”不作为已实现证据。

**五层面试答案。** L1 问“监督从哪里来？”答：合成几何、适应伪标签、单应对应。L2 问“65 为什么不是 64？”答：有无点类别。L3 问“点越多越好？”答：看覆盖、重复性与资源。L4 问“损失为何两部分？”答：定位和区分对应是不同任务。L5 问“softmax 自动亚像素吗？”答：不。易错是“SuperPoint 单独输出可靠姿态”；证据为来源 17。

### 22. SuperGlue 注意力与最优传输匹配

**任务／演进／状态：R。** 两组关键点、检测分数及兼容描述子 → 部分一对一匹配与拒配；2020 CVPR、2019 预印本，学习上下文替代孤立最近邻，代价是注意力和分配计算。仓库未实现。[cite:18](#source-18)

**L1 步骤。** 点归一化和位置编码 → 与描述子融合 → 交替 self／cross attention → 相似矩阵 → 加 dustbin 行列 → Sinkhorn 分配 → 互选及阈值 → 输出匹配索引和分数，随后另做几何估计。

**L2 机制。** self attention 比较同图结构，cross attention 交换另一图证据；dustbin 允许不可匹配点退出，避免强行全配。OT 考虑分配约束但不证明场景满足唯一物理模型。网络不是检测器，丢失的关键点无法恢复。

**L3 工程。** 点数决定显存与耗时；先查前端权重兼容／域，再查匹配数和覆盖，最后调阈值和 Sinkhorn 次数。读取到的作者源码默认 256 维、9 对 self/cross、100 次 Sinkhorn、0.2 匹配阈值，均为该源码配置，不是本仓库默认或通用最优值。

**L4 推导。** \(A=\operatorname{softmax}(QK^T/\sqrt d)V\)，关联成本 S 扩成 \(\bar S\)。熵正则 OT 最大化 \(\langle\bar S,P\rangle+\epsilon H(P)\)，约束边缘质量；作者实现未归一边缘可写行 \([1_M,N]\)、列 \([1_N,M]\)，总质量 M+N，dustbin 因而可接收多个拒配点。log-domain 交替更新 \(u=\log a-\operatorname{LSE}(Z+v)\)、\(v=\log b-\operatorname{LSE}(Z+u)\)。固定次数只给近似解；注意力成本含 \(M^2+N^2+MN\)。

**L5 复现设计。** 作者源码以 `-1` 标未匹配，空点提前返回；描述布局是 `B×D×N`，不能按 `B×N×D` 无检查传入。稳定 logsumexp 避免指数溢出，检查 dustbin 边缘质量与有限值。源码读取不等于下载权重或运行；公开文件的许可证与头部限制另核验，不作商用许可结论。

**五层面试答案。** L1 问“先输入原图吗？”答：主要接局部特征集。L2 问“为何有 dustbin？”答：允许非重复／遮挡点不匹配。L3 问“加 Sinkhorn 次数能解决漏点吗？”答：不能。L4 问“是普通行 softmax 吗？”答：同时约束行列质量。L5 问“-1 能用于数组索引吗？”答：须先过滤。易错是“网络置信度就是目标概率”；证据为来源 18。

### 23. LoFTR 粗到细无检测器匹配

**任务／演进／状态：R。** 两幅图 → 选定的亚像素对应；Sun 等 CVPR 2021 用稠密粗网格上下文绕过独立检测点瓶颈，代价是分辨率和匹配矩阵内存。本地只是研究路线文字，没有推理路径。[cite:19](#source-19)

**L1 步骤。** CNN/FPN 取得 1/8 粗和 1/2 细特征 → 位置编码与 self/cross Transformer → 粗相似矩阵 → dual-softmax 或所选 OT 变体、互选及阈值 → 细层局部窗口相关 → 坐标期望精化 → 原图坐标与几何验证。没有粗匹配应返回空集。

**L2 机制。** 上下文帮助弱纹理位置区分，线性注意力降低长序列开销；但重复结构和无信息区域仍会歧义。粗网格覆盖不表示最后每个像素都有流；细级仅精化已选粗对应，不能保证纠正任意粗错配。

**L3 工程。** 分辨率、粗阈值、细窗口大小和权重域先固定；细窗口单位是特征像素而非原图 px。先看缩图丢细节和有效 overlap，再调阈值。减少输入分辨率会同时改变几何定位尺度；高匹配数量不等于分布均匀。

**L4 推导。** 粗层 \(S_{ij}=f_i^Tg_j/\tau\)，dual-softmax \(P_{ij}=\operatorname{softmax}_j(S_{ij})\operatorname{softmax}_i(S_{ij})\)。细窗口 \(p_k=\operatorname{softmax}(s_k)\)，\(\hat\delta=\sum_kp_k\delta_k\)，用几何真值监督粗 NLL 和细坐标残差。线性注意力以 \(\phi(z)=\operatorname{ELU}(z)+1\)，计算 \(\phi(Q)(\phi(K)^TV)\) 并用核和归一；不是原 softmax 的严格等价变形。注意力线性化不消除粗匹配 \(M\times N\) 矩阵。

**L5 复现设计。** 固定输入补边 mask、两图 resize 比例与 fine window 原点；soft-argmax 多峰时可落在两峰之间，需不确定性／阈值拒绝。用单峰、双峰、无重叠、异尺寸回填和镜面数据测试。作者 fine-matching 源码入口本轮抓取为空，相关机制由论文及显式期望式支持，不声称已读该文件全文。

**五层面试答案。** L1 问“detector-free 是完全稠密流吗？”答：不是，筛粗对应后细化。L2 问“为何弱纹理有帮助？”答：大范围条件化上下文。L3 问“窗口加大一定更准？”答：增加歧义和计算。L4 问“线性注意力后全部 O(N)？”答：匹配矩阵仍二次。L5 问“期望坐标可信否？”答：看多峰与回填尺度。易错是“完全无纹理也必匹配”；证据为来源 19。

### 24. LightGlue 自适应稀疏匹配

**任务／演进／状态：R。** 兼容稀疏局部特征 → 对应与分数；Lindenberger 等 ICCV 2023 通过结构优化、深度早停和点剪除降低容易图像对成本，困难样本仍可能执行全深度。仓库仅骨架提名，未加载权重。[cite:20](#source-20)

**L1 步骤。** 描述子初始化 → 带相对位置编码的 self/cross attention → 每层预测匹配／置信 → 足够确定则早停，否则去掉有把握不可匹配点 → 末层或停止层形成部分分配 → 阈值及互选 → 几何验证。

**L2 机制。** 不需要继续推理的点和容易图像对少算，保留难点容量；置信与 matchability 不相同，有把握“不匹配”也可以早确定。误校准会过早删除真实点，因此其剪枝是学习式预算策略，不是 04 的确定性界。

**L3 工程。** 特征预算、自适应深度／宽度阈值、匹配阈值、设备后端应成组记录；先查兼容前端、分布和召回，再看尾延迟。平均变快不提供最坏延迟保证；关闭自适应可作为准确性与稳定延迟对照，但仍需测量。

**L4 推导。** 相对旋转编码使 \(q_i^TR(p_j-p_i)k_j\) 利用相对位置；匹配头可写 \(P_{ij}=\sigma_i^A\sigma_j^B\operatorname{softmax}_jS_{ij}\operatorname{softmax}_iS_{ij}\)，\(\sigma\) 为可匹配性。正确对应和未匹配事件的负对数目标训练分配，层间置信目标学习是否还需计算。该轻量头不同于 SuperGlue 的多次 Sinkhorn；总成本由实际剩余点数和层数求和，无全局误差界。

**L5 复现设计。** 剪点需维护原始索引映射，不能输出压缩后下标；小批量、空集、早停第一层和不同输入顺序都需测试。记录权重哈希、推理精度及自适应开关，冷启动和预热分开。作者仓库及 raw 源码本轮为空，L5 依据论文设计，不填未经核验的当前默认阈值。

**五层面试答案。** L1 问“何时停？”答：层置信条件满足或耗尽深度。L2 问“剪枝是数学上界吗？”答：不是，是学习预测。L3 问“节拍看什么？”答：困难样本尾延迟及回退。L4 问“与 SuperGlue 分配区别？”答：matchability 与双 softmax，不是相同 Sinkhorn。L5 问“剪点最易错？”答：原始索引回填。易错是“平均快所以固定实时”；证据为来源 20。

### 25. HOG-SVM 候选重排序

**任务／演进／状态：K。** NCC 候选窗口 → 增加 `svm_score` 的排序列表；Dalal／Triggs 2005 以 HOG＋线性 SVM 为代表，本地采用 StandardScaler＋RBF SVC，是教学组合而非逐项复现。每次调用重新生成样本并训练，不按分类阈值剔除候选。[cite:21](#source-21)[cite:22](#source-22)

**L1 步骤。** 生成 60 正、120 负样本 → HOG → 训练标准化器与 `SVC(kernel='rbf',C=10,probability=True)` → 对候选四舍五入取轴对齐原模板大小 patch → 尺寸不符跳过 → HOG、概率 → 降序返回。即使候选空列表也先训练；不是已有训练模型的纯推理接口。

**L2 机制。** HOG 聚合方向分布而保留粗空间结构，块归一减弱光度变化，分类器用负样本区分相似背景。但随机模糊负纹理不同于真实误匹配，合成增广不证明跨域泛化；候选没有召回，重排序无法补检，也不修正位置。

**L3 工程。** 64×64 窗口、16×16 block、8×8 stride/cell、9 bins 固定；应先解决数据划分与困难负例，再调 C／gamma，最后标定拒绝阈值。当前正样本增益 0.7–1.3、偏置 -20–20、噪声标准差 5；负例先采随机灰度再高斯模糊 sigma=2。以上是代码生成参数，不是本章构造的性能数据。

**L4 推导。** HOG 子区 \(h_b=\sum_x m(x)w_b(\theta(x))\)，块范数约 \(h/\sqrt{\|h\|^2+\epsilon^2}\)，L2-Hys 还限幅并再归一。布局维数 \(7\times7\times2\times2\times9=1764\)。软间隔 SVM 在特征空间最小化 \(\frac12\|w\|^2+C\sum\xi_i\)，约束 \(y_i(w^T\phi(x_i)+b)\ge1-\xi_i\)；RBF \(K(x,z)=e^{-\gamma\|x-z\|^2}\)。标准化改变距离，gamma='scale' 取训练矩阵总体方差；训练解不等于输出校准概率。

**L5 源码／验证。** [hog_svm_matching.py][code-ml] 先直接转换 uint8 再 resize，未先裁剪到 0–255，增广越界会造成回绕／截断语义风险；不能写成安全饱和变换。SVC 未固定 `random_state`，数据 seed 不保证概率标定完全复现。`predict_proba()[0,1]` 依赖训练标签类别次序，本例是 0／1。候选裁剪不适配旋转画布，负坐标／空 patch 应另检查。已静态核对，未运行本地 ML 训练或现场验收。

**五层面试答案。** L1 问“verify 真过滤了吗？”答：只跳过尺寸错窗口，其余排序。L2 问“为何困难负例重要？”答：随机纹理与真实混淆分布不同。L3 问“先调 C 吗？”答：先查数据与预处理。L4 问“1764 怎么来？”答：49 块乘每块 36。L5 问“seed 固定一切吗？”答：SVC 校准随机性还未固定。易错是“论文线性 SVM 就是本地 RBF”；证据为来源 21、22 与源码。

## 4. 搜索、数值与拒识组件

### 26. 有效掩膜与归一化重采样

**任务／演进／状态：K。** 模板与 0／1 支持 → 变换后的亮度与可靠支持；从补零矩形扩为有效区域，增加支持收缩和样本数变化。原始实现依据为 `_warp`／`_search_pose`，不是一般浮点权重 NCC。[cite:26](#source-26)

**L1 步骤。** 检查同形有限二值 mask → 同一变换分别采样 `T*M` 和 M → 支持足够时相除恢复亮度 → 仅保留接近完整支持像素 → 检查数量／纹理 → 同支持评分。图像金字塔中采用相同加权／支持分开 resize 的规则。

**L2 机制。** 如果仅 warp 灰度，掩膜洞外灰度或补零会混到有效区；分开重采样再除权重避免亮度衰减，但只保留满支持仍会腐蚀边界。掩膜 0 处也要求有限数，不能期待 NaN 乘 0 安全。

**L3 工程。** 支持阈值 `>1e-9` 用于相除，`>=1-1e-6` 用于二值有效性，两个目的不同。先查支持面积变化，再查评分及退化姿态；薄线掩膜缩放后可能完全消失。不同姿态样本数不同，相同分数不等于相同统计置信度。

**L4 推导。** 对插值权重 \(a_j\ge0\)，\(\hat T=\sum a_jM_jT_j/\sum a_jM_j\)。若有效像素亮度恒 c，则分子 c 倍分母，恢复 c；若分母零则不可定义。保留全支持使比较对象不含掩膜混合边界，但不恢复原始连续信号。复杂度线性于变换后画布。

**L5 源码／验证。** [pose_ncc.py][code-pose] `_warp` 用 `INTER_LINEAR`，降采样用 `INTER_AREA`；当前最多允许完整画布落图，mask 不支持裁掉出画区域继续匹配。现有 all-ones、排除损坏像素和旋转尺度 mask 测试通过；并不覆盖任意软 mask。优化必须保留支持阈值与插值一致。

**五层面试答案。** L1 问“为什么 warp 两次？”答：亮度分子和支持分母。L2 问“掩膜洞填零无害吗？”答：会污染插值。L3 问“薄线失效先调分数？”答：先查有效像素剩余。L4 问“常量为何能恢复？”答：归一化插值比值抵消支持。L5 问“mask 外 NaN 可以吗？”答：不允许。易错是把二值支持当任意权重；证据为源码和来源 26。

### 27. FFT 相关、核翻转与缓存

**任务／演进／状态：K。** 图像和核 → 线性有效相关图；FFT 改变计算方式不改变相似度或几何模型。两套 ZNCC 均调用 SciPy `fftconvolve`，本地没有自写 FFT、GPU、频谱缓存或 overlap-add 调度。[cite:5](#source-5)[cite:3](#source-3)

**L1 步骤。** 确定相关约定 → 将实核双轴反转 → FFT 补到线性卷积所需尺寸 → 频域乘法 → IFFT → 取 valid 区域。SciPy 完成内部变换和裁剪；不能自行省略翻转又保持同一峰坐标。

**L2 机制。** 卷积定理将重复乘加转成变换域逐点乘法；线性卷积需补边，未补边是循环相关。FFT 可能在小 ROI／只求几个值时比直接点积慢；所谓“所有核自动 2 的幂”不是现代库的通用要求。

**L3 工程。** 先统计图像／模板／FFT 尺寸和需要的输出数，再比较直接／FFT 成本。缓存需以数组内容、支持、姿态及补边形状作为有效键；不能把不同变换 mask 的频谱误复用。只读 image 频谱共享有潜力，但需改写当前三个独立调用，现状不能声称已经复用。

**L4 推导。** 对实数组 \(c(u,v)=\sum I(u+x,v+y)t(x,y)\)，等于与 \(t(-x,-y)\) 的卷积并取对应偏移。频域为 \(\mathcal F(I)\overline{\mathcal F(t)}\) 的相关约定，但直接反转核的线性卷积还有裁剪原点问题。各轴补边至少输入长度和减 1，复杂度 \(O(F\log F)\)，内存 \(O(F)\)；有限精度不保证逐位等价空间求和。

**L5 源码／验证。** 用非对称模板、脉冲、边缘峰与 `image==template` 检查翻转和 `(H-h+1,W-w+1)` 形状；对直接求和比较容差，而非仅比较 argmax。SciPy 可接受非连续输入但可能复制；内存峰不能仅看原数组。已有回归覆盖普通接口及非连续数组，未做硬件加速验证。

**五层面试答案。** L1 问“为何 flip 两轴？”答：库做卷积，目标是相关。L2 问“补边做什么？”答：避免循环回绕。L3 问“小模板一定快？”答：不一定。L4 问“FFT 让旋转不变吗？”答：只加速计算。L5 问“缓存后怎样验证？”答：不同 mask／姿态和直接参考逐值比较。易错是把 FFT、白化、相位归一混为一谈；证据为来源 3、5。

### 28. 积分图与局部矩统计

**任务／演进／状态：K。** 图像 → 任意轴对齐矩形的和／平方和；Summed-area table 在多个领域发展，Crow 1984 是图形学代表，不称唯一首创。旧 ZNCC 手写前缀和，姿态掩膜版本不用矩形积分图。[cite:23](#source-23)[cite:3](#source-3)

**L1 步骤。** 建前导零边的 `(H+1,W+1)` 表 → 两轴前缀和 → 窗口四角容斥 → 对平方图同样求 Q → `Q-S*S/n`。模板尺寸必须大于零，窗口只取有效边界。

**L2 机制。** 四角相减消除矩形外区域，查询次数与窗口面积无关；任意 mask 不是单个矩形，不能直接用四角取代加权求和。相减也可能让两个大数消去保留很小纹理量，是数值风险来源。

**L3 工程。** 构表必须提升类型，uint8 平方若先执行再转换已溢出；整图和还随像素数增长。先测最大幅值和窗口方差，再考虑中心化／稳定算法，不能只扩大分母下限。前导零边和右开区间一旦不一致会产生一像素偏移。

**L4 推导。** \(A(y,x)=\sum_{j<y,i<x}I(j,i)\)，矩形 \([x,x+w)\times[y,y+h)\) 的和为 \(A(y+h,x+w)-A(y,x+w)-A(y+h,x)+A(y,x)\)。能量由展开 \(\sum(I-\mu)^2=Q-S^2/n\)。预处理 \(O(HW)\)，单窗 \(O(1)\)，代价两张浮点大表；理论非负不防有限精度负方差。

**L5 源码／验证。** [ncc_matching.py][code-ncc] 38–48 行先把图像转 float64 再平方和累计，仍缺新实现稳定兜底。对首行首列、全图窗口、1 像素宽矩形及直接和验证四角符号；对大偏置弱纹理测试取消误差。它也是 SURF 的计算工具而非 SURF 已存在的证据。

**五层面试答案。** L1 问“表为何大一行一列？”答：统一零边界。L2 问“旋转 mask 四角能算？”答：一般不能。L3 问“负方差代表负能量？”答：通常数值相消。L4 问“为什么查询 O(1)？”答：四角容斥。L5 问“平方前还是后转类型？”答：之前。易错是“float64 就绝不失稳”；证据为来源 3、23 与源码。

### 29. ZNCC 数值稳定与分块直接兜底

**任务／演进／状态：K。** 原始图像和有效模板 → 稳定有限分数或无效标记；本地姿态实现为极端偏置／小增益增加稳定化，代价是直接兜底可能很慢。旧实现没有这套策略。

**L1 步骤。** 模板按绝对最大幅值缩放 → 减参考像素 → 去均值 → 再按中心化幅值缩放 → 图像全局幅值缩放与去均值 → FFT S/Q/N → 判定可靠窗口 → 不可靠窗从原始数组按 128 窗口一批直接中心化评分 → 有限结果裁剪。

**L2 机制。** 正比例缩放和常数平移理论不改 ZNCC，缩放避免平方溢出，局部直接中心化避免大数相消。兜底必须从 original 取值，否则全局归一化已经丢失的局部动态范围不可补回。量化前已消失的纹理仍不可能恢复。

**L3 工程。** `variance>256*eps*max(1,abs(squares))` 是归一化数值可靠性门槛，不是现场纹理阈值；float64 epsilon 约 \(2.22\times10^{-16}\)。先记录进入兜底的窗口比例、支持 n 和动态范围，再查内存／时延；不要为了快随意下调 256 而缺少等价测试。

**L4 推导。** 对中心化向量 t、i，\(\rho(\alpha t,\beta i)=\rho(t,i)\) 对正 \(\alpha,\beta\) 成立。直接计算 \(\sum(i-\bar i)^2\) 避免 Q 与 S²/n 两个大值差的主要消减误差，但所有变换仍受机器精度和下溢约束。兜底新增 \(O(U n)\) 算术，U 为不可靠窗口数；不能用算法恒 O(FFT) 描述实际路径。

**L5 源码／验证。** `_score` 用 `sliding_window_view` 创建逻辑视图，但 `windows[yy,xx]` 高级索引会先物化最多 128 个完整画布 patch，再按 mask 取点，因此瞬时内存不只 \(128n\)。批内减第一列使用 `.copy()` 防引用别名干扰。已通过 `test_large_offset_and_tiny_gain`、`test_huge_amplitude_self_match`、极亮背景及常量邻窗测试；这些固定案例不是任意浮点输入可靠性证明。

**五层面试答案。** L1 问“何时直接算？”答：FFT 方差不可靠且整图非恒定。L2 问“为何保存原图？”答：避免从已失真归一值恢复。L3 问“突然慢先查啥？”答：兜底比例和完整 patch 大小。L4 问“epsilon 是对比度阈值吗？”答：是数值精度尺度。L5 问“滑窗视图零内存吗？”答：视图本身小，高级索引会复制。易错是“加极小分母即可稳定”；证据为源码及已运行极值测试。

### 30. 相似变换、包围画布与 ROI 坐标链

**任务／演进／状态：K。** 原模板像素中心、角度尺度、评分峰 → 模板到图像矩阵及原点／中心／角点；统一协议避免“匹配正确但定位偏移”。本地用 OpenCV 绕中心变换，不支持透视。[cite:26](#source-26)

**L1 步骤。** 取中心 `(w-1,h-1)/2` → 绕中心旋转缩放 → 四角求最小值及画布范围 → 平移画布原点 → warp → 加评分峰及平移亚像素偏移 → 输出同一 H 作用到全部点。ROI 输出由调用侧左乘 ROI 平移矩阵。

**L2 机制。** 使用像素中心而非外边界消除半像素误差；旋转后模板原点、画布左上角和中心不重合。warp 的逆向取样实现不改变输入前向矩阵的几何含义；只平移 center 不平移 H/corners 会使协议自相矛盾。

**L3 工程。** 角度度转弧度，正角视觉逆时针；尺度正且统一。画布容差 `1e-9` 避免几乎整数边长多出一列。先测试零角单位尺度，再非方模板旋转和 ROI；不能把 bbox 作为原点真值。

**L4 推导。** \(c=((w-1)/2,(h-1)/2)^T\)，\(A=s\begin{bmatrix}\cos\theta&\sin\theta\\-\sin\theta&\cos\theta\end{bmatrix}\)。令 \(\ell=\min_{corners}(A(p-c)+c)\)、\(b=(u+\delta_x,v+\delta_y)^T\)，则 \(t=c-Ac-\ell+b,H=\begin{bmatrix}A&t\\0&1\end{bmatrix}\)。画布宽 \(\lceil s(|\cos\theta|(w-1)+|\sin\theta|(h-1))-10^{-9}\rceil+1\)，高交换 w/h。要求完整画布在图内。

**L5 源码／验证。** `_warp` 返回 2×3，主函数补为 3×3；`x/y=t`、`center=A*c+t`、`bbox=b`。角点是 `(0,0),(w-1,0),(w-1,h-1),(0,h-1)`，不是像素外边界。姿态、图像边角、填满图像测试通过；ROI 回填是组合推导，未在此轮新增专项测试。

**五层面试答案。** L1 问“x/y 指哪里？”答：原模板原点。L2 问“为何不是 w/2？”答：零起点像素中心为 `(w-1)/2`。L3 问“旋转后固定偏移？”答：先查三种参考点。L4 问“ROI 怎么组合？”答：整图 H 为 `T_roi @ H_roi`。L5 问“只更新画框行吗？”答：所有输出同步。易错是把采样方向当几何方向；证据为来源 26 与源码。

### 31. 角度／尺度闭区间网格搜索

**任务／演进／状态：K。** 物理允许范围 → 离散姿态列表并全平移搜索；从单一平移扩展相似变换，用显式枚举换可控范围，计算量随姿态笛卡尔积增长。原始策略证据为 `_grid` 及主搜索。

**L1 步骤。** 检查有限有序边界、正步长／正尺度 → 从 lo 按 step 采样 → 必要时追加 hi → 笛卡尔积 → 画布过大先跳过 → 对其余姿态评分 → 汇总候选。组合超过 10000 或层数超过 8 拒绝配置。

**L2 机制。** 包含上端点避免范围边缘无样本，但最后间隔不必等长；同方向相差 360°不会自动去重。网格变密减少离散错配却不解决透视／遮挡／对称性，默认范围仍只搜索平移。

**L3 工程。** 步长先由模板半径 r 和可容许外围失配评估，再以独立场景做粗细对照；大模板需要更细角步长。先限制合理范围，再细化步长，最后调分数。`searched_poses` 是完成评分姿态数，不是理论网格数或检出数量。

**L4 推导。** \(k=\lfloor(hi-lo)/step+10^{-10}\rfloor\)，构造 k+1 点并用绝对容差 `1e-10` 判是否补端点。固定尺度 s、半径 r 的角偏差产生 \(2sr|\sin(\Delta\theta/2)|\)，尺度偏差产生 \(r|\Delta s|\)。小角约 \(sr|\Delta\theta|\)，只是几何关系，不是最终估计误差上界；总搜索成本对 G 近似线性。

**L5 源码／验证。** `_grid` 不用浮点 `arange` 隐含端点；布尔值被计数参数拒绝，角度不是模 360 唯一表示。已通过非整除端点、跳过大姿态、配置非法等测试。现有 off_grid 基准故意演示粗网格失败，不能把完整运行当全部场景通过。

**五层面试答案。** L1 问“上端点必包含？”答：按绝对容差追加。L2 问“细网格解决对称吗？”答：不能。L3 问“为何模板大需细角度？”答：外围位移随 r 增。L4 问“位移公式怎么得？”答：同半径两点弦长。L5 问“searched_poses 等于结果数吗？”答：不是。易错是“默认已搜旋转尺度”；证据为源码与端点测试。

### 32. 空间金字塔、候选传播与全图复核

**任务／演进／状态：K。** 单姿态模板与图像 → 原图候选；粗到细缩小局部搜索但依赖低频信息，本地默认再全图复核保留正确性参照，不能宣称天然加速。[cite:3](#source-3)[cite:26](#source-26)

**L1 步骤。** 原姿态画布先生成 → `INTER_AREA` 降采样图像和支持 → 粗层全图取 K 峰 → 上升每层坐标乘 2，±4 该层像素局部评分 → 每窗取最多 2 峰 → 合并截断 K → 若 top>0 且复核开启，用原图完整评分重新取峰替换。

**L2 机制。** 粗图缩小像素搜索量，但高频模板可被平均消失、奇数尺寸不精确二分；“乘 2＋局部半径”只是传播近似。全图复核不是仅重算已保留候选，它重新寻找该姿态原图最佳峰；但后续容量／NMS 仍可能漏多个目标。

**L3 工程。** 最大层数含原图层；模板当前最短边<16、下一层有效点<16或退化时停止下降。先比较单层与默认复核，再试近似模式，记录漏检与错误唯一性放行。增层既有重采样开销又可能增加兜底，不能只看层数猜速度。

**L4 推导。** 理想二分面积和 \(A+A/4+\cdots<4A/3\)，但这是处理像素量级而非完整程序时延界。每细层候选局部平移窗最多 \(9\times9\) 个合法位置，每次评分还需模板支持；图像宽奇数时真实比例 \(\lceil W/2\rceil/W\ne1/2\)。没有合法评分界证明粗峰对应原图最优，关闭复核无无损保证。

**L5 源码／验证。** `_search_pose` 峰元组保留全图坐标以及局部 score/ly/lx，亚像素使用局部分数坐标，不能混淆。top=0 时初始评分已是原图，复核开关不会再触发额外全图评分。已通过高频奇数相位、单层一致、小模板回退和近似可运行测试；近似测试不证明普遍等价。

**五层面试答案。** L1 问“复核算哪些位置？”答：该姿态完整原图合法位置。L2 问“为何粗层会漏？”答：低频不足及截断。L3 问“只调 candidate_limit 够吗？”答：还要看重采样与复核。L4 问“4/3 是速度保证吗？”答：只是理想面积和。L5 问“局部峰用什么坐标精化？”答：局部 ly/lx。易错是把空间金字塔当姿态层级优化；证据为源码与来源 3、26。

### 33. 候选排序、Top-K 与中心距离 NMS

**任务／演进／状态：K。** 评分图／跨姿态候选 → 空间分离候选；降低重复响应代价是密集目标召回损失。本地实现是圆形距离抑制，不是 IoU NMS，也不是严格全局最优集合算法。

**L1 步骤。** 旧入口先列出过阈值位置并排序，逐个保留远离已选点者；姿态 `_peaks` 反复 argmax 并将圆盘内设 -inf，到 K 或无有限峰结束；跨姿态再按分数排序，以精化后中心距离合并。

**L2 机制。** 同目标旁瓣／近姿态多峰会被合并，真目标相距近时也会被合并。贪心取最大后抑制不要求严格局部极大；平台响应的取点可能依内存遍历／排序规则。同中心不同角度会互相抑制，不能用它检出角度对称歧义。

**L3 工程。** 半径单位原图 px，粗层用半径除 \(2^{level}\)。先看目标间距／峰宽，再调半径和 K；K 太小可漏第二竞争峰，增加 max_count 不增加每姿态容量。tie 顺序和精化导致半径边界变化需明确。

**L4 推导。** 抑制 \((x-x_p)^2+(y-y_p)^2\le r^2\)，保留要求对所有已选点距离严格大于 r；相等即抑制。按距离构成冲突图，贪心并不等于最大权独立集。`_peaks` 每次全数组 argmax 约 \(O(KP)\)，跨姿态 C 候选最坏 \(O(C^2)\) 比距；可优化不表示已优化。

**L5 源码／验证。** `_peaks` 复制分数图避免修改输入；局部圆盘用 ogrid，无效最大值终止。旧 NMS 使用整数位置，姿态最终合并用精化中心；不含角度／尺度距离。已通过近邻双目标、替代姿态抑制与多目标测试。改为空间索引须验证等号、tie、半径浮点和输出顺序。

**五层面试答案。** L1 问“先阈值还是先 NMS？”答：旧入口先阈值，姿态先生成／合并再全局阈值。L2 问“为何漏邻目标？”答：它们在同抑制圆内。L3 问“多目标只加 max_count？”答：还需 K、半径和分差配置。L4 问“半径相等保留吗？”答：不保留。L5 问“亚像素开关会改合并？”答：可能。易错是把 NMS 当 RANSAC 或 PSR；证据为源码。

### 34. 分数、空间分差、失败协议与多目标

**任务／演进／状态：K。** 空间候选 → 匹配或拒识原因；在分数之上加入唯一性检查，代价是重复目标会被拒绝、遗漏次优会过于乐观。当前协议只用于姿态入口，旧接口不具备。

**L1 步骤。** 合并候选取 b1、b2 → gap=b1−b2 → 过滤 `score>=min_score` → 无评分姿态返回 no_valid_pose → 无过阈值返回 below_min_score → gap 存在且小于 min_score_gap 返回 ambiguous → 否则 matched。非法输入此前抛 ValueError。

**L2 机制。** 高分只说明与模板近，分差说明已保留的空间竞争者不够接近；它无法证明没遗漏竞争者，也不检查同中心角度歧义。低于 min_score 的第二候选仍参与 gap。只有一候选不等于理论唯一。

**L3 工程。** `min_score∈[-1,1]`、`min_score_gap∈[0,2]`；多目标需 `min_score_gap=0` 且 K≥max_count，单目标启用 gap 需 K≥2。先区分任务数量，再调支持、容量／NMS，最后在负例上标定阈值。无目标、重复、遮挡和网格外目标应分组。

**L4 推导。** b1≥b2 时 gap≥0；分数范围给 gap≤2，但只对两者均有效成立。接受集合 \(A=\{c:s_c\ge\tau\}\)，歧义条件 \(|A|>0\land\gamma>0\land gap\ne None\land gap<\gamma\)。等于阈值通过，次优不存在为 None 而非无穷。多重搜索影响最大分数分布，无分布模型时不能把 gap 直接换成置信概率。

**L5 源码／验证。** 顶层所有分数缺失用 None，可 JSON 序列化；调用方先看 matched 再取 `[0]`。`elapsed_ms` 包括输入检查和搜索，不包括调用方数据读取；没有分阶段计时输出。37 项回归覆盖等目标歧义、噪声／常量无目标、多目标及配置检查，未对所有浮点等号设置专项测试。

**五层面试答案。** L1 问“没姿态和低分一样吗？”答：不是。L2 问“None gap 表唯一吗？”答：只是无保留次优。L3 问“双目标被拒怎么办？”答：先确认任务，再显式关闭唯一性。L4 问“次优低于阈值还比吗？”答：仍比。L5 问“失败匹配能取第一项？”答：不能。易错是“below_min_score 证明目标不存在”；证据为源码。

### 35. PSR 峰旁瓣比

**任务／演进／状态：R。** 响应图与选定主峰 → 峰相对旁瓣统计显著度；Bolme 等 2010 MOSSE 文献是跟踪应用依据，不是全部 PSR 思想首创。本地只文档说明，没有计算或返回 PSR。[cite:24](#source-24)

**L1 步骤。** 找主峰 → 明确排除的主瓣邻域与统计 ROI → 过滤非有限响应 → 算旁瓣均值／标准差 → 非退化时 PSR → 标定拒识，若用于跟踪则决定是否暂停更新。旁瓣数不足或方差零须返回不可用状态。

**L2 机制。** 分差只看两个峰，PSR 比较主峰与一组旁瓣分布；抑制后的 -inf 图不能直接统计。低旁瓣方差可让普通峰获得很高 PSR，重复图案可能有多个尖峰；高 PSR 不等于几何或语义正确。

**L3 工程。** 排除半径／窗口大小是像素，PSR 无量纲；不同 ROI 和有效区域下不可直接共用阈值。先固定统计定义和旁瓣样本量，再用正负帧标定。论文跟踪阈值不能平移为模板定位阈值；不据仅取得的论文前部补写未核验精确排除窗口。

**L4 推导。** \(\mu_s=m^{-1}\sum_{s\in\Omega_s}r_s\)，\(\sigma_s^2=m^{-1}\sum(r_s-\mu_s)^2\)，\(PSR=(r_p-\mu_s)/\sigma_s\)。这里明确使用总体标准差；改样本标准差数值会变。正仿射响应变换保持 PSR，但主峰选取／支持也必须不变。统计量类似 z-score，旁瓣非独立正态且主峰经最大化选择，不能当标准正态 p 值。成本 \(O(P)\)。

**L5 复现设计。** 在原始完整有限响应上统计，维护主瓣排除 mask，记录有效数；零方差不要加极小数制造巨大可信值。每姿态统计和跨姿态统计需单独定义，当前实现没有统一跨姿态响应体。测试常量、全无效、边界峰、双峰、不同 ROI；未运行该扩展。

**五层面试答案。** L1 问“先排除什么？”答：主瓣而非所有竞争峰。L2 问“PSR 和 gap 一样？”答：统计集合不同。L3 问“可以照搬 MOSSE 阈值？”答：不可以。L4 问“PSR 是概率吗？”答：不是。L5 问“标准差零怎么办？”答：不可用／拒识，不造无穷置信。易错是“源码已经有 PSR”；证据为来源 24 及源码检索。

### 36. 三点抛物线平移亚像素精化

**任务／演进／状态：K。** 整数评分峰的轴向邻点 → 小数平移；低成本减少整数采样量化，代价是局部二次近似偏差。两个 NCC 入口共用该函数，不是 LK/ECC，也不精化角度尺度。

**L1 步骤。** 取峰两侧 f−、f0、f+ → 二次系数 → 顶点偏移 → 曲率幅值过小时取 0 → 限制到 ±0.5 → 分别计算 dy/dx → 更新坐标。姿态入口额外检查裁剪后的最多 3×3 邻域全部有限。

**L2 机制。** 峰附近平滑时二次插值给出采样间最大值；独立轴忽略 xy 耦合，多峰／平台不适用。邻域对角含 -inf 也会使新入口同时取消两轴精化；边缘只缺一轴邻点时该轴保整数，另一轴仍可能细化。

**L3 工程。** `abs(d)<1e-12` 的 d 是分数二阶差，`[-0.5,0.5]` 为像素偏移；裁剪是保护不是准确度证明。先看峰形、边界和姿态网格，再决定启用；分数峰拟合与图像插值不是同一件事。

**L4 推导。** 拟合 \(f(z)=az^2+bz+c\)，在 z=−1,0,1 有 \(a=(f_- -2f_0+f_+)/2,b=(f_+-f_-)/2\)，故顶点
\[
\delta=-b/(2a)=\frac{f_- -f_+}{2(f_- -2f_0+f_+)}.
\]
需 a<0 才是局部最大；若误差扰动改变小分母，顶点高敏感，无通用实际定位误差界。每峰常数算术。

**L5 源码／验证。** [parabolic_subpixel][code-ncc] 不检查 d<0，只检查幅值并裁剪；旧入口没有姿态入口的完整有限邻域保护。返回 `(dy,dx)`，最终 score 保持整数峰值不重算，排序和阈值不代表精化后的连续评分。现有小数平移、边缘和常量邻窗测试通过，未验证所有耦合峰形。

**五层面试答案。** L1 问“返回顺序？”答：dy、dx。L2 问“抛物线必为峰？”答：还需负曲率。L3 问“输出 0.01 px 就有此精度？”答：坐标分辨率不等于准确度。L4 问“公式从哪来？”答：二次顶点。L5 问“精化后 score 为何不变？”答：源码协议不重算。易错是“同时精化角度尺度”；证据为源码和推导。

### 37. 一对一评测分配、误差与计时

**任务／演进／状态：K。** 检出集合及真值 → 命中、漏检、误报、误差与耗时；由只报最好误差改成集合级验收，避免成功样本偏差。基准调用 `linear_sum_assignment`，这是评测组件，不是匹配器内部几何算法。[cite:27](#source-27)

**L1 步骤。** 每场景三个固定种子生成真值 → 每种子一次预热三次计时 → 取最后结果作检测统计 → 中心距离矩阵最小总和一对一分配 → 再用位置／角度／尺度阈值判命中 → 统计未命中真值和检出 → 汇总计时中位数。ambiguous 场景期望拒识，expected 故意置空。

**L2 机制。** 一对一避免同一检出重复命中多个真值，但只按中心距离分配后再角度／尺度门控，不必最大化最终合法命中数。多次同数组运行测计算重复性，不是重新采集的测量重复性；只统计已命中误差会有选择偏差，所以要同时看漏检／误报。

**L3 工程。** 基准命中门限是中心≤2 px、圆周角差≤7.5°、尺度绝对差≤0.1，均为测试协议而非工业精度。现场应按批次隔离数据，保留负例和困难例，记录硬件／库版本及尾延迟。吞吐量、中位时延与设备截止时间不可相互替代。

**L4 推导。** 分配目标 \(\min_X\sum C_{ij}X_{ij}\)，行列最多一次且分配数为较小集合容量。角差 \(|((\theta_p-\theta_g+180)\bmod360)-180|\)，位置 \(\|p-g\|_2\)。独立重采样 RMSE 为 \(\sqrt{\sum\|p_k-g_k\|^2/N}\)，重复坐标样本标准差分母 N−1；二者衡量不同量。一般稠密方阵分配常以三次量级讨论，库具体实现为修改 Jonker–Volgenant，不应统一写成原始 Hungarian 源码。

**L5 源码／验证。** [benchmark_pose_ncc.py][code-bench] 保存 9 次时延但仅 3 个检测场景结果，`off_grid` 故意保留粗采样失败。真值由 [test_pose_ncc.py][code-tests] 的独立矩阵和 SciPy `map_coordinates` 构造，不以被测 `_warp` 完全自证。此轮运行 37 单测和 8 冒烟，不重跑完整基准；不把历史输出作为本轮新结果。

**五层面试答案。** L1 问“9 次计时是 9 个独立样本？”答：不是。L2 问“误差小能说明检测好？”答：需同时看拒识与漏报。L3 问“现场要什么数据？”答：独立采集、批次隔离和困难负例。L4 问“先距离分配再门控最优吗？”答：不保证最大合法命中。L5 问“这个库就是 Hungarian 吗？”答：当前文档为修改 JV。易错是把门限当精度证书；证据为源码及来源 27。
