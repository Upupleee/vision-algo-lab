## 2. 先建立演进主线

核心维度是退化模型、先验、保真目标、恢复求解、下游影响和计算成本。工程线是“采集检查 → 传感器校正 → 必要去噪 → 可选增强 → 尽量一次重采样 → 原图配对下游验收”，不是把所有方法串起来。

| 节点／分支 | 前序瓶颈 → 改变维度 → 机制 | 新代价与遗留问题 |
|---|---|---|
| 暗平场／颜色校正，非单一年份发明 | 固定响应不一致 → 物理模型 → 偏置与增益校正 | 参考帧维护，饱和不可逆；与去噪并行 |
| 局部线性／秩滤波，基础分支 | 随机噪声 → 局部先验 → 平均或排序 | 边缘和窄缺陷损失 |
| 双边，ICCV 1998 | 跨边缘混合 → 值域相似性 → 联合空间／值域权重 | 噪声污染权重；非所有结构都保真 [cite:3](#p-src-3) |
| NLM，CVPR 2005 | 近邻信息不足 → 自相似 → 相似块平均 | 搜索贵、重复性依赖 [cite:4](#p-src-4) |
| BM3D，TIP 2007 | 只平均块不足 → 组内稀疏先验 → 变换域协同收缩 | 分组／聚合成本和许可 [cite:5](#p-src-5) |
| 引导，ECCV 2010／TPAMI 2013 | 大窗口保边代价 → 局部线性模型 → 盒式统计 | 引导错位与结构转移 [cite:6](#p-src-6) |
| Fast 引导，2015 技术报告 | 统计开销 → 分辨率 → 低分辨率求系数 | 近似偏差；不能省掉全分辨率输出 [cite:7](#p-src-7) |
| DnCNN，2016 预印本／TIP 2017 | 手工先验局限 → 监督残差学习 | 数据域、权重与部署成本 [cite:8](#p-src-8) |
| Noise2Noise，ICML 2018 | 干净目标难得 → 监督数据条件 → 噪声对训练 | 条件均值、对齐与有限数据限制 [cite:9](#p-src-9) |

DnCNN 是网络方案，Noise2Noise 是监督策略，可组合；增强、反卷积和重采样没有被它们替代。下列基础项未追溯单一首创年，不编造历史日期；软件文档 `4.x` 是滚动版本，不是仓库锁定版本。

## 3. 传感器校正

### P01 暗场校正

任务／前提／分支：同曝光、温度、增益的遮光帧与原图输入，输出去偏置浮点图和无效掩膜；采集校正分支。实现：无专用代码。来源：[cite:1](#p-src-1)。

- **L1 步骤**：采集遮光序列；剔除饱和及异常帧；按像素平均得到 D；对工作帧计算 I−D；保留负值和掩膜，完成一帧即停止。曝光配置不匹配时拒用校正集。
- **L2 机制**：遮光隔离偏置与暗电流；多帧平均降低参考随机噪声。不减 D 就会把加性偏置误当作信号或平场增益；它不能消除工作帧当次读出噪声。
- **L3 工程**：以重复暗帧均值漂移判断热稳定，以参考均值标准误确定帧数；先稳定温度／曝光，再增加帧数。输出负值不应立即截零，否则暗区均值上移；参考帧越多越费采集时间。
- **L4 数学**：I=gR+d+n，D 为 d 的无偏估计时，E[I−D]=gR。独立工作噪声和 M 个独立参考帧给出 Var(I−D)=σ²_I+σ²_D/M；参考相关或温漂时此式失效。离线 O(MN)，应用 O(N)，这是方差而非确定性误差界。
- **L5 数值实现**：逐帧 float64 累加或在线均值，先转浮点再相减；配置键包含相机、曝光、温度区间、增益、ROI。测试暗帧残差均值、重复性、uint16 下溢和配置拒绝；缓存 D 不改变算术含义，float32 替换须比对暗区差值。

面试追问链：L1 问“输出什么？”答“浮点去偏置图及有效性，不只有 uint8 图”；L2 问“为什么不能减单一常数？”答“像素／列偏置可能不同”；L3 问“热机后条纹？”答“先查参考温度，不盲增平滑”；L4 问“参考帧是否无噪声？”答“不是，独立平均只降低到 σ²/M”；L5 问“负数变大亮点？”答“检查无符号减法”。易错：把暗场校正称为完全去噪；证据为本项来源与方差推导。

### P02 平场校正

任务／前提／分支：原图 I、暗场 D、均匀亮场 F 输入，输出相对响应校正图；光路与曝光固定且未饱和。实现：无专用代码。来源：[cite:1](#p-src-1)。

- **L1 步骤**：均匀目标多帧平均 F；计算 G=F−D；筛掉小响应／饱和像素；在有效像素计算 m(I−D)/G；输出值与掩膜。m 可取有效 G 的均值，固定记录定义。
- **L2 机制**：暗场消加性项，除以 G 消空间乘性响应；m 恢复灰度量纲。直接 I/F 在暗区会错；亮场本身不均匀会被反向写入校正结果。
- **L3 工程**：最小 G 阈值来自参考噪声与允许放大倍数，不以机器 epsilon 充当坏点判据；先查平场均匀性、饱和与光路，后查帧数。曝光、光圈、焦距、ROI 变化要核对复用条件。
- **L4 数学**：F=gR_f+d、I=gR+d，忽略噪声得 (I−D)/(F−D)=R/R_f。固定 m 时 J_I=m/G，J_F=−m(I−D)/G²，J_D=m(I−F)/G²；小噪声协方差约为 JΣJᵀ，同一个 D 的相关性不能遗漏。G→0 时敏感度发散，无通用恢复界；应用 O(N)。
- **L5 数值实现**：先构造有效掩膜，再用有条件除法，不对失效像素加 epsilon 后宣称修复。缓存 gain=m/G 与 offset=−gain·D，采用 float32／64；将小分母、负值、参考错配、全视场均匀区和细边缘纳入测试。

面试：L1“先除还是先减？”答“先减暗场再除响应”；L2“平场能去阴影吗？”答“仅校正与参考一致的固定乘性项”；L3“角落噪声变大？”答“检查 G 与噪声放大”；L4“为什么不能只给 σ²/G²？”答“F、D 也有不确定度与相关项”；L5“怎么加速？”答“缓存有效增益和偏置，比较同一掩膜下结果”。易错：epsilon 修复坏点。

### P03 坏点表与坏点替换

任务／前提／分支：坏点位置表、原图及 CFA 排列输入，输出修复图与修复掩膜；异常应稀疏且邻域有可信样本。实现：无专用代码；来源为总览采集路线和局部秩滤波原理 [cite:2](#p-src-2)，检测阈值是工程设计，非厂商统一标准。

- **L1 步骤**：用暗／亮参考重复观察识别持续异常；生成版本化坐标表；仅在坏点位置取有效邻居中值；邻居不足则标无效而非递归传播修复值。一遍完成。
- **L2 机制**：固定表避免把偶发细缺陷当坏点；选择原始可信邻域避免修复链扩散。RAW Bayer 必须同色采样，跨色替换会造假色。
- **L3 工程**：先查持续性、连通簇大小、边缘位置，再选邻域半径；半径以像素计，必须小于需保留结构的尺度。整列失效不应按孤立坏点插值后用于计量。
- **L4 数学**：在坏点集合 B 外保持 q_i=I_i，在 B 内令 q_i=argmin_z Σ_{j∈V_i}|z−I_j|，解为有效邻居中值。隐含局部常值先验，阶跃两侧混杂时有偏；选取邻域样本不能辨识坏点真实纹理。直接排序 O(|B|k²log k)。
- **L5 数值实现**：坐标表存 `(x,y)`，访问用 `[y,x]`；从未修改的输入取邻域，返回 repaired 与 valid 两种掩膜。测试边缘坏点、连续坏点、CFA 相位及无有效邻居；稀疏索引优化只能改变遍历方式。

面试：L1“如何生成表？”答“重复暗亮帧确认持续异常”；L2“为什么不全图中值？”答“会改动正常细结构”；L3“整簇坏点怎么办？”答“拒绝计量或换设备”；L4“中值对应什么目标？”答“局部绝对偏差最小”；L5“修复结果能作真值？”答“不能，掩膜必须可追溯”。易错：修复等于观测恢复。

### P04 固定图样噪声：DSNU／PRNU

任务／前提／分支：多亮度级参考序列输入，估计像素／列的偏置与响应斜率；属于暗平场的细化，不是随机噪声滤波。实现：无专用代码；[cite:1](#p-src-1)。

- **L1 步骤**：各照度级重复采集、去掉饱和级；对每像素或每列拟合响应线；离线存斜率／截距；在线逆映射到统一响应，坏响应单独拒绝。
- **L2 机制**：DSNU 是暗响应不一致，PRNU 是光响应不一致；增加时间平均不会消掉稳定空间偏差。列校正开销小但不能表达列内像素差异。
- **L3 工程**：先固定曝光温度，再检查响应是否线性，最后选择列级或像素级；参考亮度覆盖工作范围而不饱和。平场纹理、光源闪烁会污染斜率，观察残差随亮度是否弯曲。
- **L4 数学**：I_{i,l}=a_i L_l+b_i+e_{i,l}，最小二乘解需至少两个不同 L 且设计矩阵满秩；校正 q_i=(I_i−b_i)a_ref/a_i+b_ref。未知绝对照度时只确定相对尺度。直接逐像素拟合 O(NM)，逆斜率放大噪声。
- **L5 数值实现**：用 QR／SVD 拟合而非显式求逆；亮度中心化改善条件数，掩膜失效斜率。测试跨照度残差、列频谱、参考集版本和温漂；硬件 FFC 与软件 FFC 不可不经确认重复叠加。

面试：L1“估哪些量？”答“偏置和相对增益”；L2“为何平均帧仍有条纹？”答“固定项不随帧抵消”；L3“列级够吗？”答“看列内残差”；L4“只拍一个亮度够吗？”答“偏置与斜率不能同时辨识”；L5“最常见重复校正？”答“相机已开 FFC，软件又套一遍”。易错：所有条纹都属于 PRNU。

## 4. 滤波与去噪

### P05 线性卷积与均值滤波

任务／前提／分支：图像、固定核和边界策略输入，输出同尺寸滤波图；局部平稳假设。实现：无统一模块；[cite:2](#p-src-2)。

- **L1 步骤**：定义核、锚点及边界；按邻域加权求和；需要保持 DC 时归一化核；所有有效像素计算后停止。
- **L2 机制**：平均降低独立噪声，归一化保常量；跨阶跃平均引起混合。删除边界策略会令同一图在不同库中边缘不一致。
- **L3 工程**：均值核宽度以 px 计，先由最小缺陷宽度限制上界，再用重复帧噪声选尺度；对比无处理与最小邻域起点，不给全场通用核宽。大核可用积分图，边界与整数舍入必须一致。
- **L4 数学**：q_i=Σ_j k_j I_{i−j}，Σk_j=1 保持常量；独立同方差噪声给 Var(q)=σ²Σk_j²，均匀 M 点核为 σ²/M。相关噪声应使用 kᵀΣk。直接 O(Nk²)，矩形盒式统计可 O(N)，不保证窄边缘位置不变。
- **L5 数值实现**：先用 float64 小图逐点结果作参考；OpenCV `filter2D` 实际按相关计算，非对称卷积核需翻转并处理锚点。测试常量、非对称脉冲、边界、核和及整型溢出；积分图用足够宽累加类型。

面试：L1“为什么声明锚点？”答“决定响应对应的位置”；L2“常量变暗？”答“查核和与零填充”；L3“大核怎么快？”答“矩形可积分图，不推广任意核”；L4“噪声是否都除 M？”答“仅独立均匀平均”；L5“卷积方向错？”答“查相关／卷积约定”。易错：平滑无几何代价。

### P06 高斯滤波

任务／前提／分支：灰度图和空间 σ_s 输入，输出低通图；局部线性分支。实现：`edge_subpixel.py` 的 `devernay_edges` 有 `GaussianBlur`；卡尺还有自身核，非统一配置。来源：[cite:2](#p-src-2)。

- **L1 步骤**：设 σ_s、核截断与边界；离散采样高斯并归一化；先行后列可分离滤波；完成一帧。σ_s 为零的旁路应显式定义，不能依赖库自动反推参数。
- **L2 机制**：距离越远权重越低，抑制高频噪声；与导数结合可稳定边缘，但宽 σ_s 会混合相邻边缘。对称核不意味着离散、非对称目标上永无偏移。
- **L3 工程**：先用缺陷／边缘间距给 σ_s 上限，再检查梯度信噪比与定位偏差；核截断与 σ_s 联动。OpenCV 与 SciPy 的边界默认不应视为完全相同。
- **L4 数学**：G(x,y)=c exp[−(x²+y²)/(2σ_s²)]=g(x)g(y)，因此二维卷积可分离，O(Nk²)→O(Nk)。连续频响 exp(−2π²σ_s²‖f‖²) 解释低通；离散截断后不是精确连续高斯。噪声方差沿用 P05，未提供通用边缘误差界。
- **L5 数值实现**：参考路径固定核系数、dtype、边界和坐标；检查现有卡尺 `np.convolve(...,mode='same')` 与演示中的 reflect 不是同一边界实现。测试常量、窄线、ROI 边缘和 σ_s 变化；分离优化比对完整有效支持，不能把演示当生产路径测试。

面试：L1“参数单位？”答“空间 σ_s 是像素，不是噪声灰度”；L2“为何能分离？”答“指数可拆为 x、y 两项”；L3“边缘偏了？”答“先核宽与相邻结构，再边界”；L4“频响为何压高频？”答“指数随 f² 衰减”；L5“两个高斯 API 不同？”答“核截断、边界、类型及默认 σ 都要固定”。易错：输出亚像素即物理精确。

### P07 中值滤波

任务／前提／分支：奇数邻域图像输入，输出局部中位数图；秩统计分支，适合稀疏脉冲。实现：无专用代码；[cite:2](#p-src-2)。

- **L1 步骤**：定义奇数窗口；收集边界扩展后的样本；排序或选秩；取中间值；每像素一次。无效值应排除并检查有效数。
- **L2 机制**：极端灰度只影响排序而非均值幅度；当脉冲占多数或细线本身为少数时，中值也会抹掉真实结构。
- **L3 工程**：先查脉冲密度和坏点持续性，再选最小可用窗口；核半径增大提高孤立点清除但损害角点。彩色逐通道中值可能构造原邻域不存在的颜色。
- **L4 数学**：最小化 Σ|z−I_j|，左右子梯度平衡得到中位数；它不是卷积，不能用频率响应解释全部行为。局部少于一半异常只给秩鲁棒性，不保证边缘精度；排序基线 O(Nk²log k)，固定整数范围直方图可更快。
- **L5 数值实现**：`medianBlur` 的输入类型支持随核尺寸而异，边界通常为复制；以实际版本文档为准。测试尖脉冲、单像素线、角点、边缘及 NaN；优化选秩应保留同一偶数有效数处理策略。

面试：L1“为什么奇数窗？”答“有明确中心秩”；L2“为何不怕极大脉冲？”答“排序不累积幅度”；L3“细线没了？”答“线在窗内为少数”；L4“对应什么损失？”答“L1 绝对偏差，不是平方差”；L5“浮点大核失败？”答“检查 API 类型／核限制”。易错：中值总能保边。

### P08 双边滤波

任务／前提／分支：图像、空间 σ_s 和值域 σ_r 输入，输出保边平滑图；1998 代表性局部分支。实现：未接入；[cite:2](#p-src-2) [cite:3](#p-src-3)。

- **L1 步骤**：枚举空间邻域；由位置与灰度差分别算权重；相乘、求归一化加权和；完成全图。灰度距离与颜色距离须分别定义。
- **L2 机制**：跨强边缘值域权重小，所以比纯高斯少混合；噪声同样进入权重，强噪声可能把同区样本排除。σ_r 很大时接近空间高斯，不再保边。
- **L3 工程**：σ_s 用 px，σ_r 用 DN 或归一化强度；先估噪声和目标对比度，再调 σ_r，最后调空间范围。σ_r 应允许同区噪声差异而排斥待保边缘，二者重叠时不存在完美参数。
- **L4 数学**：固定中心 i，w_ij=exp(−‖i−j‖²/2σ_s²−‖I_i−I_j‖²/2σ_r²)，q_i=Σw_ijI_j/Σw_ij。它是固定权重时 Σw_ij(z−I_j)² 的最小点，但 w 依赖观测，不能称全局凸恢复最优。直接 O(Nr²)，归一化保常量，无通用去噪界。
- **L5 数值实现**：中心自权重保分母正；先浮点做差防下溢，检查 RGB 距离和通道顺序。`bilateralFilter` 不可假设支持所有 dtype；查表近似须分别报告权重量化误差、边缘偏移与时间。

面试：L1“权重几部分？”答“空间与值域并归一化”；L2“强噪声为何难？”答“权重也被污染”；L3“255 改 1 后参数？”答“σ_r 同比缩放，σ_s 不变”；L4“是否全局最优？”答“只可解释固定权重局部平方目标”；L5“如何验优化？”答“同输入逐像素与下游对照”。易错：值域 σ 与空间 σ 混用。

### P09 非局部均值 NLM

任务／前提／分支：单幅图、块宽、搜索范围及 h 输入，输出自相似平均图；CVPR 2005／IPOL 2011 实现说明。实现：未接入；[cite:4](#p-src-4) [cite:3](#p-src-3)。

- **L1 步骤**：给参考像素取块；在搜索窗比较候选块；用块距离转权重；归一化后平均候选中心值或按指定块版聚合；固定搜索结束。不能混用像素版与块版输出定义。
- **L2 机制**：块比单像素更能区分结构，远处重复样本提供降噪信息；无重复结构时扩大窗未必有效。使用噪声修正距离可缓解噪声底，但依赖噪声模型。
- **L3 工程**：h 与灰度同量纲，块宽及搜索宽用 px；先校准 σ，再按重复结构尺度选块，最后扩大搜索并计时。h 太大纹理混合，太小残噪；边界复制可能增加虚假相似样本。
- **L4 数学**：d_ij=Σ_a g_a(I_{i+a}−I_{j+a})²，Σg_a=1；w_ij∝exp(−d_ij/h²)。独立、不同像素噪声的距离期望含 2σ²，可用 max(d−2σ²,0) 修正，重叠和相关情况需重估。直接 O(Ns²k²)；权重数据依赖，无通用无偏保证。
- **L5 数值实现**：可按位移计算差图，再盒式累计块差，避免物化所有块对；保持参考块、边界和自权重一致。OpenCV fast NLM 与原始加权块距离不能宣称逐位等价；测试重复纹理、孤立缺陷、搜索边界、归一化量纲。

面试：L1“非局部在哪里？”答“搜索相似块而非只近邻”；L2“为什么不用单灰度差？”答“区分结构能力不足”；L3“窗越大越好吗？”答“开销和误匹配也增”；L4“2σ² 从哪来？”答“两独立噪声差的方差相加”；L5“如何省内存？”答“位移差图累计，不建全像素对矩阵”。易错：任意噪声都可减 2σ²。

### P10 BM3D

任务／前提／分支：有噪灰度图及噪声模型／σ 输入，输出协同去噪图；TIP 2007 分组变换分支。实现：无依赖、权重或基准；外部作者包与 IPOL 实现许可不同。[cite:5](#p-src-5)

- **L1 步骤**：第一阶段在噪声图找相似块、堆成三维组、变换、硬阈值、逆变换、重叠聚合得到 basic；第二阶段在 basic 上重新分组，取相同位置的原噪声组，用 basic 系数计算维纳增益，过滤原噪声系数并聚合 final。两阶段完成即停。
- **L2 机制**：组内相似性增强稀疏性；聚合融合同一像素多估计；basic 改善第二次匹配与信号幅度估计。第二阶段不是再对 basic 去噪，否则观测信息被过度丢弃。
- **L3 工程**：σ 与图像幅度必须一致；块尺寸、最大组数、搜索步长是质量／速度控制。先核对 AWGN 假设、σ 与范围，再改分组；纹理塑料感、窄缺陷消失和分块接缝分别查收缩、匹配与聚合权重。
- **L4 数学**：正交变换且组固定时 y=Tg=s+η，Var η=σ²；硬阈值 y·1(|y|>λσ) 对小系数置零。固定信号系数 s 时最小化 E[(wy−s)²]=(w−1)²s²+w²σ² 得 w=s²/(s²+σ²)，实际用 basic 估计 s。q_i=Σ_g a_{g,i}\hat x_{g,i}/Σ_g a_{g,i}。数据依赖分组、重叠噪声相关和非正交变换会破坏简单方差假设；未提供全算法通用界。成本含块搜索 O(Rs²k²) 与每组变换／聚合，不能只报 FFT 成本。
- **L5 数值实现**：记录组成员位置与顺序，数组轴为组数×块高×块宽；固定变换归一化，分阶段保存 numerator／denominator，零覆盖点回退。测试变换往返、σ 单位、两阶段原图引用、聚合常量保持和步长边界；优化缓存块变换后逐阶段对照。作者软件限非营利教学科研；IPOL 标 GPL，工业分发仍须单独审查。

面试：L1“第二阶段滤谁？”答“basic 提供分组和增益，原噪声图提供被滤数据”；L2“为什么堆组？”答“增加相关冗余和稀疏性”；L3“σ 错十倍？”答“先修范围，不能用换块宽补救”；L4“维纳增益怎么来？”答“展开均方误差后对 w 求导”；L5“边缘接缝？”答“查覆盖和聚合分母”。易错：BM3D 等于三维平均。

### P11 引导滤波 Guided Filter

任务／前提／分支：引导图 I、待滤图 p、r、ε 输入，输出 q；两图坐标对齐；2010／2013 局部线性分支。实现：无本地代码，作者原理与 Fast 原文中的完整算法已核对。[cite:6](#p-src-6) [cite:7](#p-src-7)

- **L1 步骤**：求每窗 I、p 的均值及 I²、Ip 均值；得到方差／协方差；求 a、b；再平均重叠窗口的 a、b；q=āI+b̄。最后一步用原分辨率引导，一遍完成。
- **L2 机制**：局部输出随引导线性变化，边缘来自引导；ε 限制平坦区斜率；系数二次平均解决多个窗口输出不一致。去掉系数平均不是原引导算法，引导错边也会转移到输出。
- **L3 工程**：r 用 px，ε 用引导强度平方；归一化 I/a 后 ε 应除 a²。先查两图配准与可信度，再按引导噪声／平坦区方差设正则起点，后调窗口；无一组 ε 对所有引导保证保真。
- **L4 数学**：每窗最小化 Σ[(aI_i+b−p_i)²+εa²]，对 b 求导得 b=p̄−aμ；代入并对 a 求导得 a=cov(I,p)/(var(I)+ε)。最终对覆盖 i 的局部模型平均。彩色引导是 (Σ_I+εI_3)a=cov(I,p)，不是三个独立标量式。固定通道数、盒式统计下 O(N)，ε>0 保局部岭回归可解，不保证整幅真实图恢复。
- **L5 数值实现**：float64 参考计算二阶矩；大偏置小方差可先减全局常数，明显负方差须诊断而非盲加 ε；彩色用 Cholesky／求解器，不显式求逆。边缘窗口有效计数一致；测试常量 p、常量 I、不同量纲、错位引导和边界。OpenCV ximgproc 属额外模块，不能从 opencv-python 依赖推定存在。

面试：L1“要几轮均值统计？”答“输入统计和系数平滑两类”；L2“为何有 ε？”答“稳定低方差窗并限制斜率”；L3“255 归一化后？”答“ε 按平方缩放”；L4“推 a？”答“消 b 后解一维岭回归”；L5“彩色怎么解？”答“每窗三维协方差正则线性系统”。易错：把 ε 当无量纲除零常数。

### P12 Fast Guided Filter

任务／前提／分支：与 P11 同输入，新增空间下采样倍率 s≥1；系数图可低分辨率近似；2015 技术报告，不是 2010 会议论文。[cite:7](#p-src-7) 实现：未接入。

- **L1 步骤**：将 I、p 同步缩小；r′≈r/s 并固定取整规则；低分辨率计算 a、b 和均值；双线性上采样 ā、b̄ 到精确原尺寸；q=ā_up I_full+b̄_up。s=1 退回完整方案。
- **L2 机制**：假定慢变系数图可降采样，而高分辨率引导保留输出边缘。直接把 q_low 放大不是 Fast 引导；细结构若改变系数却被采样丢失仍会有偏。
- **L3 工程**：先验证完整引导基线，再逐级增 s，观察最小缺陷及边缘位移；r/s 太小或低分辨率窗样本太少时退回。s 无量纲，速度与误差应实际测量，不照搬作者可见性描述。
- **L4 数学**：近似 q_s−q=(ā_s−ā)I+(b̄_s−b̄)。若已知系数误差上限 e_a、e_b 及 |I|≤M，可得 |Δq|≤Me_a+e_b；这些上限本文未估，不可当已获精度保证。盒式统计 O(N/s²)，上采样与输出 O(N)，**整算法仍 O(N)**，原文正文明确区分。
- **L5 数值实现**：记录实际缩放后宽高而非只存 s；I 与 p 共用采样坐标、系数上采样一致；保持 ε 强度单位不随空间缩放变化。测试奇数尺寸、s=1、细线、边缘和整图／分块一致性；剖析须包含 resize 与最终乘加。

面试：L1“放大的是谁？”答“线性系数，不是最终低清图”；L2“为何用全尺寸 I？”答“以原引导调制输出”；L3“如何定 s？”答“在完整基线上用任务误差限选”；L4“整体 O(N/s²) 吗？”答“不是，输出 O(N)”；L5“奇数图为何错位？”答“实际尺寸、r′ 与半像素对齐不一致”。易错：快速版与完整版本严格等价。

## 5. 对比度与照明增强

### P13 线性拉伸

任务／前提／分支：灰度图及固定有效上下界输入，输出目标范围图；点运算增强。实现：无专用代码；总览灰度路线，映射数学为本文推导。

- **L1 步骤**：选有效 ROI 与上下界 a<b；计算归一化 (I−a)/(b−a)；按协议裁剪或保留越界；映射到输出范围。常量输入拒绝估界或旁路。
- **L2 机制**：扩展已有对比度，不增加信息；每帧自适应极值会令同一灰度随帧变动，破坏固定阈值。
- **L3 工程**：a、b 用 DN，可由冻结训练集分位数定；先查饱和与极端点，再调分位数。必须记录被裁掉的像素比例，不能以拉伸掩盖欠曝。
- **L4 数学**：q=αI+β，α=(u_max−u_min)/(b−a)；σ_q=|α|σ_I，信号和噪声同倍变化，未量化前 SNR 不凭空提高。b−a→0 时病态；应用 O(N)，分位数排序基线 O(Nlog N)。
- **L5 数值实现**：先 float，再减再乘，最后一次量化；整数 LUT 可加速固定映射。测试常量、反向边界、NaN、极端值及 LUT 单调性；冻结的 a、b 随模型发布。

面试：L1“常量图怎么办？”答“旁路或无效，不除零”；L2“为何噪声变明显？”答“噪声也被放大”；L3“跨帧阈值漂？”答“查逐帧极值”；L4“SNR 改善吗？”答“理想线性尺度不改善”；L5“为何输出回绕？”答“无符号减法／强转”。易错：拉满范围即恢复细节。

### P14 gamma 变换

任务／前提／分支：非负归一化图与 γ>0 输入，输出 q=I^γ；显示／增强分支，不把该定义与库中倒数 gamma 混淆。实现：无专用代码；总览 gamma 旁注与颜色 API [cite:10](#p-src-10)。

- **L1 步骤**：明确输入是否已编码；按固定黑白点归一化；幂映射；恢复输出范围；一遍完成。负数、NaN 按协议拒绝或另用有符号变换，后者不再是本定义。
- **L2 机制**：γ<1 抬暗区，γ>1 压暗；非线性重分配码值，不改变饱和丢失。重复编码会扭曲颜色和光度。
- **L3 工程**：γ 无量纲，先从 γ=1 旁路基线比较暗区噪声、缺陷召回再偏离；光度拟合需在线性域，不应对编码值直接假设泊松关系。
- **L4 数学**：q′=γI^(γ−1)，小噪声传播 Var(q)≈(q′)²Var(I)；γ<1 且 I→0 时斜率很大，近零线性近似也可能失效。它是可逆实值映射（I>0），量化和裁剪后不再可逆；O(N)。
- **L5 数值实现**：uint8 LUT／浮点 pow 二选一并声明插值精度；黑点单独处理。测试端点、γ=1、单调性和往返误差；不要把 sRGB 分段传递曲线当纯 γ 幂。

面试：L1“γ<1 的效果？”答“按本文定义抬暗”；L2“能救饱和吗？”答“不能”；L3“为何暗区粗糙？”答“局部导数放大噪声”；L4“噪声方差为何平方导数？”答“一阶泰勒传播”；L5“库结果反了？”答“核对 γ 或 1/γ 定义”。易错：所有颜色空间都是纯 gamma。

### P15 直方图均衡

任务／前提／分支：单通道离散图输入，输出全局单调 LUT 映射图；增强非恢复。实现：未接入；[cite:11](#p-src-11)。

- **L1 步骤**：统计有效区域直方图 h；累计 CDF；按输出级数构造 LUT；逐像素映射；常量图采用明确旁路。
- **L2 机制**：密集灰度段分配更多输出跨度，稀疏段压缩；不能创造原图没有的灰度排序信息。全图统计被背景主导时，小 ROI 未必改善。
- **L3 工程**：先选灰度／亮度通道与 ROI，再比较固定阈值可迁移性；逐 RGB 均衡可能改色。低噪声对比度提升和高噪声放大必须分别验收。
- **L4 数学**：连续情形 U=F_I(I) 在连续严格分布条件下服从均匀分布；离散 LUT 常用 round((L−1)(CDF−CDF_min)/(1−CDF_min))，平台与量化导致输出不严格均匀。常量时分母退化；O(N+L)。
- **L5 数值实现**：`equalizeHist` 面向单通道 8 位；高位深要单独定义 bins 和 LUT，不可默默截到 8 位。测试常量、双峰、空掩膜及 LUT 单调；均衡统计与应用 ROI 要一致。

面试：L1“用概率还是累计概率？”答“CDF”；L2“为何背景占比影响结果？”答“全局统计改变”；L3“颜色偏了？”答“查是否各通道独立均衡”；L4“离散输出必均匀？”答“否，有量化平台”；L5“16 位怎么办？”答“明确分箱实现而非直接套 8 位接口”。易错：均衡是去噪。

### P16 CLAHE

任务／前提／分支：灰度图、分块网格及裁剪限输入，输出局部对比度增强；实现：未接入。[cite:12](#p-src-12)

- **L1 步骤**：分块并扩展边界；每块统计直方图；裁剪过大计数并重新分配；生成每块 CDF LUT；插值相邻 LUT 后映射图像，完成即停。
- **L2 机制**：局部统计避免全局背景压制目标；限幅限制直方图峰值，块间插值减轻接缝。只裁剪不重分配会丢概率质量，取消插值会显块边。
- **L3 工程**：`tileGridSize` 是横纵块数而非块像素宽；块应容纳足够统计样本但能追踪照明变化。先控噪，再从弱限幅／大块基线调节；不同库 clipLimit 单位不可直接复制。
- **L4 数学**：h′_b=min(h_b,T)，剩余 E=Σ(h_b−T)_+ 重新分配并保证总计数；q_i=Σ_j α_ij LUT_j(I_i)，α≥0、Σα=1。它限制映射局部斜率的趋势，但重分配、量化和空间插值使 clipLimit 不是通用输出噪声界。成本 O(N+块数×bins)。
- **L5 数值实现**：检查 8U／16U 单通道支持，锁定实际 OpenCV 版本；图像尺寸不整除网格时验证补边。测试均匀噪声、分块边、细缺陷、常量与参数版本；不能从滚动文档新增 API 推断老版本可用。

面试：L1“裁掉的计数去哪？”答“重新分配”；L2“为何插值 LUT？”答“平滑块边映射”；L3“8×8 是 8px 吗？”答“不是，是块数”；L4“clipLimit 是否噪声上界？”答“不是”；L5“不同版本有差？”答“核对 bins、补边和参数换算”。易错：CLAHE 必然保边且去噪。

### P17 形态学背景估计

任务／前提／分支：图像、结构元素 B 与亮暗目标极性输入，输出背景及顶帽／黑帽残差；尺度分离分支。实现：无背景估计接口；[cite:2](#p-src-2)。

- **L1 步骤**：亮小目标用开运算估背景，暗小目标用闭运算；结构元素按目标形状和尺度选；输出背景后交 P18 减除，保持原图作对照。
- **L2 机制**：腐蚀后膨胀消掉不能容纳结构元素的亮结构；背景应比目标慢变。大目标或细长方向与元素不匹配会残留或被误作背景。
- **L3 工程**：结构元素尺寸用 px，需覆盖欲去除的前景尺度又小于背景变化尺度；先看形状与极性，再调大小。无可分离尺度时应换光学或参考背景。
- **L4 数学**：平坦对称 B 下 ε_B I(x)=min_{b∈B}I(x+b)，δ_B I(x)=max_{b∈B}I(x+b)；开为 δ_Bε_B，闭为 ε_Bδ_B；白顶帽 I−open(I)，黑帽 close(I)−I。非线性序关系不提供无偏背景保证；直接 O(N|B|)。
- **L5 数值实现**：固定元素形状、锚点、边界与迭代次数；先浮点差分保残差符号。矩形可分离加速但不能替代任意圆形元素；测试边框目标、细长目标、反极性及元素超过 ROI。

面试：L1“亮目标用开还是闭？”答“开估背景”；L2“为何元素要大于目标？”答“使目标不能完整容纳元素”；L3“大目标没检出？”答“尺度分离失败”；L4“顶帽公式？”答“I−open(I)”；L5“加速后变了？”答“检查元素形状与边界”。易错：形态学背景是线性低通。

### P18 背景减除

任务／前提／分支：图像 I、可信背景估计 B 输入，输出加性残差；选型表缓慢照明梯度子项。实现：无专用代码；工程来源为总览，B 可来自 P17／P06。

- **L1 步骤**：从空场或掩膜拟合获得 B；对齐并验证曝光；q=I−B；需要显示时加固定偏置，不逐帧重新居中；输出有效掩膜。
- **L2 机制**：适用于 I=S+B+n；若真实退化是乘性，减法不能统一不同背景处的目标相对幅度。背景含目标会产生自消除。
- **L3 工程**：先比较残差与背景强度相关性，判断加性／乘性；背景估计尺度必须大于目标且覆盖有效区。检查残差负瓣、ROI 边缘光晕，再改尺度，不能先截负值。
- **L4 数学**：B̂=B+e_B，则 q=S+n−e_B；偏差是 −E[e_B]，方差含 −2Cov(n,e_B)。由同一幅图估背景时不能假设独立。若 B̂=LI，q=(Id−L)I，是高通，会削弱低频目标；O(N) 应用。
- **L5 数值实现**：浮点有符号输出，记录背景来源、时间与滤波支持；测试空场、宽目标、背景错位和边界。缓存仅对静态背景成立，动态背景须重估并报告代价。

面试：L1“背景从哪来？”答“独立空场或明确估计器”；L2“为何宽缺陷消失？”答“进入了背景估计”；L3“先截负值吗？”答“否，先诊断”；L4“方差直接相加吗？”答“同源背景有协方差”；L5“缓存多久？”答“由曝光与场景稳定性验证”。易错：减背景等价平场。

### P19 背景除法

任务／前提／分支：正响应图与缓慢乘性背景输入，输出相对响应；不同于带独立参考的 P02。实现：无专用代码；总览背景补偿模型。

- **L1 步骤**：先暗场去偏置；估计正背景 B；筛选低信号区；计算 q=mI/B；输出比例与掩膜，一遍完成。
- **L2 机制**：I=L·R 时除 L 得相对反射响应；在加性背景下可能扭曲对比度。估计 B 过小会同时放大噪声和误差。
- **L3 工程**：B、阈值用 DN，m 定输出量纲；先核对加性偏置、背景尺度，再设最小信噪阈值。物体覆盖整图时 L 与 R 难分，应转独立参考。
- **L4 数学**：B=L(1+δ)，q/m=R/(1+δ)≈R(1−δ)，要求 |δ|≪1；J_I=m/B，J_B=−mI/B²。亮度与反射分解有乘性尺度歧义，不能从单图唯一辨识；无通用误差界，应用 O(N)。
- **L5 数值实现**：用 mask+条件除法，保留原响应和 background；拒绝全暗、饱和和无有效背景区。测试目标占比变化、阴影边缘与除零；平滑 B 的优化不能改变掩膜语义。

面试：L1“先做什么校正？”答“先减偏置”；L2“为什么不是 I−B？”答“乘性模型需要除法”；L3“暗区爆亮？”答“查背景分母与噪声底”；L4“单图能唯一拆 L、R？”答“不能，有尺度和结构歧义”；L5“加 epsilon 是否足够？”答“还需可信度掩膜”。易错：把所有阴影当固定平场。

### P20 同态滤波

任务／前提／分支：正强度图输入，输出低频照明受抑、高频反射增强的图；log 域照明分离方案。实现：无代码；总览具名路线，以下为明确参考设计而非已复现特定论文。

- **L1 步骤**：先去偏置并筛选正信号；取 log；频域乘平滑高通增益 H；逆变换；exp 恢复；做固定范围映射并输出无效掩膜。
- **L2 机制**：log 将乘积变加法，低频可近似照明；目标低频也会被抑制，高频噪声会放大。硬截止滤波易振铃，平滑过渡减少但不消除模型错误。
- **L3 工程**：截止频率用 cycles/pixel，增益无量纲；先检查正信号与边界，再调低频衰减，后调高频增益。暗区噪声占主导时优先改善曝光而非增强。
- **L4 数学**：I=LR>0，log I=log L+log R；若 log L 主要低频，H(0)<1 抑制其 DC／慢变项。加性噪声在 log 后约为 n/(LR)，因此低信号不再同方差。FFT O(Nlog N)，周期边界与尺度分离是额外假设，无通用恢复界。
- **L5 数值实现**：反射填充再裁回，明确 FFT 频率原点，取逆变换实部前检查虚部残差；exp 前查溢出。测试常量、缓慢梯度、边缘环纹及近零值；不能用无依据常数取 log 后称物理恢复。

面试：L1“为何先 log？”答“乘性转加性”；L2“为何有光晕？”答“频率分离和边界不理想”；L3“先调哪个量？”答“低频衰减且检查暗区”；L4“log 噪声还是高斯吗？”答“一般不是”；L5“图整体错相？”答“查 FFT shift 与核中心”。易错：任意照明都只占低频。

### P21 局部归一化

任务／前提／分支：图像、统计窗和噪声底输入，输出局部标准化图；低对比度选型旁注。实现：无通用图像算子；ZNCC 窗口评分不是此输出。来源为总览和 P05 统计基础。

- **L1 步骤**：估 μ、v；检查有效样本；q=(I−μ)/sqrt(v+ε)；记录局部置信度；一遍输出。
- **L2 机制**：去掉局部偏置并统一尺度，便于阈值比较；平坦区除小标准差会放大噪声，窗跨边缘会形成光晕。
- **L3 工程**：窗大小用 px，ε 用强度平方；先选目标与背景可分的统计尺度，再按噪声底设 ε。输出不再是原光度，不可直接用于反射率比较。
- **L4 数学**：固定支持下 I′=aI+b、a>0，若 ε=0 且 v>0，则标准化不变；固定 ε>0 时不严格尺度不变，需 ε′=a²ε。局部二阶矩 v=E[I²]−μ² 有消减误差；盒式统计 O(N)，未提供边缘偏差界。
- **L5 数值实现**：float64／中心化统计，检查显著负方差、无效区计数和边界；输出 q 与 confidence。测试加性偏置、缩放、常量、饱和及细线；不要与匹配 score 的 [-1,1] 范围混淆。

面试：L1“分母是什么？”答“局部标准差加正则”；L2“为什么常量区危险？”答“方差近零”；L3“ε 怎么定？”答“按强度平方和噪声底”；L4“是否严格增益不变？”答“固定 ε 时不严格”；L5“负方差如何处理？”答“先查消减与尺度，不只截零”。易错：标准化输出就是 ZNCC 分数。

## 6. 去模糊与锐化

### P22 维纳恢复

任务／前提／分支：模糊图、PSF、信号／噪声谱或正则输入，输出恢复图；已知退化分支。实现：无代码，外部 `wiener` 入口 [cite:3](#p-src-3)；统计维纳与 Wiener–Hunt 正则形式要区分。

- **L1 步骤**：确认 PSF 中心／归一化；构造卷积边界模型；FFT；每频点乘维纳增益；逆变换裁回；一遍结束。
- **L2 机制**：在模糊频响弱处抑制逆滤波噪声爆炸，以偏差换方差；不知道噪声谱而随意设常数不等于最优统计维纳。
- **L3 工程**：先验证 PSF 类型、长度（px）和方向（rad／度），再估谱比；过弱正则振铃、过强正则过平滑。频谱零点信息不可可靠恢复。
- **L4 数学**：Y=HX+N，零均值平稳 X、N 不相关时，最小化 E|WY−X|² 得 W=H* S_X/(|H|²S_X+S_N)。Wiener–Hunt 则来自 ‖Hx−y‖²+λ‖Lx‖²，解频域分母 |H|²+λ|L|²。FFT 对角化要求周期或明确嵌入边界；O(Nlog N)，无全场真实恢复上界。
- **L5 数值实现**：PSF 补零并把中心移到频域原点，检查复共轭和极小分母；float64 参考、避免在计算中截断。测试单位 PSF、非对称 PSF、DC 与边界；缓存 OTF 前绑定图像尺寸和边界。

面试：L1“需要哪些额外输入？”答“PSF 和噪声／正则信息”；L2“为什么不直接除 H？”答“零点附近放大噪声”；L3“振铃先查？”答“PSF、边界再正则”；L4“公式从哪来？”答“线性均方误差最小化”；L5“图像平移了？”答“PSF 中心错位”。易错：正则参数是任意 epsilon。

### P23 非盲反卷积

任务／前提／分支：已知 PSF 的恢复家族；此卡选择非负泊松观测下的 Richardson–Lucy 作为可执行数值方案，不能代表所有非盲方法。实现：无代码；[cite:3](#p-src-3)。

- **L1 步骤**：以正图初始化 x；计算预测 Hx；求观测／预测比值；用伴随 Hᵀ 回投影并乘性更新；达到相对变化、验证集最佳迭代或迭代上限时停，记录停止原因。
- **L2 机制**：按泊松似然调整非负强度；Hᵀ 将观测误差分配回来源。迭代过久会拟合噪声，非负并不保证没有振铃。
- **L3 工程**：迭代次数是隐式正则；先核 PSF 和噪声类型，再决定早停。泊松模型用光子／线性响应，gamma 编码图不能直接套相同统计模型。
- **L4 数学**：最小化 Σ[(Hx)_i−y_i log(Hx)_i]，乘性更新 x^{t+1}=x^t⊙Hᵀ[y/(Hx^t)]/(Hᵀ1)。归一化且通量守恒卷积时分母可为 1；边界裁剪时不能无条件省略。理想精确更新有似然改进性质，不是物理误差随迭代下降保证。每轮直接 O(Nk²) 或 FFT O(Nlog N)。
- **L5 数值实现**：显式实现 H 与伴随 Hᵀ，做内积伴随一致性测试；预测零且 y>0 要报告模型异常，不能只掩盖。测试单位 PSF、正性、边界通量、早停与不同初始化；分块须带足够 halo。

面试：L1“何时停？”答“预定早停／验证指标／上限”；L2“为何越来越锐却更差？”答“噪声被拟合”；L3“读出噪声强怎么办？”答“改似然模型或方法”；L4“为何除 Hᵀ1？”答“补偿一般观测算子的敏感度”；L5“最重要算子测试？”答“伴随内积一致性”。易错：RL 是任意噪声最优算法。

### P24 盲反卷积

任务／前提／分支：仅模糊图及受限 PSF 支持／先验输入，联合估 x、h；参考交替优化方案，不冒称仓库或指定论文复现。总览盲恢复旁注；P22、P23 为子问题依据。

- **L1 步骤**：限定核大小与非负归一化；多尺度初始化；固定 h 求 x，固定 x 求 h 并投影约束；观察目标与核变化；达到上限／停滞后输出候选及失败标记。
- **L2 机制**：额外先验限制图像与核的无穷分解；没有约束时 h=δ、x=y 是平凡解释。只加锐化不是估计 PSF。
- **L3 工程**：核支持用 px，正则权重随数据尺度定义；先依据曝光运动限制核长度，再考虑先验，最后多初值比较。大核自由度提高但可能吞掉结构；重复纹理和饱和常使解不可信。
- **L4 数学**：min_{x,h} ½‖h*x−y‖²+λR(x)+μS(h)，s.t. h≥0、Σh=1。归一化消除 x 与 h 的乘性尺度歧义但未消除平移、模糊分配等歧义。每块凸也不使联合问题凸；交替下降至驻点不保证全局真值。复杂度依赖迭代轮数与卷积实现，无通用恢复界。
- **L5 数值实现**：图像与核使用同一边界算子，核投影非负单纯形；记录所有初值与最佳候选判据。测试核和、核中心、数据项下降、不同初值稳定性和独立清晰参考；没有参考时不报 PSNR。

面试：L1“输出只要图吗？”答“还要 PSF 与诊断”；L2“为何需要先验？”答“盲分解不可唯一”；L3“核越大越好吗？”答“更易过拟合”；L4“交替收敛等于真解？”答“不等于”；L5“怎么发现伪解？”答“多初值、核约束和独立下游验证”。易错：未知 PSF 可以任意自恢复。

### P25 锐化与反差增强

任务／前提／分支：图像、低通尺度及强度 α 输入，输出高频增强图；失败模式中锐化旁注。实现：无专用代码；基于 P06 的反差遮罩参考方案。

- **L1 步骤**：算低通 B；提取 I−B；q=I+α(I−B)；保留浮点检查过冲，最终按显示协议量化；一遍结束。
- **L2 机制**：提高边缘邻域对比，不估计真实反卷积；噪声与小纹理同属高频，会一起增强。过冲可能被误判为缺陷。
- **L3 工程**：α 无量纲，低通 σ 用 px；从 α=0 基线逐步增加并限制下游假阳性。先查噪声，后定尺度，再定增益；不要先把过冲截掉掩盖失真。
- **L4 数学**：线性频响 W=1+α(1−G)，DC=1，高频近 1+α；噪声功率谱乘 |W|²。α≥0 时并无降低高频噪声的机制；O(Nk) 可分离实现，无通用定位误差保证。
- **L5 数值实现**：中间浮点有符号，统一边界；保存过冲比例和梯度位置。测试阶跃双边缘、窄线、噪声、饱和区；融合卷积与加法后与原数学算子对照。

面试：L1“锐化怎么做？”答“原图加高通残差”；L2“等于去模糊吗？”答“不是逆 PSF”；L3“伪缺陷多？”答“减 α 并查噪声”；L4“DC 为何不变？”答“G(0)=1”；L5“uint8 为什么危险？”答“残差负数和过冲提前丢失”。易错：越锐越可测。

## 7. 颜色处理子项

### P26 去马赛克

任务／前提／分支：RAW CFA 图及 Bayer 相位输入，输出多通道图；采集管线分支。实现：无 RAW 管线；[cite:10](#p-src-10)。

- **L1 步骤**：解包位深、确认 CFA 起点；先校正黑电平／坏点；保留已观测颜色，在各子格按同色邻居插值缺失通道；必要时方向自适应，输出颜色与有效边界。
- **L2 机制**：每像素只观测一个颜色，需要空间先验估另外两色；并非能从单点恢复真实光谱。高频彩色结构会假色和拉链。
- **L3 工程**：先核 Bayer 排列及 ROI 奇偶偏移，再调插值策略；边缘自适应可减少混色但计算更贵。测量若不需颜色，可评估原始单色子格，不能假定去马赛克无位置影响。
- **L4 数学**：观测 y=M_RR+M_GG+M_BB；一条观测对应三个未知通道，欠定。基线用权重和为 1 的同色线性插值，空间常值可重建，任意高频颜色不可辨识。固定核 O(N)，无普遍色彩恢复界。
- **L5 数值实现**：不要凭缩写猜 OpenCV Bayer 枚举，使用明确四字母模式并核对文档。测试红绿蓝已知色块、ROI 起点奇偶、12／16 位解包与边界；保留 RAW 用于复核。

面试：L1“额外必须知道什么？”答“CFA 相位与位深”；L2“为什么假色？”答“缺失颜色靠空间先验”；L3“裁一列颜色变了？”答“CFA 相位改变”；L4“能唯一恢复吗？”答“原始系统欠定”；L5“如何验通道？”答“已知单色目标和明确枚举”。易错：每像素 RAW 本来就有 RGB。

### P27 白平衡

任务／前提／分支：线性 RGB 和中性参考输入，输出中性校正图；对角增益校正。实现：无代码；总览白平衡路线与颜色量纲约定 [cite:10](#p-src-10)。

- **L1 步骤**：在不饱和灰参考区估各通道均值 μ_c；固定参考亮度 μ_ref；算 g_c=μ_ref/μ_c；对全图按通道乘增益；记录输出裁剪掩膜。
- **L2 机制**：以中性物体约束通道比例；灰世界替代法假定全场平均中性，单色场景违反此假设。白平衡不能修复传感器光谱失配。
- **L3 工程**：增益无量纲；先查参考反射中性、饱和与光源变化，再调增益约束。暗弱通道高增益同时放大噪声；不允许逐帧自动漂移破坏颜色检测阈值。
- **L4 数学**：q=D_g I，Σ_q=D_gΣ_ID_gᵀ；若各通道光源变化近似可用对角比例描述，中性可校正，但对所有光谱并无精确性保证。μ_c→0 不可辨识增益；O(N)。
- **L5 数值实现**：明确 RGB／BGR 排列和线性域；float 乘法后一次量化，存增益来源和光源。测试中性阶梯、彩色块、低信号和混合光源；定点实现检查系数量化与饱和。

面试：L1“怎么求增益？”答“中性参考通道均值比”；L2“灰世界何时错？”答“场景平均非中性”；L3“蓝通道噪声大？”答“检查该通道增益与曝光”；L4“为什么不够颜色标定？”答“对角模型不能表达通道混合”；L5“偏红偏蓝？”答“先查通道顺序”。易错：白平衡替代颜色矩阵。

### P28 颜色校正矩阵

任务／前提／分支：线性相机色块响应及同一白点下目标三刺激值输入，输出校正矩阵／颜色图；系统颜色校准。实现：无代码；总览颜色矩阵旁注，最小二乘为本文参考方案。

- **L1 步骤**：固定曝光／光源并采色卡；去偏置、白平衡；提取非饱和色块均值；拟合 3×3 矩阵 C；留出色块验证后逐像素应用。
- **L2 机制**：允许通道线性混合，比对角白平衡更灵活；仍不能完全解决同色异谱。若直接拟合 gamma 编码值，线性混色解释失效。
- **L3 工程**：先确认色卡参考光源、白点与线性域，再调正则；颜色样本需覆盖通道空间。矩阵可含负系数，不能强行非负而不说明模型改变。
- **L4 数学**：样本行矩阵 X，目标 Y，求 min_C‖XCᵀ−Y‖²+λ‖C‖²；λ=0 时需 rank(X)=3。QR／SVD 求解；加偏置需扩充常数列且与黑电平分工。O(M×3²)+O(9N)，未提供跨光源通用色差界。
- **L5 数值实现**：统一行样本与列像素约定，float64 拟合、float32 应用；记录 C、白点与传递函数。测试颜色基向量、留出色卡、负输出和裁剪；批次／光源变化重新验证。

面试：L1“训练数据是什么？”答“对应色块响应和目标三刺激值”；L2“为何不是三个增益？”答“需通道交叉混合”；L3“换光源还准吗？”答“须重新验证”；L4“什么时候解不唯一？”答“样本矩阵秩不足”；L5“矩阵乘反了？”答“用基向量测试方向”。易错：色卡拟合小误差等于所有物体准确。

### P29 颜色空间与灰度转换

任务／前提／分支：声明编码／通道／量纲的颜色图输入，输出灰度或指定颜色空间；表示变换分支。实现：`focus_measures.py::_gray` 有 BGR2GRAY，不是完整颜色管理。[cite:10](#p-src-10)

- **L1 步骤**：确认 BGR／RGB、整型位深与浮点范围；选择灰度、HSV、Lab 等明确目标；按库约定转换；同步更新元数据，一遍完成。
- **L2 机制**：灰度减维便于结构处理但丢失等亮异色差；HSV 适合色相表达但低饱和时色相不稳；Lab 依赖白点和编码，不是任意三通道输入都可比色差。
- **L3 工程**：先按下游所需信息选择空间，再看量纲；OpenCV 8 位 HSV 色相通常不是 0–360 数值范围，FULL 与普通模式不同。颜色缺陷不可只用灰度验收。
- **L4 数学**：常见 OpenCV 灰度 q=0.299R+0.587G+0.114B，是指定系数的通道混合，不自动成为物理辐亮度；映射由三维到一维不可逆。对固定线性混合 Var(q)=wᵀΣw；HSV／Lab 非线性需各自 Jacobian，O(N)。
- **L5 数值实现**：现有 `_gray` 会为 `cvtColor` 处理三通道 float64→float32，再转所需精度；不代表自动归一化范围正确。测试原色、黑白、中性、低饱和以及 uint8／float32 一致性；禁止未声明 BGR 直接喂 RGB 网络。

面试：L1“转换前查什么？”答“排列、编码、dtype 和范围”；L2“灰度为何漏缺陷？”答“颜色差可能被投影掉”；L3“HSV 阈值错一倍？”答“查 H 量纲”；L4“GRAY2BGR 能逆回来？”答“不能恢复丢失颜色”；L5“float64 报错？”答“查 API 支持深度”。易错：转类型等于转颜色空间。

## 8. 几何与重采样子项

### P30 裁剪与 ROI

任务／前提／分支：图像与整数 ROI 输入，输出子图和坐标偏移；几何整理。实现：匹配有 ROI 协议但无统一预处理对象。[cite:13](#p-src-13) 与 [现有坐标协议](../pose_ncc.md)。

- **L1 步骤**：定义 ROI 为半开区间；检查交集／空区域；切片；返回从 ROI 到整图的平移；不插值，完成即停。
- **L2 机制**：减少后续计算，不改变被保留像素；若仅返回图像不传坐标，所有后续定位都可能被误解释成整图坐标。
- **L3 工程**：ROI 用整数像素；先保证目标和滤波 halo 足够，再缩小范围。只裁到目标边会改变后续卷积边界与统计。
- **L4 数学**：p_full=T(x0,y0)p_roi；相机 K_roi=T(−x0,−y0)K。纯裁剪不产生插值误差，但会改变估计支持；视图创建可 O(1)，复制 O(N_ROI)。
- **L5 数值实现**：NumPy 切片可能为共享存储和非连续数组；明确是否允许后续原位操作。测试边界 ROI、空区、共享内存及四角回填；不能只给中心加偏移。

面试：L1“输出除图还有什么？”答“ROI→整图变换”；L2“为何滤波结果不同？”答“支持与边界变了”；L3“ROI 能多小？”答“留目标和滤波余量”；L4“主点怎么改？”答“减 ROI 原点”；L5“原图被改了？”答“切片共享内存”。易错：裁剪不影响任何后续算法。

### P31 缩放

任务／前提／分支：图像与目标尺寸输入，输出新网格及像素变换；金字塔／归一化分支。实现：匹配 `pose_ncc.py` 局部 resize；[cite:13](#p-src-13)。

- **L1 步骤**：定目标宽高；计算实际 sx、sy；缩小时选抗混叠；按逆映射插值；返回尺寸与变换。不要以名义倍率替代实际取整后比例。
- **L2 机制**：改变采样密度以降成本或适配网络；放大不能创造观测细节，缩小会丢信息。非统一比例使形状与圆度改变。
- **L3 工程**：先按最小结构采样要求选比例，后按质量选择插值；缩小不应默认双线性就足够抗混叠。高精度测量尽量回原图精化。
- **L4 数学**：常见半像素映射 x_src=(x_dst+½)/sx−½；相应前向 x_dst=sx x_src+(sx−1)/2。若采用此约定，K′=AK，主点包含平移项；另一些几何接口采用直接比例约定，必须匹配实际采样器。固定插值支持 O(N_out)，无任意信号重建保证。
- **L5 数值实现**：对奇数尺寸记录每层独立 A；同步图像、标签、角点和内参。测试常量、坐标斜坡、奇数大小、多层回填；不要用 `2**level` 代替实际映射而未验证。

面试：L1“如何定 sx？”答“目标宽／实际源宽”；L2“放大等于超分？”答“只是插值”；L3“缩小锯齿？”答“先查抗混叠”；L4“为何有半像素？”答“对齐像素面积中心”；L5“多层误差？”答“逐层组合真实 A”。易错：缩放后只改焦距不改主点。

### P32 旋转与统一几何重采样

任务／前提／分支：图像、前向变换及目标画布输入，输出采样图和支持；实现：`pose_ncc.py::_warp` 局部代码。[cite:13](#p-src-13)

- **L1 步骤**：定义旋转中心和角度；计算前向矩阵及画布；目标像素反投影到源；按指定插值取值；同步有效掩膜，完成目标网格。
- **L2 机制**：逆采样避免前向散点留下空洞；矩阵方向与内部采样方向不同但不矛盾。多次旋转缩放会累积模糊，应先组合矩阵再采一次。
- **L3 工程**：角度 API 可能用度，推导用弧度；图像 y 向下，正视觉逆时针矩阵与笛卡尔符号不同。先核画布／中心，再调插值；出界不应默默当有效黑色。
- **L4 数学**：A=s[[cosθ,sinθ],[−sinθ,cosθ]]，p′=A(p−c)+c+t；q(x′)=I_interp(H⁻¹x′)。H 可逆是必要条件；裁剪与离散化使像素值往返不等于恒等。固定支持 O(N_out)，画布与边界影响结果。
- **L5 数值实现**：现有 `_warp` 分别采 `template*mask` 和 mask，以支持值除回，并仅保留近完整支持；这是匹配策略，不可替代标签最近邻。测试单位、直角、任意角、掩膜边界；优化组合 H 后分别验证坐标与图像误差。

面试：L1“用前向还是逆向采样？”答“前向定义坐标、逆向填目标”；L2“为何一次采样？”答“减少离散损失”；L3“方向反了？”答“查 y 轴和度／弧度”；L4“矩阵往返对，图为何不对？”答“插值非可逆”；L5“黑边污染评分？”答“要有效支持掩膜”。易错：OpenCV 传矩阵与输出协议方向相反。

### P33 最近邻插值

任务／前提／分支：目标到源坐标和标签／图像输入，输出最近样本；离散类别优先。实现：无通用标签采样接口；[cite:13](#p-src-13)。

- **L1 步骤**：求源坐标；按固定最近规则选整数索引；检查边界；复制该值。半整数平局与负坐标策略必须显式。
- **L2 机制**：不混合类别 ID，保持标签集合；不保面积、连通性或小实例存在。连续强度可能锯齿。
- **L3 工程**：先区分标签与连续量；尺度很小时标签可能消失，必要时用面积占比投票而不是直接平均 ID，投票是另一个算法。
- **L4 数学**：q(x,y)=I(round x,round y)。最近点选择在内部网格把每轴距离限制为半像素，但这是采样点偏移，不是目标测量误差界；在不连续边界灰度误差可很大。O(N_out)。
- **L5 数值实现**：不假定 Python round 与库平局规则相同；检查标签 dtype，OpenCV 变换不支持某些整数深度时应使用安全映射而非丢精度转换。测试标签集合、单像素实例、边界和平局。

面试：L1“如何取值？”答“最近整数源样本”；L2“标签为何用它？”答“不产生混合 ID”；L3“能保面积吗？”答“不能”；L4“半像素界指什么？”答“选样坐标，不是物理边缘误差”；L5“库结果不同？”答“查 nearest 与 nearest_exact 及平局约定”。易错：标签最近邻保证拓扑。

### P34 双线性插值

任务／前提／分支：连续图与浮点采样点输入，输出四邻域混合；实现：匹配 warp 与卡尺 `_sample_points`；[cite:13](#p-src-13)。

- **L1 步骤**：先 floor 得左上格点；求 dx、dy；**先检查四邻居有效，再索引**；按四权重求和；输出值和支持状态。
- **L2 机制**：在 x、y 分别线性，常量和双线性曲面可局部精确复现；平滑但不是锐利高频恢复，也不适合直接混合类别编号。
- **L3 工程**：权重无量纲，坐标用 px；边界应选拒绝、复制或外推中的一种。下采样倍率大时仍需抗混叠；库中的定点权重表会带来微小差异。
- **L4 数学**：q=(1−dx)(1−dy)I00+dx(1−dy)I10+(1−dx)dyI01+dxdyI11，dx、dy∈[0,1] 时为凸组合，不会超过这四点极值；仅对光滑函数可讨论与二阶导数和网格间距有关的插值误差，阶跃不适用。O(N_out)。
- **L5 数值实现**：卡尺现代码虽先算 `ok`，却在掩膜生效前索引四邻居；越上界可能抛异常，不能当安全通用边界实现。本文只记录，不修改代码。新实现应先筛选再 gather；测试四角、负坐标、全无效、非连续数组及 float64 参考权重。

面试：L1“floor 还是强转整数？”答“floor，负数不同”；L2“为什么无过冲？”答“有效格内权重非负和为 1”；L3“仍有混叠？”答“四点插值不是充分低通”；L4“误差阶适用于哪里？”答“光滑函数，不是任意边缘”；L5“有 ok 为何还崩？”答“索引发生在掩膜之前”。易错：局部采样函数已覆盖所有边界。

### P35 双三次插值

任务／前提／分支：连续图与反投影坐标输入，输出 4×4 邻域三次核采样；实现：无通用接口，现有研究笔记有过冲风险记录。[cite:13](#p-src-13)

- **L1 步骤**：取周围四行四列；分别计算 x、y 三次核权重；可分离加权；按边界规则输出浮点，最后决定是否量化。
- **L2 机制**：较宽支持改善光滑变化表达，但负瓣会过冲，不能因更高阶就宣称边缘更准确。截断过冲还会改变梯度对称性。
- **L3 工程**：明确三次核参数 a 与库版本，不能把不同 cubic 实现混为一谈；先对边缘和细线比较线性基线，再决定是否用 cubic。测量优先验证位置而非观感。
- **L4 数学**：常用 Keys 核 |t|≤1 时 (a+2)|t|³−(a+3)|t|²+1，1<|t|<2 时 a|t|³−5a|t|²+8a|t|−4a，其余 0；二维用乘积。a<0 时存在负权重，凸组合界不成立；16 点支持 O(N_out)，具体逼近阶依赖核与函数光滑性。
- **L5 数值实现**：记录实际 cubic 参数，不以本文符号替代 OpenCV 内部版本；先 float 保过冲，测试脉冲、阶跃、边缘定位和输出范围。研究笔记的历史实验数字未在本文重跑，不推广成通用误差。

面试：L1“取多少邻居？”答“二维典型 16 个”；L2“为何过冲？”答“核有负瓣”；L3“计量优先什么？”答“边缘位移验证”；L4“能沿用双线性极值界？”答“不能”；L5“uint8 截断问题？”答“过冲被不对称裁剪可偏置梯度”。易错：高阶必然高精度。

### P36 面积重采样与抗混叠

任务／前提／分支：图像和缩小目标网格输入，输出像素面积平均；实现：匹配金字塔有 `INTER_AREA`。[cite:13](#p-src-13)

- **L1 步骤**：计算每个目标像素在源网格覆盖面积；按重叠面积加权平均；非整数缩放保留分数面积；生成输出并更新每层映射。
- **L2 机制**：目标像素应整合其覆盖区域而非抽一个点，减轻高频折叠；盒式面积滤波不是理想砖墙低通，仍可能有残余混叠。
- **L3 工程**：先按缩小倍率选低通带宽；下游存在周期细纹时检查频谱与漏检，不把 AREA 当万能保证。放大时面积接口可能退化为不同插值行为，需查具体版本。
- **L4 数学**：q_j=Σ_i a_ji I_i/Σ_i a_ji，a 为覆盖面积；常量保持且非负权重不越局部极值。下采样 s 倍的理想带限需低于原坐标 Nyquist 1/(2s)，盒核 sinc 频响不完全满足；直接面积枚举成本依赖覆盖，整数比例分块平均可 O(N_in)。
- **L5 数值实现**：使用真实宽高更新金字塔坐标；图和 mask 一起面积采样，但 mask 阈值改变支持必须保留策略。测试常量、斜坡、周期纹理和奇数尺寸；不能以插值等价推断检测等价。

面试：L1“权重来自哪里？”答“源目标像素覆盖面积”；L2“为何优于抽点？”答“先积分再降采样”；L3“还可能混叠？”答“盒核阻带不理想”；L4“频率上限？”答“缩小 s 倍后源坐标低于 1/(2s)”；L5“奇数层偏了？”答“查实际尺寸和坐标映射”。易错：AREA 是理想抗混叠。

### P37 畸变校正重采样

任务／前提／分支：原图、已标定投影模型及新内参输入，输出校正图和有效视场；实现：无相机标定／remap 管线。[cite:14](#p-src-14)

- **L1 步骤**：为每个目标像素用 K_new⁻¹ 得射线；按原模型施加畸变投到原图；构造 map；采样并返回有效 ROI。内参求解见标定卡片，不在这里伪造标定结果。
- **L2 机制**：向原图找供体实现去畸变，不是对每个原像素简单减偏移；新内参决定裁剪与视场。无效区域没有真实观测。
- **L3 工程**：先匹配针孔／鱼眼模型与图像尺寸，再选视场保留，最后选插值；测量角点可直接反投影，避免为少量点重采整图。
- **L4 数学**：map(p_new)=π_dist(K_old,D,K_new⁻¹p_new)，q(p_new)=I(map(p_new))；若加校正旋转还需相应逆旋转。模型可逆与有效视角是前提，矩阵坐标变换不能替代非线性畸变。预计算 O(N)，每帧 O(N)。
- **L5 数值实现**：缓存 map 时绑定 K、D、K_new、尺寸与 ROI；测试投影往返、四周有效性、直线残差和标签插值。校正图后续使用新 K 和零畸变，不再次套原 D。

面试：L1“map 指向哪？”答“校正目标像素→原图供体”；L2“为何黑边？”答“目标射线无原图覆盖”；L3“少量点怎么做？”答“直接校正点”；L4“能用一个 H 去任意畸变？”答“通常不能”；L5“重复校正如何发现？”答“跟踪坐标域及 K、D 版本”。易错：去畸变后坐标仍属于原图。

## 9. ML／DL 与选择策略

### P38 ML 参数选择、质量分类与旁路

任务／前提／分支：噪声、对比度、频谱、清晰度特征输入，输出已批准算子／参数／旁路；不是恢复器本身。实现：无对应训练工程；总览 ML 路线，以下为决策参考方案。

- **L1 步骤**：离线为冻结候选管线采集下游效果和耗时；按设备／批次划分；拟合参数回归或状态分类；在线提特征、判域外、选批准动作；不可信时旁路或拒绝。
- **L2 机制**：学习有限状态与配置的关系；模型仅看到特征，无法恢复未观测状态。旁路是合法动作，不应强制每帧增强。
- **L3 工程**：特征标准化由训练集固定，参数输出受白名单及范围限制；先看跨设备失效和代价，再改模型复杂度。准确率不代表错误动作风险低。
- **L4 数学**：策略 a(z)=argmin_a E[C(a,Y)|z]，C 包含漏检、误报、几何偏差与耗时；监督标签可取独立数据上最优可行动作。有限候选不保证连续最优；域外条件期望未知。线性策略 O(dA)，计算图像特征本身可能 O(N)。
- **L5 数值实现**：保存 scaler、特征顺序、策略版本、候选参数和回退；禁止模型直接输出未约束核／除零值。测试缺失特征、域外曝光、异常值、同批泄漏和最坏延迟；不把匹配 ML 示例声称为预处理策略实现。

面试：L1“模型输出什么？”答“批准动作而非一定输出图”；L2“为何保留旁路？”答“增强可能伤害任务”；L3“分类率高仍漏检？”答“损失与风险不一致”；L4“目标函数是什么？”答“条件期望任务代价最小”；L5“怎样发布？”答“连同特征、范围及回退版本化”。易错：学到参数可跳过下游验收。

### P39 DnCNN

任务／前提／分支：训练阶段噪声图 y 与干净图 x；推理输入 y，输出 y−Rθ(y)。监督残差网络分支，2016 预印本／2017 期刊；不同噪声设定是不同训练版本。实现：无权重或训练代码。[cite:8](#p-src-8)

- **L1 步骤**：建立配准训练对及固定归一化；网络前段卷积／ReLU、中间卷积／BN／ReLU、末端回归噪声残差；训练最小化残差误差并按留出集早停；推理一次前向再相减。
- **L2 机制**：学习噪声残差而非直接记干净图可利用残差分布，BN 稳定训练统计；不意味着任何真实噪声都与训练一致。移除残差相减会把噪声预测误当恢复图。
- **L3 工程**：噪声 σ 与输入范围一致；先确认固定噪声／盲高斯／多任务模型版本，再查真实相机域差，后调网络。统计更新、块尺寸和批量影响训练；现场无干净真值时不能伪报 PSNR。
- **L4 数学**：minθ (1/2M)Σ‖Rθ(y_i)−(y_i−x_i)‖²，固定输入时等价最小化 ‖(y−Rθ(y))−x‖²。平方损失总体最优为条件均值而非每幅真值；非凸训练无全局保证。卷积推理成本约 Σ_l NH_l?：更准确逐层为 Σ_l H_lW_l k_l² C_in,l C_out,l，内存取决于特征图。
- **L5 数值实现**：NCHW、float32、通道数及边界与训练一致；推理 `eval` 固定 BN 并关闭梯度；分块需感受野 halo，中央区拼接。验收残差符号、BN 状态、强度尺度、整图／分块、缺陷保留和设备迁移；量化／半精度必须独立复验。

面试：L1“输出如何得到？”答“输入减预测噪声”；L2“BN 推理为何不同？”答“用训练移动统计”；L3“真实噪声差？”答“先查域和训练设定”；L4“残差损失等价什么？”答“恢复图 MSE”；L5“拼块接缝？”答“边界填充与感受野不一致”。易错：盲高斯去噪等于任意未知退化恢复。

### P40 Noise2Noise

任务／前提／分支：同一潜在场景 x 的噪声观测对 y1、y2 训练，推理一张图；改变监督条件而非规定网络结构。实现：无采集协议／训练工程。[cite:9](#p-src-9)

- **L1 步骤**：采独立重复观测、控制对齐曝光与固定图样；同一潜在场景成对；按场景而非裁块随机划分；用平方损失 fθ(y1)→y2 训练，留出早停；推理一次网络。
- **L2 机制**：目标含不可预测的零条件均值噪声时，平均目标仍对应干净目标的条件均值；相关帧噪声或固定图样可被预测并保留下来。空间相关噪声不必自动使理论失效，关键是目标相对于输入的条件均值。
- **L3 工程**：先用重复观测检查配准、闪烁、饱和与跨帧相关，再选网络；运动和曝光漂移会改变潜在目标。目标噪声使训练 loss 有噪声底，不能简单与干净监督 loss 数值比较。
- **L4 数学**：令 y2=x+n2，若 E[n2|y1]=0 且相关二阶矩有限，E[y2|y1]=E[x|y1]；平方损失最优 f*=E[y2|y1]，与干净目标最优一致。更强充分条件是给定 x 时目标噪声零均值并与输入噪声条件独立。它不是保证 f(y1)=x；L1 损失对应条件中位数，不能直接沿用均值结论。训练非凸且有限样本无同等实测保证，推理复杂度由所选网络决定。
- **L5 数值实现**：数据记录 latent_id、拍摄状态、配对 ID；对几何变换保持两帧一致，不能把同一张图复制为两份当独立噪声。测试配对泄漏、错位、共用固定图样、目标均值和独立下游真值；保存原噪声对，不声称仓库 DnCNN 已可直接改训练。

面试：L1“需要干净图吗？”答“训练可不需要，但仍需合格噪声对”；L2“为什么不是任意两张？”答“同一潜在信号和正确条件统计”；L3“训练残差下不去？”答“目标噪声底可能正常”；L4“推导关键一句？”答“E[y2|y1]=E[x|y1]”；L5“同帧两次裁剪行吗？”答“不构成独立目标噪声”。易错：只要噪声全局均值为零就够。

### P41 DL 去模糊

任务／前提／分支：模糊／清晰对训练，模糊图推理；总览 DL 路线未指定网络。实现：**参考残差 CNN 方案，未实现、未训练、未验证**；监督原理参照 [cite:8](#p-src-8)，不能声称其去噪权重已支持本任务。

- **L1 步骤**：记录真实曝光运动／PSF 分布；配准清晰对；训练 x̂=y+Fθ(y)；冻结权重后单次推理，域外或不可信曝光回退原图。
- **L2 机制**：网络用训练图像先验补偿模糊频段；PSF 零点仍有多解，网络会选先验解释，可能生成双边缘。
- **L3 工程**：先验收真实模糊类型与标签对齐，再选感受野；曝光路径超出训练支持时拒绝。损失先包含像素保真，再评估边缘项，不以观感替代下游误差。
- **L4 数学**：y=Hx+n，min E‖y+Fθ(y)−x‖²；总体最优是 E[x|y]，不等于唯一物理逆解。空间变 PSF 不符合单个卷积 H，模型应在数据中体现；无通用恢复界，复杂度按各层卷积计算。
- **L5 数值实现**：沿用明确 NCHW／范围／残差符号；训练按设备和序列隔离，整图或 halo 分块推理。测试静态、运动方向、饱和、PSF 越界和假边缘；基线必须含不处理与已知 PSF 恢复。

面试：L1“训练对怎么组织？”答“同场景清晰／模糊且对齐”；L2“为何会假边缘？”答“逆问题多解靠先验”；L3“先扩大网络吗？”答“先查退化覆盖”；L4“MSE 学到什么？”答“条件均值”；L5“验证重点？”答“真实边缘位置和假缺陷，不只 PSNR”。易错：去噪网络天然去模糊。

### P42 DL 超分辨率

任务／前提／分支：低／高分辨率对训练，输出高密度图；与 P31 插值不同。实现：无代码和权重；总览 DL 路线及 Noise2Noise 原文对超分多解的讨论 [cite:9](#p-src-9)。

- **L1 步骤**：定义倍率与下采样退化；对齐 LR／HR；训练预测 HR 或高分辨率残差；固定倍率推理并传出 LR→HR 坐标关系；尺寸不符即拒绝。
- **L2 机制**：学习条件先验补细节，不增加相机实际观测信息；MSE 可平均多个解释而模糊，生成损失可能清晰但不真实。
- **L3 工程**：先核真实下采样、噪声、压缩与训练退化一致性，再选倍率和损失；增加像素数不能降低物理测量不确定度承诺。
- **L4 数学**：y=DHx+n，DH 有零空间时 x 与 x+z 可给同一 y，故不可唯一恢复。min E‖fθ(y)−x‖² 的解为条件均值；数据一致性 ‖DHfθ(y)−y‖ 只约束可观测部分。输出内存随倍率平方增长，无通用真细节界。
- **L5 数值实现**：记录倍率、像素中心、训练 crop 对齐与通道；pixel shuffle／上采样层需验证输出排列。测试细周期纹理、文字笔画、最小缺陷及回投影；原图始终是判定证据，不用 SR 图构造自身真值。

面试：L1“输出尺寸由谁定？”答“训练／部署倍率”；L2“细节都是真的吗？”答“零空间由先验补”；L3“能提升毫米精度吗？”答“需独立量具验证”；L4“多解怎么证明？”答“DH 存在非零零空间”；L5“棋盘伪影查什么？”答“上采样排列和训练退化”。易错：像素翻倍等于分辨能力翻倍。

### P43 DL 低照度增强

任务／前提／分支：低照度图及配对正常曝光／任务标签训练；输出增强图。实现：无具体网络，以下为参考增益图＋残差方案；总览路线、P01／P02／P14 的成像条件与 [cite:9](#p-src-9) 噪声监督限制。

- **L1 步骤**：采曝光对并按线性曝光比例归一；对齐、掩膜运动／饱和；学习受限增益图和残差；单次推理后输出有效性与原图，过暗拒绝。
- **L2 机制**：空间增益调整亮度、残差处理噪声；光子未到达或黑电平截断的信息不能恢复。只最小化“更亮”会放大噪声。
- **L3 工程**：先校准黑电平和曝光，再设增益上限，后评估损失；增益无量纲，阈值用线性信号／噪声单位。必须按温度、曝光、暗缺陷分层验收。
- **L4 数学**：计数模型 y∼Poisson(tx) 加读出噪声；简单曝光补偿 y/t 的方差约 x/t+σ_r²/t²，解释低曝光放大代价。网络 q=gθ(y)y+rθ(y) 可表达校正，但分解非唯一；没有通用暗区真值界，成本由网络与输出分辨率决定。
- **L5 数值实现**：记录 RAW／sRGB 域与曝光元数据，增益正值约束并设上限，保留饱和掩膜；测试全黑、热像素、暗色缺陷、曝光外推和闪烁。不能用同一网络输出作正常曝光标签。

面试：L1“需要曝光信息吗？”答“配对／标定时必须一致处理”；L2“全黑能恢复？”答“无可靠观测不能承诺”；L3“先调亮度损失？”答“先校准噪声和黑电平”；L4“短曝光为何方差大？”答“归一化把噪声除以 t”；L5“发布保存什么？”答“域、曝光范围、增益限制和掩膜”。易错：低照度增强只是 gamma。

### P44 DL 颜色恢复与生成模型

任务／前提／分支：退化颜色图和参考／条件输入，输出颜色恢复图或多个可能解释；总览卷积、残差、生成模型均是家族称谓而非指定单算法。实现：无专用代码；监督原理 [cite:8](#p-src-8) [cite:9](#p-src-9)，以下为本文明确方案。

- **L1 步骤**：先定义恢复色偏还是缺失颜色；固定线性域／白点；配对监督训练确定性残差映射；若采用生成模型，另定义条件分布与采样停止步数，并保留多个候选和随机种子。
- **L2 机制**：卷积局部先验与残差连接改善映射表达；生成先验选取“像真实图”的输出，不保证对应实际颜色。灰度着色多解，不能冒充颜色校准。
- **L3 工程**：先评估物理白平衡／颜色矩阵基线，再判断是否确需学习非线性；生成结果不能作为缺陷判定唯一依据。感知权重、采样次数增加会改变真实性／耗时权衡。
- **L4 数学**：确定性方案 min E‖fθ(y)−x‖²；若加入分布匹配项 λD(p_generated,p_reference)，分布接近不推出逐样本 x̂=x。缺失颜色的观测算子非单射，颜色不可唯一辨识；生成采样成本还乘步骤数，无通用计量误差界。
- **L5 数值实现**：训练与推理保持白点、通道、传递函数和量纲；权重 hash、训练集版本及随机种子可追溯。测试中性色、特殊材质、混合光源、灰度多解、重复推理稳定性；量化前后报告独立色卡和缺陷误判，不以逼真度替代真实性。

面试：L1“输出一定唯一吗？”答“生成方案可能多候选”；L2“逼真等于真实？”答“分布逼真不保证个体对应”；L3“先上网络吗？”答“先做物理校准基线”；L4“分布损失能保证色差吗？”答“不能”；L5“怎么追溯？”答“权重、颜色域、数据与种子一起记录”。易错：生成式颜色恢复可当量具。

## 10. 选型回接、来源与验收

| 现有资料的症状／旁注 | 对应独立卡片 | 必须同时验收 |
|---|---|---|
| 固定亮度不均、暗角、固定图样 | P01–P04 | 暗亮残差、坏响应、温漂、空间一致性 |
| 椒盐、坏点、高斯噪声、保边／自相似 | P03、P05–P12 | 细线／角点位置、最小缺陷召回与耗时 |
| 缓慢照明梯度、背景减除／除法 | P17–P20 | 目标幅度保持、宽目标和边界光晕 |
| 局部低对比度、归一化、gamma | P13–P16、P21 | 原图配对误报／漏检，灰度可比性 |
| 已知／未知模糊、锐化 | P22–P25、P41 | PSF 可辨识性、振铃、假边缘、误差 |
| 传感器颜色链 | P26–P29、P44 | CFA 相位、颜色域、独立色卡、特殊材质 |
| 裁剪、缩放、旋转、标签、畸变 | P30–P37 | 坐标域、半像素、支持掩膜、频谱损失 |
| ML、DnCNN、Noise2Noise、复杂恢复 | P38–P44 | 设备／场景留出、域外拒绝、权重追溯 |

PSNR、SSIM、MSE、MAE、SNR 是评价量而非新的预处理算法；不计入 P01–P44。没有干净真值不报全参考 PSNR／SSIM；重复帧只能估特定随机分量。数据应来自真实冻结采集集，本次未产生任何实验数据。验收要配对比较原图与处理图，包含位置偏差、最小缺陷召回／假阳性、最坏延迟和内存。参数范围从工艺公差与有效数据得出，而不是从本文建议直接获得工业批准。
