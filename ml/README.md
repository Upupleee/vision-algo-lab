# 机器学习路线（ml/）

手工特征 + 浅层学习器。与 `traditional/` 的区别：引入从数据中学到的参数；
与 `dl/` 的区别：特征仍是人工设计的，模型为浅层结构（SVM/RF/GBDT 等）。

| 文件 | 方向 | 思路 |
|------|------|------|
| `hog_svm_matching.py` | 模板匹配候选验证示例 | NCC 粗定位 → HOG 特征 → SVM 概率评分与候选重排序 |

当前 `verify_candidates` 对尺寸合法的候选评分排序，没有按分类阈值剔除误匹配，也不重新估计坐标；每次调用均生成合成正负样本并训练模型。模型概率未经独立现场数据校准，不能直接解释为产线正确率。前端没有产生正确候选时，后端重排序不能找回缺失位置。

输入候选的 `x/y` 按轴对齐模板窗口左上角解释，四舍五入后裁取原模板大小的图块；返回仍保留原候选坐标。不能直接把旋转／尺度接口的原点当作同尺寸裁框使用。`seed` 只传入合成训练样本生成器；当前 `SVC(probability=True)` 未设置 `random_state`，因此固定该 seed 不保证概率评分和重排序完全复现。准确度与重复性须分别评测，不能因坐标原样保留就宣称定位精度提升。

匹配与拒识基础见 [核心理论与现场排障](../docs/pose_ncc.md)。模型持久化、独立训练／推理、困难负样本和拒识阈值验证仍待补充。

## 研究约定

- 训练/测试数据划分固定随机种子；样本不要泄漏时序信息。
- 与传统路线对比时使用 `tests/metrics.py` 中的同一套指标。
- 记录：特征维度、训练样本量、训练耗时、推理耗时/帧、与传统基线的对比。
